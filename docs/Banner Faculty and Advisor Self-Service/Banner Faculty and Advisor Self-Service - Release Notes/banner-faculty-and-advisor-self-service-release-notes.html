Application Review Centre (ARC) Self Service changes

A new Document section has been introduced in ARC. When the Fetch Documents button is selected, documents associated with the Personal ID are retrieved, and their metadata, such as Document ID, Document Name, Document Type, and Document Category, is displayed in Self-Service. Selecting the hyperlink in the Document ID field opens the corresponding document in the browser or initiates a file download.

This enhancement addresses PE0006670 in the Ellucian Customer Center.

Update to the SWF Faculty Standard Workload Form (SVAFSWF)

Ellucian has updated the SWF Admin Page Faculty Standard Workload Form (SVAFSWF) to align to the collective agreement. The label was Complementary Hrs Allowance (Min 6) and is now changed to Complementary Hrs Allowance (Min 7).

This enhancement addresses PE0008441 in the Ellucian Customer Center.

Grails 7.1.0 Framework Upgrade

This release upgrades the underlying application framework from Grails 6.2.3 to Grails 7.1.0. This major framework upgrade modernizes the technology stack to Jakarta EE 10, Spring Boot 3.5.14, Groovy 4.0.31, and Tomcat 10.1.x. There are no changes to application functionality or user-facing behavior. Existing configurations remain compatible and no database changes are required. JDK 17 continues to be the minimum supported version. Customers who have developed extensions or customizations must update their code to replace javax.* imports with jakarta.* equivalents, update CAS client imports from org.jasig.cas.client.* to org.apereo.cas.client.*, and align with the updated framework versions.

Refer to the Install Guide for the updated technology stack requirements and Grails 7.1.0 Migration Guide in Banner Self Service Developer Documentation.zip in Banner Self-Service - Get Started for detailed code change instructions.

This enhancement addresses PE0008352 in the Ellucian Customer Center.

California Community College attendance tracking enhancement

Banner Faculty and Advisor Self-Service 9.32 includes enhanced attendance tracking for California Community Colleges. When the GTVSDAX ATTENDHRS setting is configured to M (Maximum), the system enforces attendance hour caps based on course data in SSBSECT and SSRMEET tables when the attendance totals are transferred into Grade Entry. This is the activity that updates the SFRSTCR_ATTEND_HR field. Instructors should continue to enter the actual attendance in Attendance Tracking. This enhancement ensures institutions can comply with California regulations that limit maximum attendance hours for specific course types and funding scenarios.

This enhancement addresses PE0007640 in the Ellucian Customer Center.

This expansion provides space for more comprehensive contact information across 18 pages in Banner Student Self-Service and Banner Faculty and Advisor Self-Service. Banner 9 Self-Service menu migration

With end of life for Banner 8 in September 2025, Ellucian is transitioning from the Banner Web Tailor TW% tables to the new GU% tables. The Banner Faculty and Advisor Self-Service application has delivered seed data to migrate all the Baseline records from Banner Web Tailor TW% tables to the new GU% tables.

You can copy the delivered Baseline records to create local records and customize them using the two new Banner Administrative pages, GUAWMNU for Self-Service Menu Maintenance and GUAWROL for assigning or modifying user roles in the Banner Self-Service application pages. You must copy the existing Local records from the TW% tables manually. Ellucian recommends using the GUAWMNU and GUAWROL administrative pages.

The seed data for Ellucian-supported languages is also delivered for the Baseline menu items.

See Banner 9 menu in the Banner Self-Service Common Features Use content for information about the new Banner 9 menu configurations.

See the following information in the Banner General Use content for more details about using the Banner Administrative pages to manage and customize menu settings.
  • Manage Self-Service menus on GUAWMNU
  • Maintain Self-Service user roles on GUAWROL
  • Add custom roles to Banner 9 Self-Service

For more information about the new Banner 9 menus including Banner Faculty and Advisor Self-Service specific updates delivered with this release, see Banner Faculty Self-Service menu updates.

Release 9.27.1

Banner Faculty and Advisor Self-Service 9.27.1 includes quality improvements and updates to support California's AB1111 Common Course Number Legislation.

Display Course Alias Regulatory Compliance (AB1111) support

To comply with the Common Course Numbering System (AB1111) regulatory compliance in California, Banner Faculty Self-Service displays a Course Alias field based on the system configuration.

Students can view the Course or Course Alias values based on the settings that are configured by Administrators in Banner Faculty Self-Service.

The following pages are enhanced to support the AB1111 changes:

Faculty Grade Entry Student Academic Review Faculty Attendance Tracking Attendance Tracking Page 
Office hours Faculty Detail schedule Assignments active assignments Syllabus Information
Student Week At A Glance Faculty Feedback Roster Faculty Feedback session Faculty Assignment → History
Faculty Week at A glance Registration override Student Schedule by Centric Period Registration History

Display Course Alias:

  • If the Course Alias is enabled (Display Course Alias) on the Course Alias Usage Rules (SCACARL) page for a term or college, and if there is a value in the Course Alias field for a Course, the Course Alias field will display as the Course Number throughout all of Faculty Self-Service for that course.
  • If the Course Alias is enabled (Display Course Alias) on the SCACARL page for a term or college, and there is no value in the Course Alias field for a Course, the Course Number will display as normal throughout Faculty Self-Service for that course.
  • If the Course Alias is disabled (Display Course ID) on the SCACARL page for a term or college, regardless of whether there is a value in the Course Alias field for any course, the Course Number will display as normal throughout Faculty Self-Service.

Search by Course Alias:

  • The search parameter is compared against both the Course Number and Course Alias fields irrespective of the SCACARL configuration.
  • If the Course Alias is enabled (Display Course Alias) on the SCACARL page, and there is a value in the Course Alias field for a course, whether you search for the Course Number or Course Alias, the applicable course will be returned displaying the Course Alias.
  • If the Course Alias is disabled (Display Course ID) on the SCACARL page, and there is a value in the Course Alias field for a course, whether you search for the Course Number or Course Alias, the applicable course will be returned displaying the normal Course Number, and not the Course Alias.

Redis caching

You can configure Redis caching for Banner Self-Service applications. Redis can handle large amounts of real-time data, using its in-memory data storage capabilities to help support highly responsive database constructs. For more information, see Redis cache configuration in the Banner Faculty Self-Service Install content.
