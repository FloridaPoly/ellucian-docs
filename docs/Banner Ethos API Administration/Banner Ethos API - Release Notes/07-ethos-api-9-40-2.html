Student API Release 9.40.2

The Banner Student API 9.40.2 release contains enhancements and defect resolutions.

Banner Student API 9.40.2 runs on Banner platform version 11.4.1 and Banner Common DB Upgrade 9.41.1.

Tip: For more information about the following APIs, see the Banner API Catalog.

Updates for catalog-course-descriptors API

The catalog-course-descriptors Banner ERP API has been modified. The enhancements include:

  • Updates to OAS and schema to ensure the objects display as singular titles or property names.
    • learningObjectives is now learningObjective
    • requiredMaterials is now requiredMaterial
    • technicalRequirements is now technicalRequirement
    • objectives is now objective
    • requiredCourseMaterials is now requiredCourseMaterial
    • courseTechnicalRequirements is now courseTechnicalRequirement
  • Removed modifiedOn as a required property from longTitleAndUrl object in response schema.

This enhancement addresses PE0007604 in the Ellucian Customer Center.

Updates for catalog-course-descriptors-adjustments-process API

The catalog-course-descriptors-adjustments-process Banner ERP API has been modified. The enhancements include:

  • Validation for CalBStu environments. When adjusting an existing course with CEU indicator = Y, the credit status (CA-only property) must have a credit course = N, or the API should throw an error.
  • Updates to OAS and schema to ensure the objects display as singular property names if the object is not an array:
    • objectives is now objective
    • requiredCourseMaterials is now requiredCourseMaterial
    • courseTechnicalRequirements is now courseTechnicalRequirement
  • Enhanced array processing. The API first does a compare of the submitted array and updates any existing records, deletes records not included in the array, and adds any new records submitted in the array. The API user must still send the full array.
  • Correct misspelling of property name from “programTaxomony” to “programTaxonomy”

This enhancement addresses PE0007605 in the Ellucian Customer Center.

Updates for catalog-course-restrictions API

The catalog-course-restrictions Banner ERP API has been enhanced for base call performance, and there are no schema changes.

This enhancement addresses PE0007606 in the Ellucian Customer Center.

Updates for catalog-course-restrictions-adjustments-process API

The catalog-course-restrictions-adjustments-process Banner ERP API has been enhanced for base call performance, and there are no schema changes. The API has also been modified to enhance array processing. Now, the API first does a compare of the submitted array and updates any existing records, deletes records not included in the array, and adds any new records submitted in the array. The API user must still send the full array.

This enhancement addresses PE0007607 in the Ellucian Customer Center.

Updates for catalog-course-requisites-and-equivalents API

The catalog-course-requisites-and-equivalents Banner ERP API has been modified. The enhancements include:

  • Updates to OAS and schema ensure the objects display as singular property names if the object is not an array:
    • checkMethodDetails is now checkMethodDetail
    • prerequisites is now prerequisite
  • The object name for the basic array is pluralized.
    • basic is now basicPrerequisites

This enhancement addresses PE0007608 in the Ellucian Customer Center.

Updates for catalog-course-requisites-and-equivalents-adjustments-process API

The catalog-course-requisites-and-equivalents-adjustments-process Banner ERP API has been modified.

  • Updates to OAS and schema to ensure the objects display as singular property names if the object is not an array:
    • checkMethodDetails is now checkMethodDetail
    • prerequisites object is now prerequisite
  • Updates to OAS and schema to ensure arrays display as pluralized.
    • basic object is now basicPrerequisites
  • Enhanced array processing. The API first does a compare of the submitted array and updates any existing records, deletes records not included in the array, and adds any new records submitted in the array. The API user must still send the full array.

This enhancement addresses PE0007609 in the Ellucian Customer Center.
