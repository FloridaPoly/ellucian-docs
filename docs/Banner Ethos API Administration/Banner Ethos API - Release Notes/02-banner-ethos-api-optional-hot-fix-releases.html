Banner Ethos API optional hot fix releases

Optional hot fix releases address the issues listed under the Related Defects and Related Enhancements tabs on the associated release page. This page maintains hot fix links for the current and previous year.

Hot fix release documentation

Content published to the Ellucian Documentation site for a standard Banner release also applies to the hot fix release. For example, to see the documentation related to the Banner Student API 9.28.0.2 release, go to the Banner Ethos API 9.28 standard release content on the Ellucian Documentation site.

To find previously released content for a standard release that is no longer available on the Ellucian Documentation site, go to the Previous Versions page, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. All content is available in English (enus), and some content is available in Spanish (esmx).
