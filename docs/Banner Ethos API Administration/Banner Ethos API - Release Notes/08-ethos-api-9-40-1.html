Ethos API 9.40.1

Integration API Release 9.40.1

The Banner Integration API 9.40.1 release contains enhancements and defect resolutions.

Banner Integration API 9.40.1 runs on Banner platform version 11.4.1 and Banner Common DB Upgrade 9.41.1.

Tip: For more information about the following APIs, see the Banner API Catalog.

Updated security-objects-details API

To accommodate Banner security object details that are used to populate the GURAOBJ table, the security-objects-details ERP API (v1.1.0) is updated to allow PUT, POST, and DELETE request methods.

This enhancement addresses PE0006291 in the Ellucian Customer Center.

Updated security-class-details API

To accommodate Banner security class details that are used to populate the GTVCLAS table, the security-class-details ERP API (v1.0.0) is updated to allow PUT, POST, and DELETE request methods.

This enhancement addresses PE0006951 in the Ellucian Customer Center.

Student API Release 9.40.1

The Banner Student API 9.40.1 release contains enhancements and defect resolutions.

Banner Student API 9.40.1 runs on Banner platform version 11.4 and Banner Common DB Upgrade 9.41.1.

Tip: For more information about the following APIs, see the Banner API Catalog.

Enhanced ca-priority-registration-eligibility API

The ca-priority-registration-eligibility API is enhanced to process additional elements from the following pages and tables.

New Elements Page Table
Program SGASTDN SGVACUR
Degree SGASTDN SGVACUR
Cohort SGASADD SGRCHRT
Attribute SGASADD SGRSATT
Committee SHACOMI SHRCOMM
Umoja SVAMIST SVBSUST
Puente SVAMIST SVBPNTE

This enhancement addresses PE0007494 in the Ellucian Customer Center.

Enhanced ca-import-mass-education-opportunity-programs-services API

The ca-import-mass-education-opportunity-programs-services API is enhanced to support batch data imports into the second (lower) block of SGAEOPS. This update ensures accurate population of records required for MIS SE01 reporting.

This enhancement addresses PE0006029 in the Ellucian Customer Center.

Enhanced learner-concurrent-curricula-updates API

The learner-concurrent-curricula-updates ERP API (v1.2.0) is enhanced to support fields of study by using the Field of Study Type defined in the GTVLFST table. This support is beyond major, minor, and concentration. These additional fields are defined in the GTVLFST table.

The PUT request method is supported.

This enhancement addresses PE0007595 in the Ellucian Customer Center.

Updates for catalog-course-bases-initiation-process API

The catalog-course-bases-initiation-process API has been modified. The enhancements include:

  • Validation for CalBStu environments where the CEU indicator must match the credit course of the credit status. When creating a new course with CEU indicator = Y, the credit status (CA-only property) must have a credit course = N, or the API will throw an error.
  • Update OAS to ensure the objects display as singular property names if the object is not an array:
    • courseDetails is now courseDetail
    • levelDetails is now levelDetail
    • gradingModeDetails is now gradingModeDetail
    • scheduleDetails is now scheduleDetail
  • String properties are modified to boolean:
    • continuingEducation is now isContinuingEducation
    • exemptFromTuitionAndFeeRules is now isExemptFromTuitionAndFeeRules
    • additionalFees is now hasAdditionalFees

This enhancement addresses PE0007600 in the Ellucian Customer Center.

Updates for catalog-course-bases-adjustments-process API

The catalog-course-bases-adjustments-process API has been modified. The enhancements include:

  • Validation for CalBStu environments where the CEU indicator must match the credit course of the credit status. When adjusting an existing course with CEU indicator = Y, the credit status (CA-only property) must have a credit course = N, or the API should throw an error.
  • The courseDetail object no longer requires any properties when adjusting existing courses.
  • Update OAS to ensure the objects display as singular property names if the object is not an array:
    • courseDetails is now courseDetail
    • levelDetails is now levelDetail
    • gradingModeDetails is now gradingModeDetail
    • scheduleDetails is now scheduleDetail
  • String properties are modified to boolean:
    • continuingEducation is now isContinuingEducation
    • exemptFromTuitionAndFeeRules is now isExemptFromTuitionAndFeeRules
    • additionalFees is now hasAdditionalFees
  • Enhanced array processing. The API first does a compare of the submitted array and updates any existing records, deletes records not included in the array, and adds any new records submitted in the array. The API user must still send the full array.

This enhancement addresses PE0007601 in the Ellucian Customer Center.

Updates for catalog-course-bases API

The catalog-course-bases API has been modified. The enhancements include:

  • Changes to QAPI Post schema:
    • removed required indicator from courseNumber
    • added alias as an optional property
  • Changes to response schema:
    • add identifierDisplay optional property
    • aliasDetail object - changed required properties to be fromTerm and alias
  • Update OAS to ensure the objects display as singular property names if the object is not an array:
    • courseDetails is now courseDetail
    • levelDetails is now levelDetail
    • gradingModeDetails is now gradingModeDetail
    • scheduleDetails is now scheduleDetail
  • String properties are modified to boolean:
    • continuingEducation is now isContinuingEducation
    • exemptFromTuitionAndFeeRules is now isExemptFromTuitionAndFeeRules
    • additionalFees is now hasAdditionalFees

This enhancement addresses PE0007603 in the Ellucian Customer Center.
