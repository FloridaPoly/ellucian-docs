Integration API Release 9.41

The Banner Integration API 9.41 release contains enhancements and defect resolutions.

Banner Integration API 9.41 runs on Banner platform version 11.5 and Banner Common DB Upgrade 9.42.

Tip: For more information about the following APIs, see the Banner API Catalog.

Schema Designer API Enhancements

Enhanced the extension-configurations ERP API (v1.6.0), custom-table-configurations Banner ERP API (v1.5.0), extension-configuration-revisions Banner Banner API (v1.1.0), and custom-table-configuration-revisions Banner ERP API (v1.1.0) with three new properties: attributeIndex for database column indexing, attributeUniqueColumn for unique constraint enforcement, and attributeOrder for controlling field display sequence in the More Info UI.

This enhancement improves query performance, ensures data integrity, and provides better user experience through customizable field ordering, addressing PE0007833 in the Ellucian Customer Center.

identity-profile-roles Banner EEDM API (v1.0.0)

Introduced the identity-profile-roles Banner EEDM API (v1.0.0) to expose institutional role configurations from Banner for integration with the Ethos Identity provisioning service. The API provides role key identifiers from GORRSQL (GORRSQL_SQRU_CODE) and corresponding descriptions from GTVSQRU (GTVSQRU_DESC), enabling external identity management systems to discover and synchronize roles such as Student, Faculty, and Staff. The GET method is supported to list all active roles. This enhancement enables seamless role-based access provisioning, centralized role governance in Banner, and cloud-based identity management, addressing PE0007886 in the Ellucian Customer Center.

Banner ERP API dynamic-parameter-definitions (v1.0.0)

The new Banner ERP API dynamic-parameter-definitions (v1.0.0) is introduced to retrieve all dynamic parameters from the GLRSLCT table for supported Banner jobs ( GLBDATA and GLBDATAJ).

The API supports the GET request method only and allows filtering by Application Code, Selection ID, and Creator ID.

This enhancement enables Data Connect to fully support Banner job scheduling for Population Selection Extract (GLBDATA/GLBDATAJ) and addresses PE0007663 in the Ellucian Customer Center.

ucasxmlset Integration API

Enhanced the ucasxmlset Integration API by introducing a new constant definition in UcasXmlConstants to enable processing of the new getUCASClearingApplicantStatus endpoint. The new constant provides the mapping between the new endpoint and its associated Xign activity.

This enhancement addresses PE0007848 in the Ellucian Customer Center.

application-details API

A new application-details API, has been implemented to invoke packages within Banner ERP. It provides a standardized interface for data processing.

This enhancement addresses PE0007816 in the Ellucian Customer Center.

Student API Release 9.41

The Banner Student API 9.41 release contains enhancements and defect resolutions.

Banner Student API 9.41 runs on Banner platform version 11.5 and Banner Common DB Upgrade 9.42.

Tip: For more information about the following APIs, see the Banner API Catalog.

Student API 9.41 release record

For more information about the enhancements and defect resolutions for this release, see the Ellucian Customer Center Banner Student API 9.41 release page Related Enhancements and Related Defects.

New awarding and disbursement APIs

The following new ERP APIs v1.0.0 are created for awarding and disbursement, and also to create or update records in bulk.

  • applicant-disbursement-details
  • applicant-institutional-awards
  • applicant-other-awards

The GET, and POST methods are supported.

This enhancement addresses PE0005614 in the Ellucian Customer Center.

Improved Accuracy of Student Academic Data across Committees and Progression Stages

This enhancement ensures a single, accurate, and non-duplicative view of student academic data across all committee boards and progression stages.

The following APIs are updated to enforce committee code filtering and eliminate duplicate trailing credits, stage records, and course data.

  • committee-student-population

    Added stageAndCommitteeList to the response structure and underlying database view to resolve duplicate course records. The API supports GET request method.

  • progression-award-results

    Added stageAndCommitteeList to the response structure and database view to prevent duplicate course records. The API supports GET request method.

  • progression-award-results

    Updated service logic to prevent re-roll processing of records already rolled to the next term. The API supports PUT request method.

  • student-stage-courses-grades

    Updated domain, service, and HBM mappings to eliminate duplicate course records. The API supports GET request method.

  • student-search

    Added stageNumber to the committees list in the response structure. The API supports GET request method.

  • student-trailed-courses

    Updated domain, service, and database view to resolve duplicate course records. The API supports GET request method.

UI Enhancements:

  • Assigned Committee and Student Progression History cards now display accurate, committee-specific student information.
  • Student List View and Student Profile pages have been updated to consume the revised APIs, ensuring consistent and accurate academic data to support progression review decision.

This enhancement addresses PE0006589 in the Ellucian Customer Center.

Enhanced Program Description field

  • Database Schema Update:

    The SMRPRLE_PROGRAM_DESC column in the Banner Student database has been expanded from 30 to 250 characters.

  • Application Layer Enforcement:

    Input validation has been implemented across all official UI, API, and data entry channels to enforce a 120-character maximum program description length.

  • Admin Page Updates:

    Banner Administrative pages are updated to support and enforce the 120-character limit wherever the program description is displayed.

  • Process Updates:

    All relevant processes that display the program description are updated to print the full description (up to the enforced 120-character limit).

This enhancement addresses PE0007462 in the Ellucian Customer Center.

Enhanced grade-configurations ERP API

The grade-configurations ERP API has been enhanced to support filtering by effective term. You can now request grade configurations for a specific term.

The term filter is implemented using the SHRGRDE_TERM_CODE_EFFECTIVE column in the SHRGRDE table, which is the primary data source for grade configurations.

This enhancement enables consuming applications and integrations to limit results to the desired effective term, reducing the need for client-side filtering and improving relevance of returned data.

This enhancement addresses PE0007577 in the Ellucian Customer Center.

Enhanced catalog-course-additional-details-adjustments-process API

The catalog-course-additional-details-adjustments-process API has been enhanced in preparation for general availability, with schema corrections and improved handling of complex payloads. The enhancements include:

  • Added anonymousGrading, feeDetail, and integrationPartnerDetail objects.
  • Correct misspelling of property name from programTaxomony to programTaxonomy.
  • Updates to OAS and schema to ensure that objects display as singular titles or property names:
    • attributeDetails is now attributeDetail
    • reportingClassificationDetails is now reportingClassificationDetail
    • partitionPreferenceDetails is now partitionPreferenceDetail
    • roomAttributeDetails is now roomAttributeDetail
    • transferAgreementDetails is now transferAgreementDetail
  • Enhanced array processing. The API first does a compare of the submitted array and updates any existing records, deletes records not included in the array, and adds any new records submitted in the array. The API user must still send the full array.

This enhancement addresses PE0007611 in the Ellucian Customer Center.

Enhanced proxy-holds API

The proxy-holds ERP API is enhanced to perform the following:

  • When toDate is not provided in the API payload, the SPRHOLD_TO_DATE field defaults to 12/31/2099.
  • If toDate is included in the payload, the system uses the date provided in the API request.

This enhancement addresses PE0007578 in the Ellucian Customer Center.

Enhancement to Deposit APIs

The student-deposit-details (term-based) and and deposit-details (ARTERM) Banner ERP APIs (v1.2.0) are enhanced to support both person (P) and non‑person (C) records in their POST and PUT operations. This change aligns the APIs with the functionality already available in the TFADETL and TSADETL admin pages.

This enhancement addresses PE0007579 in the Ellucian Customer Center.

Enhanced ProCode APIs for fees and enrollments

The external-funding-student-fees and external-funding-student-enrollments ProCode APIs v1.0.0 are enhanced for external funding to support multiple program details and implement more robust learner matching logic.

The API response structure has been revised for clarity and consistency. The field names are updated to better reflect their purpose:

  • StudentProgressionAttributes is now StudentAttributes
  • acadYearCreditLoad is now billingHours
  • newProgramDetails is now actualProgramDetails
  • firstDateOfAttendanceis now dateOfFirstAttendance

This enhancement addresses PE0007717 in the Ellucian Customer Center.

Enhanced ca-priority-registration-eligibility API

The ca-priority-registration-eligibility Banner ERP API (v1.0.0) is enhanced to process the Ed Levels such as API, DC Pipeline, and Facts additional element.

This enhancement addresses PE0007739 in the Ellucian Customer Center.

New social and economic details API

A new API social_economic_details is added to support POST, PUT, GET, and DELETE operations for managing social and economic details (GORPSID). The API provides a standardised, secure interface for creating, updating, retrieving, and deleting records, ensuring consistent data handling across systems.

This enhancement addresses PE0007813 in the Ellucian Customer Center.
