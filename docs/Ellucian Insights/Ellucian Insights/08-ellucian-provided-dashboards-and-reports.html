Ellucian-provided dashboards and reports

Banner dashboards

Customers with Ellucian Insights Premium have access to a collection of dashboards and reports built by Ellucian. This section provides a brief description of these Banner dashboards and their component reports.

Use these visualizations, reports, and dashboards for your transactional and operational reporting needs. Or, you can use them as inspiration when designing your own reports.

The Ellucian collection contains all Ellucian-provided dashboards and reports. You must have access to this collection to see and launch these dashboards and reports. If needed, contact your Insights administrator for more information.

Note: You cannot modify Ellucian-provided dashboards and reports. However, you can duplicate these dashboards and reports and then modify the duplicated version.

You can save the duplicated dashboard or report to either your personal collection or into your institution's collection, if you have adequate permission to that collection. Only users and roles with access to the target collection can access the duplicated dashboard or report.

For information on how to duplicate Ellucian-delivered content, please see Duplicate a dashboard and Build a new report from an existing report for more information.

Accounts Receivable

Receivable Account Balance Aging

The Receivable Account Balance Aging dashboard provides a summarized view of all accounts with one or more outstanding line item balances distributed over a series of incremental aging ranges based on days past due. Individual account information also includes a total of future amounts due, and an overall account balance.

The aggregated amounts displayed in the aging range charts across the top of the dashboard are a sum of only the overall debit balances owed by each account. They do not include any individual account credit balances within those ranges.

This dashboard includes three input parameters and several optional filters so you can evaluate outstanding account balances from several different perspectives. From this dashboard, you can drill from an account name to the Receivable Account Balance Detail dashboard.

Note: This dashboard and its component reports are applicable to only Banner systems.

Required input parameters

You must define the input parameters on this dashboard to ensure an accurate result set.

Parameter Description
Run Date Default: current date (sysdate). You can change this to any date. For example, you may want to run this dashboard for the first of the month or the end of the month, or for a future date.
Receivable Date Type (Bill, Due, Effective) Default: Effective (date). In Banner there are potentially three different dates associated with an outstanding amount due: Bill date, Due date, and Effective date.

Insights compares the Run Date to the selected Receivable Date and retrieves all unpaid receivable account records where the Receivable Date is earlier than or equal to the Run Date.

Change this parameter by typing the full receivable date type, or just the first letter (B, D or E), and press Enter.

Show Zero Account Balance (Yes/No) Default: Yes. This parameter determines whether the dashboard results include any summarized account rows with an Account Balance of zero.

Change the input by entering Yes or No, or just the first letter, Y or N, and press Enter.
