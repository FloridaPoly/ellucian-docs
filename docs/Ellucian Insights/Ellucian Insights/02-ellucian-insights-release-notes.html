Insights reporting tool enhancements in Insights 1.36.0

This release provides enhancements to the Insights reporting tool for report designers and report viewers.

Note: The Insights reporting tool is available only with Ellucian Insights Premium.

Enhancements for report designers

Enhancement Description
Reusable SQL snippets with variables Report designers can now create reusable SQL snippets that support variables. These snippets allow commonly used SQL logic to be stored centrally and reused across multiple reports.

Variables within snippets allow designers to dynamically pass values into queries at runtime, helping maintain consistent query logic and reducing the need to duplicate SQL code across multiple reports.
Dynamic progress bar visualizations Progress visualizations now support dynamically calculated goals based on query results.

Instead of manually defining a fixed goal value, designers can configure a progress visualization to compare a current metric against a goal returned by the same query. This enables dashboards to automatically reflect changes in data without requiring manual updates to visualization settings.
Model list view for browsing records Models can now display records using a card-style list view in addition to the traditional table layout.

The list view highlights key attributes for each record and presents them in an easy-to-browse format. Designers can configure which fields appear on each card and select a primary field to serve as the card title.
Dependency checks for content updates When modifying models or reports that are used by dashboards or other reports, the system now performs dependency checks before saving changes.

If a change could impact existing dashboards or reports, a warning message identifies the affected content. This helps report designers review the potential impact and avoid unintentionally breaking dependent content.

Enhancements for report viewers

Enhancement Description
Record detail view When reviewing data tables, report viewers can now open a record detail view by selecting a row in the results.

The detail view displays all attributes for the selected record in a panel, allowing users to review detailed information without scrolling horizontally across wide tables. Navigation controls allow users to move between records.

Localized currency formatting in models Currency values are now automatically displayed according to the user's regional settings.

When a field is configured as a currency value, Insights formats the value using the appropriate currency symbols and number formatting for each user's locale. This improves readability for teams working across multiple regions.

Dashboard and visualization improvements

Enhancement Description
Narrative documents for presenting insights Report designers can now create documents that combine narrative text with embedded visualizations.

Documents allow designers to present data insights in a structured format that combines explanations, charts, and dashboards within a single page. This makes it easier to share analytical findings and provide context for stakeholders reviewing reports.
Improved chart presentation Dashboards now include improvements to chart presentation and styling.

Enhancements include improved font readability, refined gridline display, and more consistent legend placement. These improvements help provide a cleaner and more professional dashboard appearance without requiring changes to existing visualizations.

Insights reporting tool enhancements

The following sections highlight the enhancements to the Insights reporting tool.

Note: The Insights reporting tool is available only with Ellucian Insights Premium.

Enhancements for report designers

The query builder has several enhancements that help the report designer to work more efficiently when building a standalone report view or visualizing data.

  • Several display options were added for table visualizations.
    • You can align column headers and column content (left, right, center) to better fit your data.
    • You can also wrap text within a column for better display.
    • You can now show or hide the row index numbers for tables.
    • When placing a table report on a dashboard, you can choose whether it is scrollable (default) or uses pagination (the previous method for displaying a table).
    • You can also choose to hide a table report from the dashboard if the report returns no results.
  • Global filters on charts and tables now use filter drop-down lists rather than the full-screen filter modal. This provides a more consistent user experience for the report viewers.
  • The custom expression editor has several smarter features, including:
    • A new built-in function browser to help you write more complex logic.
    • Multi-line expressions support.
    • Auto-formatting of expressions.
    • Improved help suggestions.
    • You no longer lose unsaved work if you click away from the custom expression builder.
  • The custom expression editor includes the following new functions.
    • distinctIf() returns the count of distinct values that meet a specific condition.
    • path() extracts the path name from a URL.
    • splitPart() extracts a specific part of a string based on a separator and a starting position.
  • The custom expression editor also includes type-casting functions. Type-casting functions convert values from one data type to another, such as turning a string into a number so you can run calculations or apply numeric filters. These type-casting functions can be useful when resolving mismatched data types.
    • text(), integer(), and date() convert the value to the specified data type.
    • float() turn text-based decimal values, such as 123.45, into numbers to do math, aggregations, and analysis on string-stored data.
    • datetime converts a datetime string to a datetime value.

    Refer to Supported expressions for a full list of the supported functions and aggregations.

  • Columns with BigInt data types (large integers) are now fully supported.
  • You can now manage the intervals on the y-axis of charts. This gives you more control over the level of granularity in your chart metrics.
  • Support was added for filters with boolean data types on dashboards, SQL variables, and field filters.
  • A prior upgrade introduced a change that retained a user’s last attribute selections in optional filters on dashboards. This change has been disabled because it caused undesirable results in drill paths. Instead, optional filters will not inherit the user's previous attribute selections and will be unpopulated when a user relaunches a dashboard. If you want the filter to be populated when your users go to that dashboard, set a default value for that filter.

Enhancements for report viewers

  • As mentioned in the report designer enhancements, global filtering on charts and tables now uses filter drop-down lists rather than a full-screen filter modal. This filtering approach is more consistent with the query builder filters, providing a more consistent user experience.
  • To create a new collection, you can click in the navigation bar next to the Collections section.
  • As mentioned in the report designer enhancements, a prior upgrade introduced a change that retained a user’s last attribute selections in optional dashboard filters. This change has been disabled because it caused undesirable results in drill paths. Optional dashboard filters will not inherit the previous attribute selections and will be unpopulated when a user relaunches a dashboard.
  • General improvements were made to enhance search results and filter value loading, and provide more accurate pivot table exports.

Updates

Required action - Ellucian Insights Premium

Insights 1.13.1

As of release 1.13.1, Ellucian will schedule nightly ingestion of the Data Catalog for all Insights customers. Additionally, the Data Catalog population to the Data Warehouse is now part of the Refresh All job template. These changes will improve performance and stability for data loads and refreshes to Insights.

Insights administrators should review the specific changes and recommended actions for your product.

Banner updates and recommendations

Release 1.13.1 includes the following Banner updates:
  • The Banner SDE and Data Catalog Ingestion and Population job template was renamed to Banner SDE Ingestion. This job template now only ingests the Banner Supplemental Data Engine (SDE) and no longer ingests or populates the Banner Data Catalog.
  • Ellucian will schedule nightly ingestion jobs for the Banner Data Catalog.
  • Banner Data Catalog population is now integrated within the Refresh All Banner Insights Product job template.
Based on these job template changes, consider the following:
  • If you previously scheduled the Banner SDE and Data Catalog Ingestion and Population job, you do not need to make any adjustments. Future SDE ingestion jobs will occur as scheduled. However, the job template name in the schedule will remain Banner SDE and Data Catalog Ingestion and Population.
  • If you do not have a recurring schedule for the Banner SDE and Data Catalog Ingestion and Population job and you need to update the data in GORSDAV and GORSDAM due to customizations made on your Banner system, Ellucian recommends you schedule the Banner SDE Ingestion job. It must run at least one hour before the Refresh All Banner Insights Product job.

Colleague updates and recommendations

Release 1.13.1 includes the following Colleague updates:
  • Ellucian will schedule a nightly Colleague Data Catalog ingestion.
  • Colleague Data Catalog population will occur with the Refresh All Colleague Insights Product job template.

Therefore, Ellucian recommends removing any recurring job schedules that include the Colleague Data Catalog Ingestion and Population job template to avoid any confusion with recurring or scheduled jobs for the Colleague Data Catalog.

Refer to Pause or delete recurring jobs for instructions.

Degree Works updates and recommendations

Release 1.13.1 includes the following Degree Works updates:
  • Ellucian will schedule a nightly Degree Works Data Catalog ingestion.
  • Degree Works Data Catalog population will occur with the Refresh Degree Works job template.

Therefore, Ellucian recommends removing any recurring job schedules that include the Degree Works Data Catalog Ingestion and Population job template to avoid any confusion with recurring or scheduled jobs for the Degree Works Data Catalog.

Refer to Pause or delete recurring jobs for instructions.
