Manage Tasks

Task list overview

You can view and manage a consolidated list of assigned tasks from within Ellucian Experience. The Task List is available with Experience Premium.

The Task List allows you to view and perform a variety of workflow tasks, and monitor the progress of your assigned tasks. Within this list, you can view one or more tasks awaiting your attention. The displayed tasks are determined by the logged in user ID and user role.

Task statuses

Status Description
Pending Outstanding task with a due date in the future.
Overdue Outstanding task with a due date in the past.
Completed No more action required.
Expired Outstanding task that was not completed and is now past its expiration date.
Error There was an error reported from the source of the task, such as the Ellucian solution that provided the task.

Access your task list

Access your tasks by clicking the Tasks/Calendar icon in the Experience Bar.

Clicking that icon opens the Task List. The Task List dynamically adjusts based on the status of your tasks. The following table outlines what you can expect to see in different scenarios:

Scenario What You See
Open (Pending or Overdue) tasks. The Task List is open by default when you access Experience, displaying your open tasks. From the Task List, you can:
  • Click any task to view more information about the task, such as required actions.
  • Click the All tasks icon to go to a full-page All Tasks view displaying details about that user's tasks. The page initially displays only open tasks. You can use the tags in the FILTER BY section to display tasks with other statuses (Completed, Expired, or Error).
No open tasks, but other (Completed, Expired, or Error) tasks. The Task List is not open by default when you access Experience. If you click the Tasks/Calendar icon, the Calendar tab is displayed. On the Tasks tab, the Task List displays the message No Tasks. You can click the All tasks icon to go to a full-page All Tasks view displaying details about your tasks with statuses of Completed, Expired, or Error.
No assigned tasks. If you click the Tasks/Calendar icon, the Calendar tab is displayed. On the Tasks tab, the Task List displays the message No Tasks.

Direct access to the All Tasks page

As described above, you can access the All Tasks page through the Experience user interface. You can also provide assigned users with a link directly to the All Tasks page. The link should have the form:

<experience_home_page_url>/tasks

That link opens the All Tasks page with the open (Pending or Overdue) tasks displayed.You can use the tags in the FILTER BY section to display tasks with other statuses (Completed, Expired, or Error).

View and manage assigned tasks

You can view and manage a consolidated list of your assigned tasks through the Experience user interface. You can click any task item in your Experience Task List to open it, take any required action, view its attachments or data fields, and complete the task.

Procedure

  1. Log in to Experience with your user name and password.
    Your Experience dashboard displays.
  2. Click the Tasks/Calendar icon in the Experience Bar.
    The Open Tasks list displays overdue and pending tasks with an assigned due date.
  3. To view more tasks assigned to you, click the All tasks icon to go to a full-page All Tasks view displaying details about that user's tasks.
    The page initially displays only open tasks. You can use the tags in the FILTER BY section to display tasks with other statuses (Completed, Expired, or Error).
