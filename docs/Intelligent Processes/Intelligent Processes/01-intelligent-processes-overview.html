Intelligent Processes overview

Intelligent Processes is a no-code Software-as-a-Service (SaaS) tool for business users to compose forms, automate tasks, and build approval workflows to streamline cross-departmental processes.

Through targeted push notifications, Intelligent Processes delivers relevant information directly to your dashboard, eliminating the clutter of irrelevant emails. Intelligent Processes makes it easy for students to review academic policies and fill out necessary forms by consolidating tasks inside the Ellucian platform. Intelligent Processes also boosts employee productivity by making it easy to complete mandatory training, agree to HR policies, or set up banking information as needed.

Key features

Intelligent Processes provides the following key features.
  • Access to Intelligent Processes through the Ellucian Experience App

    Users access Intelligent Processes through Ellucian Experience. Experience offers a seamless user experience by providing a central hub for students and staff. Student users never have to leave the Experience platform to participate in a workflow task, such as checking classes, grades, and schedules. Workflow admins can build and publish workflows directly from the Experience platform.

  • Built-in designer

    Intelligent Processes includes a Designer tool that allows you to create tasks and configure holds with an intuitive workflow and form builder without writing any code. See About the Intelligent Processes Designer for more information.

  • Person filters

    Assign tasks to a population through push notifications as granular or broad as needed through role-based experiences.

    The Intelligent Processes workflow scheduling feature uses person filters to select a population of users that share common data, based on specific criteria. The Intelligent Processes person filters are based on the Banner population selection or the Colleague saved list.

  • Notifications

    Reduce paper-based tasks and emails by automating task assignments and hold notifications through app and mobile push notifications.

    Intelligent Processes uses the Ellucian Experience notification feature to send notifications to task assignees. Notifications are sent when a new task is assigned or when a pending task passes its due date. Intelligent Processes users access their notifications from the Notifications icon on the Experience dashboard.

    See Notifications for more information.

  • Scheduled triggers

    Automate the start of a workflow when someone is added to a saved list or population. See Create scheduled workflow for more information.

  • API triggers

    Use the Intelligent Processes API workflow-instances endpoint to automatically trigger a workflow based on data that is submitted from any custom form, Banner form, Colleague form, or WebForm that can call the Start API.

    See Create API driven workflow for more information.

  • Forms triggers

    Users can launch a workflow directly from an Ellucian form. Forms is a no-code tool for building, managing, and sharing forms. The Forms app provides a comprehensive range of components, including multi-select fields, tiles, ratings, and more. To get started, simply create your form, publish it, set permissions, and you are ready to link it to a workflow.

    See Create form driven workflow and the Forms documentation for more information.

  • Approval groups

    Create groups of individuals who can be assigned tasks. Any member within the approval group can complete the task. Task details will display information on which group is assigned to the task and who completed it.

    See Approval groups for more information.

  • External tasks

    External tasks empower administrators to create and configure custom Experience cards and pages, transforming them into actionable tasks within a workflow. When these custom tasks are assigned to users, Intelligent Processes automatically guides them to the designated custom Experience cards or pages for completion. This capability provides institutions with the flexibility to address various use cases beyond the simple approval tasks that are already available.

    See External tasks for more information.

  • Workflow splits

    Control a path based on task outcomes, discerning between assignees who have completed a task versus those who have not.

    See Workflow splits for more information.

  • Actions

    You can use the Data Connect pipelines and execute them within the Intelligent Processes workflow. This allows you to access additional data from your ERP system or other sources available through APIs. It also enables the transfer of data from a workflow back to the ERP or other destinations accessible through APIs.

    See Actions for more information.

  • Integration with Banner and Colleague

    Institutions can integrate Intelligent Processes with Ellucian ERPs (Banner and Colleague) using Ellucian Ethos Integration. Intelligent Processes uses the population functionality that Banner and Colleague provides to simplify and streamline the process of bulk assigning tasks to a specific population of users.

User roles for Intelligent Processes documentation

Ellucian defines user roles to facilitate faster and more accurate searches on the Ellucian Documentation site. When you search the Intelligent Processes documentation, you can filter the search results by user role.

The user roles defined for Ellucian documentation are general areas of responsibility that can align with different job titles, which might overlap depending on the size and structure of your institution.

User role for documentation Functions of this role for Intelligent Processes
System administrator Those in System Administrator roles configure this component in Ellucian Experience and Ethos Integration, and update this configuration as required. They also grant permissions to the user roles, and troubleshoot the integration of the component with other systems, including Experience ERPs.
Office administrator Those in Office Administrator roles use Intelligent Processes to create and manage workflows that will automate processes. Office administrators will assign tasks, add holds, or interact with ERP data
Developer Those in Developer roles use Intelligent Processes to create the more technical components for office administrators to use. Developers will create extensions used for start API workflows, actions, and external tasks.
Student support Those in Student Support roles use Intelligent Processes to guide students and other users in their completion of tasks within a workflow.
Student Those in Student roles complete tasks assigned to them from a workflow or start new requests from a form or Experience extension.
Alumni Those in Alumni roles complete tasks assigned to them from a workflow or start new requests from a form or Experience extension.
