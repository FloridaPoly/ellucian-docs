Intelligent Processes 1.15.0 release

These release notes describe new features and enhancements in Intelligent Processes.

Enhancement: More Flexible Array Conditions in Splits

Workflow splits now support additional array condition options, including Blank and Exact Value. This allows workflow designers to create more flexible conditional logic when working with arrays and dynamic data.

Enhancement: Improved Assignee Workflow Data Validation

When selecting workflow data for assignees, only valid person data sources are now available for selection. Supported sources include actions, external tasks, forms, and Start API data.

Update

In this release, the documentation updates the IP addresses that you need to allowlist. For more information, see Allowlist Ellucian Intelligent Processes IP addresses.

Intelligent Processes 1.12.0 release

These release notes describe new features and enhancements in Intelligent Processes.

Enhancement: Last active step and activity visibility in workflow runs

The Workflow Runs grid now displays more actionable information to help you monitor workflow progress.

Intelligent Processes adds two new columns:

  • Last Active Step – Shows the name of the currently pending step.
  • Last Activity – Shows the start date and time of the pending step, formatted as MM/DD/YYYY, HH:MM AM/PM.

Workflow run admins can sort workflow runs by the Last Activity date, making it easier to identify stalled or recently updated workflows without opening each instance. This enhancement improves monitoring and troubleshooting by giving administrators immediate insight into where workflows are currently blocked or waiting.

Enhancement: Archived workflows excluded from name uniqueness

When you create a new workflow, the system now excludes archived workflows from unique name validation. Previously, the system blocked workflow designers from reusing workflow names when an archived workflow shared the same name. This update changes that behavior:

  • Users can create a new workflow with the same name as an archived one.
  • Archived workflows no longer cause unnecessary naming conflicts.

This change removes friction during workflow creation and reduces frustration when cleaning up or rebuilding older processes.

New feature: AI-powered rich text editor (ERP SaaS only)

Intelligent Processes now enables AI functionality in additional Rich Text Editors across workflows, including:

  • Task Details
  • Approval Task View
  • Email Notification Content

When you use AI prompts, you can now access process data from all preceding blocks in the workflow. This enables AI-generated content to automatically reference workflow variables and create reusable, dynamic content.

With this enhancement, workflow designers can:

  • Generate smarter task instructions and descriptions in minutes
  • Leverage process context without manual variable insertion
  • Improve consistency and efficiency when authoring workflow content
Note: This feature is available for ERP SaaS customers. Intelligent Processes currently supports this feature only in the U.S. region, with additional regions coming in the next months.

Intelligent Processes 1.11.0 release

These release notes describe new features and enhancements in Intelligent Processes.

New feature: Dynamic array-based task assignment

You can now assign a task to a list (array) of assignees that comes directly from workflow data, such as a custom table or an ERP resource. Before this change, the only way to assign a task to multiple people was by creating an EIP Approval Group and managing its membership through ERP IDs.

Array data can come from multiple sources:

  • Forms (form submissions that include arrays of assignees)
  • Start API input (arrays passed when the workflow is triggered)
  • Actions (arrays retrieved from custom tables or ERP resources)
Note: In all scenarios, the array must contain person IDs, not ERP IDs.

With this enhancement, workflow designers select an array of users as the assignee source. When the workflow runs, every person in that array becomes an assignee. The task is available to all of them, but after one person completes it, the task is marked complete for everyone. The system tracks who completed the task and when.

All assignees receive the appropriate notifications and emails. If any user in the array cannot be assigned, the workflow continues for valid assignees and logs warnings or errors in the workflow runs. This feature reduces manual setup and supports flexible approval routing.

Intelligent Processes 1.10.0 release

These release notes describe new features and enhancements in Intelligent Processes.

New feature: Non-user triggers (API subtype)

You can now create and trigger API workflows directly from Ellucian products or third-party systems using flexible authentication methods—no Experience User Token required. This enhancement enables automation from tools like Data Connect or other Ethos applications, allowing broader orchestration and integration in the Experience platform.

When creating an API-triggered workflow, you can now choose between using an Experience User Token or an Ethos Token authentication. Workflow runs now include an “Authentication Type” field for API triggers. Non-user triggers display Ethos Token, while user-initiated triggers display Experience User Token. Existing workflows continue to show Experience User Token to maintain backward compatibility.

Intelligent Processes 1.9.0 release

These release notes describe new features and enhancements in Intelligent Processes.

New feature: Hold reason (Banner only)

Admins can now add a short, optional reason when placing a hold. The note, up to 30 characters, appears inBanner SOAHOLD, giving users quick context for each hold.

New feature: Support for Ellucian form layout fields

Intelligent Processes now supports forms with a Layout field. Any fields added to a layout can be sent to EIP and used in workflows.

For details on adding a Layout, see the Ellucian Forms documentation.

New feature: Redesigned schedules grid

To improve accessibility, the schedules grid no longer uses expandable rows. Users can click the eye icon to open a modal with schedule details, including member counts and status. This redesign ensures compliance with accessibility standards and provides a more inclusive experience.

Enhancement: Clearing exact value mapping

A new trash can icon lets users reset data mappings in actions, external tasks, or form pre-fill. This restores the field to its default or blank state, simplifying updates and reducing errors.

Enhancement: Start date process variable

A new process variable captures the exact date a workflow began. This is useful for Automation License users who want to route workflows based on elapsed time from initiation.

Intelligent Processes 1.8.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

New Feature: Conditional splits

The new conditional splits feature enables smarter, more adaptable workflows by routing tasks based on specific data conditions. This enhancement improves flexibility and accuracy in workflow design.

With conditional splits, you can do the following:

  • Create up to 10 distinct paths from a single split to support complex decisions
  • Reorder paths based on the priority of their conditions
  • Automatically define a default path when no conditions are met
  • Use data from actions, forms, or external tasks to define routing logic
  • Set up to 10 conditions per path using AND/OR logic
  • Generate paths automatically based on task outcomes when splitting after a task
  • Apply conditional logic by default when splitting after non-task or non-form blocks

Conditional splits offer several key benefits: they enable you to build intelligent workflows that respond to real-time data, reduce manual effort through automated decision-making, improve the user experience with tailored process paths, and scale complex workflows with greater clarity and control.

Supported data types and operators

Data Type Supported Operators
Boolean Equals, Blank
Date/Time Equals, Between, After, Before, Within the last, More than, Blank, Execution Date (Current Date), Exact Value
Number Equals, Greater Than, Less Than, Greater Than or Equal, Less Than or Equal, Blank, Exact Value
Person Equals, Blank, Exact Value
String Contains, Equals, Blank, Exact Value

Intelligent Processes 1.7.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

New feature: My requests (automation license only)

Enhance task tracking and create a more integrated experience for your requesters with our latest Intelligent Processes feature. As a workflow creator, you can now configure the following My Requests settings for API- or form-triggered workflows:

  • Enable or disable the ability for requesters to cancel their requests
  • Configure notifications for requesters when a request starts or completes
  • Configure and display specific workflow end statuses (such as completed, approved, or denied) to requesters
  • Workflow runs now include data from requester activity, such as:
    • Request ID
    • Who canceled a request and when

Your students, faculty, and staff can benefit from this feature by:

  • Accessing their request history at any time using the Experience profile menu
  • Viewing, managing, searching, and filtering the processes they initiated
  • Keeping track of all their requests in a centralized location
  • Canceling requests they started (if enabled)
  • Receiving notifications about the status of their requests

Enhancement: ERP ID in workflow runs

You can now see the ERP ID alongside the name in the Started For column on the Workflow Runs page. This improvement makes it much easier to search for specific individual processes.

Updates

For a list of the issues addressed in Intelligent Processes 1.7, see the Related Defects and Related Enhancements tabs on the release page for Intelligent Processes 1.7 in the Ellucian Customer Center.

Intelligent Processes 1.6.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

New feature: Resync schedules

If you encounter errors while canceling large schedules (500 or more members), you can resync the cancellation to ensure all active and in-progress workflow instances are properly canceled and any pending tasks are removed.

The resync cancellation option is only available for schedules that have already been executed and have fully completed the cancellation process.

New feature: Task display name

You can customize a task’s name by setting a display name, which overrides the default block name. This new feature lets you assign a clear, meaningful name to any task type. The display name appears in emails, notifications, and the task list for assigned users. You can also reference process data to personalize the display name dynamically.

Intelligent Processes 1.5.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

New feature: Recurring schedules with audiences

  • Create a recurring schedule – Users can now set up schedules that run on a recurring basis using audiences. Simply select a start and end date, specify the time, and choose how often the schedule should run (daily, weekly, or monthly).
  • Automatically start for new members – When a recurring Schedule runs, it can automatically start a new workflow for users who have been added to the audience since the last recurrence.
  • Automatically cancel for removed members – If a user is removed from the audience, the recurring schedule can be configured to automatically cancel any previously started workflows for that user when the next recurrence runs.

New feature: Removing holds with workflow cancellation

The Add Hold block now includes an option to determine what happens to a hold when a workflow is canceled. Administrators can choose to either keep the hold or expire it upon cancellation. Workflows can be canceled in the following scenarios:

  • When members are removed from an audience with a recurring schedule
  • When the workflow is canceled from the Workflow Run Details page.
  • When a non-recurring schedule that uses direct person filters or audiences is canceled

New feature: Email notification block

A new Email Notification block has been added for Intelligent Process Automation administrators. This allows a standalone email notification to be configured and sent within a workflow. Expanding beyond task emails, this feature enables the creation of fully customized emails for any purpose. Workflow process data can be referenced in the subject and body to dynamically generate messages tailored to recipients.

Update: Data Connect pipelines

Data Connect has updated pipelines to allow configuring the output schema as either an array or an object. However, if a pipeline is set to an array output schema, it cannot be used with Intelligent Process Actions.

Intelligent Processes 1.4.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

New feature: Form task

Administrators can now configure form tasks in addition to the existing form triggers. Form tasks allow you to assign forms to individuals as part of a workflow. You can follow the same standards used for other task types and set up email notifications to alert individuals about assignments or progress.

Form tasks support existing forms from the Form Designer, and a single form can serve as both a form trigger and a form task.

Note: Ensure that Forms Designer permissions are properly configured before you get started.

Deprecated: CSV downloads

With the introduction of the Workflow Runs feature, workflows now offer extensive data insights and troubleshooting capabilities. As a result, CSV download requests have been deprecated. We recommend using the Workflow Runs feature to access workflow data. For more details, refer to the release notes for Intelligent Processes 1.2.0 release.

Intelligent Processes 1.3.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

Enhancements to troubleshooting and workflow runs

  • Direct links to completed tasks

    Users can now open completed approvals and tasks directly from a workflow run to view detailed task information and outcomes.

  • Quick access to workflow runs

    A new link on the Schedules page (formerly "Requests") lets users quickly navigate to Workflow Runs for troubleshooting or reviewing task details.

  • Improvements to the workflow runs section
    • When referencing data marked as "a person," the person's ID and name will now be displayed.
    • The statuses “Update Required” and “Unknown” have been removed from the Workflow Runs grid to reduce visual clutter, as these statuses were unused.
    • Data from an Action without a display label will no longer appear blank on the Workflow Run Details page.

Enhancements to minimize errors and confusion

  • Refined assignee selection

    To improve clarity and reduce errors, the “Started By” option is no longer available as an assignee selection.

  • Renaming of “Requests”

    The "Requests" area for scheduled workflows has been renamed “Schedules.” Users can still access this section using the workflows grid or canvas to create and manage schedules.

Key fixes

  • Canceled large schedules

    Canceling large schedules now properly removes tasks from the Experience Task List.

  • Improved split block functionality

    Fixed issues where multiple splits in a workflow affected block visibility.

  • Accurate error counts

    Error counts within schedule details now display consistently, providing users with precise information.

  • Mac file import fix

    Mac users experienced issues with importing workflow files due to incompatible file extensions. Files now import with the .yaml extension, while previously imported files remain accessible.

  • Improved task deletion on canceled workflows

    Canceling workflows now removes only pending tasks, preserving completed tasks in the Experience Task List.

Intelligent Processes 1.2.0 release

These release notes describe new features, enhancements, and updates in Intelligent Processes.

Fix: Form-triggered workflows

The issue where tasks from form-triggered workflows appeared as pending on the Experience Task List after completion has been resolved To apply the fix, republish your form-triggered workflows.

New feature: Automated Task and Workflow Emails

Task emails is a new feature that allow you to automatically send notifications about task assignments, completions, and workflow completions. You can choose individuals already involved in the workflow or specify up to five custom email addresses. You can configure task emails for simple, approval, and external tasks. You can configure workflow emails using the end block.

To configure the "from" address for these emails, use the Experience Setup Email Application. Ensure you have the Experience Setuppermission to access this application from the App menu.

New feature: Workflow Runs

A workflow run is a new feature that provides detailed tracking and auditing, allowing you to monitor progress, ensure accountability, and maintain a clear view of the entire process from start to finish. Key features include:

  • Filter workflow Runs

    You can filter workflows by date range, workflow name, person (ERPID), and workflow status (for example, Started, Completed, Cancelled, Errored, Failure).

  • Track workflow

    You can monitor the overall progress and status of a workflow.

  • Step-by-step data capture

    You can view detailed information about data collected at each step of the workflow, such as form submissions, approvals, and decisions. This includes timestamps for each completed step, along with comments or feedback from participants. You can audit the data captured at every step.

  • See all workflow participants

    You can identify all stakeholders involved in the workflow, which may include staff, faculty, or students depending on the process.

To access workflow run features, you must apply the workflow Runs permission. After permission is granted, you can view all workflow instances across your organization in the workflow Runs space.

New feature: Workflow Troubleshooting

Workflow troubleshooting offers a comprehensive interface for you to efficiently address errors in workflow runs, minimize disruptions, and ensure smooth operations. Key features include:

  • Error tracking for workflow runs

    Provides a view of specific workflow runs that have encountered errors, allowing you to quickly identify issues. Each error is flagged, with the impacted steps clearly highlighted.

  • Cancel individual workflow runs

    You can cancel individual workflow runs that have errored or stalled, helping prevent unnecessary delays or complications.

  • Remove task

    You can remove tasks within a workflow that have encountered errors.

  • Detailed error descriptions

    Each error is accompanied by a clear, concise description, explaining what caused the issue and at which step it occurred.

  • Links to Ethos Integration for more information

    To aid in troubleshooting, links to relevant documentation or guides are provided alongside error descriptions. These resources offer in-depth information to help resolve issues.

To access troubleshooting features, you must apply the workflow Runs permission. If errors occur during a workflow run, they appear on the details page, making this section a valuable troubleshooting tool. To view details, click the Started link from the workflow runs grid. Error descriptions include links to Ethos Integration for more detailed information.

New feature: Simplified Action Designer

Creating actions is now easier than ever with the new Simplified Action Designer, tailored for non-technical users. This new designer auto-populates action definitions from the Data Connect API and offers switchable modes for simplified or advanced designing. Key features include:

  • New intuitive UI for action creation
  • Visual input-output mapping
  • Switchable design modes: UI-driven or advanced
  • Backward compatibility with Action V1
  • Auto-population of action definitions from the Data Connect API
  • Real-time updates and parameter management when the API schema changes
  • Enhances data synchronization and reduces coding errors while creating Actions
