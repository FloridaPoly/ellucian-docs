Configure User Management

Ellucian Ethos Identity manages user identities and access across various applications and services.

The user management allows for the creation, modification, and deletion of user accounts. It enables the configuration of permissions based on defined roles, ensuring that users receive appropriate access to resources. The system integrates seamlessly with other Ellucian products and third-party applications, promoting smooth data flow between different systems.

Additionally, it provides self-service options that enable users to manage their profiles, reset passwords, and request access without needing IT support. Furthermore, it helps institutions comply with security regulations by offering tools to monitor access and manage sensitive information.

Users

Add single user

A group is a collection of users who share the same privileges to access resources within an organization.

Procedure

  1. Log in to the Console.
  2. Click User Management > Group.
  3. Click New Group.
  4. On the Create Group dialog box, enter the following details as required:
    Field Description
    User Store* Select the user store where you want to create this user account.
    Group Name* Enter a unique group name.
    Add Users Select users to add them to the user group.
    Note: * indicates a required field.
  5. Click Next.
  6. On the Create Group dialog box, select the necessary roles to be added to the group.
  7. Click Finish to create a new group.

Add multiple users

Add multiple user roles and specify the permissions for each user associated with that role.

About this task

To add multiple users, enable the Invite User to Set Password option. You can activate email invitations for user password setup from the Login & Registration settings.

Procedure

  1. Log in to the Console.
  2. Click User Management > Users.
  3. Click Add User > Multiple User.
  4. To add multiple users, select the intended options:
    • Manual
    • File Based
  5. If you select the Manual option, enter the following details as required:
    Field Description
    Emails Enter the email address of the user you want to invite and press Enter.
    Groups Select a group from the list.
  6. If you select the File Based option, upload CSV File.
  7. Click Add.
    You can preview the users who have been added.
  8. Click Close.

Roles

Create a role

Add a user role and specify what permissions each user will have when you associate a user with the role.

Procedure

  1. Log in to the Console.
  2. Click User Management > Roles.
  3. Click New Role.
  4. On the Create Role page, enter the following details as required:
    Field Description
    Role Name* Enter a unique name for the role.
    Select the role audience* Set the audience of the role.
    • Application: Roles created specifically for a particular application.
    • Organization: Roles that are available throughout the organization.
    Note: The audience of the role cannot be changed.
    Assigned application* Assign an application for the role.
    Note: The assigned application for this role cannot be edited after the role is created.
    Note: * indicates a required field.
  5. Click Next.
  6. Under Permission Selection, select Select API Resource.
  7. Click Finish to add a new role.
