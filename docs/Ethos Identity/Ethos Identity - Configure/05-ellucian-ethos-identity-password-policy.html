Ellucian Ethos Identity password policy

The Ellucian Ethos Identity password policy allows users to reset their passwords during the authentication flow.

Example: If a password expires, Ellucian Ethos Identity prompts users to reset their passwords.

Ellucian Ethos Identity supports a password policy authenticator that can match some of the same policies defined on LDAP V3 compliant directory servers. These policies are outside of the default password policies available in the directory server.

Set up WSO2 Identity Server password policy authenticator

Users can set up their WSO2 Identity Server password during the authentication flow.

Procedure

  1. Download the Password Policy Authenticator and Artifacts from WSO2 Store website.
  2. Upload the artifacts to the Ellucian Ethos Identity server.
  3. Unzip password_policy_artifacts.zip file.
  4. Place the authentication pwd-reset.jsp file into the EIS_HOME/repository/deployment/server/webapps/authenticationendpoint directory.
  5. Place the following authenticator.jar file into the EIS_HOME/repository/components/dropins directory.

    org.wso2.carbon.extension.identity.authenticator.passwordpolicy​.connector-1.0.8.jar

  6. Edit the EIS_HOME/repository/conf/identity/identity-mgt.properties and add the following properties. 
    module.name.13=passwordExpiry
passwordExpiry.subscription.1=POST_UPDATE_CREDENTIAL
passwordExpiry.subscription.2=POST_UPDATE_CREDENTIAL_BY_ADMIN
passwordExpiry.subscription.3=POST_ADD_USER
passwordExpiry.passwordExpiryInDays=30
passwordExpiry.enableDataPublishing=false
passwordExpiry.priorReminderTimeInDays=0
    Note:
    • For next module, replace the module number 13 in module.name.13=passwordExpiry to one higher number than the largest module number in the identity-event.properties file.
    • The property value must be an integer and match the directory server password age.
    • If the property excludes in the file, by default, the password reset time is 30 days.

      Example: Active directory maximum password age is 30 days.

  7. Stop and restart Ellucian Ethos Identity, using the appropriate commands for your operating system:
    • Linux/UNIX:

      sh wso2server.sh stop

      sh wso2server.sh start

    • Windows:

      wso2server.bat stop

      wso2server.bat start

    Changes to the whitelist take effect only after you restart Ellucian Ethos Identity.

Set up claim mappings for password policy authenticator for Ethos Identity

Users can set up claim mappings for the password policy authenticator.

Procedure

  1. Log in to the Ellucian Ethos Identity management console as the admin user.
  2. On the left navigation pane, click Main.
  3. In the Claims tab, click List.
  4. In the Claim URI field, enter https://wso2.com/claims/ Last Password Update
  5. In the Mapped Attribute section, provide a mapped attribute that exists in your directory server.

    Example: Use extensionAttribute 1-15 on active directory, if the attribute not in use currently on your directory server.

  6. Select the Supported by Default check box.
  7. Click Update to save the changes.
  8. On the left navigation pane, click Main.
  9. Under Users and Roles, click List and then click Users.
  10. Click User Profile.
  11. Edit Last Password Update field to a lower number .

    This is the last password change timestamp in milliseconds.

  12. Click Update to save the changes.

Configure the expiration policy for Ethos Identity

You can configure the expiration policy by setting the values of the corresponding fields in the server.

Procedure

  1. Log in to the Ellucian Ethos Identity server if you are not started it.
  2. On the left navigation pane, click Main.
  3. Under Identity Providers, click Resident.
  4. Under Password Policies, click Password Expiry.
  5. Update the following fields in the Password Expiry:
    • Update Password Expiry In Days according to your requirements.
      Note: By default, the password reset time is 30 days
    • Select the Enable Sending Email Notifications check box to enable an email notification for password reset.
    • Enter the number of days in the field Prior Reminder Time In Days to receive the password expiry reminder before expiration.
  6. Click Update to save the changes.
