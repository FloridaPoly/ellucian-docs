Ellucian Ethos Identity release notes

Ellucian Ethos Identity, is an enterprise middleware solution for institutions seeking to implement, simplify, or improve their identity and access management infrastructure.

Ellucian Ethos Identity is based on the WSO2 Identity Server product, an industry leader at supporting multiple single sign on protocols. Ellucian Ethos Identity includes Ellucian-developed and Ellucian-sponsored enhancements that address specific needs of higher education.

Ellucian Ethos Identity periodically releases new content and functionality. These release notes highlight key elements of the specified release.

Release 7.0.1

Ellucian Ethos Identity 7.0.1 provides new features, enhancements, WSO2 fixes, and security updates.

UI support for Account Disable in IS 7.0.0 console

UI support for the Account Disable feature within the IS 7.0.0 console has been implemented. Administrators are now able to deactivate or re-enable user accounts directly through the interface.

Installation Overview

The Ellucian Ethos Identity 7.0.1 installer can be used to install a new instance of the product or to migrate from Ellucian Ethos Identity 7.0.0 or later version. You must be on Ellucian Ethos Identity. 7.0.0 or later to migrate to Ellucian Ethos Identity 7.0.1. WSO2 Identity Server 7.0.1 is required before you install the Ellucian Ethos Identity extensions. A baseline version of WSO2 Identity Server 7.0.1 is included with the installer.

  • Download the Ellucian Ethos Identity installer from the Download Center or using SA Valet. In SA Valet, download Installer Release Package is IN040705*1
  • Refer to the Ellucian Ethos Identity 7.0.1 README.txt for installation and configuration instructions.

Updates

For a list of the issues addressed in Ellucian Ethos Identity 7.0.1, see the Related Defects and Related Enhancements tabs on the Ellucian Ethos Identity 7.0.1 release for Ellucian Ethos Identity 7.0.1 in the Ellucian Customer Center.

Release 7.0.0

Ellucian Ethos Identity 7.0.0 provides new features, enhancements, WSO2 fixes, and security updates.

Ellucian Ethos Identity 7.0.0 features

  • WSO2 Platform Upgrade to Version 7.0.0: The underlying WSO2 platform has been upgraded to version 7.0.0, introducing numerous improvements and new capabilities.
  • Refreshing Look and Feel for the Console UI: The console has been significantly updated with a modern new appearance.
  • HYPR Integration for Passwordless and Biometric Authentication: Integration with HYPR enables passwordless and biometric authentication, enhancing security and user convenience.
  • User Portal re-branded as MyAccount Portal: The user portal has been re-branded and upgraded to the MyAccount portal, offering a more streamlined and user-friendly experience.
  • Updated Management Console: The management console has been revamped with a fresh design, improving usability and performance.
  • Email and SMS OTP for Passwordless Login: Support for email and SMS one-time passwords (OTP) is now available for passwordless login, providing additional secure authentication methods.
  • Authentication API for App-Native Authentication: An API-based authentication feature allows developers to implement comprehensive authentication workflows within their applications.
  • Branding and Internationalization (i18n) Support: Enhanced support for branding and internationalization allows for a more customized and globally accessible user experience.
  • Idle Account Identification API: An API for identifying inactive accounts helps administrators manage and secure users who do not engage with the platform.
  • Email Magic Link Login Across Different Browsers: Support for email magic link login is available across different browsers, improving user convenience and flexibility.
  • Enhanced Multi-Factor Authentication (MFA), Passwordless, and Social logins: There have been improvements in multi-factor authentication, passwordless login options, and social login integrations.
  • Visual Login Flow Editor: A What You See Is What You Get (WYSIWYG) visual log in flow editor makes it easier to design and manage authentication workflows.

Release 5.10.10

Ellucian Ethos Identity 5.10.10 provides several enhancements, WSO2 fixes, and security updates.

Migrating the configurations from eis_config.properties to deployment.toml

Default configurations have been incorporated into the deployment.toml file. Refer to the sample-deployment.toml located in <IS_HOME>/repository/conf to replicate the necessary configuration settings, including those for the database, Active Directory, and keystore, from the eis_config.properties file.

Enhancements

Ellucian Ethos Identity 5.10.7 provides several enhancements.

  • Included the fix for renew and gateway parameters both set to true in the CAS protocol against Ellucian Ethos Identity.
  • Included the fix for the default application password in Security Advisory WSO2-2023-2617.
  • Included the fix for the Reflected XSS vulnerability which affects the RelayState and isSaaSApp parameters.
  • Added parameters to server start scripts to opt out of stricter Java rules for zip64 and dot entries for Java 11.0.20 versions.
  • Introduced a new configuration to store session data and temporary data separately in the tables IDN_AUTH_SESSION_STORE and IDN_AUTH_TEMP_SESSION_STORE respectively.
  • Introduced Email OTP as a first-factor login feature.
  • Included in the WSO2 IS 5.10 base product are various fixes and enhancements as of September 2023 from WSO2.
