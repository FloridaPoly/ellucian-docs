Schema Designer overview

Schema Designer is an Ellucian Platform SaaS solution that enables institutions to create and manage extended or custom tables through an intuitive UI or by using robust APIs. It supports flexible data Banner without modifying the baseline code, allowing institutions to securely meet their unique business needs within the Banner ecosystem.

User roles for Schema Designer documentation

Ellucian defines user roles to facilitate faster and more accurate searches on the Ellucian Documentation site. When you search the Schema Designer documentation, you can filter the search results by user role.

The user roles defined for Ellucian documentation are general areas of responsibility that can align with different job titles, which can overlap depending on the size and structure of your institution.

User role Functions of this role for Schema Designer
System administrator Manage Schema Designer in the institution. Users with this role create and maintain extended or custom database structures to meet specific needs, ensure standards are followed, and control who has access to use Schema Designer.
Office administrator Work within Schema Designer to extend functionality in a customer’s environment. Users with this role create or modify schema objects, such as extended fields or custom tables, to meet specific requirements. focus on implementing solutions, and in collaboration with administrators, deploy and integrate changes into institutional workflows.
