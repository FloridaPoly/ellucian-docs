MoreInfo Extension Release 1.4.0

A summary of the new features and enhancements in the 1.4.0 release of the MoreInfoExtension for Schema Designer.

Schema Designer API Enhancement

Enhanced the extension-configurations and custom-table-configurations APIs to provide consistent handling of PIDM-related columns and resolve issues with ambiguous column definitions during GET operations.

Columns named pidm or <tableName>_pidm are mapped to xbannerId, while additional _pidm columns are exposed by replacing pidm with bannerId in the JSON property name (for example, xcustom_pidm_other → xcustombannerIdOther). This enhancement enables support for multiple PIDM-related columns without ambiguity in GET and POST operations.

Validation has also been introduced to ensure that pidm and <tableName>_pidm cannot coexist, as only one column can be mapped to xbannerId per table. The Schema Designer UI has been updated to enforce these rules when creating or modifying extended and custom tables.

For existing tables, extended table APIs must be regenerated by making a POST call to the /schema-extensibility-specifications API if:

  • Multiple PIDM columns exist, or
  • A PIDM column exists with a name other than pidm or <tableName>_pidm (for example, <tableName>_pidm_col)

This update resolves issues related to ambiguous column definitions and ensures consistent and reliable API behavior, addressing PD0025164 in the Ellucian Customer Center.

Release 1.5.0

A summary of the new features and enhancements in the 1.5.0 release of Schema Designer.

Support for Indexing in Schema Designer UI

Schema Designer now supports indexing for non-key columns during the creation of extended or custom table fields.

Users can enable indexing by selecting a check box while defining extended or custom table fields within the UI.

To support this, both extension-configurations ERP API (v1.6.0) and custom-table-configurations Banner ERP API (v1.5.0) are enhanced to include an additional attributeIndex property.

For the extension-configurations API, the GET, LIST, POST, PUT, and DELETE request methods are supported.

For the custom-table-configurations API, the GET, LIST, POST, and DELETE request methods are supported.

This enhancement improves performance optimization capabilities and addresses PE0007981 in the Ellucian Customer Center.

Support for Unique Constraint in Schema Designer UI

Schema Designer now allows defining a unique constraint on a single non-key column during extended or custom table creation.

Users can enable the unique constraint through a check box option available in the UI.

To support this, both extension-configurations ERP API (v1.6.0) and custom-table-configurations Banner ERP API (v1.5.0) are enhanced to include an additional attributeUniqueColumn property.

For the extension-configurations API, the GET, LIST, POST, PUT, and DELETE request methods are supported.

For the custom-table-configurations API, the GET, LIST, POST, and DELETE request methods are supported.

This enhancement ensures better data integrity and addresses PE0007981 in the Ellucian Customer Center.

Support for Setting Display Order of Extended/Custom Fields

Users can now control the display order of fields during extended/custom table creation.

A sequence number can be assigned to each field. The fields will appear in the More Info UI according to the defined sequential order in Schema Designer.

To support this, both extension-configurations ERP API (v1.6.0) and custom-table-configurations Banner ERP API (v1.5.0) are enhanced to include an additional attributeOrder property.

For the extension-configurations API, the GET, LIST, POST, PUT, and DELETE request methods are supported.

For the custom-table-configurations API, the GET, LIST, POST, and DELETE request methods are supported.

This enhancement ensures that high-value fields appear first and related fields are grouped logically, and addresses PE0007981 in the Ellucian Customer Center.

Support for Flexible LOV Search Matching

The List of Values (LOV) in the More Info UI now supports sub-string search.

Previously, search results matched only values beginning with the entered text. With this enhancement, results will return any values containing the entered keyword anywhere within the text.

This improvement enhances search usability and addresses PE0007981 in the Ellucian Customer Center.

Support for Improved Handling of Long Text Fields in More Info Grid View

Schema Designer’s More Info UI now includes ellipsis support for long text fields in the grid view.

Truncated text is displayed with a user-friendly ellipsis (…) to clearly indicate that additional content is available. Users can view the full text either by hovering over the field to display a tool-tip or by clicking the edit action button within the grid.

This enhancement improves data clarity, reduces the likelihood of misinterpretation, and addresses PE0006914 in the Ellucian Customer Center.

Spec Engine Security Enhancement

To improve security, the Spec Engine has been enhanced to prevent potential SQL injection vulnerabilities. Previously, the engine directly replaced filter or named parameter placeholders (for example, ::value::) in SQL statements with user-provided input. This approach could expose the system to SQL injection risks if malicious content was supplied.

With this release, the engine no longer performs direct string substitution. Instead, it converts placeholders (e.g., ::population::) into bind variables (?) and applies parameter binding to safely pass user inputs.

Example:

If the SQL statement is:

select * from table where table_name = ::population::

and the API request is:

apiName?population=abcd

The engine will now transform the SQL to:

select * from table where table_name = ?

and bind the value abcd as a parameter, ensuring SQL injection safety.

This change may affect existing Spec Engine configurations that rely on direct string replacement.

Ellucian recommends customers to test their existing specifications with the new release to ensure expected behavior. As the bind variables alter execution plans in Oracle and PostgreSQL, there may be performance variations. Performance validation is recommended as part of testing.

This enhancement addresses PD0031995 in the Ellucian Customer Center.

Release 1.4.0

A summary of the new features and enhancements in the 1.4.0 release of Schema Designer, with links to more detailed information as required.

Support for Auto Increment in Schema Designer UI

Schema Designer has been enhanced to include support for Auto Increment feature for the numeric data type when you set it as a key column during custom table creation.

This enhancement addresses PE0007243 in the Ellucian Customer Center.

Support for baseline table change in Schema Designer UI

The Schema Designer UI allows you to change the baseline table during extended table creation before publishing. The system automatically picks the key columns corresponding to the newly chosen baseline table while retaining any additional data fields that you previously added or associated with the previously selected table.

This enhancement addresses PE0007244 in the Ellucian Customer Center.

Support for versioning in Schema Designer UI

The Schema Designer UI has been enhanced to support versioning for both extended and custom tables.

For more information, see Edit an extended table and extended table API and Edit a custom table and custom API.

This enhancement addresses PE0007379 in the Ellucian Customer Center.

Support for composite primary keys and one-to-many relationships in SDE migration framework

The Supplemental Data Engine (SDE) migration framework has been enhanced to support data migration scenarios involving composite primary keys and one-to-many relationships. The GURMSDC job now handles schema migration for tables with complex relational structures, while the GURMSDV job ensures accurate migration of associated data values with preserved referential integrity.

This enhancement addresses PE0006937 in the Ellucian Customer Center.

Release 1.3.0

A summary of the new features and enhancements in the 1.3.0 release of Schema Designer, with links to more detailed information as required.

Support for additional data types in Schema Designer UI

Schema Designer has been enhanced to include support for two additional data types: datetime and large_object. Informational text is now displayed for each data type to clarify its intended usage, helping you make informed decisions when designing extended or custom tables.

The More Information UI has also been updated to reflect these enhancements. You can now add and store datetime fields, enabling precise date and time capture in UTC format. The large_object data type supports multi-line entries and allows for richer content storage in extended and custom tables.

Limitation: In the current release, the datetime field in the More Information UI does not track the seconds component—it always defaults to 00. This will be addressed in a future update to support full timestamp precision.

This enhancement addresses PE0006953 in the Ellucian Customer Center.

Change in terminology: Schema Extensibility → Schema Designer APIs

Beginning with this release, all references to Schema Extensibility APIs (also known previously as CSE APIs) will be referred to as Schema Designer APIs.

The functionality of the APIs remains the same and only the terminology has been updated for consistency with the Schema Designer UI.

Release 1.2.0

A summary of the new features and enhancements in the 1.2.0 release of Schema Designer, with links to more detailed information as required.

Export and Import functionality for extended and custom tables

Schema Designer has been enhanced to support export and import capabilities for extended and custom tables. Users can now manage one configuration at a time through the UI, streamlining the process of transferring table definitions.

This enhancement addresses PE0006468 in the Ellucian Customer Center.

Use Schema Designer to map extended tables

Schema Designer has been enhanced to allow users to map extended tables to relevant Banner Admin Pages directly from the UI. This ensures that extended data can be managed (viewed, created, updated, deleted) through the More Info section on the Banner Administrative pages. This makes it much easier and faster for users to set up and manage where their extended data appears, without needing technical help.

This enhancement addresses PE0006471 in the Ellucian Customer Center.

Release 1.1.0 (beta release functionality)

A summary of the new features and enhancements in the 1.1.0 release of Schema Designer, with links to more detailed information as required.

The More Information functionality remains accessible when invoked by using the Banner Search card in the Banner in Experience extension. Additionally, a new Experience card, MoreInfoCard, is available as part of the Schema Designer SKU.

Users can access MoreInfoCard through the More Information section when they directly access Banner Administrative pages. New Banner Applications Configurations (GUACONF) page settings enable Experience page access from the Banner Admin pages. Use the Set up More Information card – for more information, see Configure More Information card.

This enhancement addresses PE0005949 in the Ellucian Customer Center.

The Schema Designer home page is enhanced with a search field, which allows a user to quickly find tables by entering a Name or Description and allows to a user to view the OpenAPI specifications for the respective extended or custom tab page with detailed information about the custom table API or extended table API. The API is documented by using the industry standard OpenAPI specifications and the API is displayed by using Swagger.

This enhancement addresses PE0005947 in the Ellucian Customer Center.

For more information, see Schema Designer Home page and View extended table and custom table details.

Release 1.0.0 (beta release functionality)

Schema Designer is a new Ellucian Experience extension that provides a no-code solution for creating, managing, and extending database tables to meet unique institutional requirements. Designed for SaaS clients, Schema Designer enables users to set up and customize data structures without complex coding, which streamlines data management and supports seamless SaaS integrations.

Schema Designer leverages Ellucian's SaaS-safe APIs to create extended and custom tables. These APIs are accessible through the Banner Ethos API application, which enables efficient creation and management of tables to meet specific business needs.
