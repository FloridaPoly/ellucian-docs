Ellucian API Designer overview

Ellucian API Designer helps users create and maintain APIs to unlock institutional data for seamless integration and extensibility.

API Designer is a user-friendly, no-code interface that allows users to create and deploy APIs that are immediately available. API Designer simplifies intuitive data browsing, which makes defining data sources easier.

Users can use API Designer to complete the following tasks:
  • Define endpoints.
  • Define an API data source by using the filter, function, join, sort, summarize, and custom fields options.
  • Configure pagination settings such as page size (records per page).
  • Define API security.
  • Define API Schema.
  • Create a draft or publish an API.
  • Modify an existing API and republish it with a different version.
  • Deprecate or reinstate an API.
  • Export or import an API.
  • Delete an API.

For details, see Use API Designer.

API Designer Release Support Policy

API Designer supports the current Banner Integration API release as the recommended version and also supports one prior release as the minimum required version. After API Designer is deployed in the cloud, support for the previous release is maintained until customers upgrade by using internal feature flags to manage compatibility.
