API Registry and Open API specification

The Open AI specification is available in the API registry for APIs that are published through API Designer.

Make sure that the API Registry is configured for users to view published APIs that are published through API Designer. For details about how to set the API registry on Banner Applications Configurations (GUACONF) page, see Add the endpoint specification.
