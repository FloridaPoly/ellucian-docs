Prerequisites

Make sure that the Ellucian Experience environment meets the prerequisites for API Designer before starting any other configuration procedures.

The prerequisites for API Designer are as follows:
  • You must have an existing active Principal User ID and Banner ID that has a third-party access to Ellucian Experience to use API Designer.

    For details, see Experience prerequisites

  • Refer to the release notes documentation for release-specific prerequisites. For details, see Ellucian API Designer release notes.

About Dialog overview

The About dialog provides key versioning information for API Designer and its integration with the underlying API platform. This includes:
  • The API Designer Version displays the current version of the API Designer tool that you are using.
  • The Integration API Version indicates the version of Banner Integration API being consumed by the API Designer tool that you are using.
  • The Minimum Supported Version is the lowest version of Banner Integration API that is required for proper functionality.
  • The Recommended Version is the preferred version of Banner Integration API for optimal performance and access to the latest features.

    For more information, see Enable access to API Designer in Ellucian Experience.

Use API Designer

Enable access to API Designer in Ellucian Experience

User permissions can be configured in Ellucian Experience to access and use the API Designer application.

Before you begin

  • Set up the Experience Application menu
  • Set up roles for Ellucian Experience

Procedure

  1. Navigate to and log in to the Ellucian Experience Setup application.
  2. Select the Permissions tab.
  3. Select the Environment.
  4. Search for API Designer.
  5. Select All Resources in the left pane.
  6. Select the Access check box for users who need access to API Designer.
  7. Click Save.

What to do next

Give a user security access to API Designer in GSASECR

Give a user security access to API Designer in GSASECR

Users who or classes that require access to API Designer must have permissions granted to them on the Banner Security Maintenance (GSASECR) page.

Before you begin

Make sure that users are enabled to access API Designer. For details, see Enable access to API Designer in Ellucian Experience.

Procedure

  1. Log in to Banner Access Management.
  2. Navigate to the Security Maintenance (GSASECR) page.
  3. Assign the API_DESIGNER_QUERY security object to Users or Classes with the BAN_DEFAULT_M role.
  4. Assign the API_DESIGNER_CREATE security object to Users or Classes with a specific role.
    Note: By default, the BAN_DEFAULT_M role grants full access to all data sources and should be assigned only to super users or administrators. To restrict access, you must define role-based permissions. For details, see Define role-based permissions.
    For details, see Banner Access Management Security Maintenance (GSASECR).

Define role-based permissions

Restrict access to APIs and database tables by assigning custom roles to ensure that users see and interact only with data relevant to their department or function.

API Designer allows administrators to implement fine-grained and targeted access control by defining custom roles that limit access to specific database tables and API operations. This enables organizations to tailor access based on departmental or functional needs.

For example, you can create roles that grant access only to tables that are relevant to a specific department (such as HR, Finance, or Student Services). This ensures that users interact only with data that is pertinent to their responsibilities. This prevents cross-departmental data exposure (for example, HR users cannot access student data and vice versa).

Custom roles are defined on the Security Maintenance (GSASECR) page and then assigned to the API_DESIGNER_CREATE security object. These roles specify which objects (such as tables or views) a user can access and what actions that user is permitted to perform.

By default, users with the BAN_DEFAULT_M role can perform all activities within API Designer, including previewing data for APIs. This role grants full access and should be reserved for super users or administrators. For all other users, Ellucian recommends assigning custom roles that limit access to specific database tables, functions, and other database objects to ensure appropriate data governance and security.

Note: Access to API Designer also requires that a user is assigned both API_DESIGNER_CREATE and API_DESIGNER_QUERY security objects. For details, see Give a user security access to API Designer in GSASECR.
