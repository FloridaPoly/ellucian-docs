Banner STUDEMRE release notes

Ellucian typically posts release notes the day before it makes the software available to customers. You can review Banner product release dependency information in Ellucian Solution Manager or the Banner Interdependency Matrix attached to Article KB000500135 - Banner Interdependency and Compatibility Matrix in the Ellucian Customer Center.

Banner 8 Self-Service is in sustaining support

As of October 1, 2025, Banner 8 Self-Service has moved out of Maintenance Support and entered Sustaining Support through December 31, 2025.

During this time, Ellucian will provide support only for critical vulnerabilities.

Sustaining support does NOT include:
  • Regulatory updates
  • Other security issues not classified as critical vulnerabilities
  • Functional defect fixes

This sustaining support period is intended only to help institutions complete their transition off Banner 8 Self-Service. On January 1, 2026, Banner 8 Self-Service will reach End of Support.

If your institution has not yet transitioned, Ellucian strongly urges you to finalize your plans now. Your Customer Success Manager can connect you with resources and support to ensure a successful move.

For detailed information on support statuses, please review our Support Assurance Policy.

DEMRE 2024 Reporting

To align with 2024 DEMRE requirements, Ellucian made updates to the specification for the DEMRE to accurately report for the upcoming year. The 9.3.32 / 8.5.4 release delivers support for DEMRE 2024 file upload and processing.

Mass Data Update Utility (MDUU)

Ellucian updated the specification for the Mass Data Update Utility (MDUU).

The following files were updated with new fields for DEMRE 2024 reporting:
  • File B, D1, D2
  • File E
The detailed information about the new fields and field descriptions that are included are available as an attachment for you to download. Click Attachments on this page, and then select Permanent_Tables_STUDEMRE_2024.xlsx to download.

DEMRE 2022 Reporting

To align with 2022 DEMRE requirements, Ellucian made updates to imported data to accurately report for the upcoming year.

Mass Data Update Utility (MDUU)

Ellucian updated the Mass Data Update Utility (MDUU) to include the following identifiers in the data it imports for DEMRE 2022 reporting.

New Identifiers
  • File D, D-BEA, D-PACE
    • ID Type
    • ID Digital Verifier
  • File E, E-BEA, E-PACE
    • Publish Social Name
    • Social Name
    • Publish Ethnic Code
    • Ethnic Code
