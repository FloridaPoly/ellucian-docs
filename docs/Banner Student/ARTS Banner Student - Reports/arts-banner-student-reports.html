Australia - Processes and Reports

Banner delivers processes and reports for institutions.

This 9x version corresponds to the Banner 8.3 release version.

Student Overall Process ARTS (SOPARTS) process

The SOPARTS process fetches the student transcripts from banner to provide student data based on the TAC request. The request comes to the system in a FLAT file format. SOPARTS processes the request file and generates the Acknowledgment for Request (ACK) and Result for Request (RLT) files.

The SOPARTS process uses the following parameters to run the process.
Parameter Name Required? Description Values
Run In Sleep/Wake Mode Yes Runs in sleep/wake mode or on demand mode Y: Sleep/wake mode

N: Ondemand mode
Sleep Interval Yes Sleep interval for sleep/wake internal 60: For every minute

120: For every 2 minute
On Demand Evaluation Yes Runs in sleep/wake mode or on demand mode Y: Sleep/wake mode

N: Ondemand mode
Internal Directory Yes Path of internal directory /U02/jobsub/dataload/arts
TAC Source Yes Enter ARTW for Windows Machine Enter ARTU for Unix Machine ARTU: UNIX SFTP folder ARTW: Windows SFTP folder
Ellucian recommends the following:
  • Create a TAC folder in the SFTP home and place all the files in the TAC folder.
  • For example, If you are using Windows, and if your SFTP home location is c:/user/test, your SFTP path is c:/user/test/TAC. If you are using UNIX, and if your SFTP home location is /user/test, your SFTP path is /user/test/TAC.
  • Update the SFTP credentials in the SOAREST Page where user need to add fallowing details:
    • URL: IPAddress
    • User name: SFTP username
    • Password: SFTP password
    • SFTP to be enabled at port 22

Re-run the Scheduler job process for .list file

Institutions can re-run the Scheduler job process to veiw the .lis file by scheduling a Sleep/Wake job process re-run.

Procedure

  1. Access the Sleep Wake Maintenance (GJASWPT) page.
  2. Enter SOAPARTS in the Process field.
  3. Enter SOPARTS_PRNT in the Printer field.
  4. Click Go.
  5. In the Sleep Wake Maintenance block, enter N in the Continue to Run field to kill the current job that is running.
  6. Save your record.
    When you change the Sleep/Wake mode from Y to N or N to Y, ensure if any job is already running in the GJASWPT page. If you want to view the .lis file for the Sleep/Wake run, abort the current Sleep/Wake instance. You will then be able to view the .lis file and can reprocess the new Sleep/Wake run.
