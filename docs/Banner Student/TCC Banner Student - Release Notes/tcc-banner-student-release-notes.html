Release 8.28

These release notes describe new features, enhancements, and updates in TCC Banner Student.

Gender X support

This enhancement will enable future versions of TCC Banner Student to use Ellucian's new Gender X functionality, so that customers can cross-walk the value in SPBPERS_SEX to the appropriate gender values.

Ellucian's Gender X project allows customers to configure and assign a new Gender code for a user's legal sex to ensure that all persons, including transgender, gender non-conforming, and non-binary persons' identities are fully reflected and represented in the institution's system. This functionality is already implemented in the baseline Banner products.

Note: The TCC Banner General March 2024 release contains a script that will allow TCC Banner customers to use Gender X. TCC Banner Student customers will not be able to apply the Gender X functionality in the Student Previous ID Data (SZAPRID) page until they install the TCC Banner General March 2024 release. Please refer to the Gender X Support topic in the Appendix of the TCC Banner Student Use documentation for instructions on how to set up Gender X.

This enhancement addresses PE0003085 in the Ellucian Customer Center.

CBM002 Documentation update

Beginning with the ACT tests administered on or after February 15, 2023, Ellucian provided new functionality in TCC Banner Student that requires schools to use a combination of the Reading and English scores to determine ACT exemption. This change required some additional set-up within Banner to record and report ACT exemptions.

To support the functionality delivered in 2023, Ellucian has updated its TCC Banner Student Use documentation with instructions on how to set up the Banner records in preparation for these exemptions. See Set up new ACT score.

This defect fix addresses PD0006112 in the Ellucian Customer Center.

These release notes describe new features, enhancements, and updates in TCC Banner Student.

This enhancement addresses PE0003472 in the Ellucian Customer Center.

Correction for PD0009104

As part of this release, Ellucian corrected the defect, PD0009104 so that 3-peat charges are processed correctly the first time a student registers for a course.

Previously, customers were not able to process the 3-peat charge on their first attempt. However, when customers processed subsequent 3-peat fees—using the TCC Student Course Registration (SZAREGS) page, self-service registration, or the Batch Fee Assessment (SFRFASC) process—the 3-peat charge processed correctly.

The defect did not impact self-service registration 8.x or 9.x.

Release 8.26.1

These release notes describe new features, enhancements, and updates in TCC Banner Student.

RTE-5344 ACT Exemption and CBM002 Updates

For all ACT tests administered on or after February 2023, schools have been instructed to use a combination of the reading and English scores to determine any ACT exemptions. The TSI Update (SZPTSPU) process uses this combination to establish the TSI status.

The CBM002 report currently pulls test scores directly from the TSI Student Information (SZATXSI). However, the Coordinating Board has requested that the individual ACT reading and English scores be reported on the CBM002 report. To allow TCC schools to stay in compliance with state reporting requirements, Ellucian has updated CBM002—including the elimination of several CBM002 values that are no longer relevant.

This enhancement addresses PE0002718 in the Ellucian Customer Center.

COVID-19 placement waiver

As of Spring 2023, the COVID-19 placement waiver is no longer valid for Banner students.

Customers should update the records for students who have a COVID-19 waiver with their current TSI status on the TSI Student Information (SZATXSI) page. A value of Z on Items 20, 21A, 24, 40, 41A, 44, 60, 61A, 64 is no longer valid and will result in a reporting error.

For more information, see the SZRCBM2 record selection topic.

Release 8.25.1

These release notes describe new features, enhancements, and updates in TCC Banner Student.

CBM005 enrollment counts

With this release, Ellucian has modified the CBM005 reporting process in preparation for the Fall 2023 reporting cycle.

In September 2022, the Texas Higher Education Coordinating Board (THECB) announced changes to the CBM005 reporting layouts slated for the Fall 2023 semester. In response to this requirement, Ellucian has modified the CBM005 Building and Room Report (SZRCBM5) job sub process, to produce the new, 77-character submission file, which contains a single, total enrollment field in Item 15. These changes will enable institutions to complete their regulatory reporting and remain in compliance with state reporting requirements.

This satisfies PE0002053.

STVSBGI code expansion

Because the school code in STVSBGI has been expanded in baseline Banner Student, we have updated the code in TCC to enable you to stay in sync with baseline Banner Student and to continue accurate state reporting.

As a result, we have modified several TCC processes—including the following pages to accommodate the longer code:
  • Course Cross Reference Information (SZACXRF)
  • Section Cross Reference Information (SZASXRF)
  • Student Drop Limit Status (SZASDLM)
  • Section Crosswalk (SZASXWK)
  • TSI Student Information (SZATXSI)
  • CBM00T Reason (SZATDAD)
  • Progress Measures (SZAPGMS)

This satisfies PE0001573 and PE0001574.
