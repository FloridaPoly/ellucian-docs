Alternative Grades pages.

Course Alternative Grade Range Maintenance (SKAAGRR) page

Use the SKAAGRR page to view and maintain the grade ranges calculated for a course by the distribution.

You can change how the grades were distributed to a course before assigning the grades. When the grades ranges are acceptable, the grades can be assigned using the audit and final tasks.

Key block

Use this block to specify the details for which you want to view and maintain the grade ranges calculated for a course by the distribution.

Field Description
Subject Subject code for the course for which you want to view or maintain the grade range.
Course Number of the course for which you want to view or maintain the grade range.
Term Term code of the effective term of the grade range to be viewed or maintained.
Grade Type Type that defines the alternative grade type. For example the grade type ECTS will be used for ECTS grades. The grade type is defined on the Alternative Grade Type Validation (SKVAGTP) page.
Course Title Title of the course that is in the Course field. Display only.

Base section

Use this block to enter the grade range details for the date specified in the Key block.

Field Description
Grade Alternative grade that will be assigned to a student when a grade is between the values in the Grade Range fields.
Grade Range From Lowest value (quality points as in the Grade Code Maintenance (SHAGRDE) page) that a student can have to be assigned the associated alternative grade.
Grade Range To Highest value (quality points as in the Grade Code Maintenance (SHAGRDE) page) that a student can have to be assigned the associated alternative grade.
Fail Indicator Indicates if the grade achieved in the entered grade range is considered a failing grade. Display only.

Default Alternative Grade Range Maintenance (SKAAGTP) page

Use the SKAAGTP page to define how alternative grades will be calculated.

After the grade ranges are defined, the ECTS_GRADE_PROCESS rule set can be used to distribute the alternative grades to selected courses. Seed data, which allows ECTS grade to be calculated, is delivered for this page.

Key block

Use this block to specify the code for which want to define how alternative grades to be calculated.

Field Description
Grade Type Code Alternative grade type code to which the grade ranges will apply.

Base section

In this section the Range From, Range To, and Grade fields work as follows, using the seed data delivered with ECTS for the examples.

Examples

For the grade A, if the value in the Range From field is 90, the value in the Range To field is 100, and the Fail Indicator check box is unchecked, the top 10% of passes in the course would receive an alternative grade of A.

For the grade B, if the value in the Range From field is 65, the value in the Range To field is 89.99, and the Fail Indicator check box is unchecked, the next 25% of passes in the course would receive an alternative grade of B.

For the grade FX, if the value in the Range From field is 0.1 and the Fail Indicator check box is checked, any student obtaining a final grade corresponding to a number of quality points between 0.1 and the number of quality points corresponding to the lowest passed grade (that is, alternative grade E) would receive an alternative grade FX.

Field Description
Sequence Order Order in which the grade range will be applied.
Range From Lowest value associated with the alternative grade of the record. The unit of measure is percentage for passed grades and quality points for failed grades.
Range To Highest percent of passes that will receive the alternative grade. The unit of measure is percentage for passed grades and quality points for failed grades.
Grade Alternative grade that will be assigned if a student’s marks fall within the specified range.
Fail Indicator Indicates if the grade achieved in the entered grade range is considered a failing grade.

Section-Dependent Course Maintenance (SKATCKN) page

Use the SKATCKN page to view and maintain the alternative grades and credits assigned to a student.

This page is derived from the Baseline Course Maintenance (SHATCKN) page but with the following differences.
  • SKATCKN includes the Alternative Grades section in the main window.
  • Only changes made in the Alternative Grades section can be saved. Any change for another section in the page must be made on baseline SHATCKN.

See the Banner Student Localization Online Help for the SHATCKN page for information about that page. Only the Alternative Grades section is described in this handbook.

Alternative Grades section

Use the Alternative Grades section to enter and display the alternative grades and credits assigned to a student.

If an alternative grade is changed, a new sequence number must be added for the record and a change code must be specified to indicate why the alternative grade was changed.

This section references the Student Alternative Credits and Grades Table (SKRALGR).

Field Description
Sequence Number Highest number is the latest grade for the course.
Alternative Grade Alternative grade that was calculated and assigned to the student for the course using the Alternative Grade Process.
Alternative Credit Number of credits that the student has achieved for the course as calculated by the ESC_FINAL task, which inserts data into SKRALGR.
Change Reason Code that indicates why an alternative grade was created or changed.
Final Grade Change Date Date of the assignment of the alternative grade.

Alternative Grade Type Validation (SKVAGTP) page

Use the SKVAGTP page to view and maintain the codes used to designate the alternative grade type code.

Note: The ECTS code is delivered as seed data.
Field Description
Code Alternative grade type code. For example, ECTS. Any rules and grades assigned to the ECTS grade code will be used to distribute and assign ECTS grades and credits.
Description Description of the grade code.
Activity Date Date the record was created or last modified. Display only.
User Name User who created or last modified the record. Display only.
