Troubleshooting

These are some errors and their solutions to help you through troubleshooting HEIMS.

JWT validation failure

Why a JWT validation fails, and what you must do to remedy the error.

Error

{
   "httpCode": "500",
   "httpMessage": "Invalid-JWT-Validate",
   "moreInformation": "JWT validation failed"
}

Cause

Access Token has expired.

Remedy

Refresh the Access Token by running the SOPPDAD process.

To learn more to about the TCSI validation errors and their details, see https://www.tcsisupport.gov.au/validations-download

Note: See the Banner_ASCGEN_HEIMS_TCSI_Error_Management spreadsheet for more . You can download this spreadsheet from the SC Australia ASCGEN Generic Objects documentation library in the Ellucian Customer Center.
Related tasks
  • Activate your device and refresh the access token

Endpoint connection failure

Why an endpoint connection fails, and what you must do to remedy the error.

Error

Message Code: 500

Message: URL Open error: Could not connect to endpoint.

Cause

The API request has timed out.

Remedy

Submit your API request again.
