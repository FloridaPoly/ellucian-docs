Reporting VET Diploma Specialisations

Each Diploma specialisation has a record on SKATRCO and these are linked by the TCSI Course Code so that students can have one TCSI course admission, but, have the Unit Enrolments in multiple study paths linking back to that same course admission UID.

For AVETMISS reporting, each study path represents a specific specialisation with its own commencement and end dates and its own units.

For TCSI reporting the main study path is the course admission with a commencement date that aligns with the earliest commencement date reported for AVETMISS and a course outcome date that aligns with the latest completion date reported for AVETMISS, so that specific specialisations can be completed over time but the course admission ends when they are all complete.

The TCSI reporting logic refers to these as Modular Programs to keep them separate from the TCSI concept of Course Specialisations. The unit registrations connect to each separate study path and are linked to the study path sequence of the original TCSI course admission using the TCSI Course Code link.

The SOPHBDP process includes logic to process the Modular Programs records based on the value of the MODULAR-PROGRAMS-EXIST system parameter for the report year. If the MODULAR-PROGRAMS-EXIST = Y, the system executes the logic when the SOPHBDP process is run for Unit Enrolment. If MODULAR-PROGRAMS- EXIST = N, the system does not execute that logic.
