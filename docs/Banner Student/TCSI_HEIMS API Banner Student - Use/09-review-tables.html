Review tables

You can review notifications from the SOTINOT table using the Notifications (SOATNOT) page. To review the GET/Submit data for each of the HEIMS/TCSI APIs, use the Universal Data Review (SOAUREV) page. Select the records and process either to the TCSI system or to the respective Banner pages.
