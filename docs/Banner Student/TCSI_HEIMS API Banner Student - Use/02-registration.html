Registration

Before you begin the registration process, ensure that you have met these conditions.

  • You have successfully registered and logged into ProDA.
  • Your organization has successfully registered in ProDA.
  • You must have appropriate device management access to manage organization devices.

Register and activate a new B2B device

A Provider (the organization's authorized person) can perform these steps to successfully register a device under an organization.

Procedure

  1. Log in to the ProDA online application.
  2. Select Organization.
  3. Select the organization requiring the device.
  4. Select Register New B2B Device.
  5. Select the relying parties the device can access.
    This is dependent on the Relying Party providing the authorization.
  6. In the Register New B2B Device window, populate device details such as the device name.
  7. Click Register Device.
    ProDA generates a device activation code (DAC) and displays it on the screen.
  8. Copy the displayed DAC, Device Name, and Organization Id from the screen and transfer them into the Banner application.

Results

This registers the device in ProDA and it activates successfully.

Generate a DAC on ProDA

You can use the new Device Activation Code (DAC) on the Banner SKASYSC page to activate the device and refresh the access token.

Procedure

  1. Log in to the ProDA online application.
  2. Select Organizations.
  3. Click on the organization name link that is registered.
  4. Select B2B Devices.
  5. Select the Device Name for which you need to generate a new DAC.
  6. Click Generate New Code under the Device Management section.
  7. Click Yes from the Generate New Device Activation Code pop-up.
    A new Device Activation Code (DAC) generates with the Code Expiration Date information.

Activate the Device

After you generate a new DAC, you must activate the device.

About this task

Activate the device by following these steps:

Procedure

  1. Access the External Systems Interaction Control (SKASYSC) page.
  2. Go to the ProDA tab.
  3. Go to Tools > Options.
  4. Select Activate Device and Create Access Token.
    This activates the device and creates an Access Token.
