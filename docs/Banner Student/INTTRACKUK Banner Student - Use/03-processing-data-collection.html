Processing data collection

INTTRACKUK uses rule sets in MDUU to generate snapshots and export data into XML files for exporting. Data collection and export functionality required to create reports are available along with INTTRACKUK that meet the SMS portal requirements.

To understand how the reports are built, you must understand the process, task, and activity elements of MDUU. Refer to the MDUU use content for a complete explanation of tasks and activities, and how the process elements work to support INTTRACKUK reporting requirements.

You can collect data and create a Graduates CAS XML bulk report using the SORGCAS process that is available through Banner job submissions.
