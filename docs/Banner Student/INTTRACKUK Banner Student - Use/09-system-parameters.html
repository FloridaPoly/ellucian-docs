System parameters

System parameters for Banner INTTRACKUK.

Report System Parameters (GKAKSYS) page

The following table details the system parameters that are available from the GKAKSYS page.
Field   Description
ADVANCEUPLDDAYS   Number of days in advance of program start date (visa start date) that CAS applications need to be uploaded.
BULKEXPORTID   Used for the header.BulkExportIDin the SMS export document to be imported into Banner.
BULKREPORTFILEID   Used for the header.BulkReportingID in theSMS export document to be exported from Banner.
BULKUPLOADFILEID   Used for the header.BulkUploadFileId in the upload document.
CASLATEACCDAYS   Number of days to be added to the program start date to calculate the latest date for acceptance on program.
CATEGORY General Used for the header.Category in the upload document.
EMAILTYPE Home Type of email address for the which e-mail notification should be sent.
EMAIL_ADDR_TYPE_CODE   Address type code used to generate the notification.
EMAIL_FROM_ADDR   Email address from where the e-mail notifications should be sent.
EMAIL_HOST   Details of the e-mail host to be used.
EMAIL_HOST_PORT_NUM   The port number of the SMTP Server.
EMAIL_SUBJECT   Subject of the email.
EMAIL_FROM_NAME   Name to be used in the From field of e- mail notification.
FROM_STATUS_CLOSED USED Allows institutions to define which current status of a CAS application should allow for the record to be set to CLOSED.
FROM_STATUS_REFUSED USED Allows institutions to define which current status of a CAS application should allow for the record to be set to REFUSED.
MAXRECSPERFILE   Allows to specify maximum number of records to be included in one exported XML file. The standard value would be 1000 as this is the maximum value number specified by UKVI.
MISCON_CRNMEETTNUM 10 The number of CRN meetings that a student must have missed to be included in the UKVI missed contact report.
MISCON_CRNMEETTYPE   A valid meeting type from the Meeting Type Validation (GTVMTYP) page identifying the expected UKVI contact point meetings.
MISCON_EVENTNUM 10 The number of events that a student must have missed to be included in the UKVI missed contact report.
MISCON_EVENTTYPE   A valid event type from the Event/Function Type Code Validation (STVETYP) page identifying UKVI contact point events.
NOSHOW_STATUS_CODE   Student status code indicating that the student did not enroll in the institution.
SCHEMAID T4GeneralReady To Go The schema ID value to be used in the header.SchemaID in the upload document.
SPONSORLICENCENUMBER   The institution’s sponsor license number to be used in the header.SchemaID of the upload document.
TIERID Tier4 Used in the header.TierID of the upload document.
WP_ADDR_TYPE_CODE   Used to define under which address type code (setup in STVATYP) the work placement address is recorded in the General Personal Identification (SPAIDEN) page.

Graduates CAS XML Bulk Upload File

For the Graduates CAS XML report, the following parameters are available in the GUACONF page.

Field Description
CAS_GRADUATE_LEVEL_CODE Used to define the Degree Levels for Outcome records that you want to extract CAS Numbers for students CAS applications, using the SORGCAS process.
CAS_STATUS Used to define the CAS statuses for CAS Numbers that you extract to print in the XML using the SORGCAS process.
