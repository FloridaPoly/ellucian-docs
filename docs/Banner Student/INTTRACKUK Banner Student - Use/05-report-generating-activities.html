Report generating activities

Tasks and activities used to generate reports with INTTRACKUK.

Application generation

INTTRACKUK delivers a template for automatic generation of new CAS applications records which can be customized by the user to meet the individual requirements and business process of the institution.

The following table describes the activities for this file.
Activity Type Activity Name Description
INTTUK CAS Application Generation ESC_GEN_CAS This activity generates records in the new CAS Application Table (SKRICAS) based on student residence code, status, and program start date. When a new record is created, the activity also sets the user defined status of the new record in SKAICAS to manual check (MANCHK).

Applicant upload

Activities to generate applicant upload reports.

The following table describes the activities for this file.
Activity Type Activity Name Description
INTTUK Applicant Upload Snapshot ESC_SNA_AUPLD This activity pulls data from various Banner tables to populate the Applicant Upload Snapshot Table (SKRAULD). The activity uses the applicant ID, CAS application ID, snapshot type, and export batch as populate keys.
Export ESC_EXP_AUPLD This activity pulls data from the Applicant Upload Snapshot (SKRAULD) table to create the XML document for upload to the SMS portal.

Applicant update

Activities to generate applicant update reports.

The following table describes the activities for this file.
Activity Type Activity Name Description
Applicant Update Snapshot ESC_SNA_AUPDT This activity pulls data from various Banner tables to populate the Applicant Upload Snapshot (SKRAULD) table. The activity uses the applicant ID, CAS application ID, snapshot type, and export batch as populate keys.
Export ESC_EXP_AUPLD This activity pulls data from SKRAULD to create the XML document for upload to the SMS portal.

CAS data import

Activities to generate CAS data import reports.

The following table describes the activities for this file.
Activity Type Activity Name Description
INTTUK CAS Number Export Load ESC_IMP_ CASEXP_ACT This activity imports data from an XML document extracted from the SMS portal into the Temporary Import Table (SKRICLD).
Processing ESC_PROC_ CASEXP_ACT This activity matches the records from the Import Table (SKRICLD) with existing CAS application records in SKRICAS. When a match is found, the application record in SKRICAS will be updated with new CAS information.

Email notification

Activity to generate email notification reports.

The following table describes the activities for this file.
Activity Type Activity Name Description
INTTUK E-Mail Notification ESC_PBS_EMAIL This activity triggers an e-mail notification containing CAS application data from the Applicant Upload Snapshot Table (SKRAULD) to the e-mail address of the applicant specified in Banner.

No-Shows upload

Activity to generate no shows upload reports.

The following table describes the activities for this file.
Activity Type Activity Name Description
INTTUK Applicant No Shows Snapshot ESC_PBS_EMAIL This activity pulls data from the CAS Application Table (SKRICAS), the student status, or the end of student instance reason to populate the Applicant No Shows Data Snapshot Table (SKRNOSH). The activity uses the CAS number as populate key.
Export ESC_EXP_NS This activity pulls data from SKRNOSH to export to an XML document for upload to the SMS portal.
