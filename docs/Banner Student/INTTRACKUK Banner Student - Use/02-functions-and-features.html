Functions and features

Institutions must follow various steps and processes to use and organise the INTTRACKUK reporting system.

  • Set up the INTTRACKUK module: Procedures and forms are used to define elements, values, and processes that are required to produce the INTTRACKUK reports.
  • Create the Report: Snapshot and export generation procedures and forms are used to create and view the data snapshot and export data into an XML file downloaded from the SMS portal.
  • View Data: INTTRACKUK provides an audit form where all users authorized to access the audit form can see and review changes made to the CAS record. The MDUU Universal Viewer is used to view the data produced by the snapshot and export processes.
Note: Configuring the INTTRACKUK module requires knowledge of the underlying database tables and is usually carried out with the assistance of technical staff within the institution or Professional Services.

REFUSED status

The status, REFUSED, is an INTTRACKUK-specific status not used by UKVI. When a CAS application is set to the REFUSED status, institutions can either copy the refused record into a new CAS application record or directly create a new CAS application for the same person, term, program and priority.

The Higher Education Institution (HEI) can then extract and upload this new application to the SMS.

Note: When the status of the CAS in the SMS is still ASSIGNED, the HEI can withdraw the record in the SMS and import the latest status WITHDRAWN into INTTRACK. This status also allows the creation of a new CAS application for the same person/term/program/priority.

Your institutions can also revert the status from REFUSED to the previous status. This allows error correction when the REFUSED status was applied by mistake or an administrative review was successful after the record was marked as REFUSED.

CLOSED status

The status, CLOSED, replaces the Manual Withdraw functionality. The CLOSED status is an INTTRACKUK specific status not used by UKVI.

This status allows institutions to close a CAS application that cannot be withdrawn from the SMS and create a new CAS application in the Confirmation of Acceptance for Studies (SKAICAS) page for the same person/term/program/priority.

This status allows students with an existing valid visa, for example, for a pre-sessional course, to apply for a second visa for the duration of the degree program. In addition, the Close functionality enables students who have already applied for a visa to cover their post graduate studies, but need to defer, to process a second CAS application for the same program/term/priority.

System parameters

A set of default system parameters are available for institutions to configure the INTTRACKUK application. Use the System Validation (GKAKSYS) and the System Parameters (GKARSYS) pages to configure the data to the specifics of your implementation. Appropriate permissions are required to modify data in GKAKSYS and GKARSYS pages.

The set of parameters required for Graduates CAS Reports are available for institutions to configure in the GUACONF page. To view these parameters, you should execute the seed data which for the first time is delivered with the Banner Student 8.21.1 release for Banner INTTRACKUK 8.3.6/9.3.24 release.
