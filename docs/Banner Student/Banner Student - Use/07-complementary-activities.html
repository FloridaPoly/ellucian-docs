Complementary Activities

Complementary Activities is a feature that allows institutions to capture extra-curricular activities of a student that a student pursues in addition to the main program. In the UK, you can use this feature to store and access information about a student’s degree apprenticeships.

With the Complementary Activities feature, you can do the following:
  • Create and define the Complementary Activities document type
  • Associate the activity code to the document type
  • Define the complimentary activity program rules
  • Approve or reject the complementary activity submissions
  • View the Complementary Activities submission details

Tasks with Complementary Activities

Set-up rules for Complementary Activities

Before you begin to use the Complimentary Activities feature, you should setup few rules in Banner.

Procedure

  1. Access the Banner Student Activity Code Validation (STVACTC) page.
  2. Enter the activity code in the Code field.
  3. Select the activity type that is available in the Activity Type Validation (STVACTP) page.
  4. Click the Category Type LOV field to select a category type from the Activity Category Validation (STVACCG) page to associate the activity code to the selected category type.
  5. Save the record.

Define Complementary Activities document type

Steps to create and define Complementary Activities document type.

Procedure

  1. Access the Complementary Activities Document Type Validation (STVCADT) page.
  2. Specify the document type code in the Code field.
  3. Enter the document type code description in the Description field.
  4. Click Save.

Associate activity code to document type

Steps to associate activity code to document type.

Procedure

  1. Access the Complementary Activities Submission Rules (SOACASR) page.
  2. Select the activity code from the STVACTC page that you already created.
    You can see that the associated category type displayed automatically with the activity code.
  3. Enter the minimum hours and maximum hours for the selected complementary activity.
  4. Save the record.
  5. In the Activity Document Types section, click the Document Code LOV and select the document code from the STVCADT page that you already defined.
  6. Save the record to associate the selected activity code details to the activity document type.

Define Complementary Activities program rule

Steps to create and define the complementary activities program rule.

Procedure

  1. Access the Complementary Activity Program Rules (SOACAPR) page.
  2. In the Key block, enter the program and term code for which you want to create the Complementary Activity program rules.
  3. Go to the next block.
  4. In the Program and Term Rules section, enter the required hours in the Required Hours field.
  5. In the Required Hours field, enter the required number of credits that is taken to complete Complementary Activities general requirements for the program.
    You need to either enter the Required Hours or Required Credits only.
  6. In the Equivalent Credits field, enter the number of hours a student must submit to follow one credit.
  7. In the Category Rules for the Program section, enter the category code that identifies the Complementary Activity category code for the program.
    You need to either enter the Category Hours or Category Credits only.
  8. In the Category Hours field, enter the required number of hours that are taken to complete Complementary Activities category requirements for the program.
    If you decide to enter the Required Hours in the Program and Term Rules section, you need to enter the category hours. The Category Hours should not exceed the Required Hours entered in the Program and Term Rules section.
  9. In the Category Credits field, enter the required number of credits that are taken to complete Complementary Activities category requirements for the program.
    If you decide to enter the Required Credits in the Program and Term Rules section, you need to enter the category credits. The Category Credits should not exceed the Required Credits entered in the Program and Term Rules section.
  10. In the Activity Rules for the Program section, enter the activity code for the program.
    You need to either enter the Activity Hours or Activity Credits only.
  11. In the Activity Hours field, enter the required number of hours that are taken to complete Complementary Activities activity requirements for the program.
    The Activity Hours should not exceed the Category Hours entered in the Category Rules for the Program section.
  12. In the Activity Credits field, enter the required number of credits taken to complete the Complementary Activities activity requirements for the program.
    The Activity Credits should not exceed the Category Credits entered in the Category Rules for the Program section.
  13. Save the details to create a complementary activity program rule.

Approve or reject Complementary Activities submission

Steps to approve or reject the Complementary Activities submission details for admissions.

Procedure

  1. Access the Complementary Activities Submission Admissions (SOACASA) page
  2. In the Key block, specify the student’s Complementary Activities submission record details for which you want to approve or reject.
  3. In the Complementary Activities Submission section of the Base block, you will view the Complementary Activities submission details of the student ID specified in the Key block.
  4. In the Status field, select the status to specify your approval or rejection decision for the submitted Complementary Activities.
  5. In the Approval/Rejection Comment field enter your comments for the approved or rejected statuses.
  6. In the Approved Hours field, enter the number of approved hours for the submitted Complementary Activities.
  7. Click Save to submit your approval/rejected statuses.
    After submitting your approval/rejected status details, you cannot update/delete the record.
  8. In the Approval/Rejection Date field displays the system date on which the record is approved or rejected.
  9. In the Complementary Activities Summary section, view the student’s Complementary Activities hours sorted by program and category.

View Complementary Activities submission details

Steps to view Complementary Activities submission details.

Procedure

  1. Access the Complementary Activities Submission Inquiry (SOICASA) page
  2. Use the filter options on various fields available in the page such as Program, Term, ID, Activity, Category, CA Request ID, etc.
    Depending upon the filter criteria(s) in this inquiry page, you can view the Complementary Activities submission details.
