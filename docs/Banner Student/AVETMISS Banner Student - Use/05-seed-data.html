Seed Data

This chapter outlines the seed data that is included in the AVETMISS release, and also seed data in ASCGEN that is relevant to AVETMISS reporting.

Typically, seed data that is included in ASCGEN has potential for use by a number of Australian localisation products, whereas seed data that is included in AVETMISS is likely to only be needed by clients who need to be AVETMISS compliant.
