F_DELIVERY_LOC_ID f_delivery_loc_id (p_pidm, p_acyr_code, p_report_period, p_camp_code, p_key_seqno, p_insm_code, p_site_code)

Used in several activities to calculate the delivery location identifier using location mapping rules.

In the NAT00120_CU snapshot activity, the function finds records on the Location Mapping Rules (SKARLOC) page where the campus code matches the campus of each CRN. The mapping rules must be for the report collection that is used as a runtime parameter when the MDUU process is executed and for an academic year that is valid for the term of the CRN.

If there is only one rule for the matching campus code, and if on that rule on SKARLOC both Instructional Method and Student Location are blank - then the matching Delivery Location code has been found.

If there are multiple rules for the matching campus code, then this means that there are rules where Instructional Method and Student Location are not blank.
F_DELIVERY_LOC_ID (Contd) The Instructional Method on SKARLOC is compared first to the Instructional Method of the CRN (on SSASECT) and if that is blank, then the Instructional Method on SKARLOC is compared to the Session of the CRN (also on SSASECT). If the Session of the CRN is also blank, then the Instructional Method on SKARLOC is compared to the Session on the student's study path (SGRSTSP), and if that is also null, to the Session on the student's general learner record (SGBSTDN).If there are multiple rules for the matching campus and instructional method, then the Student Location is used to select the correct Delivery Location for this student and CRN.

If the student has a student attribute and if that student attribute is in the string of values for the VET-INTERSTATE system parameter and if the student's record on SGASADD is for a term code that is effective for this CRN, then the function will retrieve the Location code where the Student Location matches the student's attribute.

If the student's attribute does not match a rule on SKARLOC, or isn't listed in the VET-INTERSTATE system parameter, or if the effective term of the student attribute is for a later term than the CRN, or if the student doesn't have any student attributes - then the function compares the student's Site Code with the Student Location value from SKARLOC.
F_DELIVERY_LOC_ID (Contd) First, the function compares the Site Code from the LEARNER curriculum with the Student Location value. If a match is found, then that Delivery Location Code is used.

If the Site Code on the LEARNER curriculum is null or doesn't match any Student Location, then the function compares the Site Code on SGBSTDN (viewed on the first tab of SGASTDN) to the Student Location value. If a match is found, then that Delivery Location Code is used.

If there isn't a row for the matching campus and instructional method where student location is blank - then the function is not able to find a matching delivery location on SKARLOC and will now look at SKRTDLV (the table behind the Delivery Locations tab on the SKATORG page.

When the function looks on SKRTDLV, if there is a record that is effective for the term of the CRN where the campus code matches the campus of the CRN, then the Delivery Location code of that record will be returned.

If the function cannot find a record for the matching campus on SKRTDLV either, then Delivery Location will be null for the CRN in the ASC_VET_SNA_NAT00120_CU snapshot.

F_NAT00120_​IN_NAT_OUTCOME f_nat00120_in_nat_outcome(:academic_year, shrtckn_ptrm_date, shrtckn_pidm, shrtckn_seq_no, shrtckn_term_code, shrtckn_crn, shrtckg_grde_code_final, shrtckg_term_code, shrtckl_levl_code)

This function is used in the ASC_VET_SNA_NAT00120_IN snapshot activity to translate a local grade code to the appropriate Outcome Identifier - National value.

First, the function looks up the grade code on the SHAGRDE page to find the record where the grade code matches the latest grade for the student for the CRN, the level code matches the primary level code for the student for the CRN, and the term code is the latest term code that is earlier than or equal to the term code for the student for the CRN.

For the record on SHAGRDE:
  • If the grade is an incomplete grade and the registration status of the CRN is one of the values listed for the NSW-DISCONTINUED-RSTS or NSW-DEFERRED-RSTS system parameters, then the value for Outcome Identifier - National is null.
  • If the grade code matches one of the values listed for the SUPERSEDED-GRADE-CODE system parameter, then the value for Outcome Identifier - National is '61'.
  • When the Attempted Indicator, Completed Indicator and Passed Indicator are all 'Y', then the function re-turns a value of '20'
  • When the Attempted Indicator is 'Y' and the Completed Indicator and Passed Indicator are both 'N', and the grade is not an incomplete grade, then the function returns a value of '30'
  • When the grade is an incomplete grade, then the function returns a value of '70'
If the function cannot calculate a value, then it will return '70' as a default.
