Common file details

This section provides more information about the parameters used and the files generated for INTTRACKAUS.

INTTRACKAUS parameters

The following parameters are used for INTTRACKAUS.

Tracking Code

Tracking Code is a parameter used in the International Student Compliance and Government-Sponsored Students activities to allow users to easily differentiate between records that have been generated by different activities populating a single snapshot table.

For example, when a student takes a leave of absence, the International Student Status Changes snapshot inserts a row into the ESOS Data Snapshot (SKRSESO) table with one tracking code. If another student completes their program of study early, the International Student Early Completion snapshot will insert a row into the same snapshot table, but with a different tracking code.

Since Date

ESOS and AusAID reporting requires continual monitoring of student status and progression.

Unlike the other pages of statutory reporting, information is required as soon as the trigger event (such as a change of program) has occurred, rather than on a fixed schedule. Therefore, it is intended that the ESOS and AusAID activities included in INTTRACKAUS are run on a regular (such as daily or weekly) basis.

To ensure that the reporting activities detect only students whose status has changed from the last time the report was run, a Since Date parameter has been included in the activities. This allows you to specify a date as the starting point for detecting changes, ensuring that an entire term's worth of data does not have to be re-run. For example, an activity run on a weekly basis would involve changing the Since Date parameter every week to pick up only the previous week's changes.

Overseas Student Health Cover data (OSHC)

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot SC_SNA_OSHC This activity pulls data from various INTTRACKAUS baseline tables to populate the OSHC Data Snapshot (SKRSOSH) table. The activity uses the PIDM, program code, academic year, report period, and submission number as populate keys.
Extract SC_EXT_OSHC This activity pulls data from the OSHC Data Snapshot (SKRSOSH) table to populate the OSHC Data Extract (SKREOSH) table. The activity uses the PIDM, program code, academic year, report period, and submission number as populate keys.
Export SC_EXP_OSHC This activity pulls data from the OSHC Data Extract (SKREOSH) table to populate the OSHC Data Export (SKRXOSH) table. The activity uses the PIDM, program code, academic year, report period, and submission number as populate keys.
