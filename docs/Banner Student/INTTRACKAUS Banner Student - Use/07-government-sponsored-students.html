Government-sponsored students

Australian AusAID compliance requirements have been used as the model for Government-Sponsored Student reporting.

Most of the AusAID snapshot activities update a single snapshot table and this table is used as the source for an extract activity. Only one extract activity is needed to pull the data needed for AusAID reporting for the combination of effective term and since date values.

Government-Sponsored International Students Status Changes

Government-sponsored international students status changes cover the following scenarios.

  • Student applies for and is granted a leave of absence
  • Student's enrolment is suspended by the institution
  • Student's enrolment is terminated by the institution
  • Student chooses to withdraw from their program of studies
  • Student transfers to another institution.

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot (Status Changes) SC_SNA_AUSAID_STAT This activity pulls data from various Banner baseline tables to populate the AusAID Data Snapshot (SKRSAID) table. The activity uses the PIDM, program code, tracking code, academic year, term code, report period, submission, and since date as populate keys.
Data Extract SC_EXT_AUSAID_DATA This activity pulls data from the AusAID Data Snapshot (SKRSAID) table to populate the AusAID Data Extract (SKREAID) table. The activity uses the PIDM, program code, tracking code, academic year, term code, report period, submission, and since date as populate keys.
Data Export SC_EXP_AUSAID_DATA This activity pulls data from the AusAID Data Extract (SKREAID) table to populate the AusAID Data Export (SKRXAID) table.

Government-Sponsored International Students with Other Changes

Students with other changes will be categorised under one of the following scenarios.

  • Student needs to extend their completion date
  • Student needs to change their program/course and this affects their completion date

Monitoring Progression for Government-Sponsored International Students

The Government-sponsored international students whose grades or academic standing indicate a progression issue or a potential progression issue will be included in the snapshot.

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot (Progression) SC_SNA_AUSAID_PROG This activity pulls data from various Banner baseline tables to populate the AusAID Progression Data Snapshot (SKRSAPR) table. The activity uses the PIDM, program code, CRN, tracking code, academic year, term code, report period, submission, and since date as populate keys.
Extract (Progression) SC_EXT_AUSAID_PROG This activity pulls data from the AusAID Progression Data Snapshot (SKRSAPR) table to populate the AusAID Progression Data Extract (SKREAPR) table. The activity uses the PIDM, program code, CRN, tracking code, academic year, term code, report period, submission, and since date as populate keys.
Export (Progression) SC_EXP_AUSAID_PROG This activity pulls data from the AusAID Progression Data Extract (SKREAPR) table to populate the AusAID Progression Data Export (SKRXAPR) table.
