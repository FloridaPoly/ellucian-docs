File details for Australia

This section provides more information about the files generated for CRICOS.

CRICOS Course Data Reporting

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot ASC_SNA_CRICOS_COURSE This activity pulls data from the CRICOS Course Data (SKRCRIC) table and Program Definition Rules (SMRPRLE) table to populate the CRICOS Course Data Snapshot (SKRSCRC) table. The activity uses the program code, institution (non-person) PIDM, and effective term as populate keys.
Extract ASC_EXT_CRICOS_COURSE This activity pulls data from the CRICOS Course Data Snapshot (SKRSCRC) table to populate the CRICOS Course Data Extract (SKRECRC) table. The activity uses program code, institution PIDM, and effective term as populate keys.
Export ASC_EXP_CRICOS_COURSE This activity pulls data from the CRICOS Course Data Extract (SKRECRC) table to populate the CRICOS Course Data Export (SKRXCRC) table.
