International student compliance

Australian ESOS compliance requirements have been used as the model for International Student Compliance reporting.

Most of the ESOS snapshot activities update a single snapshot table and this table is used as the source for an extract activity. Only one extract activity is needed to pull the data needed for ESOS reporting for the combination of effective term and since date values.

International Student Status Changes

International student status changes cover the following scenarios.

  • Student applies for and is granted a leave of absence
  • Student's enrolment is suspended by the institution
  • Student's enrolment is terminated by the institution
  • Student chooses to withdraw from their program of studies
  • Student transfers to another institution

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot SC_SNA_ESOS_STATUS This activity pulls data from various Banner baseline tables to populate the ESOS Data Snapshot (SKRSESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Data Extract SC_EXT_ESOS_DATA This activity pulls data from the ESOS Data Snapshot (SKRSESO) table to populate the ESOS Data Extract (SKREESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Data Export SC_EXP_ESOS_DATA This activity pulls data from the ESOS Data Extract (SKREESO) table to populate the ESOS Data Export (SKRXESO) table.

International Student No Shows

Students who are considered to be "No Shows" will be categorised under one of the following scenarios.

  • A new student has accepted the offer of a place and has paid fees but has not attended enrolment and registration.
  • A continuing student has not re-enrolled.

International Students with Other Changes

Students with other changes will be categorised under one of the following scenarios.

  • Student has received transfer credit after their enrolment that is sufficient to shorten their course/program
  • Student needs to extend their completion date
  • Student needs to change their program/course and this affects their completion date
  • Student needs to change their program/course and this does not affect the completion date.

The following table describes the activities for this file.

Activity Type Activity Name Description
Snapshot (Transfer Credit received after Enrolment) SC_SNA_ESOS_CREDIT This activity pulls data from various Banner baseline tables to populate the ESOS Data Snapshot (SKRSESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Snapshot (Extending Completion Date) SC_SNA_ESOS_EXTEND This activity pulls data from various Banner baseline tables to populate the ESOS Data Snapshot (SKRSESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Snapshot (Curriculum Changes) SC_SNA_ESOS_ CURRIC This activity pulls data from various Banner baseline tables to populate the ESOS Data Snapshot (SKRSESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Data Extract SC_EXT_ESOS_DATA This activity pulls data from the ESOS Data Snapshot (SKRSESO) table to populate the ESOS Data Extract (SKREESO) table. The activity uses the PIDM, program code, tracking code, academic year, report period, submission number, and since date as populate keys.
Data Export SC_EXP_ESOS_DATA This activity pulls data from the ESOS Data Extract (SKREESO) table to populate the ESOS Data Export (SKRXESO) table.
Note: The data extract feature can create a data extract that can be used in Excel. The CLOB text can be converted to columns within Excel. You can use an ODBC connection to import data directly into Excel to import the contents of the ESOS Data Extract (SKREESO) table or the ESOS Data Export (SKRXESO) table directly into an excel workbook.

Monitoring International Student Progression

The international students whose grades and academic standing indicate a progression issue or a potential progression issue will be included in the snapshot.
