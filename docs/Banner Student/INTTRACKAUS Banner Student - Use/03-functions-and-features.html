Functions and features

The INTTRACKAUS module is made up of various steps and processes. These are organised as follows.

  • Set up the INTTRACKAUS: Procedures and pages are used to define elements, values, and processes that are required to produce theINTTRACKAUS extracts.
  • Create the Report: Extract and Report Generation procedures and forms are used to create and view the data snapshot and extract. This step has three stages: snapshot process, extract process, and export process.
  • View Data: The Banner Mass Data Update Utility Universal Viewer is used to view the data produced by the snapshot and extract processes.

Although the INTTRACKAUS reporting software is delivered with a default configuration, many of the functions and processes can be tailored to your institution. For example, if your institution records a student's passport number in a custom field instead of GOBINTL_PASSPORT_ID, this description can be remapped so that the INTTRACKAUS extract will refer to the custom field.

Note: Configuring the INTTRACKAUS module requires knowledge of the underlying database tables and is usually carried out with the assistance of technical staff within the institution or Professional Services.

Use of International data forms

Many of the data elements included in INTTRACKAUS extracts make use of Baseline international pages, particularly the International Information (GOAINTL) page and the SEVIS Information (GOASEVS) page.

Refer to INTTRACKAUS Reference for complete information about the INTTRACKAUS pages.

System parameters

A set of default system parameters is delivered with the INTTRACKAUS module. These parameters are used to configure the INTTRACKAUS system.

Use the Report System Parameters (SKARSYS) page to configure this data to the specifics of your implementation. Appropriate permissions are required to modify these forms. Refer to the System Parameters section for details on these parameters.
