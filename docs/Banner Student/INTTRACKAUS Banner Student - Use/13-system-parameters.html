Report System Parameters (SKARSYS) page

The following table details the system parameters that are available from the SKARSYS page.

Name Default Value Description
INTTRACK_REPORTS   Used to indicate the report collection code that has report calendar rules on the SKAREPT page for use in INTTRACKAUS reports.
SORLFOS_CSTS_COMPLETED PENDING, AWARDED Used to indicate the curriculum status codes on the SORLFOS form that correspond to pending or awarded field of study records attached to active, current OUTCOME curriculum records.
SORLFOS_CSTS_INPROGRESS INPROGRESS, STUDYPATH Used to indicate the curriculum status codes on SORLFOS form that correspond to active, current field of study records attached to active, current LEARNER curriculum records.
AUSAID_ADS_ID   If each AusAID-sponsored student's AusAID ID is stored in the Additional ID field, then this parameter allows clients to indicate the additional ID type used for recording the AusAID ID for students with an Australian Development Scholarship.
AUSAID_ALA_ID   If each AusAID-sponsored student's AusAID ID is stored in the Additional ID field, then this parameter allows clients to indicate the additional ID type used for recording the AusAID ID for students with an Australian Leadership Award scholarship.
COE_TYPE   Indicates the visa type code used to record a confirmation of enrolment.
CRICOS_ID_TYPE   Each institution's CRICOS ID is stored in the Additional ID field, so this parameter allows you to indicate the additional ID type used for recording CRICOS ID.
INTL_APPEAL   Indicates the contact type code used on the Appointments and Contacts (SOAAPPT) page when an international student has made an appeal.
OSHC   Indicates the detail code used for overseas student health cover.
OSHC_ATTRIBUTE   Indicates attribute code used when an international student has made their own arrangements for overseas student health cover.
POSTAL_ADDR_TYPE   Records the hierarchy of address type codes used to identify a student's postal address for reporting.
STUDENT_EMAIL_TYPE   Records the e-mail type code used to identify the e-mail address for students.
UNSATIS_LETTER_CODE   Records the letter code(s) used for sending unsatisfactory progress or unsatisfactory attendance letters to international students.
UNSATIS_PROGRESS_CODE   Indicates the academic standing code(s) used when the student's progress is unsatisfactory.
