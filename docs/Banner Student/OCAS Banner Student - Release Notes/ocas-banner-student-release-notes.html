Release 9.3.38 and 8.20

Banner OCAS 9.3.38 and 8.20 include regulatory enhancements and defect corrections.

OCAS Coltrane enhancement

Each year Ellucian updates the Banner OCAS application to remain compliant with the OCAS Coltrane regulatory changes. This year, Ellucian will deliver the second phase of changes initiated last year (with releases OCAS 9.3.34.1, OCAS 8.17.2, and Banner Student 8.31.1), in addition to changes for the 2025 – 2026 admissions cycle.

For the details of the phase two changes, see the OCAS Coltrane enhancement topic. Refer to the Coltrane specifications on the OCAS, Inc. website for up-to-date information.

This enhancement addresses PE0005870, PE0005872, and PE0005873 in the Ellucian Customer Center.

The Start Date Full field has been added to the Online Confirmation (OC) file as a result of the Coltrane file upgrades. OCAS, Inc. will no longer process the Start Date field.

Ellucian is including two optional scripts with this release. These optional scripts look for and find places in your existing configuration that refer to the deprecated Start Date fields. Examine these rules to determine if they should be changed to use the corresponding Start Date Full field. You can re-run these scripts.

The first script reports any Boolean Variable Definitions (configured on the Override Billing Rules (SVAOBOV) page) that reference any Start Date fields.

SELECT SVROBOV_OBOV_CODE, SVROBOV_TERM_CODE, SVROBOV_YEAR,
SVROBOV_TABLE_NAME, SVROBOV_WHERE_COLUMN
FROM SVROBOV
WHERE upper(SVROBOV_WHERE_COLUMN) LIKE 'SVROC__\_START\_DATE'
ESCAPE '\'
order by SVROBOV_OBOV_CODE, SVROBOV_TERM_CODE;

The second script reports any Numeric Variable Definitions (configured on the Override Numeric Variable Definition (SVAONUV) page) that reference any Start Date fields.

SELECT svronuv_onuv_code, svronuv_term_code, svronuv_year, 
svronuv_table_name, svronuv_select_column, svronuv_where_column 
FROM (SELECT svronuv_onuv_code, svronuv_term_code, svronuv_year,
svronuv_table_name, svronuv_select_column, svronuv_where_column
FROM svronuv
WHERE UPPER(svronuv_select_column) LIKE 'SVROC__\_START\_DATE' ESCAPE '\'
UNION
SELECT svronuv_onuv_code, svronuv_term_code, svronuv_year, 
svronuv_table_name, svronuv_select_column, svronuv_where_column
FROM svronuv
WHERE UPPER(svronuv_where_column) like 'SVROC__\_START\_DATE' ESCAPE '\')
ORDER BY svronuv_onuv_code,svronuv_term_code;
Note: These scripts are not part of the installation.

The OCAS Numeric Variable Definition (SVAONUV) page still shows SVROCCC_START_DATE and SVROCAC_START_DATE in the Select Column Field menu. The corresponding table_START_DATE_FULL fields are not in this menu.

The table_START_DATE fields in this menu are retained for historical purposes so you can review older definitions. Going forward, table_START_DATE will not be populated and should not be used. Because table_START_DATE_FULL is not a numeric field, it cannot be used to define a numeric variable.

OCAS Coltrane enhancement

The first phase of the OCAS Coltrane enhancement for the 2024 and 2025 admissions cycles included data table changes.

Minimal changes were made to Banner OCAS to accommodate the following fields:
  • Start Date Full – added in the program choice table and related tables; provides DD-MON-YYYY date information.
  • Delivery Type – added in the program choice table and related tables; identifies the delivery method associated with the program.

Subsequent to the addition of the Delivery Type field, OCAS, Inc. announced they were delaying their implementation of this information. Banner OCAS retains the Delivery Type fields in the tables, but does not provide any functionality at this time.

This phase of the OCAS Coltrane enhancement for the 2024 and 2025 admissions cycle includes:
  • Complete support for the Start Date Full functionality. This includes updating all administrative pages and batch processes that previously used Start Date.
  • You will now see date fields instead of separate year and month fields on the administrative pages to display and maintain Start Date Full.
  • Because Start Date was part of the unique (primary) key for the tables, the key structure was modified to replace Start Date with Start Date Full.

Seed data

Ellucian provides seed data for the SVRORCC_START_DATE_FULL field, which is visible on the OCAS Field Description (SVAOFLD) page.

Record ID fields

The OCAS Coltrane enhancement for the 2025 and 2026 admissions cycle includes data table changes.

These optional fields have been added:
  • Application ID – in the applicant table and related tables
  • Program Choice ID – in the program choice table and related tables
  • Education ID – in the educational data table and related tables
  • Document ID – in the supporting document table and related tables
  • Course ID – in the grade data table and related tables
  • Test ID – in the test data table and related tables
  • Course ID – in the international transcript table and related tables

Ellucian provides seed data for the SVBOFLD table for the above new fields. They are visible on the OCAS Field Description (SVAOFLD) page.

Ellucian added the Record ID fields to the appropriate tabs of the OCAS data (SVAOCAS) page as view-only fields. You can use the Banner masking capability to mask these fields. If you want to use the Banner masking capability, first set up the fields shown in the following table on the Data Display Mask Columns (GORDMCL) page for the SVAOCAS object, and then create your masking rules on the Data Display Mask Rules (GORDMSK) page.

Field you want to mask Table Column
Application ID SVROCAC SVROCAC_APPLICATION_ID
Program Choice ID SVROCCC SVROCCC_PROGRAM_CHOICE_ID
Education ID SVROCEC SVROCEC_EDUCATION_ID
Document ID SVROCSC SVROCSC_DOCUMENT_ID
Course ID (grades) SVROCGC SVROCGC_COURSE_ID
Test ID SVROCTC SVROCTC_TEST_ID
Course ID (international) SVROCIC SVROCIC_COURSE_ID

Deprecated fields

OCAS, Inc. is deprecating the fields shown in the following list. Ellucian is removing the fields from the Coltrane definition and from the XIGN tables, but is retaining the fields in other 8.31.1 OCAS tables for historical purposes. With the exception of the Start Date field, Ellucian has also retained the fields on the OCAS administrative pages.
  • Start Date – in the program choice table and related tables
  • Program Name – in the supporting document table and related tables
  • Level Achieved – in the supporting document table and related tables
  • Credential Code – in the supporting document table and related tables
  • Immigration Record Landing Date – in the supporting document table and related tables
  • Immigration Record Landing Signature – in the supporting document table and related tables

OCAS Coltrane enhancement

This first phase of the OCAS Coltrane enhancement for the 2024 and 2025 admissions cycles includes data table changes to add fields to administrative pages.

For phase one of this update, Ellucian added the following fields to all applicable OCAS tables.
  • Start date full added in the program choice table and related tables - provides DD-MON-YYYY date information.
  • Delivery type added in the program choice table and related tables - identifies the delivery method associated with the program.

Ellucian also added processing logic to the OCAS Data Processing (SVPOCAS) and OCAS Applicant Transaction (SVPOCAT) processes to accept the data from OCAS and move them into the permanent tables.

The new fields are available in the Boolean variables drop down list on the OCAS Boolean Variable Definition (SBAOBOV) page.

Warning: The implementation of these two new fields will not be complete until the next OCAS release. Before that release, the Start date full and Delivery type fields may not be consistently populated if used. Ellucian recommends against using these new fields as Boolean variables at this time.

You can see the initial valid values for the Delivery type field on the OCAS Validation Code Rules (SVROVXW) page for validation group DELTYP. Phase two will deliver updated values.

Phase one versus future phases

The Start date full and Delivery type fields were not added to any administrative pages or any other batch processes at this time. A future release will complete the implementation of this functionality.

  • The SVBOERR error table.

2023 Releases

Release 9.3.31 and 8.17.1

These release notes describe new features, enhancements, and updates in Banner OCAS.

SPBPERS_SEX field changes

As part of the Banner General enhancement that replaces the legal sex option buttons with a list of values, customers must keep the list of values in baseline Banner in sync with the list maintained on the OCAS Common Detail (SVAOCOM) page. The field label, AC015, is associated with legal sex codes.

If your institution does not make additions to the Legal Sex Code Validation (GTVLGSX) page in Banner General, you don't need to make any changes in SVAOCOM.

New page

Ellucian has added a new page, Applicant Diversity and Demographics Inquiry (SVIODEI). SVIODEI displays the applicant's diversity and demographics information by year and includes the following sections: Ethnic Group, Religion, Sexual Orientation, Disability, and Military Connected.

As part of this enhancement, Ellucian also delivered the following items:
  • seed data scripts to populate diversity and demographics values into the existing OCAS Validation Code Rules (SVROVXW) and OCAS Validation Group Code (SVVOVGP) tables
  • two new tables to accommodate diversity and demographics processing: OCAS Raw Diversity and Demographics Data (SARORDE) and OCAS Diversity and Demographics Data (SAROCDE)

This enhancement addresses PE0002351 and PE0002561 in the Ellucian Customer Center.

Statistics Canada field enhancement

The DML script that provided new OCAS clients with a standard set of values for the STVNATN table did not include values for the stvnatn_statscan_cde field. These values are required for the OCAS Data (SVAOCAS) page and are institution-dependent.

As part of this enhancement, Ellucian added the instruction on the Set up pages to remind OCAS users to update the field directly on the Nation Code Validation (STVNATN) page.

This enhancement addresses PE0002328 in the Ellucian Customer Center.
