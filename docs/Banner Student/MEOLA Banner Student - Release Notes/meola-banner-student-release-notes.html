Banner MEOLA, release notes

These release notes describe enhancements, new features, and updates in the Banner MEOLA releases.

To download documents and files that support the installation or upgrade of the two most recent major releases, click Attachment on this page to select the associated compressed file (.zip) from the displayed list.

Release 8.0.1.2

Banner MEOLA 8.0.1.2 version is a patch release that includes the security fix. To know more about the problem resolution and to view the supporting documents associated with this release, click Attachment on this page to download the documents available as attachments.

Release 9.3.27

Banner MEOLA 9.3.27 release version includes the accessibility compliance fix. To know more about the problem resolution associated with this release, click Attachment on this page to select the associated compressed file (.zip) from the displayed list.

Release 8.0.1.1

Banner MEOLA 8.0.1.1 version is a patch release that includes the Log4j fix. The release also delivers the PDF install facility. To know more about the problem resolution and to view the supporting documents associated with this release, click Attachment on this page to download the documents available as attachments.

Release 8.0.1

The Banner MEOLA 8.0.1 documentation contains all content that supports the most recent major release.

To download documents and files that support the installation or upgrade of the two most recent major releases, click Attachment on this page to select the associated compressed file (.zip) from the displayed list.

The compressed file contains the following files:

  • Banner MEOLA Release Guide 8.0.1, last revised January 2016
  • Banner MEOLA Resolutions Report 8.0.1, last revised January 2016
  • Banner MEOLA Use 8.0, last revised January 2014
  • Banner MEOLA Install Guide 8.0, last revised January 2014
