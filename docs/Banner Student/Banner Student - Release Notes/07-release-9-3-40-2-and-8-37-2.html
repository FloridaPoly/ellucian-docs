Release 9.3.40.2 and 8.37.2

The Banner Student 9.3.40.2 and 8.37.2 release includes quality improvements and technical currency updates.

Support for Banner 8 Self-Service has ended

As of January 1, 2026, Banner 8 Self-Service has moved out of Sustaining Support and has entered End of Support.

For detailed information on support statuses, please review our Support Assurance Policy.

Multi-Level Transcript Support through SHRTETC

The eTranscript Rule (SHRTETC) page is enhanced to support multi-level mapping. The Transcript Type can now be mapped to multiple academic levels instead of a single level. Institutions can now print courses from multiple levels on a single transcript.

Multi-level transcript support is now available when transcripts are generated using:

  • SHRETRN
  • SHRPESE
  • SHRTRTC

This enhancement addresses PE0007581 and PE0007568 in the Ellucian Customer Center.

Updated Banner Business Process API (BPAPI)

Updated the telephone API to support collecting the Phone Sequence number which was added as a read-only field on the General Person Telephone (SPATELE) administrative page.

This enhancement addresses PE0007591 in the Ellucian Customer Center.

Enhance Banner Student Registration to pass section-level attributes to Degree Works

With Banner Student 8.37.2, the existing queues (DW_PREQ_REQUEST and DW_PREQ_RESPONSE) are cloned as new versions (DW_PREQ_REQUEST_V2 and DW_PREQ_RESPONSE_V2).

The new queues, DW_PREQ_REQUEST_V2 and DW_PREQ_RESPONSE_V2, use a RAW payload type. RAW payload types are Oracle’s recommended method for transmitting data strings.

All supporting functions and procedures in the sfkdwaq package, which is responsible for reading from and writing to these queues, are also cloned.

Note: The DESCription queues are not modified or cloned.

A new Crosswalk Validation (GTVSDAX) page entry, JSONQUEUE/DEGREEWORKS, is introduced with the following values:

  • N (not enabled, which is the default)
  • Y (enabled)

JSONQUEUE/DEGREEWORKS is a JSON-based message queue endpoint that is used for Banner integrations with Degree Works. This endpoint acts as a switch to determine which set of queues the system can use.

  • JSONQUEUE refers to the queue or service endpoint that accepts JSON messages.
  • DEGREEWORKS refers to the target system.
Note: This endpoint requires DegreeWorks version 5.1.6.

The database procedure sfkpreq.p_prerequisitecheck is updated to read the JSONQUEUE/DEGREEWORKS endpoint and route the payload to the appropriate queues based on whether the endpoint value is N or Y.

Note: Ellucian is supplying the string that contains the necessary JSON data.

The new function f_get_prereq_request_content_v2 assembles the JSON payload in the following format:

{"correlationId":"M8JUJBNUAU.1.531896.31233.201410", "registrationTerm":"201410", "studentId":"HOSWEBPL1", "courseList":[ { "crn":20002, "subjectCode":"ART", "courseNumber":"1100", "partOfTerm":"1", "sectionNumber":"01", "creditHours":3, "attributes":["ARTL","PSOC","SOCL"] } ]}

Tip: This version includes additional section-level attributes and the partOfTerms value for each section.

This enhancement addresses PE0007316 in the Ellucian Customer Center.

New GTVSDAX rule

A new GTVSDAX page rule, JSONQUEUE, is available with Banner Student 8.37.2.

The JSONQUEUE rule defines whether the JSON queue is used for prerequisite checking in Degree Works. The JSONQUEUE rule is defined as follows:

  • The group value is DEGREEWORKS.
  • The internal code value is JSONQUEUE.
  • The sequence value is NULL.

For example:

Group=DEGREEWORKS, Internal Code=JSONQUEUE, Sequence=NULL

Note that the external code might have one of the following values:

  • Y, which indicates to use JSONQUEUE
  • N, which indicates to not use JSONQUEUE (and is the default)
Note: If the GTVSDAX page entry is missing or not valid (meaning it is not one of the values above), the external code defaults to N.

The following additional fields are now included in the course section payload and are considered during prerequisite evaluation:

  • Section level attributes
  • Section level part of term
