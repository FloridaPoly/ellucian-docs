Enhancement to student-registration-group BPAPI

The student-registration-group Banner BPAPI (v1.0.0) works with administrative pages, and not every new record uses a POST request. In cases where there is a 1:1 mapping and the page only allows updates (not insert or delete), the system uses a PUT request instead. You can change group assignments, whether that means updating an existing SFBRGRP record or creating a new one.

SHRTRTC Job Process Enhancement

The Academic Transcript (SHRTRTC) job process has been enhanced to improve transcript formatting based on the new width flag Expanded Course Width settings defined in Transcript Type Rules (SHATPRT) for each transcript rule type. This change enables more control over how course-related information is presented in the transcript output.

The job now dynamically formats the Course / Course Alias and Course Title column widths based on the value of the Expanded Course Width flag. For more information, see Print Options in Banner Student - Page Reference.

The users now have the ability to choose between two output formats for the Course Number and Course Title fields:

Format Option Course Number width Course Title width
Pre-February 2025 5 characters 30 characters
Post-February 2025 10 characters 25 characters

Release 9.3.36.1 and 8.33.0.2

The Banner Student 9.3.36.1 and 8.33.0.2 releases include quality improvements and technical currency updates.

Student file updates

The Student file has an optional Student ID field in the layout.

  • We added the column heading for these releases.
  • We will address adding the Student ID field in the records in a future release with PE0005123.

Calculations for Total Amount (TA) students

TA students are the graduates and withdrawn students who should have their TA reported. We did not historically distinguish between monies associated with GE programs and monies associated with non-GE programs. We are now making this distinction for the following fields:
  • Total Amount Student Received in Private Education Loans During Student's Entire Enrollment in the Program
  • Total Amount of Institutional Debt During Student's Entire Enrollment in the Program
  • Total Amount of Tuition & Fees Assessed During Student's Entire Enrollment in the Program
  • Total Amount of Allowance for books, supplies, and equipment included in the student's title IV, HEA COA During Student's Entire Enrollment in the Program
  • Total Amount of Grants and Scholarships

Calculations for GE programs

Calculations for GE programs are unchanged. We are accumulating for each program (Office of Postsecondary Education Identifier (OPEID) + Classification of Instructional Programs (CIPC) + credential level).

Calculations for non-GE programs

Calculations for non-GE programs are being changed. We are accumulating at the OPEID + credential level, but only for non-GE programs.

Calculations for Annual Amount (AA) students

AA students are the students who are either actively enrolled (registered) or who are have taken a leave of absence.

Values no longer reported for programs with certain characteristics

We are no longer reporting values for programs with certain characteristics. The characteristics are:
  • Program is flagged as Comprehensive Transition and Postsecondary Program (CTP).
  • Program is flagged as a prison education program.
  • Student did not receive Title IV aid for the program.
  • For AY2016-2017 standard cohort type, program is not a qualifying graduate program.
  • Program is not a gainful employment program, is in a withdrawn status, and should be excluded from the cohort.

For TA student records, we are now leaving the above fields empty.

For AA student records, we are now leaving the following fields empty:
  • Annual Cost of Attendance
  • Tuition and fees amount for award year being reported
  • Residency tuition stats by state or district
  • Allowance for books supplies and equipment
  • Allowance for housing and food
  • Institutional Grants and Scholarships
  • Other State, tribal, or private grants
  • Private loans amount

Regulations that mention a program is neither a GE nor an eligible non-GE program

We are assuming that programs that fall into this category will not be your program configuration seen on SFAGECR.

Replacement record for an existing Student record that is no longer valid

National Student Clearninghouse (NSC) specifications previously included a field to enable you to submit a replacement record for an existing Student record that is no longer valid. You can see this on the SFAGEFM page with the label “Invalidate Previous”. The valid values were Yes (invalidate) and No (don't invalidate).

There are new values for this field. The new values are:
  • T: Title IV Aid not received for the program (for NSC use only)
  • X: Not a Qualifying Graduate Program (for NSC use only. Value only applicable for AY 2016-2017)
  • R: Not a GE program and is in a Withdrawn status (for NSC use only)
  • N: No

Here is an example of how we are calculating the value in SFPGESC:

If this is the 2016:2017 aid year, AND the student’s SFAGECR row has SFRGECR_QUALIFYING_GRD_PGM_CDE <> “Y”, use X.

If the student’s SFAGECR row has SFRGECR_GE_PROGRAM_IND = “W”, use R.

If a student who is in a program specified on SFAGECR does NOT have any Title IV aid while in the program, use T.

In all other cases, use N (which is the default).

We are leaving the previous value of Y in the list of values (LOV) because you may have existing records with this value.

This field will be read-only on SFAGEFM. We will update the field label at a future time.

To calculate the new R value, we changed the program configuration on SFAGECR.

Previously, if the GE Program Ind field was selected, that meant that the program was a GE program. If the GE Program Ind field was not selected, that meant that the program was not a GE program.

We changed the GE Program Ind field as follows:

  • A Y means the program is a GE program.
  • An N means the program is not a GE program. N is the default.
  • A W means the program is not a GE program. The program is in withdrawn status.

You can update the GE Program Ind field on SFAGEFM.

You will need to review your configurations to see which (if any) of your programs may need to have the GE Program Ind field changed to a W.

Title IV funds in the aid year of the report

We previously assumed that any student would need to have Title IV funds in the aid year of the report to be included or counted. We changed our selection of students so that the selection does not rely on the presence or absence of Title IV funds. This change impacts both the student file that SFPGESC creates and the program file that SFPGEPC creates.
