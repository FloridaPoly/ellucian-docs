Release 9.3.41.2

The Banner Student 9.3.41.2 release includes quality improvements and technical currency updates.

Support for Banner 8 Self-Service has ended

As of January 1, 2026, Banner 8 Self-Service has moved out of Sustaining Support and has entered End of Support.

For detailed information on support statuses, please review our Support Assurance Policy.

Business Process APIs for CAPP Request Management

A new compliance-request-management v1.0.0 BPAPI is introduced for the Compliance Request Management (SMARQCM) page to enable automated, mass creation and management of CAPP Request records (SMRRQCM) as part of an integrated batch workflow with SMRBCMP.

The GET and POST request methods are supported.

The new BPAPI for SMARQCM allows institutions to:

  • POST CAPP requests (create SMRRQCM records) for a selected population or integration-driven workflow
  • GET existing request records to validate and monitor request creation and status

The API enforces the same Banner validations and security as the SMARQCM Admin page and supports batch-scale processing patterns. The scope of the BPAPI is limited to the following sections of the SMARQCM Admin page:

  • Compliance Request Management
  • Compliance Curriculum

Key benefits:

  • Minimizes operational errors and improves audit-ability through supported APIs
  • Ensures timely CAPP outcomes for academic decision-making and downstream processes
  • Enables evaluation of all active curricula, not just the first one processed by SMRBCMP, eliminating manual case-by-case handling

This enhancement addresses PE0007532 in the Ellucian Customer Center.

Business Process API for Study Path Management

New student-course-registration-study-path, general-student-study-path, and student-course-registration-enrollment-study-paths v1.0.0 BPAPIs are introduced for the Study Path tab on the Student Course Registration (SFAREGS) page to enable programmatic retrieval and updates of Study Path entries.

The GET and PUT request methods are supported. The BPAPI for Study Path allows institutions to:

  • GET Study Path records to retrieve current status and details
  • PUT updates to Study Path Status (SGRSTSP_STSP_CODE) in line with Banner processing logic

Updating the Study Path Status is required across multiple stages of the academic lifecycle and academic processes, including:

  • Enrollment process
  • Workflows
  • Academic dismissal processes
  • Graduation and degree conferral processes
  • Program abandonment process

The API enforces the same data fields, validation, permissions, and business rules as the SFAREGS Admin page, preserving audit-ability and integrity checks without bypassing existing effective-dating or entity/MEP restrictions.

Key benefits:

  • Enables safe automation of Study Path maintenance at scale, reducing manual effort and error
  • Supports integration of Study Path updates into larger data pipelines for onboarding, curriculum changes, and corrections
  • Improves operational efficiency and data consistency without compromising governance
  • Preserves established business rules and audit trails

This enhancement addresses PE0007544 in the Ellucian Customer Center.

Business Process API for Enrollment Study Path

A new student-course-registration-enrollment-study-paths v1.0.0 BPAPI is introduced for the Enrollment Study Path section on the Student Course Registration (SFAREGS) page to support creation and maintenance of SFRENSP (Enrollment Study Path) records.

The GET, POST, and PUT request methods are supported.

The new BPAPI for Enrollment Study Path allows institutions to:

  • POST - Create new SFRENSP records during student enrollment to register the student's enrollment study path
  • PUT - Update existing SFRENSP records to reflect changes in enrollment status, study path information, or academic status
  • GET - Query existing SFRENSP records for validation, workflow processing, and downstream use

The API follows the same business rules and validations currently enforced through Banner Admin processing through SFAREGS, ensuring that automated updates (including downstream impact) behave consistently with manual maintenance. The API fully honors the existing SFAREGS page logic and functionality in the Enrollment Study Path section, ensuring consistent behavior and downstream impact across sections, fee assessment, refunds, and all other impacted areas.

Key benefits:

  • Reduces operational effort and eliminates manual SFAREGS data entry for enrollment study path maintenance
  • Minimizes risk of human error in student registration and study path management
  • Improves student experience through faster, more accurate enrollment processing

This enhancement addresses PE0007835 in the Ellucian Customer Center.

Enhancement to Curricula Summary Learner Outcome API

The curricula-summary-learner-outcome v2.0.0 BPAPI for the Degrees and Other Formal Awards (SHADEGR) Admin page has been enhanced to support the PUT request method.

The PUT request method enables programmatic updates to all fields on the Learner Outcome and Dual Degree tabs in SHADEGR, which are mapped to the SHRDGMR table in the database.

The PUT method for curricula-summary-learner-outcome allows institutions to:

  • Update learner outcome information for degree programs programmatically
  • Modify dual degree configuration and relationships at scale
  • Integrate degree program maintenance into automated workflows

The API enforces the same data validation, permissions, and business rules as the SHADEGR Admin page, preserving data integrity and audit-ability.

This enhancement addresses PE0008128 in the Ellucian Customer Center.

Business Process API for Qualifying Paper Management

A new qualifying-paper v1.0.0 BPAPI is introduced for the Qualifying Papers for Student (SHAQPNO) page to enable programmatic management of qualifying paper records for graduate students.

The GET, POST, and PUT request methods are supported.

The new BPAPI for Qualifying Paper Management allows institutions to:

  • POST - Create new qualifying paper records with student ID, paper sequence number, qualifying paper type, and title information
  • PUT - Update existing qualifying paper records including title, dates, and qualifying paper type
  • GET - Query qualifying paper records by student ID and paper sequence number for validation and reporting

The API enforces the same business rules and validations currently applied through the SHAQPNO form, ensuring data integrity and consistency. Required fields include student ID, paper sequence number, qualifying paper type code, and title line 1. Optional fields include additional title lines and descriptive text.

Key benefits:

  • Enables automation of qualifying paper record creation and updates for graduate programs
  • Reduces manual data entry effort and minimizes errors in qualifying paper tracking
  • Supports integration with thesis and dissertation management systems
  • Facilitates bulk updates for qualifying paper information across multiple students
  • Improves operational efficiency for graduate schools managing large volumes of qualifying papers
  • Ensures consistent application of date validation rules (acceptance criteria date cannot occur before application date)

This enhancement addresses PE0008135 in the Ellucian Customer Center.
