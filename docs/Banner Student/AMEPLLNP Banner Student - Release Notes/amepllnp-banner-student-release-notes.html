Banner AMEPLLNP release notes

Ellucian typically posts release notes the day before it makes the software available to customers. You can review Banner product release dependency information in Ellucian Solution Manager or the Banner Interdependency Matrix attached to Article KB000500135 - Banner Interdependency and Compatibility Matrix in the Ellucian Customer Center.

Release documentation

The product documentation available on the Ellucian Documentation site supports the latest available version.

The following table describes where to find additional supporting documentation for the latest and previous versions.

Table 1. Supporting documentation and previous releases
Documentation type Description Where to find
Supporting documentation for latest version Includes files that support the installation or upgrade of this release and the last three major releases, Click Attachment on this page and then select the associated compressed file (.zip) from the displayed list.
Documentation for previous versions Documentation for earlier releases. This content is available to download. On the Ellucian Documentation site home page, select Previous Versions, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. All content is available in English (enus), and some content is available in Spanish (esmx).

Information about optional hot fix releases

For information about issues addressed in optional hot fix releases, access the release page for a release in the Ellucian Customer Center and view the Related Defects and Related Enhancements tabs. See Banner Application Navigator optional hot fix releases to find a link to the release page for a hot fix release.

If you cannot find a release that you expect to see here, you can search for a specific product release on the Banner Product Releases page in the Ellucian Customer Center.

Release 8.1

The Banner AMEPLLNP 8.1 release documentation contains all content that supports the most recent major release.

To download documents and files that support the installation or upgrade of the two most recent major releases, click Attachment on this page to select the associated compressed file (.zip) from the displayed list.

The compressed file contains the following files:
  • Banner AMEPLLNP readme 8.1
  • Banner AMEPLLNP Resolutions Report 8.1
  • Banner AMEPLLNP Upgrade Guide 8.1
  • Banner Student readme 8.27
  • Banner Student Page List 9.3.30
  • Banner Student Resolutions Report 8.27
  • Banner Student Resolutions Report 9.3.30
  • Banner Student 903300005 Installation Reference

Prerequisites

The minimum required releases for Banner AMEPLLNP 8.1 are as follows:
  • Banner AMEPLLNP 8.0
  • Banner ASCGEN 8.18
  • Banner Mass Data Update Utility (MDUU) 8.2

Global database consolidation

This release includes updates to consolidate Banner database objects for regional localizations into a single global database.

See the Banner General 9.3.26 and 8.16 Release Notes for more detailed information, including a list of tables and scripts.

See KB000502796 - Global Database Project Customer Communication and FAQ in the Ellucian Customer Center for additional details about the global database impact and benefits.

This enhancement addresses PR00036211 in the Ellucian Customer Center.
