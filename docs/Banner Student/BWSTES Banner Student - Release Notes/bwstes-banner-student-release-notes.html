BWSTES Banner Student release notes

Ellucian typically posts release notes the day before it makes the software available to customers. You can review Banner product release dependency information in Ellucian Solution Manager or the Banner Interdependency Matrix attached to Article KB000500135 - Banner Interdependency and Compatibility Matrix in the Ellucian Customer Center.

Release documentation

The product documentation available on the Ellucian Documentation site supports the latest available version.

The following table describes where to find additional supporting documentation for the latest and previous versions.

Table 1. Supporting documentation and previous releases
Documentation type Description Where to find
Supporting documentation for latest version Includes files that support the installation or upgrade of this release and the last three major releases. Click Attachment on this page and then select the associated compressed file (.zip) from the displayed list.
Documentation for previous versions Documentation for earlier releases. This content is available to download. On the Ellucian Documentation site home page, select Previous Versions, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. 2023 Releases

BWSTES Banner Student optional hot fix releases

Optional hot fix releases address the issues listed under the Related Defects and Related Enhancements tabs on the associated release page. This page maintains hot fix links for the current and previous year.

Hot fix release documentation

Content published to the Ellucian Documentation site for a standard Banner release also applies to the hot fix release. For example, to see the documentation related to the Banner General 9.3.25.1 release, go to the Banner General 9.3.25 standard release content on the Ellucian Documentation site.

To find previously released content for a standard release that is no longer available on the Ellucian Documentation site, go to the Previous Versions page, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. All content is available in English (enus), and some content is available in Spanish (esmx).
