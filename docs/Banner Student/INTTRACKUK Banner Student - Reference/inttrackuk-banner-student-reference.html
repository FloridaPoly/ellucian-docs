INTTRACKUK Banner Student - Reference

Pages for International Student Tracking for the UK.

Confirmation of Acceptance for Studies (SKAICAS) page

Use the SKAICAS page to enter data required to request a CAS for an applicant in the SMS portal which is not recorded in any other place in Banner.

The CAS data for the applications downloaded from the SMS portal is stored in SKAICAS. The page also displays the upload history for the Upload, Update, No Shows, and Missing Contacts Reporting.

You can also use this page to close a CAS application, if necessary. For example, if a student does not get a visa based on the CAS number for any reason (such as if the student needs to defer the start of postgraduate studies or to request a new CAS for the same term and degree program while the student already has a valid visa for a pre-sessional course), the CAS status will remains as USED in the SMS. If you need to create a new CAS application for the same person/term/program to re-apply for a visa, you can close the existing one using the Close CAS button in the Confirmation of Acceptance for Studies Data window.

When a CAS application is refused (for example, if the data provided with the application is not correct or qualification criteria are not met), the student is not issued a visa and you must either request an appeal/administrative review or create a new CAS application. You can use the Refusal Information window to record and maintain refusal-related data.

Refusal information is not available for download from the SMS. Your institution will receive the data directly from the student or from communications with UKBA.

Refusal Information window

Use the Refusal Information window to enter and display information about visa refusals and appeals for the applicant or student specified in the Key block.

The refusal information is not available for download from the SMS. Hence, the information must be entered on this window manually.

The window has a button that allows you to change the CAS status to REFUSED and, if necessary, to revert to the original status, such as if the REFUSED status was set prematurely or by mistake.

Field Description
Date of Refusal Date on which the application was refused by UKBA.
Reason for Refusal Reason the application was refused.
Set Status to REFUSED/Revert Status to: xxx Click this button to change the status of the application. The label of the button is dynamic, based on the current status.

If the status is not REFUSED, the label of this button is Set Status to REFUSED.

If the status is REFUSED, the label of this button is Revert Status to: xxx, where “xxx” represents the last status applied to the CAS application before it was changed to REFUSED.
Entry Clearance Post Name of the entry clearance post where the application was refused.
Appeal/Adm. Review Requested Check box used to specify whether an appeal or administrative review was requested.

Enter any available information regarding the appeal or review in the text box to the right of the field.
Appeal Successful Check box used to specify whether the appeal was accepted by UKBA.

Enter any available information on the appeal in the text box to the right of the field.
Further information Any further details on the refusal or appeal, such as refund information and so on.
