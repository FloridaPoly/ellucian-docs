Script

The ocas_svroprc_reports.sql script is delivered to support Banner OCAS.

This script helps you identify the program/term/start date/semester/campus that are not valid or inactive combination in the following tables as compared to the SVROPRC table.

  • SVROAFP
  • SVROALH
  • SVROALP
  • SVROCCC
  • SVROOFR
  • SVROPEX
  • SVROPOF
  • SVROPOR
  • SVRORCC
  • SVRORNK
  • SVROWLQ
  • SVROWPC

In addition, this script retrieves the records from SVROPRS and reports the program schedules that do not exist in SVROPRC (that is, any program that does not have an associated campus).

When running this script, you can enter a year for the OCAS Year parameter to find the combinations that are not valid or inactive for a particular year, or you can enter "ALL" to find combinations that are not valid or inactive for all the open OCAS years.

You can run this script at any time.
