Self-Service

Banner OCAS contains core Self-Service pages that applicants can access to view the programs to which they have applied and their institutional test results. The OCAS Web Application is an optional add-on module that you can install to allow applicants to apply for admission using Self-Service.

OCAS Self-Service menus

The following menus are delivered for OCAS Self-Service.

  • OCAS Main Menu (twbkwbis.P_GenMenu)
  • Application menu

OCAS Main Menu (twbkwbis.P_GenMenu)

The following links are displayed on this menu.

  • The View My Applications link goes to the Login page.
  • The New Applicant link goes to the Create a New Application page.

Application menu

The following links are displayed on this menu.

  • The Select OCAS Applicant Number link goes to the OCAS Applicant Number Selection Web Page (bwvkocas.P_OcasSelectOAN).
  • The Institutional Testing Results link goes to the Institutional Testing Results Web Page (bwvkocas.P_OcasInstTest). If an OCAS application number has not been selected, the OCAS Applicant Number Selection Web Page (bwvkocas.P_OcasSelectOAN) will be displayed first.
  • The Applied Programs link goes to the Applied Programs Web Page (bwvkocas.P_OcasAppliedProgs). If an OCAS application number has not been selected, the OCAS Applicant Number Selection Web Page (bwvkocas.P_OcasSelectOAN) will be displayed first.

Web pages

This section describes the following web pages.

Security Access Web Page (bwvkolog.p_wwwlogin)

This page is used to enter a Banner ID and Personal Identification Number (PIN), which will allow the applicant to access the OCAS web pages.

Setup requirements

This page has no setup requirements.

Web page fields

This page contains the following fields.

Item Description/source information
User ID Banner user ID.
PIN Personal identification number.
Updates to Banner

This page does not update information in the Banner database.

Buttons/icons on this page

This page contains the following buttons/icons.

Button/icon Action
Login Goes to the Login Verification Security Question and Answer Page (bwvkolog.P_ValLogin) when the applicant is logging in for the first time. The ID and PIN must be entered before this page opens.

Goes to the Login Verification Change PIN Page (bwvkolog.P_ValLogin) if the applicant’s PIN is expired. The ID and PIN must be entered before this page opens.
Forgot PIN? Goes to the Security Answer Page (bwvkolog.P_ValLogin).

Web Page Fatal/Warning Error Messages

Message: Authorization Failure - Invalid User ID or PIN.

Source: bwvkolog.P_ValLogin

Action: Enter the correct user ID and PIN.

OCAS Applicant Number Selection Web Page (bwvkocas.P_OcasSelectOAN)

This page is used to select the year and application number with which to view institutional testing results and applied programs.

The name and Banner ID of the applicant is displayed on the right side of the web page. When a year and OCAS application number have been selected, that information is also displayed on the right side of the web page.

The web page only displays applicants that have an application with an active status (SVVOLTR_APPL_STATUS = A).

Institutional Testing Results Web Page (bwvkocas.P_OcasInstTest)

This page is used to display the institutional testing results of the applicant. The data is from the SVROETD table. If a year and application number has not been previously selected, the OCAS Applicant Number Selection web page is displayed first.

The selected OCAS year and application number, and the name and Banner ID of the logged-in applicant are displayed on the right side of the web page.

Only the tests where the Display on Web check box is selected (SVROTSC_DISP_WEB_IND = Y) on the SVAOTSC form will be displayed.

Setup requirements

The following setup is required for this page to work as expected.

Item Description
OCAS Test and Sub Test Code (SVAOTSC) page Only the tests where the Display on Web check box is checked (SVROTSC_DISP_WEB_IND = Y) will be displayed.
Web page fields

This page contains the following fields.

Item Description/source information
Test Code OCAS test code.
Subtest Code OCAS sub-test code.
Test Description Description of the test code.
Test Date Date the applicant achieved the test marks.
Raw Score Score in its natural form before being normalized using one of the four methods defined in SVROTSC_NORM_METHOD_IND. This value is one of the ones defined in any of the following tables: SVRONCR, SVROPCT, SVROGEQ and SVROSTN.
Normalized Score Numeric score assigned to the test. When calculated, the SVAOETD form asks for the raw score, and then calculates the normalized value using the Calculate button. This checks the method defined in the SVROTSC_NORM_METHOD_IND field, then depending on this value, the form finds the corresponding table where ranges are stored and tries to match the range. When the range is matched, the SVAOETD form brings back the score from the corresponding table (SVRONCR, SVROPCT, etc.) and assigns it to SVROETD_NORMALIZED_SCORE. If a value is not found, zero is assigned as the value.

Applied Programs Web Page (bwvkocas.P_OcasAppliedProgs)

This page is used to display the programs to which the applicant has applied. If a year and application number has not been previously selected, the OCAS Applicant Number Selection web page is displayed first.

An applicant’s active, alternate and inactive programs are displayed. The data is from the SVVOLTR view.

The selected OCAS year and application number, and the name and Banner ID of the logged-in applicant are displayed on the right side of the web page.

If a student is waitlisted for a program and you have defined a notice on the OCAS Control (SVAOCTL) page, the text of the notice is displayed on this page.

you can now include a notice on the Applied Programs Web Page (bwvkocas.P_OcasAppliedProgs) that lets waitlisted applicants know their status.

A record will be displayed for every CC program (active or inactive) to which the applicant has applied. Only active applicants (SVROCCC_STATUS = A) are displayed. If an applicant is not active, the following message is displayed: Please contact your Admissions Officer.

The data that is displayed is determined by the value in the Offer Active Date field on the SVAOCAS page, and the values in the Web Display Date and Web Exclude Indicator fields on the SVAOPRS and SVAOTCT pages. The queue data will be displayed on the web page if the system data is greater than or equal to the value in the Offer Active Date field (when the value is not null). If the Offer Active Date field has a null value, then the system date must be greater than or equal to the value in the Web Display Date field on SVAOPRS (when the value is not null). If the Web Display Date field on SVAOPRS has a null value, then the system date must be greater than or equal to the value in the Web Display Date field on SVAOTCT.

Note: The information about the applicant will be viewable all the time, however, the data that is queue related will only be viewable depending on the values in the Web Exclude Indicator and the Web Display Date fields.
Setup requirements

The following setup is required for this page to work as expected.

Item Description
OCAS Program Schedule Maintenance (SVAOPRS) page If the value for the Web Exclude Indicator field on the SVAOPRS page is Y, the data is not displayed. If the value is N, the data is displayed. If the value is null, the queue data will be displayed if the Exclude from Web field (SVROTCT_WEB_EXC_IND) on the SVAOTCT form is null.
OCAS Term Control (SVAOTCT) page If the value in the Exclude from Web field (SVROTCT_WEB_EXC_IND) on the SVAOTCT form is Y and the Web Exclude Indicator field (SVROPRS_WEB_EXC_IND) on the SVAOPRS form is null, then the program/term queue data will be not displayed.
OCAS Data (SVAOCAS) page The Offer Active Date field (SVROCCC_OFFER_ACTIVE_DATE) on the SVAOCAS form will be used to indicate if the Offer data and any other Queue data (such as waitlist, refusal, etc.) can be viewed from this page. If the date the user is logged in to the web page is equal to or later than the Offer Active Date, then the data will be displayed.

If the SVROCCC_OFFER_ACTIVE_DATE field has a null value, then the web page looks at the value in the Web Display Date field (SVROPRS_WEB_DISP_DATE) on the SVAOPRS page. If the SVROPRS_WEB_DISP_DATE field has a null value, then the web page looks at the value in the Web Display Date field (SVROTCT_WEB_DISP_DATE) on the SVAOTCT form. If the SVROTCT_WEB_DISP_DATE field has a null value, then no data can be viewed.

The Offer Active Date field (SVROCCC_OFFER_ACTIVE_DATE) is not displayed on the web page, it is only used in the logic.
OCAS Control (SVAOCTL) page If you want a notice that lets waitlisted applicants know their status to be displayed on this page, define the text of the notice in the Waitlist General Statement field.

Missing Requirements Web Page (bwvkocas.P_OcasMissReq)

This page displays the requirements that an applicant is missing in the OCAS year. The selected OCAS year and application number, and the name and Banner ID of the logged-in applicant are displayed on the right side of the web page.

An applicant can have many combinations for the same program on the eligibility output table, however, only the data attached to the most recent category for the most recent stage is displayed. The applicant will never see more than one output for the same program combination. The data is retrieved from the SVVOLTR view.

Setup requirements

This page has no setup requirements.

General Requirement Description Description of a missing general requirement.

Missing Documentation Web Page (bwvkocas.P_OcasMissDoc)

This page displays the documentation related alerts that an applicant has in an OCAS year.

The data is from the SVVOLTR view. A record is displayed for every alert that belongs to the MDOC (missing document) group and alert code. If the same alert code exists multiple times for the applicant, the page will display the most recent alert.

The selected OCAS year and application number, and the name and Banner ID of the logged-in applicant are displayed on the right side of the web page.

Setup requirements

This page has no setup requirements.
