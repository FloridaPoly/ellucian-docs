Packages

This section describes the packages delivered for Banner OCAS.

OCAS Field Validation (svkoca1.sql/svkocas.sql) package

Package to perform validations for all the OCAS raw fields.

Identify Existing Applicants - OCAS Data page (svkocd1.sql/svkocdp.sql) package

Package to identify potential duplicates or perfect matches in Banner OCAS for the incoming applicant records that come from the input in the OCAS Data (SVAOCAS) page.

You can also insert personal information into the Banner baseline tables, such as SPRIDEN, SPBPERS, SPRTELE, GOREMAL, and SPRADDR, if applicable, when the applicant records are new to the Banner system.

Alerts Management (svkoal1.sql/svkoalp.sql) package

Package to handle alerts management.

Process OCAS Transactions (svkoct1.sql/svkoctp.sql) package

Package to handle transaction processing. It contains various functions that are used through all the OCAS modules.

Letter Generation (svkolt1.sql/svkoltr.sql) package

Package to generate data fields used in the OCAS Letter Data (SVVOLTR) view that will be used when generating letters.

Eligibility and Scoring Calculation (svkoes1.sql/svkoesp.sql) package

Package used when calculating eligibility and scoring.

Generate Fields in SVVOCAC (svkocv1.sql/svkocvw.sql) package

Package used by the OCAS Applicant Data (SVVOCAC) view when building the eligibility/scoring rules.

Build OCAS Web Pages (bwvkocas1.sql/bwvkocas.sql) package

Package used to build the OCAS web pages.

Operate Security Web Page (bwvkolog1.sql/bwvkolog.sql) package

Package used to operate the OCAS Security Access web page.
