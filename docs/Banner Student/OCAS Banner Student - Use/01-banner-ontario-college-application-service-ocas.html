Banner Ontario College Application Service (OCAS)

The Ontario College Application Services (OCAS) Centre is responsible for collecting and processing information for all first-year students applying to a full-time program at an Ontario college. The OCAS Centre collects and distributes application and acceptance data to the colleges.

A typical application cycle begins late November for the following Fall, Winter and Summer sessions. OCAS processes the initial applications and subsequent updates. OCAS makes transaction files available to the schools on a daily basis. The institutions must then read the OCAS data, perform detailed edit checks, generate error reports and suspend transactions that are not valid.

Banner OCAS allows colleges to collect the data from OCAS, return data to OCAS, apply local rating/ranking algorithms to the data to help with automatic selection and matching of students to programs, and manage online confirmation.

Note: You must meet the following requirements before you install the release and process the OCAS COLTRANE XML files in your production database.

Before you install this release, all of existing OCAS application data loaded from COLTRANE DAT files must be processed, and all data errors must be cleared because some of data errors generated from the DAT files cannot be cleared with this release.

Banner OCAS can perform the following functions:
  • Process OCAS data
  • Manage online confirmation
  • Manage applications
  • Communicate with students
  • Determine program eligibility
  • Create and calculate program scoring rules
  • Create and calculate ranking rules
  • Process offers
  • Process acceptances

Process OCAS data

Banner OCAS allows you to do the following when processing Banner OCAS data.

  • Read and store Banner OCAS raw data files
  • Edit the Banner OCAS raw data
  • Generate Banner General Person information for the applicant
  • Assign new applicants to an administrator
  • Correct OCAS raw data that has an error condition.

Manage online confirmation

OCAS provides the ability for Ontario college applicants to respond to their Offer of Admission using the Web. Institutions will be able to receive data from the OCAS office regarding the online confirmation made by applicants to the programs at the institution.

The file related to online confirmation (Offer Data Error file) is different than the normal COLTRANE file that is received with the regular applications (raw data file). The COLTRANE file is the file that contains data about new applicants that applied to the institution and the status of their applications.

The Offer Data Error file is where the OCAS office reports if errors occurred while the online confirmation file (sent by the institution to OCAS) was being processed.

Manage applications

When an application is received, it will be assigned to an admissions administrator for processing. Many factors need to be evaluated to finalize an application.

Applications need to be categorized as OSSD, mature student, or international student. A great deal of data will be collected including transcripts, test scores, checklist items, etc. Many iterations of data may be received from OCAS for an application before all the data has been received to facilitate making an assessment on program eligibility, and ultimately the issuance of an offer. Each application may contain up to three program requests per institution. Each of these requests will be evaluated on its own merit. Some of the assessment can be done automatically but some information will need to be entered manually.

Banner OCAS allows you to do the following when managing applications:
  • Process OCAS transactions and categorize the applicant
  • Manually input complete applications
  • Manually input courses and tests not included in OCAS file.

Communicate with students

An inherent part of the OCAS application process is communicating with prospective students. Numerous letters and materials need to be sent to students at various times.

These actions are dependent on the program and the amount of information that is available for an applicant. Examples of correspondence include acknowledgment of receipt of the application, request for additional information, request to attend information seminars, etc.

The OCAS Transaction Letter Control (SVAOTLC) form will be used to enter letters that can be generated when processing OCAS transactions.

Prospective students will also be able to view the results of the tests they wrote at the institution, and the details of programs to which they applied. A Web page exists that will allow applicants to track their applications. This way, applicants will be able to see the programs to which they applied, the tests that they wrote at the institution, the missing requirements for every program, and the existence of an offer, waitlist, etc.

Determine program eligibility

For each program to which an applicant applies, it is necessary to do a compliance check to see if the student meets the eligibility criteria.

Depending on the outcome, numerous alternative actions can take place including - rejection, offer, wait-listing, or alternate program. A complex structure of rules needs to be built to perform the evaluations.

Banner OCAS allows you to do the following when determining program eligibility:
  • Normalize course, tests and grades
  • Create rules for program eligibility
  • Calculate applicant eligibility based on eligibility rules.

Create and calculate program scoring rules

Most colleges categorize a program as over-subscribed or open.

Over-subscribed programs typically have a limited number of seats available, and usually there is stiff competition to fill these seats. As a result, colleges devise creative schemes to assign a score or rating to individual applicants. The score is often based on academic grades but can also be based on more subjective criteria. Therefore, the scores are ranked by program, and a selection process has been developed to determine which applicants receive an offer, which are wait-listed, which are offered an alternative and which are rejected.

Some applicants can be offered positions early in the process, others are subjected to the ranking process. Others, late-applicants, are processed on a first-come first-serve basis as long as they meet the minimum cut-off score requirement if applicable.

Banner OCAS allows you to do the following when creating and calculating scoring/ranking rules:
  • Create the scoring rules
  • Calculate the score for an applicant
  • Calculate the score for an applicant in a given program.

Create and calculate ranking rules

Ranking rules are used to calculate the ranking of an applicant based on the score. The ranking process ranks and grades selected applicants, which is used to place them on offer, wait or refusal lists.

  • Create the ranking rules
  • Calculate the rank of an applicant
  • Calculate the rank of an applicant in a given program.

Process offers

The actual process of generating offers is time restricted. These times are established by the province. The whole process involves applying the ranking system above, generating letters and managing the various queues - offer, waitlist, alternatives and rejections.

Process acceptances

When an applicant decides which offer to accept, they remit an acceptance form to OCAS. OCAS in turn sends an electronic transaction to the colleges reflecting the applicant’s decision. The College must process these transactions.

If the student accepts, then additional actions occur including further correspondence with the applicant, generation of a Banner Student Record, generation of a bill, offer of a scholarship, etc.

Banner OCAS allows you to do the following when processing acceptances:
  • Manually process acceptances
  • Automatically process acceptances
  • Generate admission information in Banner for the applicant
  • Generate the gross amount of fees per program, which is in the offer letter
  • Offer scholarships.
