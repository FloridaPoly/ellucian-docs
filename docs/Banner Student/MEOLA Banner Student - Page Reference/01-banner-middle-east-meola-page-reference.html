Application Form Maintenance (SYAOAFR) page

Use the SYAOAFR page to create and configure the online application forms as per the institution requirements. Administrators use this page to setup the core and optional data elements that govern the online application page. Administrators can create, copy, and modify the page information and rules for each term.

Use this section to specify the term code and the application page name for which you want to define the rule settings as per the institution needs.

Field Description
Term Term code for which the application page is valid.

Summary button Click this button to display all of the online application forms that have been created. This button opens the Application Form Inquiry (SYIOAFR) page.

Processing options

There are several processing options available from the Options menu.

Copy Application to a New One

This option displays the Copy Application window in which you can copy the application page and term specified in the Key block to the target term and page you specify in the window.

Mark Application to be “In Process”

This option changes the Status field in the Application Form Maintenance section to In-Process. If the application page has been used by applicants, meaning records associated with the application page exist in the Online Admission Non-student Application Table (SYBONAP), the status cannot be changed and the system displays a message that the page has been used and cannot be changed.

Mark Application to be “Released”

This option changes the Status field in the Application Form Maintenance section to Released. If all objects needed for an application page are not in place, the system displays a message with details about which settings are missing or incorrect and that the application page is cannot be marked Released.

Processing options

There are several processing options available on the Options menu.

Study Preferences Control (SYAOSCT)

Selecting this option will open the SYAOSCT page which lists only the study preferences that are defined for the selected term and application page entered in the Key block.

Select Excluded Applications

Selecting this option displays the Generate Exclude Applications window in which you can specify the rule set and reasons for rejecting. The applications that satisfy the rule set will be excluded by this process and will not be eligible for the offer.

Note: You can only run and audit this process. The process results are only temporary and the rejection will not be applied to the applications during this processing.

View Excluded Applications

Selecting this option will display the Exclude Applications Process Results window which lists all the applications that are rejected by the exclude processing.

Process Excluded Applications

Selecting the option will apply the excluding process results to the applications. After this process is executed, the actual applications will be permanently rejected.

Run application Process (Audit)

Selecting this process will display the Run Application Process window. The option runs the scoring and offer process for the selected term and application page in the Key block. You can also run this process only for specific study preferences and category associated to the study preferences when you select the respective values from the LOV.

In the Run Application Process section, select the Run Offer Process Only check box to run the offer process without running the eligibility and scoring processes.

Note: This process is a trial run and is for view only. The actual applications will not be affected.

Run application Process (Update)

Selecting this process will display the Run Application Process window. The option runs the scoring and offer process for the selected term and application page in the Key block. You can also run this process only for specific study preferences and category associated to the study preferences when you select the respective values from the LOV.

In the Run Application Process section, select the Run Offer Process Only check box to run the offer process without running the eligibility and scoring processes.

Note: This process is a real run and the actual applications will be processed.

Reallocate Offered Seats

Selecting this process will reallocate already offered applicants to their higher priority study preference that come available after the applicants for the higher priority study preference seats are removed due to rejection.

This will cause freeing the existing seats and moving the applicants to new study preference seats.

Announce Offer Results

Selecting this process will announce the offer results to the applicants in the Online Application Summary page.
