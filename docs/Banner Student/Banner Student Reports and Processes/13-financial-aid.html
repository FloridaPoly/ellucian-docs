SUSI File Import (SOPSUIM)

This process allows the administrator to import the data received from the SUSI files. This process is common for all the types of file.

The administrator must enter valid parameters to run the SOPSUIM process successfully and the process generates the following files:
  • Lis file – Displays the file with process parameter information and version number. It also displays the number of processed, duplicate, error, unmatched and suspended records.
  • Log file –Displays in details the information of the record with the row number.

With a successful import of the Registration, Verification and Validation file, the SOPSUIM process stores the data as follows:

Table 1. Data storing in tables with varying file types
File Type Data stored in table
Registration SORSURG
Validation SORSUFE
Verification SORSURG

Additionally the data is also stored in the SORSUSA table irrespective of the file type. The SORSUSA table is always updated with the latest data. The purpose of SORSUSA table is to store current award eligibility, registration progress and award amount for the students who are eligible for Student Universal Support for Ireland (SUSI) grants.

Parameter Name Required? Description Values
Academic Year Yes Enter an valid academic year. Academic Year Validation (STVACYR) page
File Name Yes Enter the name of the file to be imported without any file extension.  
File Type Yes Enter the file type.
  • RG- Registration file
  • VA- Fee Validation file
  • VR- Verification file

SUSI File Export (SOPSUEX)

SOPSUEX process is used to export the Registration, Fee Validation and Verification files back to SUSI.

The administrator must enter valid parameters to run the SOPSUEX process successfully and the process generates the following files:
  • Lis file – Displays the file with process parameter information and version number.
  • Log file –Displays message when the process is completed successfully or else displays the error message if any.

The process exports/create the file in the user's home directory.

The process exports the file in the format filename_oneupnumber.xlsx.

Parameter Name Required? Description Values
File Name Yes Enter the name of the file to be exported without any file extension.  
File Type Yes Enter the file type.
  • RG- Registration file
  • VA- Fee Validation file
  • VR- Verification file
Export Fee Amount Yes Enter your choice for exporting fee payable amount into the file.
  • Yes
  • No
