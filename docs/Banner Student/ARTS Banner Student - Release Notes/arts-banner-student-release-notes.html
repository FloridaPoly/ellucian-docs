Release 8.8.1

The Banner ARTS 8.8.1 release version delivers the migration of all the TCSI element references (such as Program Title, FOE/CIPC, FOE Type, Course Type, and Org PIDM) from the SKRDRCO table to the SMRPFPA table.

To support the release enhancements the following are the changes to satisfy PE0007471.

Changed Views Changes
SGVCSUB Addition of the ARTS_DEFAULT_ORG_ID parameter reference from the GUACONF page.
SGVPSUB Addition of the ARTS_DEFAULT_ORG_ID parameter reference from the GUACONF page.
SGVCPRG Changes to get the PROG_TITLE column from SMRPFPA table instead of SKRDRCO table, Field of study code, and Field of study type code from STVMAJR.
SGVPPRG Changes to get the PROG_TITLE column from SMRPFPA table instead of SKRDRCO table, Field of study code, and Field of study type code from STVMAJR.
SGVCTRN Addition of the ARTS_DEFAULT_ORG_ID parameter reference from the GUACONF page.

Banner ARTS releases for the year 2025.

Release 8.8

The Banner ARTS 8.8 release version includes a few regulatory enhancements. The release also includes a few defect fixes.

To support the regulatory enhancements, the following updates are available with the Banner ARTS 8.8 release.

Changed process

The SOPARTS process delivers updates to automatically trim the 10-digit student IDs to nine digits, by removing the excess characters from the left-hand side (LHS) and eliminating spaces from both ends and in between, before processing. This update ensures seamless integration with Banner's 9-digit ID standard, preventing errors during data insertion. This enhancement satisfies PE0005733.

Changed views

List of view changes for this release.

Changed Views What is the change?

SGVCSUB

SGVPSUB

 Updates to dynamically calculate the EFTSL (Equivalent Full-Time Student Load) by dividing Credit Hours by a configurable divisor when EFTSL data is unavailable, and bill hours are zero, ensuring accurate calculations.

Administrators can update the divisor in GUACONF, and the views validates to ensure that the EFTSL does not exceed the 1.0 threshold for the full-time students. If the EFTSL exceeds 1.0, the Subject Weighting is set to 1.0.

These enhancement satisfy PE0005734.

New system parameter

To support the EFTSL calculation enhancement, the new ARTS_EFTSL_CONFIGURABLE_CALCULATION is available in the GUACONF page under the Configurations window, with the application ID APAC. The new parameter serves as a configurable divisor in the ARTS process, allowing the calculation of the Subject Weighting value by dividing the Credit Hours, when EFTSL data is unavailable and billable hours are zero.

This enhancement satisfies PE0005734.

2024 Releases

Banner ARTS releases for the year 2024.

Release 8.7

The Banner ARTS 8.7 release version includes a few regulatory enhancements. The release also includes a few defect fixes.

To support the regulatory enhancements, the following updates are available with the Banner ARTS 8.7 release.

Changed views

List of view changes for this release.

Changed Views What is the change?

SGVCSUB

SGVPSUB

 Updates to ensure the legacy values are right-padded with spaces instead of left-padded with zeros. This defect fix satisfies PD0013624.
SGVPSUB Updates to the view to show the subject details with both active and inactive program study paths. This enhancement satisfies PE0004258.

SGVCPRG

SGVPPRG.

 Updates to refinement to the program term logic to avoid duplicate of courses and subjects in the result file. This defect fix satisfies PD0013624.
SGVSTUD. Updates to the view to add a new condition for WITHHELD_CDE mapping to ensure the SKRRMAP table entries are present for the WITHHELD_CDE mapping. This enables to get the student's correct WITHHELD status. This enhancement satisfies PE0004260.
Note:
Ellucian recommends the following one time configuration:
  • Create a TAC folder in the SFTP home and place all the files in the TAC folder.

    For example, for Windows, your SFTP home location is c:/user/test and your SFTP path is c:/user/test/TAC. For UNIX, your SFTP home location is /user/test and your SFTP path is /user/test/TAC.

  • Update the SFTP credentials in the SOAREST page. The user must add the following details:
    • URL: IPAddress
    • User name: SFTP user name
    • Password: SFTP password
    • Enable SFTP at port 22.
