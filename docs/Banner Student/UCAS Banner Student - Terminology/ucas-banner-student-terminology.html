UCAS Banner Student - Terminology

An alphabetical list of functional and technical terms used in Banner UCAS along with the definitions for those terms.

ABL

Awarding Body Linkage, a procedure where UCAS notifies institutions of the results of examinations. Also known as EBL.

API

Application programming interface. API is a set of methods through which an application exposes business logic, data or both. For Banner, this refers to the Banner Common Business APIs that all client application types (including messaging clients) must use. These APIs provide consolidated business logic to make Banner “messaging enabled.”

For more information about the Banner Student APIs, see the Banner Student TRM Supplement.

Attribute

A column reference element in the SKASSDT table to filter data mappings used in conjunction with Entity.

BTEC

Business and Technology Education Council

Campus

UCAS campus code and Banner SAAADMS campus code

College

Banner SAAADMS college code

Degree

Banner SAAADMS degree code

DFE

Department for Education (United Kingdom Government Department)

EBL

Examination Board Linkage, a procedure where UCAS notifies institutions of the results of examinations. Also known as ABL.

Entity

A table element in SKASSDT to filter data mappings used in conjunction with Attribute.

Get Method

The XML-Link operations used to download data from UCAS to Banner.

GNVQ

General National Vocational Qualification

GTTR

Graduate Teacher Training Registry, former name of the central agency for applications to teacher training courses from graduates. Now called UCAS Teacher Training (UTT).

Level

Banner level defined in curriculum rules.

Major

Banner major defined in curriculum rules.

Mapping

Allowing UCAS codes to be converted into institutional codes.

Marvin

Marvin is the name of the offer coding system used by UCAS. When transmitting data to and from UCAS, Marvin uses shorthand codes that can be expanded if, for example, the data is to be used in a communication to the applicant.

NMAS

Nursing and Midwifery Admissions Service. Central agency for applications to Nursing and Midwifery diploma courses. NMAS admissions have been processed within the UCAS Admissions System from the start of the 2008/09 admissions cycle.

NVQ

Non Vocational Qualification

ODBC-Link

Open Database Connectivity method of transferring data to and from the UCAS database; was formerly known as Hercules. No longer supported in Banner UCAS.

ODBC-Link Common Views

General reference data that can be viewed by any institution, such as a list of institutions and associated codes, domicile descriptions and codes, and disability descriptions and codes.

ODBC-Link Institution Views

Applicant data views specific to an institution, such as offers made to applicants, applicant addresses and applicant choices.

Set method

The XML-Link operations used to upload data (transactions) from Banner to UCAS.

ODBC-Link Institution Views

Institution specific reference data, which can be updated, such as institution contact references and groups, course keywords, and course vacancies.

Targets

Institutional targets for admissions

Target Group

Filtered group to which to apply admissions targets.

UCAS

Universities and Colleges Admissions Service

UTT

UCAS Teacher Training, central agency for applications to teacher training courses from graduates. Formerly called Graduate Teacher Training Registry (GTTR).

XML-Link

Web-service method for transferring data to and from Banner.
