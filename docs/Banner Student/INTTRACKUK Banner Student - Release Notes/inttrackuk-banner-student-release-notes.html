Release 9.3.42 and 8.10

Summary of the Banner INTTRACKUK 9.3.42 and 8.10 release updates.

Technical Currency Upgrades

As part of ongoing technical currency initiatives, Banner General Java batch programs have been upgraded to support the latest versions of key Spring frameworks. This enhancement ensures improved compatibility, performance, and alignment with modern development standards.

Banner General Java batch programs now support Spring Framework 7.x, Spring-boot 4.x and Spring-batch 6x libraries at runtime.

Modified java processes: SORGCAS

This enhancement addresses PE0008177 in the Ellucian Customer Center.

New Data Connect Pipelines

Two new Data Connect (DC) pipelines are introduced to retrieve agency and agent-related data from Recruit and insert or update in Banner. The Integration API intt-agent-transactions is used in DC pipelines call.

New DC Package Name: INTTRACK AGENCY AGENT RECRUIT INTEGRATION

Pipeline 1 – Agency GET Pipeline

Retrieves agency-related data (Agency, Branch, and Primary Contact) from Recruit through the Integration API intt-agent-transactions and API in turn calls function fn_agency_data_processing of SKKICAS package and inserts or updates the records in Banner. During pipeline execution, an error file named INTT_AGENCY_TRANSACTIONS_P_ERROR.txt is generated.

This file contains a summary of the processing results, including:

  • Number of records processed
  • Number of records skipped
  • Reason(s) for any skipped records

Pipeline 2 – Agent GET Pipeline

Retrieves agent data from Recruit through the Integration API intt-agent-transactions and API in turn calls function fn_agency_data_processing of SKKICAS package and inserts or updates the records in Banner. During pipeline execution, an error file named INTT_AGENT_TRANSACTIONS_P_ERROR.txt is generated.

This file contains a summary of the processing results, including:

  • Number of records processed
  • Number of records skipped
  • Reason(s) for any skipped records
Note: Request for new DC pipelines and the new INTTRACK DC pipelines depend on INTTRACK 8.10, INTTRACK 9.3.42, Integration API 9.42 versions. For more information about Data Connect pipeline and crosswalks, refer to the INTTRACK Pipelines section of the INTTRACKUK Banner Student - Use content.
Note: Before creating jobs to use these pipelines, ensure the Ethos Proxy API Key is set in the pipeline parameter Ethos API Key. This key is required to authenticate all Ethos Proxy API calls made by the pipeline.

Follow the procedure in INTTRACK Pipelines available in the INTTRACKUK Banner Student - Use content.

This enhancement addresses PE0008175 in the Ellucian Customer Center.

Modified MDUU activity

The ESC_GEN_CAS MDUU activity is modified to populate SKAICAS page fields Course Hours Per Week, Course Includes Remote Delivery, Is 21% - 40% of Course Delivery is Remote, Applicant is Undertaking a Work Placement as Part of The Program check box (Work Placement Details tab), Percentage of Work Being Undertaken (Work Placement Details tab), If Percentage More Than Permitted, Supply Justification (Work Placement Details tab), Program Fees First Year Only, Program Fee Comments, Program Fee Includes Accommodation Costs check box, Accommodation Fees First Year Only, Program Requires ATAS check box, Research Program check box, Joint CAS check box, Joint CAS Program with values from GOANPID page for Program, Campus, Major and Concentration combination for UKVI_PROGRAM SEID code.

To support this functionality, the SKKICAS package is modified to add new functions fn_get_gornpid_value and fn_get_joint_cas_value.

Note: New seed data, PRE_SESSIONAL_ACADEMIC_LEVEL_CODES, has been introduced for the GKAKSYS page, where the program’s degree level description must be maintained. If multiple values are required, they can be configured as comma-separated entries.

When the ESC_GEN_CAS MDUU process is run, the Joint CAS check box and Joint CAS program values for pre-sessional programs are automatically populated. This is achieved by comparing the PROGACADLVL code from the GOANPID page with the values configured under PRE_SESSIONAL_ACADEMIC_LEVEL_CODES parameter in GKAKSYS page.

In essence, the program’s degree level description is mapped to the PROGACADLVL code in GOANPID through the PRE_SESSIONAL_ACADEMIC_LEVEL_CODES parameter defined on the GKAKSYS page.

Note: The Joint CAS indicator and Joint CAS program will be automatically populated when the ESC_GEN_CAS MDUU process is executed, provided that the decision in SAADCRV is first recorded for the pre-sessional program and then for the main program, and both belong to different programs. If the values are not auto-populated, they must be selected manually on the SKAICAS page.
Note: When both a main program and a pre-sessional program are involved, ensure that the ESC_GEN_CAS MDUU activity is always executed for the most recent term.

This enhancement addresses PE0008040 in the Ellucian Customer Center.

Release 9.3.41.1 and 8.9.0.1

Summary of the Banner INTTRACKUK 9.3.41.1 and 8.9.0.1 release updates.

Enhanced CAS record status management

The Confirmation of Acceptance for Studies (SKAICAS) page is enhanced to support API-based status updates through the student-acceptance-confirmations-close-cas API. The Close CAS button on the SKAICAS page now updates CAS record status using the API, providing improved integration capabilities and workflow automation.

This enhancement enables users to transition SKAICAS records from USED status to CLOSED status through standardized API calls, supporting better integration with external systems and automated workflows.

Close CAS button functionality:

The Close CAS button on the SKAICAS form provides the following functionality:

  • Identifies SKAICAS records where skaicas.casStatus = 'USED'
  • Updates the record status to CLOSED through the student-acceptance-confirmations-close-cas API
  • Maintains data integrity through API validation and business rules
  • Supports audit tracking of status changes

A new BPAPI student-acceptance-confirmations-close-cas is introduced to address CLOSE CAS button functionality on the SKAICAS page.

The confirmation-of-acceptance-for-studies-data BPAPI is modified to address the latest agent related changes.

Note: From within Ethos Integration on the Owned Resources tab, click Auto-Configure Resources to ensure you have the student-acceptance-confirmations-close-cas and confirmation-of-acceptance-for-studies-data resources.

This enhancement addresses PE0007491 in the Ellucian Customer Center.

confirmation-of-acceptance-for-studies-data API

The Agent ID field from confirmation-of-acceptance-for-studies-data API is removed, and the Added UK Arrival Date field is added.

This defect addresses PD0032908 in the Ellucian Customer Center.

The MIN sequence is used to retrieve details of the first branch or agent associated with the application.

Release 9.3.34 and 8.4

A summary of the Banner INTTRACKUK 9.3.34 and 8.4 releases that include regulatory enhancements. The releases also include a few defect fixes.

Changed page

The SKAICAS page delivers the following regulatory updates for this release.
  • In the SELT and Progression Details window, the page displays a Cannot update as the fields are read only/display only warning message, when you try to switch from the SELT and Progression Details window.
  • The Progression Justification Text and Work Placement Percentage Justification fields allow users to enter only 1000 (VARCHAR2(1000)) characters.

Changed package

The following are the updates to the SKKICAS package:
  • Updates to the FN_GET_ACADEMIC_LEVEL function to use the BDT codes instead of description for academic level tag as a part of CAS XML.
  • Replacement of the UTL_FILE.GET_LINE function with the UTL_FILE.GET_RAW, to read linear XML files that have greater that 32,767 characters. This defect fix satisfies PD0014392.

Changed process

The SORGCAS process includes a new Oracle Directory Name parameter. This is a mandatory entry of parameter value (06) that allows institutions to create the CAS XML into the specified directory, if the directory is valid.

This enhancement satisfies PE0004057.

Note: There are no modifications to the logic to generate the CAS XML; this release enhancement to the SORGCAS process is only to change where the CAS XML exists. Previously, the process created the CAS XML in the default job sub directory. However, with the new parameter, the process creates the CAS XML in the Oracle Directory that the user specifies.

Recommendations to run MDUU activities

Ellucian recommends that you compile the ESC_PBS_REPORTING process in the GKAPEXE page to get the latest updates available in the MDUU activities.

Seed data

The following seed data is available to support the new parameter in the SORGCAS process.
  • Seed data for the GJBPDFT table to define the new Oracle Directory Name (6). It does not have a default value delivered.
  • Seed data for the GJBPDEF table to define the new Oracle Directory Name (6).

Delete and update scripts

Ellucian recommends that you note the following:
  • To avoid any redundant/duplicate records, this release delivers delete scripts to remove the seed data records with DATA_ORIGIN as 'GLOBAL' for the SKRUFDS and SKVSDDT tables, that were delivered with the earlier INTTRACKUK 8.3.9 release. This defect fix satisfies PD0013819.
  • For new users, where the GJBPDFT seed data for the SORGCAS process has the DATA_ORIGIN as 'GLOBAL', this release delivers update scripts to modify the GJBPDFT_USER_ID to null, for clients to run the SORGCAS process without any issues. This impacts only the new users who consumed INTTRACKUK for the first time using the 8.3.9 version. This defect fix satisfies PD0011141.
