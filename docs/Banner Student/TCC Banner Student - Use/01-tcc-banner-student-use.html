TCC Banner Student use

The Texas Connecton Consortium (TCC) modifications for Banner General enable you to implement Texas State Coordinating Board (CBM) requirements.

The collection of the data and data extraction for CBM report processing is performed in the Banner Student database. The report processing is designed to perform data collection and reporting as described in Reporting and Procedures for Texas Public Universities and for the Texas Community, Technical, and State Colleges.

The TCC maintains the programming and provides timely updates as Texas reporting requirements change. Other Texas-related solutions are also provided such as enhanced registration and transcripts.

How to contact us

The Ellucian Customer Center refers to the secured area of the Ellucian website dedicated to client support.

Users must be registered to obtain access to the secured site.

Users can request an account to gain access to the Ellucian secured web pages here: https://clientapps.ellucian.com/signup. Clients that already have account credentials can access the Ellucian Customer Center here: https://login.ellucian.com/.

When submitting a case through the Ellucian Customer Center, make sure that you identify whether the issue is baseline or TCC-related. If the issue is TCC-related, to route the issue to the TCC Support Center, designate <product> Texas Modifications in the Product field.

Texas Connection website

The Texas Connection website is maintained by the TCC Board. It contains information such as the by-laws, names of Board members and voting reps, and other general TCC information.

Collaboration site

Community is the site used to collaborate on Texas requirements. Everyone is welcome to log on, read, contribute to discussions, and download solution information.

If you have access to the Ellucian Customer Center or the Software Download area, you already have access to Community. If you are a new user, go to the Ellucian Customer Center and create an account: https://clientapps.ellucian.com/signup.

After you enter Community, click the plus sign next to Browse Forums, then the Sub Forums line under Usergroups and Regional Forums, then finally Texas Connection – Private. To initiate an invitation to the private forum, click the link requesting access. You will receive an email when access is granted.

Set up Banner Student

Learn how to install software and perform preliminary setup for Banner Student.

About this task

The TCC for Banner Student releases software in chronological order. Always ensure that you install software in the order that it was released. Each release can be dependent on previous versions of the software.

Procedure

  1. Install the appropriate Banner 8.x modules.
  2. Install the appropriate Banner 9.x modules.
  3. Install the TCC modifications.
  4. Build the Banner and TCC module validation tables and rule pages.
  5. Build relevant data using the Banner and TCC data entry pages.
  6. Build Crosswalks in Banner, using GTVSDAX.
