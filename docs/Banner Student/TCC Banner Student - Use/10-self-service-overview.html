Self-Service Overview

Student Self-Service 9.x Overview

The TCC modifications to Banner Student Self-Service were released with the baseline 9.17 version.

A menu entry for the Texas-specific information displaying Texas Success Initiative (TSI) Status, Drop Limit, and Core Curriculum is displayed on the Student Records menu.

On entering the page, the student supplies a term code from a menu list, then the page is populated.

TSI status

A summary of the student's TSI status is displayed. This information is pulled from the data on the administrative page, TSI Student Information, SZATXSI.

Rather than display test codes and scores, the information is summarized. A student who is fully exempt will see on the TSI Information screen the following:

TSI Area TSI Status
All Exempt

A student who is not college ready or partially college ready will see will see a screen with information similar to the following:

TSI Overall Not College Ready
TSI Math Not complete in this area
TSI Writing Complete in this area
TSI Reading Complete in this area

A student with no TSI status on file will see a screen will see a screen with information similar to the following:

TSI Area TSI Status
TSI Overall No TSI Status on file
TSI Math Not complete in this area
TSI Writing Not complete in this area
TSI Reading Not complete in this area

A college ready student will see a screen with information similar to the following:

TSI Area TSI Status
TSI Overall College Ready
TSI Math Complete in this area
TSI Writing Complete in this area
TSI Reading Complete in this area

A student who is not an undergraduate will see a TSI, Drop Limit and Core Curriculum screen with the Term specified and a message Student Level does not allow display of undergraduate Texas specific data.

Drop limit

Use this page to understand how drop limits display.

The drop limit portion of the display will show how many drops the student has that count against the state drop limit.
TEC 51.907 State Drop Limit Count
Institution Drops 0
Transfer Drops 1
Total State Drops 1

A student who is exempt from the drop limit will receive a message that indicates TEC 51.907 State Drop Limit Not subject to drop limit.

Accounts Receivable Self-Service 9.x Overview

The TCC modifications to Banner Accounts Receivable Self-Service were released with the baseline Student SSB 9.17 version.

Account Summary

The Self-Service Account Summary page will now display a check box labeled Tuition Grouping if the TCC AR modifications are in use.

This is determined by the entry TCCAR on the Installed Localization Inventory page, GUILCIN. Clients do not have to make this entry, it is created during installation.

The Account Summary page for an example student can show tuition charges for undergraduate, graduate, and tuition refund penalty. Each tuition charge, listed on its own line, begins with T in the Detail Code column.

The Account Summary page shows tuition charges for undergraduate, graduate, and a tuition refund penalty. In the baseline view of the Account Summary page, these charges are displayed within the detailed list in three separate lines.

The Tuition Grouping check box appears at the top of the page and is cleared by default when the page is initially launched. Selecting the check box causes the three tuition charges to be summarized in a single line.

Note: For clients not using the TCC AR modifications, the check box does not appear.

Account Summary by Term

Use the menu options at the top of the page, to view the account for all terms or a specific term.

Procedure

  1. To view the account summary for all terms or a single term, select the menu options at the top of the page.
    Under the Detail Code field, an example student can show four tuition charges, including Undergraduate Tuition, Graduate Tuition, 3-Peat Tuition, and Tuition Refund Penalty.
  2. To view the consolidated tuition charge summary, select the check box for Tuition Grouping.
    Note: If a term in which the student has registration activity fails to display in the menu list, it may need to be enabled on administrative page, TSATERM.

Account Detail for Term

The Tuition Grouping feature is also included on the Account Detail for Term self-service page. This page shows individual transactions for a given term.

On the Account Detail for Term page, select the term to view account details for the student for the term.

All tuition charges for that term appear in the list under Detail Code.

To view the tuition charges on a single, consolidated line, select the check box for Tuition Grouping at the top of the page.
