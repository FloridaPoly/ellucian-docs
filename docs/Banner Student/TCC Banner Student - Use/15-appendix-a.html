Appendix A

Gender X support

The Gender X project, brought about by changes in the IPEDS report, replaces the current options on the SPAPERS, SPAIDEN and the other %AIDEN pages with a drop-down LOV to allow institutions to create their own values for the Legal Sex field, SPBPERS_SEX. Current values are F, M, and N.

Banner Applications Configurations (GUACONF)

Use the Banner Applications Configurations (GUACONF) page to enable the Gender X changes.
  1. In the Application ID, enter BAN_GEN.
  2. On the Configurations tab, locate the Configuration Name, gender.x.enabled.
  3. Verify that the Configuration Value equals Y, which indicates that Gender X is enabled.
  4. Note: You will not have to perform these steps if you installed TCC Banner General 8.15.

Legal Sex Code Validation (GTVLGSX)

To add new values for gender, use the Legal Sex Code Validation (GTVLGSX) page. This will control what entries can be made on the Legal Sex fields of the *IDEN pages and SPAPERS. These are the entries that will be displayed on the list of values (LOV) for the Legal Sex field.

  1. Access GTVLGSX.
  2. Select Insert and in the Code and Description fields, enter a new alphanumeric code and description.
    Note: The default gender codes, F, M, and N, delivered by Ellucian, are required as indicated by the selection of the System Required check box.
  3. Click Save.

Social Economic Identity Report (GTVSEIR)

To create a crosswalk between the gender codes on GTVLGSX and the values required by various reporting agencies, you must first create a social economic report on GTVSIER. The following values are mandatory for TCC reporting purposes:

  • TCC_STU - Gender reporting for Texas CBM reports
  • TCC_FAD - Financial Aid database report
  • TCC_PZRED01 - Employee Data Report for TEAMs
  • TCC_PSRHRS1 - Personnel Report for HRIS

Legal Gender Rules Crosswalk (GORWKSX)

To create the gender value crosswalk, access the Legal Gender Rules Crosswalk (GORWKSX). Enter the Social Economic Identity Report Code, such as TCC_STU. This step is necessary to support reporting, even if your institution is not currently supporting additional gender codes. At a minimum, you'll need entries for Banner values, F, M, and N.

  1. Access GORWKSX.
  2. In the Key block, enter the Social Economic Identity Report code created in GTVSEIR or click the Lookup button to select the code and click Go. Example: TCC_PZRED01
  3. In the Banner Value field, enter a Banner gender code used by the Banner Applications or click the Lookup button to select a code from the GTVLGSX page. Example: F, M, or N
    Note: The Banner value description should auto-fill after you select a Banner value.
  4. Enter the reporting agency gender code in the External Value field.
  5. Enter a description in the External Value Description field. This step is optional.
  6. Select a Start Date and End Date.
    Note: The Start Date value defaults to the current date but you can change the date if needed.
  7. Click Save.

Starting in Spring 2024, the Texas Higher Education Coordinating Board only accepts values of F or M for Student reporting while Financial Aid reporting also allows a value of U to be reported for Banner values of N. Any other value for sex is returned as an error. Consider how you will crosswalk new gender codes for reporting purposes before introducing additional gender codes.
