SaaS Processing

SaaS and Cloud hosted environments

SaaS processing through TCC Student Job Submission is activated for a job using the baseline JobSub Output Definition page (GJAJBMO) in TCC Student 9.

This page is only accessible through TCC Student 9. For additional information regarding SaaS and Cloud hosted environments, review a recent TCC Student General User Guide (Example - Banner_General_User_Guide_8.10.4_9.3.12_November_2018) which may be downloaded from the Customer Support Center Documentation Libraries.

In support of SaaS and Cloud hosted environments, many TCC delivered TCC Student reports and processes have been enhanced. These enhancements include modifying the File name parameter by designating the file name as optional.

If the GJAJBMO Enabled flag is selected for a report or process, then SaaS is enabled when submitting the job through the Process Submission Controls (GJAPCTL) page. In this case the File name parameter is not used, and the resulting files are named according to baseline standards. (Example - szrcbms_142176.txt). These files are also placed in the Job Sub folder and any path name parameter ignored.

Be aware when using the GJAJBMO Enabled flag that all file extensions are lowercase, according to baseline standards.

If the GJAJBMO Enabled flag is not selected for a report or process, then SaaS is not enabled when submitting the job through the Process Submission Controls (SJAPCTL) page. In this case the File name parameter value is used when naming files (Example - Prod-cbmS.txt). If the File name parameter value is blank, the file is named according to baseline standards, which is the process name concatenated with an underscore and the job number. (Example - szrcbms_142176.txt).

In either of the above situations the LOG and LIS files are still named as per baseline standards (Examples - szrcbms_142176.lis and szrcbms_142176.log).

Note: This functionality does not affect jobs which are uploading files into TCC Student. In this case the file name parameter is still required. The same is true of the path name, if needed for a process which uploads a file of data into TCC Student.
