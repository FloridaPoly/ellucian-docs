TSI Area Obligation Validation (SZVAOBL)

Use the TSI Area Obligation Validation (SZVAOBL) page to define values assigned to the TSI Area Obligation values on the TSI Status (SZATXSI) page.

Operation

The values entered on the TSI Area Obligation Validation page are used to maintain the individual TSI Obligation in the TSI Areas on the TSI Student Information page (SZATXSI).

Field Description
Code Use the Code field to enter the appropriate one-character state value.
Description Use the Description field to enter the appropriate description, up to 100 characters.

Special Note — SZRCBM2 (CBM002) report process

The SZRCBM2 (CBM002) report process uses only one value defined on this page when it creates the CBM002 report for each student.

If the TSI Obligation Code value of 3 is assigned to a Student’s Area TSI Obligation on the TSI Status page (SZATXSI), the following CBM002 reported data is detailed:

  • Report 1 (Satisfied) in Items 20, 40, or 60.
  • Check the SZVTSPC CBM002 Items 21A/41A/61A value.
    • If this value is non-blank, report the value in Items 21A, 41A, or 61A.
    • If this value is blank, report a 1 in Items 21A, 41A, or 61A.
Note: As of the release of RTE 5190 NCBO Interventions Phase 2, values of N and S are no longer used to report CBM002 Items 23, 43, and 63.

To determine other values used for the CBM002, see TSI Status Code Validation (SZVTSPC).

CBM00T Reason Code Validation (SZVCBTR)

Use the CBM00T Reason Code Validation (SZVCBTR) page to define the CBM00T Reason Codes.

The CBM00T Reason Codes are defined by THECB and can be found in THECB Reporting and Procedures Manuals for universities and community colleges. The CBM00T Reason Codes are referenced in CBM00T Reason (SZATDAD) and CBM00T Reason Crosswalk (SZATRXW)

Operation

The values entered on SZVCBTR are used for maintaining the reason a course was not awarded credit towards a transfer student's degree. The CBM00T reason code is reported on the CBM00T report.

Field Description
Code Use the Code field to enter the appropriate one-character state value.

This field may be used for reporting CBM002.
Description Enter the appropriate description using up to 30 characters.

Special Note — SZRCBM2 (CBM002) report process

The SZRCBMT (CBM00T2) report process uses the CBM00T reason code to populate item 10 on the CBM00T report. The values are also present and validation occurs on the administrative pages, CBM00T Reason (SZATDAD), and CBM00T Reason Crosswalk (SZATRXW).

Major CIP Code Validation (SZVMCIP)

Texas Public Universities and Community Colleges use the Major CIP Code Validation (SZVMCIP) page to define the state CIP code for majors. Community Colleges also define the state Type field for majors. Key values of Effective Term, Major, Program, and Level are required while Concentration is optional.

The SZVMCIP records are used by CBM0C1 and CBM009 for Texas Public Universities, and by CBM0C1, CBM009, and CBM00A for Community, Technical, and State Colleges.

Program hours

For Texas Public Universities, you can define the Program Hours for a Program of Study and Major combination on SZVMCIP.

The Program Hours value is used by CMB0C1, CBM0CS, CBM00S, and CBM005, depending on the existence of the GTVSDAX rule called PGMHRSMCIP. If the institution chooses to use the SZVMCIP Program Hours instead of the Program Hours on SMAPROG, then the GTVSDAX rule called PGMHRSMCIP must have an External Code equal to Y and the Program Hours column must be completed for each Program/Major combination.

University reports

University reports contain logic for selecting records from either SZVMCIP or SMAPROG for the correct effective term. The logic performs the following steps.

  1. Reads the Term Codes listed in the Term parameter and determines the most recent (highest numbered) Term Code listed.
  2. Selects the most recent effective SGASTDN record and corresponding curriculum records that have a term code that is before or the same as the Term Code in step 1. Extracts the Program, Major and Catalog Term for this student.
  3. Reads the SZVMCIP table for the correct Major CIP Code or Type Major using the Program, Major, and Catalog Term. The SZVMCIP record with the highest Effective Term before or the same as the catalog term is chosen.
  4. Extracts the Program Hours as follows:
    1. If the External Code of the GTVSDAX rule PGMHRSMCIP is Y, read the SZVMCIP table for the Program Hours using the Program, Major, and Catalog Term. The SZVMCIP record with the highest Effective Term that is before or the same as the catalog term is chosen.
    2. If the External Code of the GTVSDAX rule PGMHRSMCIP is not Y then the Total Required Credits (smbpgen_req_credits_overall) is extracted from SMAPROG using the Program, Major, and Catalog Term.

Community college reports

Community college reports contain logic for selecting records from SZVMCIP for the correct effective term. The logic performs the following steps.

  1. Reads the Term Codes listed in the Term parameter and determines the most recent (highest numbered) Term Code listed.
  2. Selects the most recent effective SGASTDN record and corresponding curriculum records that have a term code that is before or the same as the Term Code in step 1. Extracts the Program, Major, and Catalog Term for this student.
  3. Reads the SZVMCIP table for the correct Major CIP Code or Type Major using the Program, Major, and Catalog Term. The SZVMCIP record with the highest Effective Term that is before or the same as the catalog term that is chosen.

Community college recommendations

Learn about the recommendations for community colleges.

CBM009 considerations

  • Create a row for the Core Curriculum Program to allow reporting the Core Curriculum Completions by the CBM009 Report process (SZRCBM9). Include the 8-digit CIP Code and Major Type.
    Note: A Major of Unknown or Undecided is used for the purposes of defining a row on this page, however, the Major for Core Curriculum is not used for CBM009 reporting purposes.
  • Create a row for each Field of Study Program offered at this institution to allow reporting the Field of Study Completions by the CBM009 Report process (SZRCBM9). Include the 8-digit CIP Code and Major Type.
  • The CIPC field is used to report Item 7.
  • The Type field is used to report Item 13.

CBM00A considerations

  • Add a record for each Continuing Education major to the State Major CIP Code Validation (SZVMCIP) page.
    • Assign a Type Major of 4 to each of those CE majors.
    • Create this Program/Major in SOACURR and assign to CE students, as appropriate.
  • The CIPC field is used to report 12.
  • The Type field is used to report Item 13C.

Operation

The data contained on this page is required for Texas Community, Technical and State Colleges, and Texas Public Universities.

Program Codes not identified as Non-Degr or not defined on this page are considered as degree seeking.

Duplicate records with the same Effective Term, CIP Code, Major, Program, Level, and Conc are not allowed.

Field Description
Effective Term Enter the effective term for this row of data.

This is the term for which the program hours become effective. The CBM report processes compare this term code value to the student Catalog Term to determine CIP Code, Pgm Hrs, or (Major) Type for the student. If the Effective Term is equal to the Catalog term of the student, then this record is chosen to extract a CIP Code, Pgm Hrs, or Type. If the Effective Term is not equal to the student Catalog term but is less than the student Catalog Term, then this record is chosen to extract a CIP Code, Pgm Hrs, or Type.
CIP Code Enter the appropriate eight-digit Texas state value.
Note: The code must be a THECB Reporting value.
Major Enter the Major corresponding to the CIP Code indicated. A list of values is available using the Major, Minor, Concentration Code Validation (STVMAJR) page.
Program Enter the Program corresponding to the CIP Code/Major indicated. A list of values is available (SMIPROG).
Program Name Display only.
Levl Enter the Level corresponding to the CIP Code/Major indicated. A list of values is available (STVLEVL).
Conc Optional. Enter the Concentration corresponding to the CIP Code/Major indicated. A list of values is available (STVMAJR).
Pgm Hrs Enter the program hours for the Major/Program/Level/Conc combination.
Type Enter the major type.
Note: Required for Texas Community, Technical, and State Colleges (CBM00A). Not used for Texas Public Universities.
Non Degr Select this check box to indicate that this is a non-degree seeking program code.

TSI Status Code Validation (SZVTSPC)

Use the TSI Status Code Validation (SZVTSPC) to define Student TSI Status codes that are used by the TSI Rules Control (SZATSPC) page, the TSI Update Process (SZPTSPU) page, the TSI Student Information (SZATXSI) page and the CBM002 process (SZRCBM2).

Required System Values for TSI Status Codes (SZVTSPC)

The required CR – College Ready Status should be flagged as a THECB defined College Ready code. The Required System values, in the table that follows, plus the institutionally defined exempt or waiver codes are the only status codes recognized by TSI processing. The institutionally defined codes should have a value of E for exempt status or a value of W for waived status in the Exempt/Waive column.

TSI Status Codes Description
CR College Ready
NCR Not College Ready
Retested Retested
RR Retest Required

Operation

SZVTSPC is used for both Texas Public Universities and Community Colleges. The member institutions should review the TSI Status Codes (SZVTSPC) page and ensure that their institution TSI status codes are properly crosswalked to the THECB reporting values.

Field Description
Status Code Use the Status Code field to enter the appropriate eight-character state value.
Note: The code must be a THECB Reporting value.
Description Use the Description field to enter the appropriate description using up to 30 characters.

This description can appear on the Transcript within the TSI Information section.
Exempt/Waive Enter E for exempt status and W for waived status.

A value of E or W will cause a check box on the Met flag on the TSI Student Status (SZATXSI) page.

Note: See SZATXSI documentation of the Met indicator as other conditions will check the SZATXSI Met flag.
CBM002 Item 10 Enter the appropriate state THECB Reporting value for CBM002 Item 10 (TSI Obligation Waived or Blanket Exemption) for the corresponding TSI Status Code. A blank value is reported as 0.
Note: CBM002 Item 10 must be a THECB Reporting value.
CBM002 Items 21A/41A/61A Enter the appropriate state THECB Reporting value for CBM002 Items 21A, 41A, or 61A (TSI Area Waived or Satisfied through Exemption) for the corresponding TSI Status Code. A blank value is reported as 0.
College Ready Select the check box to indicate this status is College Ready according to the TSI Obligations. Selecting this check box indicates this status is assigned a value of Met on the TSI Student Status (SZATXSI).
Note: See SZATXSI documentation for more information on the Met indicator as other conditions will check the SZATXSI Met flag. The SZATXSI Met field is not used by the SZRCBM2 CBM002 process but is used for TSI Restrictions during Registration processing. An Area Status of CR, Exempt, or Waive is considered Met to allow Registration regardless of TSI Restrictions.
