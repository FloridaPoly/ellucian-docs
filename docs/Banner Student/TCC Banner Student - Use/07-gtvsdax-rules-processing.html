GTVSDAX Rules Processing

Crosswalk Validation Definitions (GTVSDAX)

Review the complete list of GTVSDAX crosswalk rules required for TCC report processing, data entry, and transcripts. The list is in alphabetical order by GTVSDAX Internal Code and contains information regarding which report or process uses the crosswalk.

Following are tips for entering GTVSDAX rules:

  • Multiple entries for each rule are allowed unless Single Rule Only is specified.
  • Any rule entered with multiple rows and like External Codes requires a Sequence number. To define a rule with multiple rows, enter new rows (Insert Record, Duplicate Record) and add one to the sequence number. For example, any GTVSDAX rule with a State value in the External Code that translates to multiple TCC Student values will require multiple rows with like External Codes.
