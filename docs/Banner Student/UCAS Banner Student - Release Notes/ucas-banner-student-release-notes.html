Release 9.3.42 and 8.31

The Banner UCAS 9.3.42 and 8.31 introduces the new Document Management feature, which includes enhancements to DC pipelines, updates to the SKAUDEC page, and improvements to ARC self-service functionality. Additionally, it addresses several defect fixes related to pages and DC pipelines.

Note: Document Management functionality is not available in this release. While related UI elements and entry points may be visible within SKAUDEC and ARC, the associated features are not yet active. Full Document Management support is planned for a future release.
Note:
  1. On the GKAKSYS page ensure that the parameter value for INSTITUTE CODE is not set to UPDATE_ME.
  2. Verify that the INSTITUTE CODE configured on the GKAKSYS page matches the corresponding values in the following tables:
    • GKVWSPR
    • GKVWSPV
    • GKRWSOP
    • GKRWSMP

    Example:

    If the INSTITUTE CODE on GKAKSYS is set to Z92, then entries in the tables must reflect this value. For instance, in GKVWSPR, values such as SC_XLT2_Z92_GTTRAPPS must be present. Apply similar naming conventions across the other listed tables.

    Pre-Requisite before using Banner UCAS:

    Before you begin using Banner UCAS, ensure the following steps are completed:

    1. Configure the correct client institution code as the parameter value for INSTITUTE CODE on the GKAKSYS page.
    2. Execute the SOPUWIN process to update records in the following tables from the default code (Z89) to the client’s institution code:
      • GKVWSPR
      • GKVWSPV
      • GKRWSOP
      • GKRWSMP
Note: There are changes to DC pipelines and crosswalks. Ensure that you request the latest version of Pipelines only after upgrading to the latest supported releases.

The new version of pipelines depend on UCAS 8.31, UCAS 9.3.42, Integration API 9.42 and WINC Version 8.3.2 versions. For more information about Data Connect pipeline and crosswalks, refer to the UCAS Pipelines in Banner UCAS Use content.

Technical Currency Upgrades

As part of ongoing technical currency initiatives, Banner General Java batch programs have been upgraded to support the latest versions of key Spring frameworks. This enhancement ensures improved compatibility, performance, and alignment with modern development standards.

GKAKSYS Seed Data Changes

This update ensures that a valid Institute Code is configured for UCAS integration within Banner. The change standardizes the value and corrects any incomplete or not valid existing configurations.

The system updates the GKBKSYS configuration to set the INSTITUTE CODE parameter value to Z89 when the current value is NULL/UPDATE_ME/Invalid value(for example, longer than 4 characters without a comma-separated format).

DC Pipeline changes

  • The XML-Link UCAS Reference Data GET pipeline has been updated to include two new reference endpoints: getReferenceApplicationSections and getReferenceDocumentCategories.
  • The Xml-link UCAS Unicode Applicant Data GET pipleine is updated to process upto 80k records in single run.
  • The Xml-link UCAS Applicant Data SET pipeline is updated to address issues related to PD0033388.

Document Management Pipelines

  • DM Credentials Update Pipeline

    Updates the UCAS OAuth credentials (Client ID and Client Secret) used by the Document Management integration. Run this pipeline whenever UCAS credentials are rotated or first configured for a tenant.

  • DM Import Pipeline

    Retrieves applicant documents from UCAS for a given admissions cycle and institution and writes to S3. The pipeline submits a supplemental data job and writes the response for downstream processing.

  • DM Import Status Pipeline

    Retrieves the status of supplemental data (document management) jobs. Can return a specific job by ID or all jobs for the tenant, with optional date range filtering.

Note: For more information on the DC Management pipelines, see Document Data download from UCAS LINK content in UCAS Banner Student - Use.

Application Review Centre (ARC) enhancements

The following ARC enhancements are available as a part of the Banner UCAS 9.3.29 and 8.19 and Banner Faculty Self-Service 9.20 releases.
  • The new Applicants Prior Activities Data (SOVAPRA) view displays the higher education data for applicants in Faculty Self-Service ARC from the SORAAEA and SORUAEA tables. The SOVAPRA view is available along with the Banner Student 8.26 release. This satisfies PE0001590.
  • The Higher Education activity related fields are available to the Applicant Activities and Employment History section of Applicant Details page in ARC.
  • The Higher Education Activity related fields are available in the ARC PDF.
This satisfies PE0001587.

For more information about the field names, description, and tasks related to Applicant Activities and Employment History data, see Banner UCAS Use content.
