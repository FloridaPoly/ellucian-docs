Application Review Centre

The Application Review Centre is a UCAS-specific section of Banner Faculty and Advisor Self-Service, and includes pages that faculty members and advisors can use to view and print an applicant's UCAS applications.

You can search for an individual applicant by personal ID, forename, or surname, or you can search for a group of applicants by UCAS course or programme. Applicant data displays on a series of Self-Service pages or you can output to a PDF for printing.

The Application Review Centre uses the concept of an ‘application review group’. An application review group can represent any grouping of programmes for the purposes of admissions processing. For example, if applications are reviewed by the departments to which the programmes belong, those programmes are assigned to an application review group that represents the parent department. If some applications are reviewed by a Central Admissions office, those programmes are assigned to an application review group for that office. The review groups can represent whatever you want and are the means for users of the Application Review Centre to search for applications to review. Therefore, if it is useful to search for applicants by department and campus; you can construct your application review group codes to represent combinations of these two entities. When you select an application review group as a search criterion on the Group of Applicants Search page, the search only returns programmes assigned to that review group.

The Application Review Centre also uses ‘actions’, which are codes that you can design to represent any aspect of the admissions business process that you require. They can be the same as or different from the standard UCAS decision codes. Examples include ‘Invite to Interview’ or ‘Refer to Department X’. In the latter example, you can define action codes so that when they are applied to an applicant, the application review group of that applicant is changed to the code for the department to which you are referring. Action codes are assigned to applicants and you can view them on the Applicant Details page. You can also view them on the Saved Review Group Actions and Comments page.

The Application Review Centre displays applications that have an SKRSAIN record. This means UCAS and UCAS Teacher Training (UTT, formerly GTTR) applicants and direct applicants whose data has been entered through the Banner UCAS pages (SKASAIN, SKAUATD, SKAUDIR, and so on) are therefore stored to the Banner UCAS tables. If you enter your direct applicants are through the baseline SAAADMS page, or through the baseline Web for Admissions product and if you do not have a local process to transfer data to the Banner UCAS (SK*) tables, these applicant records are not available in the Application Review Centre.

An applicant must also be assigned to at least one application review group for the search pages to retrieve them.

Self-Service pages

The Self-Service pages enable you to view more detailed information about an applicant.

If one of the Self-Service pages requires setup, it is listed under Setup requirements. If no setup requirements are listed for a particular Self-Service page, there are no Setup requirements listed for that page. If one of the Self-Service pages impacts the Banner database, it is listed under Updates to Banner. If a page does not impact the Banner database, there are no Updates to Banner for that page.

Setup requirements for the Self-Service pages

Setup requirements to use the search pages

To use the Individual Applicant Search and the Group of Applicants Search pages, setup is necessary.

About this task

Setup is required for this page to work as expected.

Procedure

  1. On the System Parameter Maintenance (GKAKSYS) page:
    1. Using the APPLICATION REVIEW GROUP PRINTCODE parameter, specify which rows on SMRPCMT (SMAPROG program text) contain the application review codes you want to use.
    2. Using the ONLINE PROGRAMME DISPLAY parameter, specify if the programme names should populate from SMARPLE or SMAPROG.
      Note:

      If you specify SMAPROG for the ONLINE PROGRAMME DISPLAY parameter, enter a valid value from STVPRNT to specify which program title to use.

  2. On the Programme Requirements (SMAPROG) page:
    1. Define the program title in the Program Text block as described in Define programme titles.
  3. On the Value Mapping and List-of-Value Definition (SKASSDT) page:
    1. Define your application review group codes. See Define application review group codes for step-by-step instructions.
  4. On the Web Application Term Display Control (SOAATRM) page:
    1. Define the terms to display on the web. See Specify terms to be available in the Application Review Centre for step-by-step instructions.

Setup requirements to use the PDF print functionality

To use the print to PDF functionality, setup is necessary.

About this task

Setup is required for this page to work as expected.

Procedure

On the SystemParameter Maintenance (GKAKSYS) page:
  1. Define the value for the UCAS ONLINE SERVER URI system parameter. This is the UniformResource Identifier of the resource on which this application is hosted, for example, http://10.10.10.10:1234.
  2. Define the value for the UCAS ONLINE SESSION TOKEN TIMEOUT system parameter. This is the timeout in seconds after which the token used to authenticate the PDF Application servlet expires. The recommended value is 30.

Security restrictions for the Self-Service pages

Security restrictions

Your institution can add security restrictions to the Application Review Centre by assigning faculty members to security classes based on Application Review Group.

Application Review Group assignments

If your institution implements security restrictions, you have access only to applicant data depending on the security classes assigned to the Application Review Group you are a member of. Your institution can use the WebTailor Administration page to add the FACULTYARCUPDATE user role.
  • All of the Application Review Groups display in the My Review Group is drop-down list. It does not matter if you are one of the assignees to the Application Review Group. You can still see all of the review groups in the drop-down list.
  • If you search for an applicant using an Application Review Group of which you are not an assignee, a No applicant found. message displays.
  • If you are an assignee to one Application Review Group, only records in the review group to which you are an assignee return in the search results.
  • If you an assignee to all review groups, all records in the review groups to which you are an assignee return in the search results.

Application Review Group permissions

If you have additional roles and update permissions, such as Faculty Application Review Centre Update permissions (FACULTYARCUPDATE), you can select an action item, enter comments, and save those comments.

If you do not have an additional role and you do not have update permissions, the Actionand Comments fields are read-only. The Save button does not display because you do not have the permissions to save comments.

If you have an additional role but no update permissions, the Action and Comments fields are read-only. The Save button does not display because you do not have the permissions save comments. If you encounter this scenario, an error message displays that reads, You do not have access to add actions and comments. Please contact administrator.

Assign a review group to faculty using the Faculty Application Review Group (SAAFARG) page

You can use the Faculty Application Review Group (SAAFARG) page to assign an application review group to a faculty member.

Procedure

  1. On the SAAFARG page, select a review group from the Review Group field, and then click Go.
  2. Click the ellipses on the ID field to open the Option List window.
  3. Click Faculty/Advisor search.
  4. Click the record for the faculty member to which you want to assign a review group.
    The SAAFARG page opens.
  5. On the SAAFARG page, specify the dates in the From Date, and a To Date fields.
  6. Use the Active and Update Allowed options to assign a faculty member to the review group.
  7. Save the selected record.

Documentation

The Documentation section displays the list of documents provided by an applicant.

When you select the Fetch Documents , the documents associated with the Personal ID are retrieved, and their metadata such as Document ID, Document Name, Document Type, and Document Category is displayed in Self-Service. Selecting the hyperlink in the Document ID field opens the corresponding document in the browser or initiates a download.

Note: Document Management functionality is not available in this release. While related UI elements and entry points may be visible within SKAUDEC and ARC, the associated features are not yet active. Full Document Management support is planned for a future release.

Review Group Actions and Comments

Review Group Actions and Comments displays details about previously entered comments for the applicant.

Self-Service fields

The Review Group Actions and Comments contains the following fields:

Field Description
Action A drop-down list in which you select the action you desire. Actions include options such as Conditional offer, Invite to interview, and Pending review.
Comment A field in which you enter comments related to the action selected. Comment is a required field.
Save A button to save your selected action and comments. Save is enabled after you enter the comments in the Comment field.

Updates to Banner

Review Group Actions and Comments updates the Banner SKRUOCT table. You can view the data on the Saved Review Group Actions and Comments page.
