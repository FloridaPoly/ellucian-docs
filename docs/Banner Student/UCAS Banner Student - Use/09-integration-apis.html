Integration APIs

UCAS Integration APIs to download and upload data from UCAS through Data Connect pipelines.

HTTP Method API Name Description
GET ucas-transaction-statuses Retrieves records from the SKRUJOB table where the SKRUJOB_JOB_STATUS column is NEW. This GET API calls the SKARDCN.F_FETCH_SKRUJOB function that is used in the Recruit UCAS Transaction Statuses DC pipeline, which sends the UCAS transaction status from Banner UCAS to CRM Recruit.
GET ucas-application-transactions-details Retrieve records from the SARSDUS table which has the UCAS transaction details (UCAS data download and upload record count details per end point when data is downloaded and uploaded using the UCAS XML LINK DC pipelines). This API is used in the UCAS-TRANSACTION-DETAILS-API Data Connect pipeline and is called in the UcasTransaction Details Experience page to display the UCAS transaction details.
POST ucasxmlset This API is called from the pipelines to load data in to the XIGN and MDUU tables using the functions and procedure from the Banner PLSQL packages. The API collects the decision details from for the set methods.
POST ucas-update-job-statuses Updates the SKRUJOB table job status and calls the SKARDCN.F_UPDATE_SKRUJOB function. This POST API is used in the Recruit UCAS Transaction Statuses DC pipeline, which sends the UCAS transaction status from Banner UCAS to CRM Recruit.
POST ucaslink-mcds-transactions Downloads the MCDS (Modernised Contextual Data Services) information from UCAS to Banner using UCAS-LINK. This API is called internally by UCAS MCDS Pipeline 1 and UCAS MCDS Pipeline 2.

This is the pro-code API to CREATE/READ/UPDATE MCDS (Modernised Contextual Data Service) data from and to Banner tables (sarmcmd, sarmcmu, sarmcml, sarmcds).

In previous UCAS and API releases, supporting tables and API security scripts are provided.
POST ucaslink-transactions Downloads the Personal Statement information from UCAS to Banner using UCAS-LINK. This API is called internally by UCAS Personal Statement pipeline 1 and UCAS Personal Statement pipeline 2.This is the pro-code API to CREATE/READ/UPDATE Personal Statement data to Banner tables (sarulmd, sarulmu, sarulml, sarulps).
