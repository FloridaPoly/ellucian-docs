Overview

Banner UCAS is the abbreviation for Universities and Colleges Admissions Service for the UK.

UCAS is the UK central organisation through which applications are processed for entry to all full-time and sandwich first degrees, Diplomas of Higher Education (DipHEs), Foundation Degrees, Higher National Diplomas and Certificates (HNDs and HNCs), and certificates of Higher Education (CertHEs). Information about UCAS is displayed on the UCAS web site at http://www.ucas.com.

UCAS also provides the central system for processing applications to Initial Teacher Training programmes, through its UCAS Teacher Training (UTT, formerly GTTR) admissions scheme.

The Banner UCAS release enables institutions to do the following for both UCAS and UTT applications:
  • Connect from Banner to UCAS using web services to connect to XML-Link
  • Capture data from UCAS
  • Check all incoming applicants for duplicates in the Banner database
  • Process applicants in the Banner database (enter decisions and offers)
  • View applicant data in Self-Service Banner
  • Upload data from the Banner UCAS module to UCAS

Key stages for UCAS processing

The Banner UCAS module has three key stages for processing UCAS information.

For the implementation stage, you need to set up mappings and system parameters and configure the Banner system.

For the data handling stage, you need to understand data download procedures.

For the applicant processing stage, you need to do the following:
  • Maintain data
  • Manage applications
  • Make decisions
  • Manage confirmation and clearing
The rest of this section discusses the methods of communication with UCAS, the transactions involved and about the Marvin codes.

Methods of communication with UCAS

There are several ways in which applicant information may be passed between institutions and UCAS.

Interactive connection to UCAS (ODBC-Link)

This method allows direct access to the UCAS database using SQL*net, and was supported by Banner in releases up to and including Banner UCAS 8.4.2. From UCAS 8.5 onwards, ODBC-Link is not supported by Ellucian although the functionality has not been removed.

XML-Link

This method allows direct access to the UCAS database using an XML transfer and is the only method supported in Banner.

Web-link

This method allows direct access to the UCAS database through a web interface and is not supported by Banner.

Summary of UCAS transactions

The transaction names such as '*N' for data downloaded from UCAS are historical but will be familiar to many admissions staff. They have therefore been listed to show how this data is downloaded from XML-Link.

There are additional XML-Link methods providing other applicant data such as references, personal statements, education and employment history. See Download behaviour section for complete details of the download methods.

Marvin codes

Marvin is the name of a coding system used by UCAS. When transmitting data to and from UCAS, Marvin shorthand codes are used that can be expanded if, for example, the data is to be used in a communication to the applicant.

An example of Marvin codes used to specify the conditions of an offer on a decision transaction would be as follows:

A@MATHS,P@ELEC,70%@PHYS,Q@BU-ST

This would translate into the following:

A in Mathematics

PASS in Electronics

70% in Physics

MERIT in Business Studies
