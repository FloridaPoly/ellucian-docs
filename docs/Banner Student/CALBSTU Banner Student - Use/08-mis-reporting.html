Output Definition

You can use the JobSub Output Definition (GJAJBMO) page to define and activate Job Submission processes for the file save and download process.

About this task

Note: This setting is used by the SVRCAAA, SVRCASY, and SVRCASL processes for the AA, SY, and SL MIS reports.

The Insert, Update, and Delete check boxes are disabled if the environment setting is defined as Windows.

Entries for GJAJBMO are delivered with baseline upgrades for each of the products after the shell scripts for the jobs have been updated to include the step to execute the Saved Job Report Output (GJRJLIS) process. The entry in GJRJBMO allows the administrator to enable the process and users can start using the Saved JobSub Reports (GJAJLIS) page to view their output.

Procedure

  1. Access the JobSub Output Definition (GJAJBMO) page.
  2. In the Job Name field, enter a job name.
  3. In the MIME Type field, specify the format in which the file should be saved: plain text or PDF.
  4. In the PDF Font field, specify the font that should be used for the PDF.
    The font is Courier by default.
  5. In the PDF Font Size field, specify the size of the PDF font.
    The font size is 8 by default.
  6. Select the Enabled check box to indicate that the file should be imported.
  7. Save your changes.
