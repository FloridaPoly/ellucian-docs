Drop Roster

In Banner 9, the Drop Roster functionality has been removed from the California localized application and incorporated into the core Banner Admin pages and Banner Student Self-Service Registration application.

This makes it available to all Banner Student users. For more information about this functionality, see Banner Student Self-Service Use. The California localization in CALBSTU continues to enable this feature in Banner 8 Self-Service Registration. Refer to the Self-Service section for more information.
