CalWORKs

The CalWORKs localizations allow your institution to collect CalWORKs information, such as CalWORKs student data and the student work activities data. Pages, tables, and a process support CalWORKs data collection, and two MIS reports are available for reporting CalWORKs data to the CCCCO.

CalWORKS Pages

The following pages are part of the CalWORKs functionality.

  • CalWORKs Student Data Page (SVACWSD)
  • CalWORKs Case Management Service Validation Page (SVVCMSV)
  • CalWORKs Eligibility Status Validation Page (SVVELST)
  • CalWORKs Other Services Validation Page (SVVOTHS)
  • CalWORKs Program Eligibility Time Limit Status Validation Page (SVVPETL)
  • CalWORKs Student Counseling Status Validation Page (SVVSCST)
  • CalWORKs Student Family Status Validation Page (SVVSFST)
  • CalWORKs Student Work Activity Status Validation Page (SVVSWAS)

These pages are discussed in the Banner CALBSTU Reference Pages documentation on the Ellucian Documentation site.

CalWORKS Tables

The following tables are part of the CalWORKs functionality.

  • CalWORKs Student Data Table (SVRCWSD)
  • CalWORKs Student Work Activity Data Table (SVRCWSW)
  • CalWORKs Case Management Service Validation Table (SVVCMSV)
  • CalWORKs Eligibility Status Validation Table (SVVELST)
  • CalWORKs Other Services Validation Table (SVVOTHS)
  • CalWORKS Program Eligibility Time Limit Status Validation Table (SVVPETL)
  • CalWORKs Student Counseling Status Validation Table (SVVSCST)
  • CalWORKs Student Family Status Validation Table (SVVSFST)
  • CalWORKs Student Work Activity Status Validation Table (SVVSWAS)

These tables are discussed in Tables used in California Processing.

Process

The Copy Student CalWORKs Data Process (SVRSCWR) was added to support the CalWORKs functionality. This process is discussed in “Reports and Processes”.

Reports

The following reports were added to support the CalWORKs functionality.

  • CalWORKs Student Work Activity Report (CW)
  • Student CalWORKs Report (SC)

These reports are discussed in the Banner Student California Reports documentation on the Ellucian Documentation site.
