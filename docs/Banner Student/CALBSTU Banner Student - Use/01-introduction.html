Introduction

Banner® CALBSTU (CALBSTU) localizes several products to support the California Community College District.

These localized products include the following:

  • Baseline Banner Student
  • Faculty and Advisor Self-Service
  • Student Self-Service
  • Baseline Banner General

Installing CALBSTU

Install CALBSTU by using the scripts described in the relevant Upgrade Guides.

After you have run the scripts to install CALBSTU, you can identify whether a particular page was created or modified for California by viewing the About Banner Page (GUAABOT) (Help>About Banner). If C3SC appears in the page’s title bar and the Modification ID field, the page is for CALBSTU; if C3SC does not appear in either place, the page is the same as baseline. When a page is localized, the baseline page version is noted immediately after the page name, and the CALBSTU page version is noted in brackets following the C3SC notation.

You can identify whether CALBSTU localizations have been applied to your system by viewing the application list on GUAABOT. If Report Engine and California Student are listed, your system has been localized.
