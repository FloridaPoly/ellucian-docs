SWF Banner Student page reference

This online help provides the fields and field descriptions for Banner Standard Workload Form (SWF) pages.

Faculty Standard Workload (SVAFSWF) page

The SVAFSWF page allow administrative users to create and maintain a faculty member’s Standard Workload (SWF) page according to the collective agreement pertained to the Ontario colleges’ academic employees.

Faculty members’ teaching contact hours, preparation, feedback, and complementary hours are entered and SWFs are generated in this application page. SWF summary and complementary signing statuses are tracked. Multiple "what if" working scenarios can be created before a final scenario.

A SWF roll process is also available to the designated administrators or departmental users based on their SWF security access to generate SWF course records.

Key block

Use this section to specify the faculty member’s ID and the term code. Faculty member’s general information is displayed in this section.

Field Description

Untitled Name associated to the faculty member’s ID.

If you enter a valid ID in the ID field, the system automatically displays the faculty member’s name in this field. If you leave the ID field blank and enter a valid name in this field (in last name, first name, middle initial format), the system automatically displays the faculty member’s ID in the ID field.
Term Term code.
Scenario SWF scenario number. The final scenario is 0.
Revision SWF revision. A revision number represents the scenario is a revised and previously completed history record.

Summary button Click this button to open the Summary Records window (SVRSWFB) which displays the summary of the existing records. If an ID is entered in the ID field, the summary records are for the selected person only.

If a term code is entered in the Term field, the summary records are for the selected term only.

If both the ID and Term fields are entered, the summary records are for the combination of the ID and the term only.

To list existing records for all of faculty members, clear out both the ID and the Term fields before clicking this Summary button.

Employment Status Employment status. Options available are Probationary and Non-probationary. The employment status of a faculty member is entered in the SVASFAC page.
Program Group Program group. Options available are Post-secondary course teaching or Non Post-secondary course teaching. The program group information of a faculty member is entered in the SVASFAC page.
Category Coordinator. Indicates the faculty member's level of coordinator. The coordinator information of a faculty member is entered in the SVASFAC page.

Options menu

Use the item under the Options menu to execute actions or navigate to a window.

Field Description
SWF Roll Process This process generates SWF for a future term from three data sources, and the options to create SWF scenario records with or without generating the actual SWF and to allow departmental users to run the process. A desired 100% evaluation/feedback type can also be selected.

Reporting Code Group: PC - Roll Process Course Data Source

Institutions can decide which one of the data sources to be used for the process in SWF Report Data Mapping Rules (SVRDMAP) page. The following seed data is delivered in SWF Reporting Data Element Validation Table (SVVRDAT).

For options of the processing data sources select the "PC- Roll process course data source" for Reporting Code Group in SWF Report Data Mapping Rules (SVRDMAP) page. Select the desired reporting code record in the detail section and enter a "Y" in the Banner Value field.

Reporting Code Group: GS- Generate SWF with Roll and Enrollment Audit Process

Institutions can decide whether to generate SWF with the process. The following seed data was delivered in SWF Reporting Data Element Validation Table (SVVRDAT).

For the option of generating SWF with the process, select the "GS- Generate SWF with roll process" for Reporting Code Group in SWF Report Data Mapping Rules (SVRDMAP) page. Select the desired reporting code record in the detail section and enter a "Y" in the Banner Value field.

Reporting Code Group: RD- SWF Roll and Enrollment Audit by Department

Institutions can decide whether to allow departmental users to run the process. The following seed data is delivered in SWF Reporting Data Element Validation Table (SVVRDAT). If the departmental user runs the process, only the SWF data of the user's accessible faculty members will be generated.

For the option of allowing departmental user to run the processing select the "RD- SWF roll by department" for Reporting Code Group in SWF Report Data Mapping Rules (SVRDMAP) page. Select the desired reporting code record in the detail section and enter a "Y" in the Banner Value field.
SWF Roll Process (contd) Reporting Code Group: DE- Default Evaluation for Roll Process

Institutions can decide on which unknown evaluation/feedback type will get the 100% to be defaulted in by the process. The following seed data is delivered in SWF Reporting Data Element Validation Table (SVVRDAT).

For the option of allowing departmental user to run the processing select the "DE- Default Evaluation for Roll process" for Reporting Code Group in SWF Report Data Mapping Rules (SVRDMAP) page. Select the desired reporting code record in the detail section and enter a "Y" in the Banner Value field.
SWF Enrollment Audit Process This process creates a new scenario that the class size of each course is the actual enrollment for the target term. The institution's selections depends on the following options in SWF Report Data Mapping Rules (SVRDMAP) page apply to this process:

GS- Generate SWF with Roll and Enrollment Audit Process

RD- SWF Roll and Enrollment Audit by Department

Any errors/warnings generated from the process are stored in the SWF Process Errors and Warnings (SVASERR) page.
From Term Enter the term code to copy SWF from.
To Term Enter the term code to copy SWF to.
Run Click this button to execute the SWF process.
Cancel Click this button to cancel the action.

Field Description
Generate SWF Execute this action to generate SWF records based on the information in the Detail window. Validation against rules is performed and warning messages are displayed after the action. If there are existing SWF records a warning message is displayed to confirm the override. If the number of total workload hours exceeds the maximum hours allowed, an error message is shown and no SWF summary records are generated. For the message detail, go to the SWF Error (SVASERR) page.

Finalize Scenario Execute this action to make the present scenario to the final scenario as 0. Scenario 0 is displayed in the Faculty Self-Service. Other scenarios are the classified as What if scenarios. If there is an existing 0 scenario a warning message is displayed to confirm the override.
Revise SWF in effect Allows you to revise a completed SWF. The SWF can only be revised when its status is Completed.

Field Description
Active Overtime Hours Indicates the selected overtime hour option is activated or assigned to the SWF. The overtime options are:
  • Teaching contact OT hours: Indicates the teaching contact overtime hours option is activated or assigned if checked.

If the external code is set to YES, then this field is not editable; If the external code is NO, then the field is editable.

Referred to WMG: If this option is selected, then the faculty member can only disagree on the SWF by referring the matter to College Workload Monitoring Group (WMG).

Referred to WRA: if this option is selected, then the faculty member can disagree on the SWF by further referring the matter to the Workload Resolution Arbitrator (WRA) after the WMG option has been exhausted.

Data section

Use this section to specify the colleges and departments that the business profile can access.

Field Description
Read only for all college code Check box used to give the subject business profile the read only access to all institution-wide SWF records.
Include all colleges code Check box used to indicate whether to allow all users in the business profile to access all SWF records and perform SWF Roll process. All access control records in the data section are ignored.

Clear the check box to control the users in the business profile to accessing SWF records in the specified colleges and departments in this section.
College Code College code to which the users in the business profile have access.
Description College code description.
Department Code Department code to which the users in the business profile have access.
Description Department code description.
Read only Check box used to indicate that users in the business profile can only read the records and will not be allowed to update the records of the department and college.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.

SWF Workload Type Factor Rules (SVRWTYP) page

Use the SVRWTYP page to set up all workload type rules for a SWF workload category.

Key block

Use this section to specify the SWF category code and the effective year.

Field Description
Category Code Category code.
Effective Year Effective calendar year.

Data section

Use this section to specify effective year from which the category type to be copied to the corresponding year.

Field Description
Effective From Year Code of the category type year whose rules are effective from and to be copied.
Copy Click this button to copy category type rules from one effective year to another.
To Year Code of the category type year to which the rules are in effect and to be copied.
Workload Type Code Workload type code of the category.
Untitled SWF type description.
Hours Number of hours associated with the SWF workload type code. Used for complementary activities.
Factor Factors related to the workload type code.
Fixed Value Check box used to indicate whether the workload type is fixed in value and cannot be changed in the SWF record of a faculty member.
Default Required Check box used to indicate whether the workload type record will display as default into a new SWF record.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.
