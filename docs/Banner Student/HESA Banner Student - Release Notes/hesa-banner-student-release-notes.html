Release 8.34

The Banner HESA 8.34 release delivers GOANPID changes, regulatory updates and a new java process.

New HGO export Activity ESC_HGO_EXP_CON_2526

This new export activity contains the following changes:

  • Reordering the tags based on c25071 xsd.
  • EMAIL tag is changed to EMAIL1,EMAIL2,EMAIL3
  • INTTEL tag is changed to INTTEL1, INTTEL2, INTTEL3(Only generated when HOMEEUOS ≠ 3)
  • UKMOB tag is changed to UKMOB1, UKMOB2, UKMOB3(Only generated when HOMEEUOS ≠ 3)
  • UKTEL tag is changed to UKTEL1, UKTEL2, UKTEL3(Only generated when HOMEEUOS ≠ 3)
  • Display PostalAddress only when GRADSTATUS=02 and AND COUNTRY IN ('XF', ‘XH', 'XI', 'XG', 'XK')

This enhancement addresses PE0007899 in the Ellucian Customer Center.

GOANPID updates

Added seed data for the GOANPID page along with the following changes:

  • Two new fields DUSANDWICH and DUDISTANCE are added to Report Program > HESA tab.
  • A new repeat block, Discover UNI Accreditation, has been created. As part of this enhancement, the following fields were added under the associated report program:
    • DUACCTYPE
    • DUACCDEPEND
    • DUACCDEPENDURL
    • DUACCDEPENDURLW
  • The GOANPID BPAPI has been updated to align with recent page changes. In addition, the associated documentation has been published to the documentation site to ensure consistency and accuracy.
  • A Description column has been added to the main program block under the report type of program. This enhancement ensures that LOV values now display their corresponding descriptions, improving clarity and usability.
  • The LOV box for the report field on the key block has been resized. This enhancement allows larger report type values to be displayed more clearly, improving usability and visibility.
  • The issue causing LOV values to appear for all free text fields on the SLC tab under the program report type has been resolved. This fix ensures that LOV values now display only where appropriate, improving accuracy and usability.

This enhancement addresses PE0008009 in the Ellucian Customer Center.

New Java batch process

SHPNPDM is a new Java batch process introduced in this release to load XML data into the GOANPID page for both existing and non-existing HESA Data Futures (DF) records. It supports both existing clients (migrating current HESA DF data) and new SaaS customers (populating GOANPID for new setups).

As part of the SHPNPDM process setup, DML scripts are created to insert the new Java process and its related parameters into the following tables:

GUBOBJS GJBJOBS GJBPDEF
GJBPDFT GOBFEOB GJRJBMO
GURAOBJ GURUOBJ GJBPVAL

This enhancement addresses PE0008205 in the Ellucian Customer Center.
