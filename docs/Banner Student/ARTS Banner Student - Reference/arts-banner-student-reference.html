Automated Results Transfer System pages.

ARTS Request File Tracking (SOAARTS) page

The SOAARTS page allows you to view the ARTS file status. You can also re-process the ARTS file that has result acknowledge error or algorithm error.

Key block

Use the Key block to specify the status of the request file and the transaction date for which you want to view the results.

Field Description
Status (Optional) Status of the request file.
Transaction Date Transaction date of the request file.
Application ID Identification code of the student whose details that the institution requests.
Request ID A code for the request that the institution receives.
File Name Name of the request file that the institution receives.

Base section

Use the Base section to view the results information for the status and transaction date specified in the Key block

Field Description
Process Level Details section
Use the Process Level Details section to view the process level error details for the selected record item in the Key block.
Re-process All in a Page Check box to indicate whether administrators can select all the records in the page to re-process.
File Name Unique fine name of the request file.
Request ID Request ID of the file.
Application ID Application ID of the file.
Institution Code Institution code of the file.
ARTS Version ID ARTS version ID of the file.
Status Description Status description of the file
Result Error Result error of the Result Acknowledgment (ACS) file, if any.
Processing Error Processing error in the algorithm file, if any.
Validation Error Validation error of the Request Acknowledgment (ACK) file, if any.
Transaction Date The date on which the file is processed.
Re-process Check box used to indicate whether the selected file is eligible to reprocess the result error or processing error.
Record Details section
Use the Record Details section to view the error details for the selected record item in the Process Level Details section.
Error Code Error code of the record.
Student Identification Code Student identification code of the record.
Course Code Course code of the record.
Subject Code Subject code of the record.
Error Message Error Message of the record.
