CLCONC Banner Student - Reference

Centrelink Concession Validation pages.

Concession Details (SKACONC) page

Use the SKACONC page to enter and display information to determine whether a student is entitled to a concession.

You can also use this page to submit student records to Centrelink for verification and to provide facilities to store concession types and concession IDs (for example, customer reference numbers and so on.)

Key block

Use this section to specify the student’s current ID and name for which you want to enter or display concession details.

Field Description
ID ID of the student.
Name (untitled) Name of the student. If you enter a valid ID in the ID field, the system automatically displays the student’s name in this field. If you leave the ID field blank and enter a valid name in this field (in last name, first name, middle initial format), the system allows you to search for the ID and automatically displays the student’s ID in the ID field.

Base section

Use this section to enter or display program-specific data elements for the ID and name specified in the Key block.

Field Description
Concession Type Type of concession.
Concession Status Status of the concession.
Concession Verified Date Most recent date on which the student’s concession was verified.
Note: Records with a date in this field need do not need to be further verified.
Active Check box used to indicate whether the record is active.
Concession ID ID or customer reference number of the concession.
Secondary Concession ID Secondary reference number or ID of the concession.
Concession Verified Date Date on which the student wants the concession to be verified.
Proof Sighted Check box used to indicate whether the supporting evidence (such as a card or letter) is produced for the concession claim.
Proof Sighted Date Date on which the proof was sighted.
Type of Proof Type of proof used to document the concession.
Concession Start Date Date on which the concession was commenced.
Concession Expiry Date Date on which the concession will expire.
Consent to Verify Radio button group used to verity student’s consent for their data to be shared. Choices are Given, Refused, and Not Known.
Note: Centrelink requires an explicit consent for the data to be shared, and if you clear the Given option, the student will not be included in the Centrelink request file.
Consent Date Date on which the student gave the consent to verify their data to be shared.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.

Report Element Values (SKARVAL) page

Use the SKARVAL page to enter or display valid values for each report element used in statutory reporting.

Base section

Use this section to map reporting element values for the academic year specified in the Key block.

Field Description
Element Code Code of the reporting element that requires a set of valid values.
Maximum Length Displays the maximum length of values that has been set for an element code.
Element Value Valid values for the element code.
Description Description of the element code.
Active Check box used to specify whether this record is active.
End Date Last date on which the value is to be used. After the system date is after the date entered in this field, the value can no longer be used on the relevant data capture page and will not appear in lists of values. This field can be left blank.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.

External Systems Interaction Control (SKASYSC) page

Use the SKASYSC page to maintain settings used in transmitting files to external systems. Examples of such systems include Higher Education Management System (HEIMS), Centrelink and the USI Registry.

DEEWR window

Use the DEEWR window to enter and display control settings for the interaction between baseline Banner and Banner DEEWR.

Field Description
System Code of the external transaction system.
ID Unique institution identifier for the organisation.
Request ID Prefix Prefix to be used for generating request IDs.
Latest Request ID Sequence Latest request ID generated by an Oracle sequence. Display only.
Maximum number of records allowed in a batch Maximum number records that can be included in a batch request for CHESSN and entitlements data. The number of records that can be included in a batch request for CHESSN and entitlements data is limited to 10,000.
Batch Interval Number of weeks after which the entitlements data is refreshed, by including the student in a batch request.
Institution Code Code that DEEWR uses to recognise the institution.
Institution Name Name that DEEWR uses to recognise the institution.
Real-time Web service URL URL to access DEEWR for real-time requests.
Batch Web service URL URL to access DEEWR for batch requests.
Username Institutional user name to access DEEWR.
Current Password Institutional password to access DEEWR.
Password Date Date when the institutional password to access DEEWR was last changed.
New Password New institutional password to access DEEWR.
Next Password Change Date Date when the institutional password to access DEEWR will need to be changed again.
Proxy Server Proxy server that allows users to make real-time requests.
Proxy Port Port on the proxy server for making real-time requests.
Proxy Username User name used on the proxy server for real-time requests.
Proxy Password Password used on the proxy server for real-time requests.
Activity Date Date the record was created or last updated. Display only.

Centrelink window

Use the Centrelink window to enter and display Centrelink CCeS settings.

Field Description
ID ID of the organisation.
Name (untitled) Name of the organisation.
CCeS System Code of the CCeS system.
Batch Code Code to identify the batch.
CCeS User ID User ID supplied by Centrelink for the CCeS system.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.

CART window

Use the CART window to enter and display CART settings.

Field Description
ID ID of the organisation.

CART System Code of the CART system.
CART User ID User ID for the CART system.

Report Elements Validation (SKVRVAL) page

Use the SKVRVAL page to enter or display reporting elements used in statutory reporting. After a report element has been created on this page, you can assign values to the element on the Report Element Values (SKARVAL) page.

Base section

Use this section to enter or display reporting element details that are used in statutory reporting.

Field Description
Element Code Code of the reporting element that requires a set of valid values.
Description Description of the element value.
Active Check box used to specify whether this record is active.
End Date Last date on which the element is to be used. After the system date is after the date entered in this field, new values cannot be added for the element on the Report Element Values (SKARVAL) page, and the element code will not appear in lists of values. This field can be left blank.
Restrict to Uppercase Indicates that any values created for an element code will be saved in upper case.
Maximum Length of Values Restricts the length of values created for an element code.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.
