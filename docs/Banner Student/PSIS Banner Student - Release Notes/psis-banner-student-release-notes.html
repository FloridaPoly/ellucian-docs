Release 8.6

These release notes describe new features, enhancements, and updates in Banner PSIS.

PSIS Extraction Process (SVPESIS) enhancement

With the Banner General team's expansion of the functionality of the SPBPER_SEX field to support Gender X, customers are no longer limited to the following valid values: M, F, and <null> and can now customize the gender value using an LOV. Banner reports that previously relied on a limited set of values will no longer be able to use the value in SPBPER_SEX and will have to provide a crosswalk from the stored value into the mandated values.

As a result, Ellucian has updated the PSIS Extraction (SVPESIS) process in Banner PSIS, so that it uses the Statistics Canada PSIS Crosswalk (SVAXWLK) page for gender instead of hard-coding. This change includes:
  • new seed data for the Statistics Canada Crosswalk Code Validation (SVVXWLK) validation table for code SD4240
  • corresponding seed data for SVAXWLK for the basic gender codes of M, F, and N
  • updates to SVPESIS to begin using the defined crosswalk

This change will allow institutions to use the expanded gender values that are being provided in Banner General.

Attention: As you provide new values in the Banner General table, Legal Sex Code Validation (GTVLGSX), you will be required to add corresponding values to SVAXWLK.

This enhancement addresses PE0002163 in the Ellucian Customer Center.

Release 9.3.30 and 8.5

These release notes describe new features, enhancements, and updates in Banner PSIS.

Global database consolidation

This release includes updates to consolidate Banner database objects for regional localizations into a single global database.

See the Banner General 9.3.26 and 8.16 Release Notes for more detailed information, including a list of tables and scripts.

See KB000502796 - Global Database Project Customer Communication and FAQ in the Ellucian Customer Center for additional details about the global database impact and benefits.

This enhancement addresses PE0001874 and PE0002141 in the Ellucian Customer Center.

STVSBGI code expansion

With this release, has expanded the STVSBGI code from 6 to 20 characters.

Because the school code in STVSBGI has been expanded in baseline Banner Student, we have updated the code in PSIS to enable you to stay in sync with baseline Banner Student and to continue accurate state reporting.

As a result, we have modified the Statistics Canada PSIS Crosswalk (SVAXWLK) page.

This enhancement addresses PE0001792 in the Ellucian Customer Center.

Release 8.4

These release notes describe new features, enhancements, and updates in Banner PSIS.

STVSBGI expansion

The Universities and Colleges Admissions Service (UCAS) has changed the school code length to ten characters. Ellucian expanded the Source/Background Institution code to 20 characters to support this change. As a result, Ellucian updated the PSIS Extraction (SVPESIS) process to support the new 20-character code length.

This enhancement addresses PE0001664 in the Ellucian Customer Center.
