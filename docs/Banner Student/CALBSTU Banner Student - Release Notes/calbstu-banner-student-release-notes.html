New SVAMIST tabs

Ellucian added three new tabs to the MIS Special Term Data (SVAMIST) page to support additional student programs and services reporting:

  • Asian American, Native Hawaiian, Pacific Islander - Documents student achievement status for AANHPI students.
  • Student Equity and Achievement - Documents student equity and achievement program status.
  • Transfer Center - Documents transfer center program participation status.

Services section for MIS-VR reporting

Ellucian added a Services section to all SVAMIST tabs and the CalWORKs Student Data (SVACWSD) page to support the Student Vision Aligned Report (MIS-VR). The Services section includes the following fields:

  • Service Code - The code that identifies the type of service provided to the student. Refer to the CCCCO Data Element Dictionary website for the current list of valid service codes.
  • Service Type - Description of the service code.
  • Service Status - Status of the service (DC: Delivery complete, IP: In progress, RF: Service refused, RP: Referred to provider, SR: Service recommended).
  • Service Status Description - Description of the service status code.
  • Service Date - Date the service was provided or status was updated.
  • Service Comments - Optional comments about the service.

The Services section information appears in the Student Vision Aligned Report (VR) for submission to the California Community Colleges Chancellor's Office (CCCCO).

Important: For the CalWORKs Student Data (SVACWSD) page, enter D06 (Child Care Hours) and D14 (Work Activities) services on this tab only. Services entered on other pages will be flagged as errors and ignored.

New Student Pilot Programs (MIS-PP) report

Ellucian added the Student Pilot Programs (MIS-PP) Report to support reporting on student participation in pilot programs at the college during the reporting term. The report includes participation data for the following pilot programs:

  • AgTEC demonstration project (AGT)
  • Homeless and Housing Insecurity Pilot (HHIP) Program (HHP)
  • Mental Health Workforce Development demonstration project (MHW)
  • Nursing Workforce Development demonstration project (NWD)
  • United Domestic Workers program (UDW)

The report uses SVRCAPP to generate .DAT and .LIS files for submission to the CCCCO. Configure PP01 seed data in SOAXREF to map institutional cohort codes (STVCHRT) to the MIS-PP report values.

A new MIS report has been defined for the California Community Colleges. It is called Student Vision Aligned Report (VR). This report provides information about services a student received from the college. The report is a new term file. The file contains one record for each distinct combination of college, student, service program, and type of service which occurred during the term.

Release 9.3.34 and 8.20

These release notes describe new features, enhancements, and updates in Banner CALBSTU.

MIS enhancement

To comply with the specifications from the California Community Colleges Chancellor's Office, Ellucian has provided the following 2024 MIS Regulatory Reporting updates in the California Banner Student product, CALBSTU:
  • Student Disability Data Report (SD): new element, SD06, STUDENT-ASL-INTERPRET-CAPTION
  • Student Enrollment Report (SX): new element, SX07, ENROLLMENT-CVC

Ellucian also provided the seed data for the new element, SF21, STUDENT-AID-AWARD-TYPE and the new element, SG29, STUDENT-RISING-SCHOLARS-NETWORK, which will be provided in the July 2024 release.

This enhancement addresses PE0003985 in the Ellucian Customer Center.

SVPACAD enhancement

Ellucian has modified the Recalc Academic Calendar Process C3SC (SVPACAD) to allow users to choose if they want to override the Reporting Year. Previously, if a user wanted to update a Reporting Year that spanned over Academic Years in the SVPACAD process, the Reporting Year reverted back to the default Reporting Year. With this release, Ellucian has added a new parameter, Overwrite Reporting Year where users can select Y if they want to recalculate the Reporting Year or select N if they want to recalculate the Start Date but not update the Reporting Year. This change will impact regulatory California CCFS-320 reporting.

This enhancement addresses PE0004011 in the Ellucian Customer Center.

Student disability services APIs

Ellucian has added new security scripts are available to support the following APIs:
  • the new ca-import-mass-student-disability-services POST API
  • the updated ca-import-mass-economically-disadvantaged GET API
  • the updated ca-import-mass-workforce-innovation-opportunity-act GET API

These APIs manage student disability services data that Banner imports from external resources and puts into the Student Disability Services (SGADISA) page and Workforce Innovation and Opportunity Act (WIOA) Data (SVAWIOA) page.

The following database objects support this update:
  • sgubobjsi_093500_01.sql
  • sgubpagei_093500_01.sql
  • sguraobji_093500_01.sql
  • sguruobji_093500_01.sql

This enhancement addresses PE0004133 in the Ellucian Customer Center.

New non-credit values in STVTERM

Ellucian added new non-credit term values in the Apportionment Category in the Term Code Validation (STVTERM) table. This change will allow customers to run the California College Promise Grant (CCPG) and the CCFS-320 reports and processes without changing a student's eligibility when a non-credit term is in the aid year. When the admin user clicks the Apportionment Category drop-down menu, they will see the following options:
  • Not Reported
  • First Primary
  • Second Primary
  • Third Primary
  • Intersession
  • Non-Credit First Primary
  • Non-Credit Second Primary
  • Non-Credit Third Primary
  • Non-Credit Intersession
  • None

This change addresses PD0010810 in the Ellucian Customer Center.

New SVRCALX fields

Ellucian added new fields to the 320 Attendance Extract Process C3SC (SVRCALX) to support the new non-credit term values in the Apportionment Category in the Term Code Validation (STVTERM) table.

The list identifies the fields and how the values are stored in the database on STVTERM_APPORT_CDE:

  • Not Reported stored as (N)
  • First Primary should be stored as (1)
  • Second Primary should be stored as (2)
  • Third Primary should be stored as (3)
  • Intersession should be stored as (I)
  • Non-Credit First Primary should be stored as (A)
  • Non-Credit Second Primary should be stored as (B)
  • Non-Credit Third Primary should be stored as (C)
  • Non-Credit Intersession should be stored as (D)
  • None should be stored as (null)

SSASECT and SSRROLL warnings

Ellucian has updated the warning messages on the Schedule (SSASECT) and Term Roll Report (SSRROLL) pages in Banner Student to support the new non-credit term values in the Apportionment Category in the Term Code Validation (STVTERM) table. The new warning message is triggered when the apportionment is an intersession or a non-credit intercession and course credit status is non-credit and is not an actual CRNand attendance type is Weekly. If these conditions exist, the admin user will see the following warning: Term is intersession; CRN has a weekly type attendance method and will be skipped in apportionment reporting.

SVRCALU enhancement

Ellucian has updated the CCFS-320 Supplemental Reports C3SC (SVRCALU) to separate centers into two sections: Centers Noncredit Sections and Centers Credit Sections. This change allows sections offered by in Centers FTEs to be reported by Center Code and includes separate totals for each section.

This change addresses PD0013682 in the Ellucian Customer Center.
