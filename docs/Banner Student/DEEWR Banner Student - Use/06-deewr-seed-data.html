DEEWR Seed Data

Seed data for tables is included with Banner® DEEWR.

Report System Parameters Table (SKBRSYS)

Seed data for the Report System Parameters (SKARSYS) page is stored in the SKBRSYS table.

Name Description
AD_FILE_CSP Rate code values that indicate a Commonwealth supported program for AD file selection purposes.
AMOUNT_PD_FEE Used in the Student Load-Liability (LL) file in the calculation of Element 381 - for fee-paying students. In the LL file snapshot, HECS-HELP and FEE-HELP payment strands are separated, for ease of calculation. The strands for elements 381 and 384 are combined for the LL file extract activity.
AMOUNT_PD_HECS Used in the Student Load-Liability (LL) file in the calculation of Element 381 - for HECS-HELP students. In the LL file snapshot, HECS-HELP and FEE-HELP payment strands are separated, for ease of calculation. The strands for elements 381 and 384 are combined for the LL file extract activity.
AMOUNT_PD_SA Used in the calculation of the amount each student has paid for Student Services and Amenities Fee
APP-WITHDRAWN Application status code used to decide whether an application has been withdrawn for DEEWR reporting purposes.
BANNER-REG-FROM-TERM The first term in which CRNs have been created in SSASECT and registrations have been saved in the SFRSTCR table. The revisions page SKADREV uses this value to determine whether to check SFRSTCR or SHRTCKN for data that needs to be revised.
CENSUS-DATE-PERCENTAGE Used to specify the duration percentage to be used when calculating a census date for a unit of study (CRN). For example, if the census date should be 20% of the duration of the CRN, the value of this system parameter should be set to 20.
CENSUS-UPDATE-SAPR-CODE Used to specify the single special approval code that is to be assigned to a traditional CRN when that CRN’s census date has passed if the CRN does not already have a special approval code.
CENSUS-USE-SSRMEET This system parameter allows clients to Indicate whether meeting data from SSRMEET should be used when calculating the census date for CRNs that use parts of term.

The setting of the system parameter controls this for all CRNs with a part of term for all terms in the academic year. Data from SSRMEET is never used in calculating the census date for Open Learning Registration CRNs.
CHESSN_HE Used to list rate codes that indicate that the HEIMS system is to allocate a CHESSN and provide entitlements data for the student. Parameter values should be entered for rate codes that indicate the student is a Commonwealth-assisted HE student.
CHESSN_PRIOR_HE Used to list academic category codes that indicate the student has prior HE study. The listed values are compared to the academic category code for the student prior degree record on SOAPCOL.
CHESSN_VET Used to list rate codes that indicate that the VITS system is to allocate a CHESSN and provide entitlements data for the student. Parameter values should be entered for rate codes that indicate the student is a VET FEE-HELP student.
COMMENCE-ADDR-TYPE Used to record the hierarchy of address type codes used to identify a student's commencing address for reporting.
DEEWR-APPS Used to indicate the report collection code that has rules for use in the DEEWR Higher Education Applications and Offers collection.
DEEWR-APPS-LOCATION Used to indicate the report collection code that has campus location (Reporting Locations Mapping (SKARLOC)) page rules for use in the DEEWR Higher Education Applications and Offers collection.
DEEWR-CS Used to indicate the scholarship codes used in the DEEWR CS file.
DEEWR-HE-LEVEL Used to indicate which level codes are HE students. Used in the DEEWR Higher Education Applications and Offers collection and in the DEEWR Higher Education Student collection.
DEEWR-PARENT Relationship codes on STVRELT used to identify parents/guardians for DEEWR reporting.
DEEWR-SA-HELP Used to indicate the report collection code that has calendar (Reporting Calendar (SKAREPT)) page rules for use with the SA-HELP file in the DEEWR Student collection.
DEEWR-SA-HELP-LOCATION Used to indicate the report collection code that has campus location (SKARLOC) rules for use with the SA-HELP file in the DEEWR Student collection.
DEEWR-STUDENT Used to indicate the report collection code that has rules for use in the DEEWR Higher Education Student collection
DEEWR-STUDENT-LOCATION Used to indicate the report collection code that has campus location (SKARLOC) rules for use in the DEEWR Higher Education Student collection.
DEEWR-VFH Used to indicate the report collection code that has rules for use in VET Student Loan reporting
DEEWR-VFH-LOCATION Used to indicate the report collection code that has campus location (SKARLOC) rules for use in VET Student Loan reporting.
DEEWR-ZERO-LOAN-FEE-DATE Used in DEEWR processing as a reference date after which OS-HELP debts do not incur a loan fee.
DEFAULT_ADMIT_INTAKE When Program Offering rules on SKAPOFR are copied from one academic year to another, then the default Admit Intake value is used to populate the Intake field when a valid term code cannot be determined.
DEFAULT-TBRACCD-DUE-DATE This system parameter is used by the skkrept.p_update_tbraccd_due_date process to set a value for the Due Date of eligible charge transactions where there is no corresponding CRN. When a transaction is associated with a CRN, the Due Date value is updated with the value of the corresponding census date.
DETAIL-CODE-LIST When the DETAIL-CODE-LIST-PROVIDED system parameter is set to Y, this parameter is used by the skkrept.p_update_tbraccd_due_date process to determine which records should get updated for eligible students, based on the detail code of eligible charges.
DETAIL-CODE-LIST-PROVIDED This system parameter is used by the skkrept.p_update_tbraccd_due_date process to determine whether to update tuition charge records for eligible students and charges or to only update records for specific detail codes.

If this parameter is set to N, then eligible charges for eligible students will be updated if the category is TUI.

If this parameter is set to Y, then eligible charges for eligible students will be updated if they are for a detail code that corresponds to a value listed for the DETAIL-CODE-LIST system parameter.
DIRECT_ENTRY_CODE Admissions category codes used to identify students applying directly to a HEP, not through a TAC.
E730_COM SORDEGR_EGOL_CODES (educational goal codes) used to indicate that a postgraduate course has been completed for element 730.
E730_INCOM SORDEGR_EGOL_CODES (educational goal codes) used to indicate that a postgraduate course has been commenced but not completed for element 730.
E730_PG_CODE Award category codes for valid postgraduate courses reported in element 730.
E731_BACH_CODE Award category code used to indicate whether a course is a bachelor's degree for the purposes of reporting in element 731.
E731_COM Educational goal code used to describe a completed bachelor's degree for element 731.
E731_INCOM Educational goal code used to describe a commenced but incomplete bachelor's degree for element 731.
E732_COM Educational goal code for a complete sub-degree course for element 732
E732_HE_LEVEL Level code used to identify an institution as Higher Education for element 732
E732_INCOM Educational goal code for an incomplete sub-degree course for element 732.
E732_SUB_CODE Award category code used to describe a sub-degree course for reporting in element 732.
E733_COM Educational goal code for a complete sub-degree course for reporting in element 733
E733_INCOM Educational goal code for an incomplete sub-degree course for reporting in element 733
E733_SUB_CODE Award category code used to describe a sub degree course for reporting in element 733
E733_VET_LEVEL Level code used to describe a VET institution for reporting in element 733
E734_COM Educational goal code used for complete VET course for reporting in element 734
E734_INCOM Educational goal code used for incomplete VET courses for reporting in element 734
E734_VET_CODE Award category code used to identify VET courses for element 734
E735_VET_SCH_LEVEL Level code used for identifying a VET institution for reporting in element 735
E736_SEC_LEVEL Level code used to identify an institution as secondary school for reporting in element 736
E737_OTHER_CODE Award category code used to describe a course for reporting in element 737
ECAF_BRIDGING_PROGRAM Used to list any program codes indicating that an Australian permanent resident is undertaking a bridging program that is approved for FEE-HELP and therefore, allows the student to be potentially eligible to receive FEE-HELP.
ECAF_CITZ_ELIGIBLE Used to list the Banner Citizenship values indicating that the student is either an Australian citizen or holds an Australian permanent humanitarian visa - and is therefore, potentially eligible to receive all forms of Commonwealth Assistance. It is likely that users will use the element 358 values in the Citizenship Validation (STVCITZ) page, but this is not compulsory. However, this system parameter looks at SPBPERS_CITZ_CODE and therefore, the parameter value(s) must correspond to valid values on STVCITZ.
ECAF_CITZ_NEW_ZEALAND Used to list the Banner citizenship values indicating that the student is a New Zealand citizen. It is likely that users will use the element 358 values in STVCITZ but this is not compulsory. However this system parameter looks at SPBPERS_CITZ_CODE and therefore, the parameter value(s) must correspond to valid values on STVCITZ.
ECAF_CITZ_PR Used to list the Banner citizenship values indicating that the student is an Australian permanent resident (not a permanent humanitarian visa). It is likely that users will use the element 358 values in STVCITZ but this is not compulsory. However, this system parameter looks at SPBPERS_CITZ_CODE and therefore the parameter value(s) must correspond to valid values on STVCITZ.
ECAF_OS_HELP Used to list the HELP_TYPE code value(s) that refers the Commonwealth assistance is OS-HELP.
ECAF_REPLACE_KEEP Used to set the default value for each record on the Existing Commonwealth Assistance page (ASC_ECAF_REPLACE_KEEP).

KEEP = If a student clicks Continue without making any changes, any existing current Commonwealth assistance records that are for a different type of Commonwealth assistance to the one selected remain current (SKRECAF_CURRENT_IND remains as Y)

REPLACE = Any existing current Commonwealth assistance records that are for a different type of Commonwealth assistance than the one selected will be updated to not current (SKRECAF_CURRENT_IND will be updated to N) when the new selected Commonwealth assistance record is submitted
ECAF_RESD_ELIGIBLE Used to list the Banner residence code values that indicate that the student is deemed to be resident in Australia for their studies and is therefore, potentially eligible to receive Commonwealth assistance, or be in a Commonwealth-supported place.
ECAF_SET_TERM_MSG Allows clients to modify the message displayed to students on the ASC_ECAF_SELECT_PROGRAM Self-Service page if none of the current terms have been set up for web registration.
ECAF_VET_FEE_HELP Used to list the HELP_TYPE code value(s) indicating that the Commonwealth assistance is VET Student Loan.
ECAF-CANCEL-REDIRECT Used to specify the URL of the page to which a user is to be directed after clicking Cancel on an eCAF Self-Service page. If you do not specify a value for this parameter, the Student Records menu is displayed when a user clicks Cancel.
ECAF-CENSUS-ERROR-MSG Used to specify the message to be displayed on the Select Commonwealth Assistance Type (ASC_ECAF_SELECT_HELP_TYPE) Self-Service page if all of the census dates for the student’s registrations and Recognition of Prior Learning (RPL) are in the past. The delivered message is as follows: The census dates for all of your registrations have passed. This means you are not allowed to submit a request for Commonwealth assistance this term.
ECAF-CITZ-CHECK-ERROR-MSG This system parameter allows clients to modify the message displayed on the ASC_ECAF_CITIZENSHIP_CHECK self-service page to students who are not eligible to submit a request.
ECAF-CLOSED-MSG Used to specify the information text message to be displayed if there are no term codes set up to allow Requests for Commonwealth assistance to be submitted. If no term code is available, student curriculum records and the Term field are not displayed on the Generate New Request for Commonwealth Assistance (ASC_ECAF_SELECT_PROGRAM) Self-Service page.
ECAF-COURSE-COST-ERROR-MSG Used to specify the message to be displayed on the Request for VET FEE-HELP (ASC_ECAF_VFH) Self-Service page if the user attempts to submit a VET FEE-HELP request without entering an amount in the Estimated Course Cost field.
ECAF-COURSE-LEN-ERROR-MSG Used to specify the message to be displayed on the Request for VET FEE-HELP Self-Service page if the user attempts to submit a VET FEE-HELP request without entering a value for the estimated duration of the course.
ECAF-DEFAULT-PROGRAM-EFTSL Used to specify whether the value in the Program EFTSL field on the Course File Data (SKADRCO) page is to be used to pre-populate the estimated duration of a course when a student submits a Request for a VET FEE-HELP loan eCAF. Valid values are as follows:
  • Y: Yes, use the value in the Program EFTSL field to determine the estimated course duration
  • N: No, do not use the value in the Program EFTSL field to determine the for estimated course duration

If you specify Y for this parameter, and if you want Self-Service to display a plain-language description instead of a code, you can define the description using the PROGRAM-EFTSL element on the Report Element Values (SKARVAL) page. If there is no corresponding record for the value, the exact value from the Program EFTSL field will be displayed.
ECAF-DEFAULT-STATE Used to specify the value from STVSTAT that is to be used for the default state for students who submit an eCAF for VET FEE-HELP and are subsidised in a reform state or territory.
ECAF-DERIVE-VFH-RATE Used to specify which field on student records is to be used to determine the correct curriculum rate code when the student's VET Student Loan eCAF record from the Australian government portal is uploaded to the SKRECAF table. Valid values currently recognised by the function that inserts SORLCUR records are as follows:
  • RATE-CODE: The existing rate code is to be used to determine the new rate code
  • STYP-CODE: The existing student type code is to be used to determine the new rate code.

You must create mapping rules on SKARMAP to map values to rate codes.
ECAF-DUP-PROGRAM-MSG Students with multiple current, active learner curriculum records for the same program are redirected to the ASC_ECAF_DUP_PROGRAM page after selecting any of those programs for an eCAF submission. This parameter allows users to configure the message that is displayed to students on the ASC_ECAF_DUP_PROGRAM page. If you do not customise the value for this parameter, the following message is displayed by default:

"You have multiple current, active, learner curriculum records for this program and will need to complete a paper request for Commonwealth assistance. Please contact your local Student Administration office to complete the appropriate request for Commonwealth assistance form."
ECAF-ENRL-BUSINESS-DAYS Used to specify the number of business days that need to pass after students have enrolled before they can submit a Request for a VET FEE-HELP loan. This is to comply with the legislated cooling-off period between enrolment and submission of a Request for a VET FEE-HELP loan.
ECAF-ENRL-CHECK-ERROR-MSG Used to specify the message displayed on the Select Commonwealth Assistance Type Self-Service page to users who might be eligible for VET FEE-HELP but have enrolled too recently to be allowed to submit a request. This check is to comply with the legislated cooling-off period between enrolment and submission of a Request for a VET FEE-HELP loan. The delivered message is as follows: "You have enrolled too recently to be allowed to submit a Request for VET FEE-HELP loan. Please try again when it has been two business days as of your enrolment."
ECAF-EXCLUDE-RATE Used to specify rate codes that should exclude a student's curriculum/study path record from being displayed on the Generate New Request for Commonwealth Assistance Self-Service page.
ECAF-HELP-TYPE-MESSAGE If a student attempts to submit a request for Commonwealth assistance in Self-Service and the ECAF-HELP-TYPE-OFFERED system parameter does not have a value for the academic year of the term code selected on the ASC_ECAF_SELECT_PROGRAM Self-Service page, then the ECAF-HELP-TYPE-MESSAGE system parameter is used to determine what message is displayed to that student.
ECAF-HELP-TYPE-OFFERED Used to specify the types of Commonwealth assistance that your institution offers. The eCAF Self-Service pages only display details of and allow students to apply for the types of Commonwealth assistance specified in this parameter.
Use single-character codes for each type of assistance to list those that are offered by your institution. Codes should be separated by commas with no spaces, Valid values are as follows:
  • F = FEE-HELP
  • H = HECS-HELP
  • O = OS-HELP
  • S = SA-HELP
  • V = VET FEE-HELP.

For example, if your institution offers VET FEE-HELP and FEE-HELP, the value for this parameter should be V,F or F,V. If your institution offers all of the types of Commonwealth assistance, the value for this parameter should be F,H,O,S,V.

The delivered value for this parameter is UPDATE-ME, and if you do not change this, the system displays following message on the Select Commonwealth Assistance Type page (ASC_ECAF_SELECT_HELP_TYPE): This institution currently does not offer any Commonwealth assistance, or has not provided information on the types of Commonwealth assistance offered.

If you do not enter any valid values for this parameter but want a different message to be displayed, you can the message in the ECAF-HELP-TYPE-MESSAGE parameter.
ECAF-NO-STATE-MSG Allows clients to modify the message displayed to students on the Request for VET FEE-HELP page (ASC_ECAF_VFH) if no reform states or territories have been set up as web-enabled for the label ECAFSTAT on SOAXREF.
ECAF-NO-VALID-PROGRAM-MSG Used to specify the message to be displayed on the Generate New Request for Commonwealth Assistance Self-Service page to a student who does not have a program that is eligible for Commonwealth assistance. This could be because none of the student’s current programs are in the CO File Locked Data (SKRLDCO) table or VCO File Locked Table (SKRLVCO) table. If you do not specify a value for this parameter, a default message is displayed when a student’s program is not in either of the locked tables.
ECAF-NO-VALID-RATECODE-MSG Used to specify the message to be displayed on the Generate New Request for Commonwealth Assistance Self-Service page to a student whose programs are in SKRLDCO and SKRLVCO but do not have a rate code that is eligible for Commonwealth assistance. If you do not specify a value for this parameter, a default message is displayed when a student’s program has an excluded rate code for an otherwise eligible curriculum.
ECAF-OBLIGATIONS-ERROR-MSG Used to specify the message displayed to students on the ASC_ECAF_VFH Self-Service page if they attempt to submit a VET FEE-HELP request without checking each obligations indicator.
ECAF-PARENT-ERROR-MSG Used to specify the message displayed on the Request for VET FEE-HELP Self-Service page if a user who is under 18 years of age attempts to submit a VET FEE-HELP request without providing parent or guardian details.
ECAF-REPORT-COLLECTION Used to specify the report collection codes that are to be included when evaluating the reference end dates on the Report Calendar (SKAREPT) page for a term code to determine whether that term code should be available on the Generate New Request for Commonwealth Assistance Self-Service page.

ECAF-TERM-TABLE The Banner table that is to be used to compare the current date against term start and end dates when controlling whether students can lodge eCAFs for the term.
ECAF-VFH-UNDER-18-MSG Used to specify the message displayed on the Select Commonwealth Assistance Type Self-Service page if the user would normally be eligible to submit a request only for VET FEE-HELP and is under 18 years of age.

If EXCLUDE-IN-RATE-CODE parameter value is N, then rate code checking against the values listed for the INTERNATIONAL-RATE-CODE parameter is not done.

The parameter is used in the process that is used to update TBRACCD_DUE_DATE so that if a student has a curriculum record where the latest term code is an excluded term, that record is not used and the next latest curriculum record is used instead.

If the student is registered only in the EXCLUDE-TERM-CODE and no other term code for the current academic year, then they will be excluded from the process.

SKADREV_VFH_HE This parameter sets the default revisions type on the SKADREV page. The expected values are V for VET FEE-HELP and H for Higher Education. OS-HELP is not available as a default.
SKAECAF-CHESSN-VALIDATION The SKAECAF page includes a validation that requires students to have a record on SKACHSN for which they either have a CHESSN or have given consent for a CHESSN to be requested. This system parameter is used to set the level of this SKAECAF validation to either prevent navigation to the data block, present a warning, or perform no validation. Valid values are as follows:
  • E: Error and prevent navigation
  • W: Warning but allow navigation
  • Null or any other value: Save with no error or warning message
SKAECAF-HELP-TYPE-OFFERED Enables an institution to list the types of Commonwealth assistance that they offer on the SKAECAF page. Users must use single-character codes for each type of assistance to list those that are offered by the institution. Each code should be separated by a comma. That is, F = FEE-HELP, H = HECS-HELP, O = OS-HELP, S = SA-HELP, V = VET FEE-HELP and L = VET Student Loan. Therefore, if your institution offers VET FEE-HELP and FEE-HELP, the value for this system parameter should be V,F or F,V.
SKAECAF-RATE-VALIDATION The SKAECAF page includes a validation that requires the student to have an appropriate rate code. This system parameter allows authorised users to set the level of this SKAECAF validation to either prevent navigation to the data block, present a warning or have no validation. Valid values are E - Error and prevent navigation; W - Warning but allow navigation; any other value, including null - Save with no error or warning message.
