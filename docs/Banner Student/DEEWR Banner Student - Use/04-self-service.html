Self-Service

Banner DEEWR includes Self-Service pages to allow students to submit electronic Commonwealth Assistance Forms (eCAFs). This chapter describes the template Web pages as delivered. These descriptions are used to help you modify the delivered pages to meet your institution's needs.

Note: Due to legislative changes from 1 January 2017, students are no longer allowed to make new applications for VET FEE-HELP, and can only apply for VET Student Loans using the Australian government portal, or through a paper form.

Therefore, there is no self-service solution for VET Student Loan application in Banner DEEWR.

To prevent students from making applications for VET FEE-HELP, simply update the value for the ECAF-HELP-TYPE-OFFERED system parameter so that V is not one of the offered types of Commonwealth assistance.

Related concepts
  • eCAF processing

Tasks

This section provides instructions for performing self-service tasks.

Submit a request for Commonwealth assistance

You can use the following procedures to submit a request for Commonwealth assistance.

Submit a request for Commonwealth support and HECS-HELP

Ssubmit a request for Commonwealth support and HECS-HELP.

Procedure

  1. Access Student Self-Service.
  2. When the Student Records menu is displayed, click Submit Request for Commonwealth Assistance.
  3. When the Commonwealth Assistance page (ASC_ECAF_WELCOME) is displayed, read the information, then click Continue.
  4. When the Generate New Request for Commonwealth Assistance page (ASC_ECAF_SELECT_PROGRAM) is displayed, select the program for which you want to submit a request for Commonwealth assistance.
  5. Select the term from which this request for Commonwealth assistance is to begin.
  6. Click Continue.
  7. When the Select Commonwealth Assistance Type page (ASC_ECAF_SELECT_HELP_TYPE) is displayed, select Commonwealth support and HECS-HELP, then click Continue.
  8. When the Existing Commonwealth Assistance page (ASC_ECAF_REPLACE_KEEP) is displayed, if you have existing current Commonwealth assistance records for the selected program, specify whether this new request replaces existing records or is additional, then click Continue.
  9. When the Do you have a valid Tax File Number? page (ASC_ECAF_TFN) is displayed, read the tax file number requirements, then click Continue.
  10. When the Request for Commonwealth support and HECS-HELP page (ASC_ECAF_HECS_HELP) is displayed, complete the fields that are relevant to your request for assistance.
  11. Select the I Agree check box to indicate that you understand and agree to all declarations displayed on the page, then click Submit.
  12. When the Confirm Commonwealth support and HECS-HELP Request page (ASC_ECAF_CONFIRM_HECS_HELP) is displayed, confirm that all the details are correct, then click Continue.
  13. When the Receipt of Request for Commonwealth Assistance Page (ASC_ECAF_RECEIPT) is displayed, if desired, print a copy of the page for your records.
  14. Click RETURN TO MENU to return to the Student Records menu.

Commonwealth Assistance (ASC_ECAF_WELCOME)

This page is the entry point to the eCAF Self-Service pages.

Its underlying logic resets the global G_SPATH parameter after a student has selected a study path for registration using baseline Self-Service. This allows the other eCAF Self-Service pages to use dynamic navigation rules that are defined in the Banner Mass Data Update Utility (MDUU).

Generate New Request for Commonwealth Assistance (ASC_ECAF_SELECT_PROGRAM)

This page is used to select the program and term for which the eCAF is to be entered.

The displays only the curricula for which the corresponding program code is in the CO File Locked Data (SKRLDCO) table and for which the corresponding rate code is not specified in the ECAF-EXCLUDE-RATE system parameter.

A term code is available for eCAF submission if the following conditions are true.

  • The web registration start date on SOATERM is earlier than or equal to the current system date

    - AND -

  • A reporting calendar record exists for the term for specific reporting collections for which one of the following conditions is true:
    • The current system date falls within the reporting calendar reference dates

      - OR -

    • Reference dates are not used and the current system date is earlier than or the same as the term end date
Setup requirements

Setup is required for the Generate New Request for Commonwealth Assistance page to work as expected.

Report Calendar Form (SKAREPT) For each term you want to be available for selection on the web, create report calendar rules and either specify reference dates or leave the reference date fields blank.
Report System Parameters Form (SKARSYS) Specify values for the following system parameters:
  • ECAF-CANCEL-REDIRECT
  • ECAF-CLOSED-MSG

  • ECAF-NO-VALID-PROGRAM-MSG

Multiple Records for Program (ASC_ECAF_DUP_PROGRAM)

If a student has multiple active, current, learner curriculum records for the same program and if none of the records has a rate code that has been excluded from being available for selection on the web, the student is not allowed to submit an eCAF.

Students who attempt to start the eCAF process for a program for which they have multiple active, current, learner curriculum records are redirected to this page, which displays a message stating that an eCAF cannot be submitted.

Citizenship Status (ASC_ECAF_CITIZENSHIP_CHECK)

This page is used to navigate through the flow of pages for eCAF submission, after the ASC_ECAF_HELP_TYPE page.

If the student is a New Zealand citizen or has a non-humanitarian permanent resident visa and is potentially eligible for the type of HELP that they have selected, they will be navigated to this page.

The exact questions on the page will be different depending on the student's citizenship and the selected HELP type. The questions about residency in Australia during their studies and about special category visas for New Zealand citizens are the same as the questions on the paper version of each HELP form.

Existing Commonwealth Assistance (ASC_ECAF_REPLACE_KEEP)

This page is displayed only if the student has existing records for the selected program in the Request for Commonwealth Assistance Table (SKRECAF) where the SKRECAF_CURRENT_IND = Y.

If such an existing record is for the same type of Commonwealth assistance that the student has selected, then when the student submits this new eCAF, SKRECAF_CURRENT_IND is set to N for the existing record.

If any existing current record is for a different type of Commonwealth assistance than the one that the student as selected, then the student is asked to decide whether this new eCAF replaces the existing current record, or is additional to the existing current record.

If the student had existing records in SKRECAF and selected to replace them on the Existing Commonwealth Assistance page (ASC_ECAF_REPLACE_KEEP), SKRECAF_CURRENT_IND is updated to N for these records.

The temporary table SKTECAF is purged.

This page also populates the correct rate code into the student's curriculum, based on the values for the system parameters in the Setup Requirements section for this page. The process inserts curriculum records to the Learner Curriculum repeating Table (SORLCUR), using the same processing logic that is used by the Update button on the curriculum window on baseline pages.

The process finds the active, current, learner curriculum record for the student that matches the program that the student has selected for their request for Commonwealth assistance, and is the latest active, current, learner curriculum for the term that the student has selected for their request for Commonwealth assistance.

If the curriculum selection finds only one record, then the existing active, current, learner curriculum is ended and a record is inserted with INACTIVE curriculum status. Then a new active, current, learner curriculum is inserted for the same program and for the term code selected by the student for their request for Commonwealth Assistance. The rate code is populated with the correct value based on the type of Commonwealth Assistance that the student has selected and the data that they have provided when requesting Commonwealth Assistance.

If the curriculum selection finds more than one record, then no updates are made to SORLCUR. Instead, data for the selected curriculum records are written to an Error Logging Table (SKRELOG) and users must manually update the correct curriculum record with the correct rate code.

The inserts to SKRECAF and the purging of eCAF Temporary Table (SKTECAF) continue and the student is not presented with an error message.
