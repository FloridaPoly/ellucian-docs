Banner GRDS release notes

Ellucian typically posts release notes the day before it makes the software available to customers. You can review Banner product release dependency information in Ellucian Solution Manager or the Banner Interdependency Matrix attached to Article KB000500135 - Banner Interdependency and Compatibility Matrix in the Ellucian Customer Center.

Support for Banner 8 Self-Service has ended

As of January 1, 2026, Banner8 Self-Service has moved out of Sustaining Support and has entered End of Support.

For detailed information on support statuses, please review our Support Assurance Policy.

Release 9.3.41

The Banner GRDS 9.3.41 release version delivers product defects.

To enhance accessibility and ensure compliance with WCAG guidelines, Ellucian has added missing labels to the pages. These updates improve screen‑reader compatibility and overall usability for assistive technologies. There is no change in functionality.

Release 9.3.32 and 8.3

The Banner GRDS 9.3.32 and 8.3 releases provide one enhancement and defect corrections.

DB procedures (dbprocs) have been enhanced to meet the current coding standards that satisfy the implementation of Ellucian's Global Database initiative.

This enhancement addresses PE0002497 in the Ellucian Customer Center.
