Student Self-Service (Canadian Institutions)

Used together with the T2202A enhancement, the Banner Student Self-Service and Banner Student systems enable students and administrators to view or print T2202 and Relevé 8 forms from the web.

Administrators, who are set up in the SVATADM Form but are not part of the Student module, can access T2202A Self-Service pages to print tax receipts for a specific student.

When the t2202a_admin_web.sql script is run, a link to the T2202A Self-Service pages is added to the specified menu. See Add administrator Web pages to Banner Self-Service to see how to add a menu link.

Note: If you do not run the t2202a_admin_web.sql script, only administrators who are part of the Student module can access the T2202A Self-Service pages.

Menus and hard-coded messages in the T2202 and Relevé 8 web pages can be customized using Banner Web Tailor.

This section describes the following web pages.

Canadian Tax Forms Menu (P_CanTaxMnu)

This page allows a student or administrator to select either T2202 or Relevé 8 forms. This page is accessed from the Canadian Tax Forms link on the Student Main menu (bmenu.P_StuMainMnu).

When a link is selected, the page will check if the login ID is a T2202A administrator (as defined on the STVTADM page).

The following menu options are displayed under this category:
  • Slips For Income Tax Return
    Note: The Slips for Income Tax Return link is not delivered but can be added to this menu locally, if desired, through a script. See the Setup Requirements for more information.
  • T220A Tax Credit Form
  • Relevé 8 Tax Form

Setup requirements

The following setup is required for this Form to work as expected.

Item Description
T2202A Administrator (SVATADM) page If desired, enter the IDs that represent people who are T2202A administrators, and will be allowed to view student information from the web.
t2202a_admin_web.sql script If desired, run this script to add the T2202A Tax Credit Form link, which goes to the T2202A web pages to the specified menu of a self-service module.

Running the script allows administrators, who are set up in the SVATADM Form but are not part of the Student module to access T2202A web pages to print tax receipts for a specific student.

See Add administrator Web pages to Banner Self-Service to see how to add a link to the T2202A web pages.

If the t2202a_admin_web.sql script is not run, then only administrators who are part of the Student module can access the T2202A web pages.
yrend_check_web. sql script If desired, run this script to add the Slips For Income Tax Return link, which goes to the Slips for Income Tax Return Form (bwvkxtax.P_ChooseTaxSlip) in Employee Self-Service. The yrend_check_web.sql script will do the following:
  • Checks the PURVERS table to verify that Human Resources 7.1 (minimum release) has been installed
  • Checks the BWPVERS table to verify that Employee Self Service 7.1 (minimum release) has been installed
  • Checks the GVRVERS table to verify that Year End 2.0 software has been installed
  • Checks the TWGBWMNU table to verify that a record for bwvkxtax.P_ChooseTaxSlip exists (to ensure that the web portion of Year End 2.0 is installed)

If one or more of these is not in place, the installation of the link will be terminated, and a message will be displayed indicating what is missing to proceed.

Updates to Banner

This Form does not update information in the Banner database.

Tax Credit Data Form Page (bwvktt22.P_ChooseT2202AKey)

This Form is used by students and administrators to do the following.

  • Specify the tax year for which to view or print a T2202 form.
  • Print a Quebec receipt from the web (for years before 2013)
  • Print a Charitable Donation Receipt from the web (not displayed if the receipt number in the most recent SVBTAXC record is NULL for the selected tax year)

The system uses the XSL template associated with the selected Form type and tax year to compose the Form in PDF format, depending on the Form type and the tax year selected.

Users cannot view or print T2202 or Quebec Tuition receipts when neither a program nor a degree code exists in the SVBTAXC records for students in the tax year. An error will be displayed to the user.

When an administrator has logged into the Canadian tax Form web pages, and selected a student ID, the top of the web Form will display the following message: Working with Student BANNER ID. This allows the administrator to know the ID with which they are working.

Setup requirements - Tax Credit Data Form Page

The following setup is required for this Form to work as expected.

Item Description
T2202A Education/Tuition Amount Limits (SVATAXL) Select the Display on Web check box for each year that is to be available for selection on the Web.
T2202A Taxation (SVATAXC) Student must have a record in the SVRTAXC table for the selected year to be able to see the T2202 form.
Crosswalk Validation Form (GTVSDAX) Enter the appropriate URL in the Description field for the PDF_URL internal code in the T2202A internal group.

Item Description/source information

The available tax years are the years that are associated with the Student ID in the SVBTAXC table and for which the Display on Web check box on the T2202A Education/Tuition Amount Limits (SVATAXL) page.
View Data Select this option button to view the T2202 data as stored in the system.
Printable T2202 form (PDF)

Printable T2202 form and Charitable Donation Receipt (PDF)

 Select this option button to display and print the T2202 form and, if applicable, Charitable Donation Receipt in PDF format.
Note: If a Charitable Donation Receipt receipt exists for the selected tax year, the label of the option button includes "and Charitable Donation Receipt".
Printable Quebec Receipt Select this option button to go to a Form from where the Quebec Form can be printed. This option button is displayed only for tax years through 2012.

The Quebec receipt contains T2202 data in a special format requested by the Quebec province. This Form is sent to the province of Quebec only. Students from Quebec should send the T2202 form to the Federal Government and the Quebec receipt to the provincial one (Quebec). The Quebec receipt is not the same as the Relevé 8 form.

View T2202A Page (bwvktt22.P_ViewT2202A)

This Form enables a student or administrator to view a T2202 form. The web Form displays the word UNOFFICIAL at the top of the Form to indicate this information is an unofficial view of the T2202 information.

When an administrator has logged into the Canadian tax Form web pages, and selected a student ID, the top of the web Form will display the following message: Working with Student BANNER ID. This allows the administrator to know the ID with which they are working.

Setup requirements - View T2202A Page

The following setup is required for this Form to work as expected.

Item Description
T2202A Education/Tuition Amount Limits (SVATAXL) The Display on Web check box must be selected for the year that was selected.

A message appears on the web Form when tax data exists but cannot be viewed from the web (Display on Web check box is not selected on SVATAXL).
T2202A Taxation (SVATAXC) Student must have a record in the SVRTAXC table for the selected year, to be able to see the T2202 form. A message will be displayed on the web Form when no tax data exists for the student.

If the Hold Flag check box is selected, the student’s record for the selected year cannot be viewed. A message appears on the web form informing the student to contact the institution.
T2202A Reporting Period (SVATXRP) Records must exist in the SVBTXRP table for the selected tax year. A warning appears when no records exist in the SVBTXRP table.

Web page fields - View T2202A Page

This Form contains the following fields.

Item Description/source information
Student Name Student’s name.
Tax Year Tax year to which the T2202 applies.
Street Line 1-4 First four lines of the student’s address.
City Student’s city.
Prov/State Student’s province or state.
PC/ZIP Student’s postal code or zip code.

If the Program field (SVBTAXC_PROGRAM) on the SVATAXC page has a value, then the value from the SMRPRLE_PROGRAM_DESC field is used as the program description. From Month Beginning month of the reporting period.
To Month Ending month of the reporting period.
Claimable Amount Total eligible tuition tax credit for the reporting period.

If a term code is associated with multiple reporting periods, but these reporting periods do not completely cover the students' active period in the term (the months between SVBTAXT_FROM_DATE and SVBTAXT_END_DATE), then a word "Error-Erreur" in both English and French is displayed in this field and the following message appears under the T2202 Information table:

Error amount has occurred. Please contact the registrar's office

When the above-mentioned error is displayed on the web Form, the T2202A administrator will need to evaluate whether the term is completely associated with necessary reporting periods on the T2202A Reporting Period (SVATXRP) page. This only applies if the term is already associated with multiple reporting periods.
PtMth Number of part-time months for which the student is eligible.
FtMth Number of full-time months for which the student is eligible.
Totals Totals of the Claimable Amount, PtMth and FtMth values. If the total is less than $100.00, N/A is displayed.

Relevé 8 Tax Credit Print Form Page (bwvkrel8.P_ConfirmPrintPage)

This web page confirms that the student or administrator wants to print the Relevé 8 (RL-8) page. Printing an RL-8 page marks the record as printed.

Note: Only Internet Explorer can reliably print T2202 and RL-8 forms generated in HTML format by Banner T2202A on two pages. Users of other browsers might need to adjust the page margins to accomplish this, or they can display and print the forms in PDF format.

When an administrator has logged into the Canadian tax page web pages, and selected a student ID, the top of the web page displays the following message: Working with Student BANNER ID.

The following warning message is displayed before printing.

Warning: The printed version of Relevé-8 will not be valid if the background of the gray boxes are not printed. Note that although the gray boxes on your screen may appear 'coloured', that will not be actually printed if you do not follow the instructions below depending on the browser that is being used.

Solution for Internet Explorer:

  • Go to TOOLS in the menu toolbar,
  • Select "internet options", "advanced", "printing", then check the "print background colors and images" option.

    Solution for Netscape and Mozilla/Firefox:

  • Go to FILE in the menu toolbar,
  • Select "print preview", then click on "page setup" in the toolbar and check "Print background (colors and images)"
    Note: This message above has been delivered as information text in an SQL script ( releve8_web.sql ) included in the installation package for T2202A release 5.6. To display the message on different lines, several line breaks ( <br> ) have been inserted in the message (labeled as PRINTWARMSG3 ) within a SQL statement in the script. Removing the line breaks from the PRINTWARMSG3 message in the script will result in the line breaks disappearing from the above message.

Printable Relevé 8 HTML (bwvkrel8.P_LaunchReleve8_11, bwvkrel8.P_LaunchReleve8_08, bwvkrel8.P_LaunchReleve8, and bwvkrel8.P_LaunchReleve8_Prior07)

This page displays the printable Relevé 8 (RL-8) page in HTML format using the template for the selected tax year before 2012.

When the HTML version of the page is displayed, the user should print it because the system marks the page as having been printed and Duplicate is printed on the page if it is printed again.

Different layouts of the web page are displayed depending on the selected tax year, as follows:
  • For tax years before 2007, the Printable Relevé 8 HTML (bwvkrel8.P_LaunchReleve8_Prior07) is displayed.
  • For 2007, the Printable Relevé 8 HTML (bwvkrel8.P_LaunchReleve8) is displayed.
  • For 2008 through 2010, the Printable Relevé 8 HTML (bwvkrel8.P_LaunchReleve8_08) is displayed.
  • For 2011, the Printable Relevé 8 HTML (bwvkrel8.P_LaunchReleve8_11) is displayed.

The data displayed these pages varies according to the tax year.

  • Before 2007, only the Relevé 8 amount is shown.
  • For 2007, the page shows the Relevé 8 amount and the Box B amount. A numeric code indicates if the page is original (0) or amended (1).
  • For 2008 through 2010, the page shows the Relevé 8 amount and amounts for Box B and Box C. A letter code indicates if the page is original (R), amended (A). or cancelled (D). (There was no cancelled indicator before 2008.)
  • For 2011, the page shows Relevé 8 icon (bitmap) at the top left corner of the page and Revenue Québec logo at the bottom left corner of the page.

The Quebec Government provided the following advice for printing Relevé 8 forms.

  • For years before 2007, the RL-8.L (2005-10) Form is used for Relevé 8 forms through T2202A Self-Service.
  • For 2007 and later, the RL-8 (<year>-10) Form (where <year> represents the tax year) is used for Relevé 8 forms through T2202A Self-Service.

When an administrator has logged into the Canadian tax Form web pages, and selected a student ID, the top of the web page will display the following message: Working with Student BANNER ID. This allows the administrators to know the ID with which they are working.

A date and time stamp are displayed on the Relevé 8 page. The address on the Relevé 8 tax receipt is from the SVBTAXC table.

For 2008 or later, a facsimile number is displayed only if applicable. An XML sequence number is displayed if one has been assigned.

When a user accesses this page to print a Relevé 8 page that has previously been printed, Duplicate is printed on the page if it is printed again without any changes on the Box B amount.

The process for determining whether to create an amended record differs according to tax year, as follows.

  • For 2007, when a user accesses this page to print a Relevé 8 page that has previously been printed with a Box B amount different from the current total amount of the tuition and examination fees, an amended record is created.

    When a Relevé 8 page is printed with a different amount in Box B "Frais de scolaritéé ou d'examen", an amended record is created to reflect the changes of this amount and the Box B amount is saved in SVBREL8_BOXB_AMOUNT. The "Code du relevé" box will contain "1" for an amended Relevé 8 and the last sequence number in the "No du relevé 8 original" box will be added, in addition to a new current sequential number.

  • For 2008 or later, a changed amount in Box A (Relevé 8 amount) or Box B (tuition amount) does not trigger an amended record in the SVBREL8 table. Instead, the SVPREL8 or SVPTAXC process determines whether an amended record is created, depending on the specific situation.
