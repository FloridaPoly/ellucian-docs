Process Flows (Canadian Institutions)

Includes the process flow diagrams for Canadian Institutions.

T2202A setup

The following flow chart describes the steps involved in setting up for Banner T2202A processing.

Setup

Load data into the SVBTXTP table.

Do not perform this step if completed during installation.

SVAFRYR

Set up terms applicable to the tax year.

SVATAXL

Set up tax year limits and the calculation method.

SVAINAD

Set up addresses for multi-institutional database users.

SVAESTS, SVARSTS

Set up enrollment and CRN registration status codes.

SVAHWER

Set up rules for all terms in the tax year.

SVATPRI

Set up priority rules.

GTVSDAX

Set up crosswalk entries.

SVATXRP

Set up reporting periods.

SVACHAR

Set up charitable donation codes.

t2202a_admin_web.sql

(Optional) Add administrator web pages to Banner Self-Service.

SVAXLTM

Enter the transmitter information.

T2202A data flow

The following flow describes the flow of data during the Banner T2202A process.

SVPTAXE

Run the cleanup process.

SVPTAXC

Run the calculation process.

SVATXEX

Enter T2202A exception data.

SVATAXC

Review and recalculate T2202s.

SVRTAXC

Print T2202 forms using a dot matrix printer.

SVRTXML

Generate the T2202 XML file.

SVRTXLP

Create T2202 data file for a laser printer.

Data ProcessSVPTAXC Process

Select student records for which the term is in SVRFRYR and SFBETRM, for which TBRACCD records exist, or for which SARADAP records exist (only when processing application fees through Self-Service is turned on.

Calculate qualifying months for the tax year.

Calculate eligible tuition by term for the tax year.

Build student records in the SVBTAXC, SVBTAXT, SVBTAXS, and SVBTAXR tables.

T2202A Self-Service

Print T2202 form from a web Form.
