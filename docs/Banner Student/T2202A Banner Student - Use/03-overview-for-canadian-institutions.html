Overview for Canadian Institutions

Canadian institutions need to produce T2202 forms (or Relevé 8 forms for Quebec students) for students attending the institution. The forms are a tuition tax receipt and are generated by institutions for students to use in determining their income tax.

Banner T2202A can do the following.

  • Calculate T2202s.
  • Calculate Relevé 8s (Province of Quebec).
  • Define reporting periods for T2202s.
  • Define sessions for Relevé 8 forms.
  • Process charitable donation information for T2202s.
  • Process students under the age of 16 as of December 31 of the tax year for T2202s.
  • Process T2202s and Relevé 8s for multiple institution environments that share a database.
  • Assign a sequential number for each Relevé 8 printed, and add the code of the Relevé 8 to indicate whether it is original or amended.
  • Handle terms that overlap.
  • Support open entry/open exit course registration as implemented at some institutions.
  • Handle a term that spans more than one tax year.
  • Assign the appropriate HWEs for CRNs based on the meeting times set up in SSRMEET. In order to assign the correct HWEs to the appropriate weeks, each individual meeting time is treated as if it were a separate CRN.
  • Generate T2202s and Relevé 8s for students with no course registration data for a given term.
  • Exclude certain students or courses from the T2202 and Relevé 8 processes.
  • Define rules for calculating qualifying full-time or part-time months, and allocating eligible tuition and fees for T2202 processing.
  • Print individual T2202s to provide duplicates and amended forms.
  • Print T2202s and Relevé 8 forms using a laser printer.
  • Allow students to view T2202 information from the web.
  • Allow students to print T2202 and Relevé 8 receipts from the web.
  • Generate the XML data file for Revenu Quebec containing the Relevé 8 data.
The following existing Banner functionality is used with the T2202 enhancement:
  • The Tax Code Validation (TTVTAXT) page is used to identify the T2202 eligible tax codes.
  • The Detail Code Control (TSADETC) page is used to assign T2202 tax type codes to all eligible T2202 detail codes.
  • The Federal Reporting Year Rules (SVAFRYR) page replaces the existing Federal Reporting Year Rules (SOAFRYR) page.
