Process Flows (US Institutions)

Includes the following process flow diagrams.

TL11x setup

The following flow chart describes the steps involved in setting up for TL11x processing.

Setup

Load data into the SVBTXTP table.

Do not perform this step if completed during installation.

SVAFRYR

Set up terms applicable to the tax year.

SVATAXL

Set up tax year limits and the calculation method.

SVAINAD

Set up addresses for multi-institutional database users.

SVAESTS, SVARSTS

Set up enrollment and CRN registration status codes.

SVAHWER

Set up rules for all terms in the tax year.

SVATPRI

Set up priority rules.

SVATXRP

Set up reporting periods.

TL11x data flow

The following flow chart describes the flow of data during the TL11x process.

SVPTAXE

Run the cleanup process.

SVPTAXU

Run the calculation process.

SVATXEX

Enter TL11x exception data.

SVATAXU

Review and recalculate TTL11x’s.

SVRTXLU

Create TL11x data files for a laser printer.

Data ProcessSVPTAXU Process

Select student records for which the term is in SVRFRYR and SFBETRM, for which TBRACCD records exist, or for which SARADAP records exist (only when processing application fees through Self-Service is turned on.

Calculate qualifying months for the tax year.

Calculate eligible tuition by term for the tax year.

Build student records in the SVBTAXC, SVBTAXT, SVBTAXS, and SVBTAXR tables.
