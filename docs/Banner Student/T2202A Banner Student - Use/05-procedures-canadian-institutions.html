Procedures (Canadian Institutions)

Canadian Institutions must use the procedures listed in this section using the T2202A application.

Run the clean-up process

The SVPTAXE report is a pre-processing report that identifies errors and warnings that need to be addressed before the T2202 and Relevé 8 calculations are done.

Procedure

  1. Run the T2202A Exception Report (SVPTAXE).
  2. Enter the tax year for which you want to view the errors and warnings in the Tax Year parameter.
  3. Run the report.
  4. Review the output.
  5. Correct any errors.
    Note: If a status error of E exists on a student's record, that student will not be processed when processing the T2202 or Relevé 8 data, therefore all error records must be corrected.
  6. Rerun the report until no errors exist.

T2202A procedures

This section lists the procedures to use the T2202A T2202A.

Run the T2202 calculation

Run the T2202A Calculation Q.M.-TTC Process (SVPTAXC) process to calculate the TTC and qualifying months for students in a given tax year.

Note: If A is entered as the Run Mode parameter, the process highlights any errors but does not update the tables.

Review and recalculate T2202 data

The T2202A Taxation page (SVATAXC) displays data generated by the T2202A Calculation Q.M.-TTC Process (SVPTAXC). When a T2202 is printed, any further changes to the T2202 result in the generation of a new set of records for that T2202.

Review T2202 data

Procedure to review the T2202 data.

Procedure

  1. Access the T2202A Taxation (SVATAXC) page.
  2. Select the student for whom you want to review T2202 data.
  3. Enter the tax year and go to the next block.
  4. Review the data on the various blocks.
Recalculate T2202 data

Procedure to recalculate the T2202 data.

About this task

Tax year till 2018

Select this option to run the SVPTAXC process for the selected student, which replaces the data in the current sequence number for all blocks where the lock indicators are not set.

If indicators are set, the address, program/degree, tuition amount, and months are not updated. This option can only be selected when the Print Date field is null.

When this option is selected, the Address Information and Parameters window opens. Use the Address Information section to select which address type to use when running the SVPTAXC process. Use the Parameters section to specify the parameter values to be used when the report is run from this option.

When the SVPTAXC process is run from this option, a message will be displayed indicating what is happening. After clicking OK, the cursor will return to the Key block and the user will need to select Go button to see the data.

Tax year from 2019

When institutions select the Recalculate option to run the SVPTAXC process for the selected student, which replaces the data in the current sequence number for all blocks where the lock indicators are not set.

If the lock indicators are set, the relevant address, program/degree, tuition amount, or months are not updated. This option can only be selected when the XML Submit Indicator is not selected.

When this option is selected, the Address Information and Parameters window opens. Use the Address Information section to select which address type to use when running the SVPTAXC process. Use the Parameters section to specify the parameter values to be used when the report is run from this option.

When the SVPTAXC process is run from this option, a message will be displayed indicating what is happening. After clicking OK, the cursor will return to the Key block and the user will need to select Go button to see the data.

Procedure

  1. Access the T2202A Taxation (SVATAXC) page.
  2. Select the student for whom you want to update T2202 data.
  3. Enter the tax year and go to the next block.
  4. If the record has not been printed, take one or more of the following actions, as needed.
    • Select Manual Address Update from the Options menu to change the student’s address. This is not the address stored in SPRADDR.
    • Select Manual Months Update from the Options menu to change the student’s qualifying months.
    • Select Manual Program/Degree Update from the Options menu to change the student’s program or degree.
    • Select Manual Tuition Update from the Options menu to change the student’s tuition amount.

    The information in this section is valid only until the tax year 2018. From tax year 2019 onwards, the processing options can be selected only if the XML Submit indicator field is NOT NULL.

  5. If the record has been printed, select Create Amended from the Options menu, and modify the address, months, program/degree, or tuition amounts.
  6. Save the record(s).

Enter T2202 exception data

This procedure is used only by institutions that have students who must be processed with separate rules.

About this task

The Tax Calculation Exception (SVATXEX) page uses the same tables as the T2202A Taxation (SVATAXC) page. The address, program, months, tuition, non-claimable amounts, and charitable donation information is entered manually. SVATXEX is used only to process rare cases that need separate rules.

Records created using this Form cause the Exception Lock indicator to be set on SVATAXC, which will not allow information to be updated on SVATAXC. Any student with a record already created through the T2202A Calculation Q.M.-TTC Process (SVPTAXC) cannot be processed using SVATXEX.

Procedure

  1. Open the Tax Calculation Exception (SVATXEX) page.
  2. Select the student for whom you want to enter T2202A exception data.
  3. Enter the tax year and go to the next block.
  4. If the Address Information block opens, select the address type to use for the student.
  5. Enter the student’s program in the Program field.

    -OR-

    Enter the student’s degree in the Degree field.

  6. Go to the Education Tax Credit Qualifying Months block.
  7. Enter F (full-time) or P (part-time) in the Months field.
  8. Go to the Eligible Fees block.
  9. Enter the student’s tuition, non-claimable amounts, and charitable donation information.

    The Non-Claimable Amount field contains the amount that the student cannot claim.

  10. Save the record(s).

Generate T2202 XML file

Run the SVRTXML process to generate a T2202 XML file required for the CRA submission from 2019 year onwards.

Print T2202 forms using a dot matrix printer

Run the T2202A Report (SVRTAXC) report to print the T2202 forms using a dot matrix printer.

The procedure prints T2202s using Impact printers on the Canada Revenue Agency (CRA) continuous, pre-printed, multi-part forms. A dot matrix printer is required and some test pages are available to ensure the printer is aligned properly.

Create T2202 data files for a laser printer

Procedure to create T2202 data files for a laser printer.

Procedure

  1. Run the T2202A Laser Report (SVRTXLP) to print T2202 forms using a laser printer.
  2. Merge the files with the delivered Word templates as described in Merge flat files with Microsoft Word templates section.

Relevé 8 procedures

The Relevé 8 procedures are explained in this section.

Identify the Code Permanent number

The Code Permanent number is the student’s identification. The number must be in AAAA99999999 format. See the Ministère de l'Éducation, du Loisir et du Sport web site for more information on the code permanent for students in Québec.

The Code Permanent number of each student needs to be reported in the XML file, you have two ways of recording and retrieving the Code Permanent number:
  • Customized table
  • Banner baseline table
    Note: If a Code Permanent number was not set for a student in your customized tables or in the Banner Baseline tables, the student will be reported with xxxx00000000 as the default value for Code Permanent. The XML file generation process populates the field for Code Permanent with xxxx00000000 if the value is missing in the database. The institution should not add xxxx00000000 as default data.
Customized table

Use your customized table and add some logic to the delivered customized function.

Procedure

  1. Go to your database and find the f_t2202a_local_CodePerm function in the SVKREL8 database package.
  2. Add new logic to the function using your own table that stores the permanent code for each student.
  3. Ensure the value of the permanent code is returned for the student at the end of the function.
  4. Test that the function is working.

Results

In the Calculate or Print Relevé 8 package (SVKREL8), the f_t2202a_get_Code_Perm function first calls the f_t2202a_local_Code_Perm function. If nothing is returned, the function queries the SPRCMNT table, and the first 12 characters of the value in the Comments field are returned. At the end, a default value of xxxx000000000 is returned if the permanent code is null (blank). The f_t2202a_get_Code_Perm function is called by the SVRREL8 report, the Relevé 8 XML Transmission Report (SVRRELX), and from the Relevé 8 web pages.

Banner baseline table

Use the Banner baseline tables to store the Code Permanent number for each student.

Procedure

  1. Access the Comment Type Code Validation (STVCMTT) page.
  2. Enter QSN (Québec Student Number) in the Code field.
  3. Save the records.
  4. Access the Person Comment (SPACMNT) page.
  5. Enter QSN in the Comment Type field.
  6. Enter the Code Permanent number in AAAA00000000 format in the Comments field.
  7. Save the records.

Run the Relevé 8 calculation

Run the Calculation of Relevé 8 Process (SVPREL8) to calculate Relevé 8 amounts for individuals (multiple IDs allowed) or groups of individuals based on a population selection.

Relevé 8 is only available to full-time students. The actual page is given to the student and forwarded to the student’s parents or sponsors that live in the Province of Quebec.

The first time SVPREL8 is run for a student, when there is no previous record for the student or there is no XML file name associated with the record (meaning no XML file has been generated for the student), the SVPREL8 process generates a new record for the student.

Tax years before 2013

For tax years before 2013, after the initial XML file generation, a new record is generated for a student only in the following instances.

  • The Valid option button is selected for the record on the Relevé 8 XML Validation Status (SVARXVS) page, and the amount in Box A, B, or C changed.
  • The Invalid or File Rejected option button is selected for the record on SVARXVS. A new record that was created because the previous record was invalid or rejected keeps the same XML sequence number and the same facsimile sequence number. Another record cannot be generated until the validation status sent by Revenue Quebec is entered in the SVARXVS page.
    Note: If A is entered as the Run Mode parameter, the process highlights any errors but does not update the tables.
Tax year 2013

For tax year 2013, if the Valid option button is selected for the record on SVARXVS, a new record is generated as follows.

  • A canceled RL-8 slip is generated in the following instances:
    • The personal information is changed (such as social insurance number, student permanent code, first 30 characters of first or last name, or first character of middle name, but not address information)
    • The value for box A, B1, B2, or C is changed, and the values in boxes A, B1, and B2 are zero or less
  • An amended RL-8 slip is generated if the value for box A, B1, B2, or C is changed, and the value in boxes A, B1, or B2 is greater than zero.

If the Invalid or File Rejected option button is selected for the record on SVARXVS, no new record is generated; however, SVPREL8 updates the current record with the calculated amounts or new personal information, as applicable. In this case, you must run SVRRELX to retransmit the whole file that was partially or fully rejected by MRQ last time.

Tax year after 2013

For tax years after 2013, if the Valid option button is selected for the record on SVARXVS, a new record is generated as follows.

  • A canceled RL-8 slip is generated in the following instances:
    • The personal information is changed (such as social insurance number, student permanent code, first 30 characters of first or last name, or first character of middle name, but not address information)
    • The value for box A, B, or C is changed, and the values in boxes A and B are zero or less
  • An amended RL-8 slip is generated if the value for box A, B, or C is changed, and the value in boxes A or B is greater than zero.

If the Invalid or File Rejected option button is selected for the record on SVARXVS, no new record is generated; however, SVPREL8 updates the current record with the calculated amounts or new personal information, as applicable. In this case, you must run SVRRELX to retransmit the whole file that was partially or fully rejected by MRQ last time.

Generate Relevé 8 XML file

All Relevé 8 records, whether or not they have been printed, must be included in the XML file.

Before you can generate Relevé 8 XML files, the following setup must be completed:
  • Set up transmitter data for Relevé 8s
  • Set up XML sequence numbers
Run the Releve 8 XML Transmission Reports to generate an XML file and assign the XML sequence number and XML file name to the data records in the SVBREL8 table. Only the records without an XML file name will be included in the XML file generated. The records on hold (that is, the hold indicator is checked in SVAREL8) are not considered and will not be included in the XML file.

The XML document is due before the last day of February each year. Institutions should run SVRRELX in audit mode, and check the errors reported in the .LIS and .LOG files before sending anything to Revenu Québec. When all of the errors reported in the .LIS and .LOG files are corrected, run SVRRELX in update mode; the XML file can then be generated and sent to Revenu Québec.

Note: Only the data for the students without error reported in the .LIS file are printed in the XML file. Therefore, if errors are not fixed, data will not be sent to Revenu Québec and it will not be possible to print the RL-8 slip.

After the XML file has been validated, the institution can allow students to print their Relevé 8 page. The data on the printed Relevé 8 page and in the XML file must be the same.

Note: While students can be permitted to print their Relevé 8 forms before the XML file has been validated, this practice is not recommended. If any of the information on the Relevé forms is changed after the students printed their documents, amended or cancelled forms must be made available to the students, and a new XML file must be generated.
Note: It is strongly recommended that you run SVPTAXC and SVPREL8 before SVRRELX to make sure that the data being reported is the most recent.
Warning: Audit XML files will be generated after SVRRELX job is run in audit mode. The XML files should be removed from your job submission folder after audit or test phase is completed, as the XML files generated in audit mode should never be sent to Revenu Québec. The same naming convention is used when generating the XML file name for audit file and update file. As a result, if you select all the XML files from the job submission folder, you may get a mix between "actual" XML files and "audit" files that are still there. The best practice is to remove all XML files generated by a SVRRELX job in audit mode, before running the SVRRLEX report in update mode.

Submit the XML file to Revenu Quebec

When the XML file has been generated by SVRRELX, you need to send the XML file to Revenu Québec. Send the file as an electronic transmission through the Internet. Also send the RL-8 summary paper Form if needed.

After the XML file is received by Revenu Québec, your institution will be notified whether the file was fully validated, fully rejected, or partially validated.

On the document sent by Revenu Québec, you will find two numbers looking like the XML file name (AAPPPPPPSSS without the .XML extension) at the top right under the title of the document.

  • No de support (support number) is the XML file name given by Revenu Québec to your XML file name if they have renamed the file. This is the name you need to use when you contact Revenu Québec.
  • No de support du preparateur (support number for the transmitter) is the name of the file generated by your system. This is the name you need to use in SVARXVS.
Fully validated

If the XML file is fully validated, perform the following steps.

Procedure

  1. Enter the XML file status as described in the Enter XML file status section.
  2. Create Relevé 8 data flat files for a laser printer using SVRREL8.
    Alternatively, students can print their RL-8 from Self-Service if your institution has allowed printing.
Fully rejected

If an XML file was fully rejected, perform the following steps.

Procedure

  1. Enter the XML file status.
  2. Correct the data in your database depending on the error reported by Revenu Québec.
  3. Rerun SVPTAXC and SVPREL8 to update existing information or generate new information that will be reported in a XML transmission file.
  4. Generate a Relevé 8 XML file as described in the Generate Relevé 8 XML file section..
    The XML sequence number remains the the same.
  5. Submit the XML file as described in Submit XML file to Revenu Quebec.
Partially validated

If an XML file was partially validated, a list of student numbers that were not valid is included in a letter from Revenu Québec. For the student numbers that are not valid, perform the following steps.

Procedure

  1. Enter the XML file status.
  2. Correct the data in your database depending on the error reported by Revenu Québec.
  3. Rerun SVPTAXC and SVPREL8 to update existing information and generate new information that will be reported in a XML transmission file.
  4. Generate a Relevé 8 XML file.
  5. Submit the XML file.

Results

For the valid student numbers, perform the steps listed in the Fully validated section.

Enter the XML file status

After the XML file has been validated by Revenu Québec, you must record the status of the records from the XML file.

Procedure

  1. Access the Releve 8 XML Transmission Reports.
  2. Enter the name of the XML file with the extension .xml , and select Next Block.
  3. Take one of the following actions, as appropriate.
    • If the entire file was valid, select the Select All: Valid option button to set the status to Valid for all of the records in the XML file.
    • If the entire file was rejected, select the Select All: File Rejected option button to set the status to Rejected for all of the records in the XML file.
    • If the tax year is earlier than 2013 and the file was partially valid, mark each record in the file as follows.
      • Select the Valid option button for each valid record.
      • Select the Invalid option button for each invalid record.

        If only a few records are not valid in a file, see Shortcut for setting records as valid and not valid.

    • If the tax year is 2013 or later and the file was partially valid, select the Select All: Invalid option button to set the status to Invalid for all of the records in the XML file.
  4. Click Submit.
Shortcut for setting records as valid and not valid

For tax years earlier than 2013, you can use this method to easily mark records as valid and not valid in an XML file.

About this task

Do not start by validating the whole file, because, in that case you allow the Relevé 8 to be printed for the records that are not valid.

Procedure

  1. Enter the status of the records that are not valid, individually.
  2. Save the records.
  3. When all the records that are not valid are, perform the following steps for the remaining (valid) records.
    1. Perform a query.
    2. Select the null value in the Current XML Valid Status field to query the remaining records that have not yet been validated.

      The list of records not yet validated is displayed as the query result.

    3. Use Select All to validate them.

Review and recalculate Relevé 8 data

The SVAREL8 page allows the user to review the data and print the Relevé 8 Form.

Procedure

  1. Access the Relevé 8 Taxation (SVAREL8) page.
  2. Select the student for whom you want to review and update Relevé 8 data.
  3. Enter the tax year and go to the next block.
  4. If the Print Flag value is W, the recalculate option can be used, otherwise select Create New/Recalculate from the Option menu to create a new record and run the recalculate option.
  5. If any changes were made, save the record.

Cancel an erroneous Relevé 8 slip

For tax year 2013 and later, you can cancel an erroneous Relevé 8 (RL-8) slip as long as the last record is an Original or Amended record that has been processed successfully by MRQ and the validation status is set to V.

About this task

When an RL8 slip has been canceled, it cannot be canceled again.

Procedure

  1. Access the Relevé 8 Taxation (SVAREL8) page.
  2. Select the student for whom you want to cancel an erroneous RL-8 slip.
  3. Enter the tax year and go to the next block.
  4. Select Cancel an erroneous slip from the Options menu.
  5. When the system displays a confirmation message, click OK.

Create Relevé 8 data files for a laser printer

This procedure explains how to print Relevé 8 forms using a laser printer. Files are created that can be merged with the delivered Word templates.

About this task

Relevé 8 forms are not printed in the following instances.

  • The record does not have an XML number.
  • The record has a status of not valid or rejected on the Relevé 8 XML Validation Status (SVARXVS) page.
  • The record is on hold on the Relevé 8 Taxation (SVAREL8) page.

Procedure

  1. Run the Relevé 8 Laser Report (SVRREL8).
  2. Merge the files with the delivered Word templates.

Merge flat files with Microsoft Word templates

This procedure is used to merge the .TXT file with the delivered templates. The procedure can be used with the following reports.

  • T2202A Laser Report (SVRTXLP)
  • Relevé 8 Laser Report (SVRREL8)

This procedure works best if the template and flat files (.TXT) are all in the same directory. A flat file is generated by the processes with the header information written on the first line and student-related data written on the rest of the lines. The location of the flat file is listed in the .LOG file.

For tax years before 2007 and 2011 and later, only one template is used.

For tax years 2007 through 2010, two Relevé 8 templates are used for mail merging the flat file generated by the SVRREL8 process: one for original Relevé 8 slips and one for amended Relevé 8 slips.

You must merge the flat file into both of these templates to print Relevé 8 slips for students correctly. To do this, you must do the following for every new flat file generated by the SVRREL8 process.

  • Mail-merge the REL8LASERYYYY.txt file into the Releve8_Template_YYYY_original.doc template. All original Relevé 8 slips or their duplicates will be then printed.
  • Mail-merge the same REL8LASERYYYY.txt file into the Releve8_Template_YYYY_amended.doc template. All amended Relevé 8 slips or their duplicate slips will be then printed.

The name of the files are as follows (where YYYY is the tax year):

Update the status of the XML records

This procedure explains how to update the XML status of all the RL-8 records in the XML file simultaneously regardless of the status of the T2202A hold flag.

About this task

This new procedure solves the performance issues that occurred when clients attempted to validate records in the Releve 8 XML Validation Status (SVARXVS) process.

Procedure

  1. Access the Releve 8 XML Validation Status (SVARXVS) process.
  2. Enter the full XML file name in Releve 8 XML File Name field of the Key block.
  3. In the Select All section, select Valid, Invalid, or File Rejected.
  4. Click Save to update all the RL-8 records.
    A warning message displays: Do you want to turn OFF the Hold Flag in SVBREL8 table for records with T2202A flag ON [Total of # records in SVATAXC have hold flag on]?
  5. Click Yes to turn off the RL-8 hold flag or click No to keep the RL-8 hold flag ON.
