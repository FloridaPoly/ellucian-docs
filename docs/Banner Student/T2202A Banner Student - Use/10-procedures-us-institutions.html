Procedures (US Institutions)

This chapter contains the following procedures.

Run the clean-up process (US Institutions)

The T2202A Exception Report (SVPTAXE) is a pre-processing report that identifies errors and warnings that need to be addressed before the TL11x calculations are done.

Procedure

  1. Run the T2202A Exception Report (SVPTAXE), entering tax year for which you want to view the errors and warnings in the Tax Year parameter.
  2. Correct any errors.
    Note: If a status error of E exists on a student's record, that student will not be processed when processing the TL11, therefore all error records must be corrected.
  3. Rerun the report until no errors exist.

Run the TL11 calculation

Run the TL11x Calculation Q.M.-TTC Process (SVPTAXU) to calculate the TTC and qualifying months for Canadian students attending a United States institution in a given tax year.

Note: If A is entered as the Run Mode parameter, the process highlights any errors but does not update the tables.

Review and recalculate TL11 data

The TL11x Taxation page (SVATAXU) displays data generated by SVPTAXU. When the TL11s are printed, any further changes to the TL11s will result in the generation of a new set of records for that TL11.

Review TL11 data

Procedure to review TL11 data.

Procedure

  1. Open the TL11x Taxation (SVATAXU) page.
  2. Select the student for whom you want to review TL11 data.
  3. Enter the tax year, and go to the next block.
  4. Review the data on the various blocks.

Recalculate TL11 data

Procedure to recalculate TL11 data.

Procedure

  1. Open the TL11x Taxation (SVATAXU) page.
  2. Select the student for whom you want to update TL11 data.
  3. Enter the tax year, and go to the next block.
  4. If the record has not been printed, take one or more of the following actions, as needed.
    • Select Manual Address Update from the Options menu to change the student’s address. This is not the address stored in SPRADDR.
    • Select Manual Months Update from the Options menu to change the student’s qualifying months.
    • Select Manual Program/Degree Update from the Options menu to change the student’s program or degree.
    • Select Manual Tuition Update from the Options menu to change the student’s tuition amount.
  5. If the record has been printed, select Create Amended from the Options menu, and then modify the address, months, program/degree or tuition amounts.
  6. Save the record(s).

Results

The Exception Lock indicator is set when a record is created on the SVATXEU page for processing students who do not meet the regular requirements for receiving a TL11. For example, students with disabilities who qualify for part-time months.

Enter TL11x exception data

TL11x exception data.

Procedure

  1. Open the Tax Calculation Exception (SVATXEU) page.
  2. Select the student for whom you want to enter TL11x exception data.
  3. Enter the tax year, and go to the next block.
  4. If the Address Information window opens, select the address type to use for the student.
  5. Enter the student’s program in the Program field.

    -OR-

    Enter the student’s degree in the Degree field.

  6. Enter R (resident) or C (commuter) in the Resident/Commuter field.
  7. Enter F (full-time) or P (part-time) in the Months fields of the Education Tax Credit Qualifying Months block.
  8. Go to the Eligible Fees block.
  9. Enter the student’s tuition information.
  10. Save the record(s).

Create TL11x data files for a laser printer

Procedure to create TL11x data files for a laser printer.

Procedure

  1. Run the TL11x Laser Report (SVRTXLU).
  2. Merge the files with the delivered Word templates.

Merge flat files with templates

This procedure is used to merge the .TXT file with the delivered templates. The procedure can be used with the TL11x Laser Report (SVRTXLU).

This procedure works best if the template and flat files (.TXT) are all in the same directory. The location of the flat file is listed in the log file.

The name of the files are as follows (where YYYY is the tax year):
