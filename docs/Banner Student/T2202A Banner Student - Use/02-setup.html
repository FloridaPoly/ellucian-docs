Setup

The procedures in this section explain how to install Banner T2202A application.

Load data into the SVBTXTP table

This procedure applies to T2202, Relevé 8, and TL11x.

About this task

Use this optional procedure if your institution has terms that cross a tax year. This is only used the first time that T2202 or TL11A/TL11C objects are used. If you completed this step during the installation, you do not have to perform it again. The SVPTXTP table is used to load data from prior tax years for split terms (terms that cross tax years).

Procedure

  1. Create a data file named svbtxtp.dat using the following format (fields must be separated by a comma): 
    svbtxtp_pidm

    FLOAT EXTERNAL,

    svbtxtp_txyr

    CHAR(4),

    svbtxtp_term_code

    CHAR(6),

    svbtxtp_amount

    FLOAT EXTERNAL,

    svbtxtp_non_claimable_amount

    FLOAT EXTERNAL,

    svbtxtp_char_amount

    FLOAT EXTERNAL,

    svbtxtp_resi_cde

    CHAR(1),

    svbtxtp_activity_date

    DATE "DD-MON-YYYY",

    svbtxtp_data_origin

    CHAR(30),

    svbtxtp_create_user_id

    CHAR(30),

    svbtxtp_create_date

    DATE "DD-MON-YYYY",

    svbtxtp_user_id

    CHAR(30)

    A record must exist in this file for each tuition fee amount corresponding to splits terms from the prior year for each student (PIDM). See a sample of this file in the installation ZIP file.

  2. Run the t2202a_load_svbtxtp.shl script.

    This script loads the svbtxtp.dat file into the SVBTXTP table.

Set up terms for a tax year

This procedure applies to T2202 and TL11x.

Procedure

  1. Access the Federal Reporting Year Rules (SVAFRYR) page.
  2. Enter the year to which you want to add terms, and go to the next block.
  3. Enter the term code in the Term field.
  4. Enter a value in the Percent Fee field.

    The Percent Fee values represent the portion of the term that falls in the tax year. The default is 100 but the value can be changed if necessary. The Percent Fee values are used only if the student calculation rules are used. If the CRN calculation rules are used, then the Percent Fee value is calculated based on the start and end date of the CRNs.

  5. Save the record(s).

Set up tax year limits

This procedure applies to T2202, Relevé 8, and TL11x.

Procedure

  1. Access the Education/Tuition Amount Limits (SVATAXL) page.
  2. In a Tax Year field, enter the desired year.
  3. Enter an amount in the Full-time Amount and Part-time Amount fields to identify the education amount that is available for a tax credit per month as designated by the Canada Customs and Revenue Agency.

    This is for information only and is not used in any calculations.

  4. Enter an amount in the Full-time Hours per Week field to identify the minimum number of hours per week needed to be considered full-time by the institution.
  5. Enter an amount in the Part-time Hours per Week field to identify the minimum number of hours per week needed to qualify for part-time status.
  6. Enter a value in the Number of Reporting Periods field.

    This value is the maximum number of reporting periods an institution sets for printing on the T2202 or TL11 form. The maximum number of reporting periods is four.

  7. Enter a P or C in the Paid or Charged field to indicate if the eligible fees for calculating the Tuition Tax Credit (TTC) should be based on charged amounts (C) or on paid amounts (P).
  8. Check the Display on Web field if yours is a Canadian institution that allows students to display and print their own T2202 or Relevé 8 forms from the Web.
    Note: United States institutions should not check this field because the TL11 forms must be signed by the administrators of the institution.
  9. If your institution produces Relevé 8 forms, perform the following steps.
    1. Using the limits set by the Government of Quebec for Relevé 8 processing, enter values in the Session Amount and Annual Amount fields.
    2. Enter a value in the Maximum Number of Sessions field.

      This value is the limit an institution will set for what constitutes a Relevé 8 session. The number of sessions usually resembles the same months that are associated with the institution’s term structure for full-time students. The maximum number of sessions is four.

  10. Enter 1 or 2 in the Mode Same Start Date Term field to specify which term is to be used when two or more term codes share the same start date in the Student Table (SGBSTDN): the maximum term code (1) or the term based on the student’s registration and the priority of the term (2).
    If you enter 2 in the Mode Same Start Date Term field, you must set up your priority rules.
  11. Save the record(s).

Set up enrollment status codes

This procedure applies to T2202, Relevé 8, and TL11x.

About this task

The Enrollment Status Code Rules Definition (SVAESTS) page is used in combination with the student calculation rules. For each term a student is enrolled in a given tax year and student calculation rules are used, the enrollment status code rules calculate the qualifying months. For a term that does not have an enrollment status code defined in the tax year, the qualifying months calculation is ignored but the TTC calculation is performed.

Procedure

  1. Access the Enrollment Status Code Rules Definition (SVAESTS) page.
  2. Enter the year to which you want to add enrollment status codes, then go to the next block.
  3. Enter the enrollment status code in the Enrollment Status Code field.
  4. Select the Default indicator to use the term start and end dates for processing.

    -OR-

    Select the Early Exit indicator to use the enrollment status date as the end date for processing.

  5. Save the record(s).

Set up CRN registration status codes

This procedure applies to T2202, Relevé 8, and TL11x.

About this task

The Registration Status Code Rules Definition (SVARSTS) page is used in combination with the CRN calculation rules. An entry must be made for all registration status codes that will be used in the CRN base tax calculation. Registration status codes with missing entries are ignored in the qualifying month calculation.

Procedure

  1. Access the Registration Status Code Rules Definition (SVARSTS) page.
  2. Enter the year to which you want to add registration status codes.
  3. Enter the registration status code in the Registration Status Code field.
  4. Select the Section Dates, Meeting/Section, Early Exit, or Schedule Rules option button to specify which start and end dates are to be used to calculate qualifying months.
  5. If you selected Schedule Rules in 4, select one of the following in the Registration Status Code Exception Rules block:
    • Open Entry/Open Exit
    • Section Dates
    • Meeting/Section
  6. Save the record(s).

Set up rules for all terms

This procedure applies to T2202, Relevé 8, and TL11x.

About this task

You should attempt to capture most of the processing rules with the CRN calculation rules, and only use the student calculation rules when the data will not accurately reflect student activity.

The HWE Rules (SVAHWER) page defines the rules used in the selection of student records, registration records and course records for calculation of qualifying months.

Qualifying months and eligible tuition fees are somewhat independent of each other. Even if a student or a student’s CRNs are excluded from a term, the process checks to see if any eligible fees were paid for that term.

Procedure

  1. Access the HWE Rules (SVAHWER) page.
  2. Enter the term for which you want to define the rules, and go to the next block.
    The following steps apply to all of the blocks in SVAHWER page:
  3. Enter a number in the Rule Number field.
    The order in the Rule Number field is very important because rules are processed from lowest to highest. When setting up the rules, do not enter consecutive numbers in case a rule has to be added in the future.
  4. Enter the characteristics that specify which students and which CRNs are calculated and excluded.
  5. Save the record(s).

Set up charitable donations codes

This procedure applies to T2202. This procedure is not used by United States institutions or institutions that do not record charitable donation amounts.

About this task

The Charitable Donation Definition (SVACHAR) page captures charitable donation data for institutions that report this information on T2202s. The charitable donation detail codes must be on the student's account records for the tax year and cannot be a T2202 eligible detail code.

Procedure

  1. Access the Charitable Donation Definition (SVACHAR) page.
  2. Enter the tax year, and go to the next block.
  3. Enter each charitable donation detail code applicable to the tax year specified in the Key block.
  4. Save the record(s).

Set up ancillary fee detail codes

Use the procedure listed in this section to set up ancillary fee detail codes.

About this task

When ancillary fees or charges paid in respect of an individual's enrolment at a post-secondary educational institution would qualify for the tuition tax credit, but the payment of those fees or charges is not required from all of the institution's full-time students or part-time students, an amount not in excess of the value in the Ancillary Limit field of the Education/Tuition Amount Limits (SVATAXL) page for a tax year in respect of those ancillary fees can be included in computing the individual's tuition tax credit. This is applicable for 2014 and subsequent years in respect of those ancillary fees that can be included in computing the individual's tuition tax credit.

Procedure

  1. Access the Ancillary Fees Detail Code (SVAANCI) page.
  2. Enter the tax year and go to the next block.
  3. Add a record for each T2202 eligible ancillary fee detail code to be used for the specified tax year.
  4. Save your changes.

Copy ancillary fee detail codes from one tax year to another

You can copy the ancillary fee detail codes from one tax year to another using the following method.

Procedure

  1. Access the Ancillary Fees Detail Code (SVAANCI) page.
  2. Enter the tax year from which records are to be copied and go to the next block.
  3. Select Copy from the Options menu.
  4. Enter the tax to which records are to be copied.
  5. Click OK.

Set up reporting periods for T2202s and TL11s

This procedure applies to T2202 and TL11x.

Procedure

  1. Access the T2202A Reporting Period (SVATXRP) page.
  2. Enter the tax year and go to the next block.
  3. Enter the last month of the first reporting period in the To Month field.
    The first value in the From Month field is 1, and the subsequent values are the To Month value plus 1.
  4. Repeat 3 for each reporting period.
    The final value in the To Month field must be 12 to ensure all twelve calendar months are covered.
  5. Save the records.
  6. Select the record for the first reporting period in the base block, then go to the next block.
  7. Enter the desired term in the Associated Term to Report Period field.
    A term can be used in multiple reporting periods, if needed.
  8. If you want to associate multiple terms with the selected reporting period repeat 7 for each additional term.
  9. Save the record(s).
  10. Repeat 6 through 9 for each reporting period.

Set up priority rules

This procedure applies to T2202 and TL11x.

About this task

This procedure is optional and must be performed only if you entered 2 in the Mode Same Start Date Term field of the Education/Tuition Amount Limits (SVATAXL) page when you set up your tax year limits.

Procedure

  1. Access the T2202A Based Terms Priority Rules Maintenance (SVATPRI) page.
  2. Enter the year to which you want to assign priority rules, then go to the next block.
  3. (optional) Select the Load Terms option to populate SVATPRI with multiple terms that have the same start date defined on the Term Code Validation (STVTERM) page.
    Only new terms will be loaded. Any terms that already exist on SVATPRI for the current tax year will not be updated using the Load Terms option.

    -OR-

    (optional) Select Copy Terms from the Option menu to copy all of the terms that exist in the SVRTPRI table for the current tax year to a specified target year.

  4. Enter values in the following fields:
    • Term Code
    • Priority
  5. Save the record(s).

Set up transmitter data for Relevé 8s

This procedure applies to Relevé 8. This procedure is not used by United States institutions or institutions that do not produce Relevé 8 forms.

About this task

This procedure should be performed for each new year. You can use the Copy option to copy existing data to a target year.

Procedure

  1. Access the XML Transmission Information Control (SVAXLTM) page.
  2. Enter the year and report type code (REL8) to which you want to enter information, and go to the next block.
  3. Enter the information in the Transmitter block.
    The Transmitter Number is acquired from the Division de l'acquisition des données électroniques. Canadian postal codes must be entered without spaces in the following format: A1A1A1. If a valid postal code does not exist, enter A1A1A1. If entering a US ZIP code, enter the first five or six digits.
  4. Enter information about the IT contact in the Computer Resource block.
  5. Enter information about the accountant contact in the Accounting Resources block.
  6. Enter information in the Institution block.
    The code is acquired from Department de l'Éducation, du Loisir et du Sport. If the address fields are left blank, the information from the Installation Controls (GUAINST) page is used. Canadian postal codes must be entered without spaces in the following format: A1A1A1. If a valid postal code does not exist, enter A1A1A1. If entering a US ZIP code, enter the first five or six digits. The Québec enterprise number is acquired from Services Québec.
  7. Save the record.

Add administrator Web pages to Banner Self-Service

This procedure applies to T2202 and Relevé 8.

About this task

Use this procedure to add the Canadian Tax Forms link to a Self-Service menu. The Canadian Tax Forms link will go to the T2202A web pages. This allows administrators who are set up in the T2202A Administrator (SVATADM) page but are not part of the Student module to access T2202A Web pages for a student.

If this task is not performed, only administrators who are part of the Student module will be able to access the T2202A web pages.

The t2202a_admin_web.sql script must be run for each module menu to which you want to add the Canadian Tax Forms link. For example, if you want to add the link to all seven Banner modules, the script needs to be run seven times.

Enable PDF printing of RL-8 forms, T2202 forms, and charitable donation receipts

This procedure applies to T2202 and Relevé 8.

About this task

The following procedure explains how to allow student and administrative users to print the following in PDF format using Self-Service:
  • RL-8 forms
  • T2202 forms
  • Charitable donation receipts

Prerequisite

Your system administrator must deploy the T2202A_PDF.war file properly. For more information, please refer to the T2202A Java PDF Application Deployment Guide. The URL that points to the JAVA application will be used in this procedure.

Note: The WAR file includes XSL templates that are written in Extensible Stylesheet Language Formatting Objects (XSL-FO), per W3C recommendations. The Java application uses Apache Formatting Objects Processor (FOP), a print formatter driven by XSL-FO, to transform an XML document into PDF format. The XML document contains T2202 data, charitable donation receipt data, or RL-8 data, which is extracted from the database.

Procedure

  1. Access the Crosswalk Validation (GTVSDAX) page.
  2. Enter the URL used for PDF processing in the Description field for internal code PDF_URL in internal group T2202A.
    If your URL is more than 30 characters, you must define a second row with sequence number 2, a third row (if necessary) with sequence number 3, and so on, each row with no more than 30 characters.
    Internal Code Internal Seq Internal Group Description External Code
    PDF_URL 1 T2202A http://www.thisuniversity.com: PDF_URL
    PDF_URL 2 T2202A 8080 PDF_URL
    Note: If your URL is over 30 characters, it does not matter where you divide the elements as long as no row contains more than 30 characters. For example, you could enter http:// for sequence 1 and www.thisuniversity.com:8080 for sequence 2.
  3. Enter ON in the Description field for internal code PDF_SWITCH in internal group T2202A.
  4. Save your changes.
  5. To support printing charitable donation receipts, replace the following delivered image files.
    1. Replace bwvginstlogo.jpg with your institution’s logo.
    2. Replace bwvginstcharsig.jpg with a scan of the signature of the person at your institution who is authorized to sign charitable donation receipts.
      Your institution’s versions of these images must meet the following standards.
      • Both files must have the same names as the delivered ones, as these values are hard-coded into the software. If you use different names, your images will not be displayed on the charitable donation receipts.
      • The logo size must be 93mm wide and 15mm high, and the signature must be 30mm wide and 10mm high. If your image sizes are different, the system will resize them to these sizes, which can cause them to appear distorted.
