Tertiary Admissions Centre pages.

Program Offering (SKAPOFR) page

Use the SKAPOFR page to enter and display program offering information.

Key block

Use this section to specify the program code, major, base curriculum rule, major curriculum rule, and the academic year for which you want to enter the program offering.

Note: You can create data on this page without using valid curriculum rules. However, the process to match TAC course codes to Banner programs and then to load data correctly into Electronic Admissions is completely reliant on the use of base curriculum rule numbers and major curriculum rule numbers. Therefore, if you do not use valid curriculum records on the Program Offering page, the records will not be used appropriately in the TAC data processing.

In addition to this, SKAPOFR records must have the same campus code values as student curricula to successfully populate the Application Details File. Field Description
Program Program code for program offering records.
Base Curriculum Rule Base curriculum rule number program offering records. When a program is selected by a curriculum rule, the system automatically enters the base curriculum rule number in this field. Display only.
Major List of all the available major codes program offering records.
Major Curriculum Rule Major curriculum rule number program offering records. When the major is selected by a curriculum rule, the system automatically enters the major curriculum rule number in this field. Display only.
Academic Year Code of the academic year.
Copy to New Year Click this button to open the Copy Rules window. Use this window to copy program offering records from one academic year to another.

Base section

Use this section to enter or display the program offering information for the program code, major, and the academic year specified in the Key block.

Field Description
Admit Category Admissions category code for the program offering record.
Admit Course Course code for admissions category for the program offering record.
Term Term code for the program offering record.
Intake Intake code for the program offering record. The Term and Intake fields cannot be null. You must use at least one of these fields or can choose to use both.
Campus Campus code for the program offering record.
Note: If the campus has been specified for the base curriculum rule in the Key block, it will be automatically populated here and cannot be changed.
Site Site code for the program offering records.
Student type Student type for the program offering record.
Attendance Mode Attendance mode for the code program offering record.
Residence Residence code for the program offering record.
Attendance Type Radio button group used to specify the attendance type. Choices are:
  • Full Time
  • Part Time
  • None
Rate Rate code for the program offering record.
Income Income code for the program offering record.
Fund Fund code for the program offering record.
CRICOS Course CRICOS code for the program offering records. Click this button to open the CRICOS Code Validation window, where you can select the CRICOS record that is valid for the program and academic year in the Key block.
Note: You can assign the same CRICOS code to multiple program offering records.
Course Course code associated with the program. Display only.
National ID Code of the national ID associated with the program. Display only.
Active Check box used to specify whether the program offering record is active.
Available Check box used to indicate whether the program offering record is available for use in reports and processing.
Web Check box used to specify whether the program offering record is to be available on the web.
Cut-Off - CSP The lowest entry cut-off score required for an entry to a Commonwealth Supported Place (CSP) for this program offering. The value must be a four-digit number between 0000 and 9995.
Cut-Off - Domestic Fee-paying The lowest entry cut-off score required for entry to a domestic fee-paying place for this program offering. The value must be a four-digit number between 0000 and 9995.
QLD Cut-Off The lowest Queensland (QLD) entry cut-off score required for entry to a domestic fee-paying place for this program offering. Valid values are 0000 and any four-digit code.
QLD Cut-Off -Domestic Fee-paying The lowest QLD entry cut-off score required for entry to a domestic fee-paying place for this program offering. Valid values are 0000 and any four-digit code.
Eligibility Score Lowest possible score for the person to be considered as eligible for entry to this program offering. The value must be a four-digit number between 0000 and 9995.
QLD Eligibility Score Lowest possible score for the person to be considered as eligible for entry to this program offering. Valid values are 0000 and any four-digit code.
Quota Count Head count quota for the program offering record. The value entered in this field is for information purposes only; it is not used in any system processing.
Quota Load Load quota for the program offering record. The value entered in this field is for information purposes only; it is not used in any system processing.
Offers Number of offers for the program offering record. The value entered in this field is for information purposes only; it is not used in any system processing.
Enrolled Number of enrolled students for the program offering record. The value entered in this field is for information purposes only; it is not used in any system processing.
Expected Acceptance Percentage Expected percentage of acceptances for the program offering record. The value entered in this field is for information purposes only; it is not used in any system processing.
Enforce Lapse Date Check box used to indicate whether to enforce a lapse date for completion of enrolment for program offering. (For information only.)

Use this indicator to record that a particular program offering uses a lapse date for completion of the enrolment process.

The indicator can be used in letters and e-mails to inform students that there is a date after which their offer will lapse. The actual lapse date would be included in any such letter as a runtime variable.
