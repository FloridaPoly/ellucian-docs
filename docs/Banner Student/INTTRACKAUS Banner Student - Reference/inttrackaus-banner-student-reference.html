INTTRACKAUS Banner Student - Reference

International Student Tracking for Australasia pages.

CRICOS Course Data (SKACRIC) page

Use the SKACRIC page to enter or display CRICOS course data for each of your CRICOS institutions.

If your institution has more than one CRICOS provider ID, you must create a separate non-person record for each CRICOS provider. Then if a single program is offered under multiple provider records you can maintain this data without needing to create multiple codes for the same program.

Key block

Use this section to specify the CRICOS institution non-person ID, the program code, and term code for which you want to enter or display define your institution information.

Field Description
ID ID of the CRICOS institution.
Program Code Program code.
Term Code Code of the effective term of the data for this program.

Base section

Use this section to enter or display program-specific data elements for the ID, program, and term specified in the Key block.

Field Description
From Term Term from which the institution information data is valid.

If you are defining data for the first time, the value in this field defaults to the term entered in the Key block or for an earlier term than has already been defined.

If you are defining data for a later term than has already been defined, the value in this field defaults to the most recent term before the Key block term and for which data has been defined. You can change the code using the Maintenance button.

If you are defining data for an earlier term than has already been defined, the value in this field defaults to the term entered in the Key block.
To Term Last term till which the institution information data is in effect.

If you are defining data for the first time, the value in this field defaults to the maximum term code in Term Validation Code (STVTERM) page, typically term code 999999.

If you are defining data for an earlier term than has already been defined, the value in this field defaults to the most recent term for which data has been defined and is after the term entered in the Key block.

If you are defining data for a later term than has already been defined, the value in this field defaults to the maximum term code in STVTERM.
Maintenance Click this button to copy all data for the selected ID, program, and term to a new term or to end the record at the term in the Key block.

If the entered ID, program, and term code combination is not available in the SKRCRIC table, and if a record exists for a prior term, this button will be enabled. If you click this button, an options window opens, displaying two options. If you click End Term, the To Term field will be updated with the value from the Key block term. If you click Copy Term, the From Term field will be updated with the value from the Key block term, and this new record will be saved.
Course Name Full name of the CRICOS course.
CRICOS Course Code CRICOS course code.
Primary Field of Education Code of the primary field of education for the CRICOS course record.
Secondary Field of Education Code of the secondary field of education for the CRICOS course record.
Course Level Degree level for the CRICOS course record.
Language of Instruction Language of instruction for the CRICOS course record.
Duration Number of duration units.
Duration Unit (unlabelled) Code of the duration unit.
Estimated Total Course Cost Estimated total cost of the course for international students.
State or Province Code Code of the state or province where the course will be offered.
Dual Qualification Indicator Check box used to indicate whether the CRICOS course data record is for a dual qualification.
Foundation Studies Indicator Check box used to indicate whether the CRICOS course data record is for foundation studies.
Work Component Indicator Check box used to indicate whether the CRICOS course data record includes a work component.
Work Component Weeks Number of weeks for the work component.
Work Component Hours per Week Number of hours for each work component week.
Total Work Component Hours Total hours for the work component.
Active Check box used to indicate whether the CRICOS record is active.
User ID User who created or last updated this record. Display only.
Activity Date Date when the record was created or last updated. Display only.
