Banner STUBIBL release notes

The STUBIBL documentation contains all content that supports the most recent major release.

Release documentation

The product documentation available on the Ellucian Documentation site supports the latest available version.

The following table describes where to find additional supporting documentation for the latest and previous versions.

Table 1. Supporting documentation and previous releases
Documentation type Description Where to find
Supporting documentation for latest version Includes files that support the installation or upgrade of this release and the last three major releases. Click Attachment on this page and then select the associated compressed file (.zip) from the displayed list.
Documentation for previous versions Documentation for earlier releases. This content is available to download. On the Ellucian Documentation site home page, select Previous Versions, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. All content is available in English (enus), and some content is available in Spanish (esmx) and French Canadian (frca).

2022 Releases

Release STUBIBL 8.11.0.2

The Banner STUBIBL 8.11.0.2 hotfix contains defect corrections.

For a list of change requests resolved in STUBIBL 8.11.0.2, see the release page in the Ellucian Customer Center: STUBIBL 8.11.0.2.

To download supporting documentation for this release, click Attachments on this page and then select the associated compressed file (.zip) from the displayed list. The zip file contains the following files:

  • Banner SC Brazil STUBIBL Bibliography Change Request Resolutions Report, 8.11.0.2
  • Banner SC Brazil STUBIBL Readme, 8.11.0.2
  • Banner SC Brazil STUBIBL Release Notes, 8.11.0.2

Release STUBIBL 8.11.0.1

The Banner STUBIBL 8.11.0.1 release contains defect resolutions and an enhancement.

For a list of change requests resolved in STUBIBL 8.11.0.1, see the release page in the Ellucian Customer Center: STUBIBL 8.11.0.1.

Enhancement

STUREGP and STUBIBL dependency

Ellucian removed the dependency between STUREGP and STUBIBL. The institutions can install the STUBIBL localization without installing the STUREGP localization.
