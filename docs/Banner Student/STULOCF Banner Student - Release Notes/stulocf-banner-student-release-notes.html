Banner STULOCF release notes

Ellucian typically posts release notes the day before it makes the software available to customers. You can review Banner product release dependency information in Ellucian Solution Manager or the Banner Interdependency Matrix attached to Article KB000500135 - Banner Interdependency and Compatibility Matrix in the Ellucian Customer Center.

Release documentation

The product documentation available on the Ellucian Documentation site supports the latest available version.

The following table describes where to find additional supporting documentation for the latest and previous versions.

Table 1. Supporting documentation and previous releases
Documentation type Description Where to find
Supporting documentation for latest version Includes files that support the installation or upgrade of this release and the last three major releases. Click Attachment on this page and then select the associated compressed file (.zip) from the displayed list.
Documentation for previous versions Documentation for earlier releases. This content is available to download. On the Ellucian Documentation site home page, select Previous Versions, navigate to the appropriate product, and then click the file associated with the version you need in the preferred language. All content is available in English (enus), and some content is available in Spanish (esmx) and French Canadian (frca).

Release 8.5.6

The STULOCF 8.5.6 release contains enhancements and defect resolutions.

To download the supporting documentation click More > Attachment, and select the zip file associated with the release.
