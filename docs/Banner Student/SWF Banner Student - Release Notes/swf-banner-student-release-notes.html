Release 9.3.33.1 and 8.2.5

These release notes describe new features, enhancements, and updates in Standard Workload Form (SWF) Banner Student.

New section in the SVAFSWF page

To comply with the latest union agreement, Ellucian added a new section to the Banner admin page, Faculty Standard Workload (SVAFSWF). This new section, Discussion Dates, enables SWF customers to record the discussion dates between the supervisor and faculty members.

This enhancement addresses PE0003419 in the Ellucian Customer Center.

Global database consolidation

This release includes updates to consolidate Banner database objects for regional localizations into a single global database.

See the Banner General 9.3.26 and 8.16 Release Notes for more detailed information, including a list of tables and scripts.

See KB000502796 - Global Database Project Customer Communication and FAQ in the Ellucian Customer Center for additional details about the global database impact and benefits.

This enhancement addresses PE0001951 and PE0003901 in the Ellucian Customer Center.

Regulatory update in Faculty Self-Service 9x

To comply with the latest union agreement, institutions can now display the Standard Workload Form (SWF) in the original format or a new, updated format on the SWF Self-Service page.

This enhancement enables institutions that want to use the original format to maintain the existing layout of the signed and completed SWF for historical records.

Ellucian also provided a new seed data record in the Banner Applications Configurations (GUACONF) page where the institution can specify the term for the new format.

This enhancement addresses PE0003450 in the Ellucian Customer Center.

2022 Releases

Release 8.2.4.2

These release notes describe new features, enhancements, and updates in Standard Workload Form (SWF) Banner Student.

SWF Self-Service 8x pages transformed to 9x

Ellucian has moved the Banner SWF Self-Service 8.x pages to Faculty Self-Service 9.19 to implement a single technology stack.

Ellucian completed a page-to-page conversion of most pages and some pages are combined to streamline navigation differences. The new 9.x pages can coexist with the 8.x pages.

As part of your institution's review of the new pages, you may want to identify a time line to decommission the 8.x menu entries and the corresponding 8.x pages.

This enhancement addresses PE0001272 in the Ellucian Customer Center.

New seed data for Banner Faculty Self-Service 9x

With this release, Ellucian has added new seed data to support the Banner SWF pages in Banner Faculty Self-Service.

For more information, refer to Banner Faculty Self-Service seed data topic.

New user admin role for Banner Faculty Self-Service 9x

With this release, Ellucian has added a new user role for SWF administrators that enables them to access the Banner SWF pages of the faculty members in Banner Faculty Self-Service.

For more information, refer to Banner Faculty Self-Service seed data topic.

This enhancement addresses PE0001227 in the Ellucian Customer Center.
