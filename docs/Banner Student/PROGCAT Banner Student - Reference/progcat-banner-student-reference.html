Pages for Programme Catalogue.

Programme Catalogue Programme Access Control List (SKAPROO) page

Use the SKAPROO page to grant access allowing faculty members to update programme information in PROGCAT Faculty and Advisor Self-Service users.

Key block

Use this section to specify the programmer, term, or both for which you want to grant faculty members update access. You can enter one or both values, or leave both fields blank. If you leave both fields blank, the system displays all programmes when you go to the base section.

Field Description
Program Code associated with the programme to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members programme update access.

Base section

Use this base section to details for which you want to grant access for the data entered in the Key block.

Field Description
Program Code associated with the programme to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members programme update access.
ID Banner ID of the faculty member to whom you want to grant programme update access.
Active Indicator Check box used to indicate whether faculty members can update programme details.
Activity Date Date on which the record was last updated. Display only.
User Banner ID of the user who last changed this record. Display only.

Programme Catalogue Area Access Control List (SKAAREO) page

Use the SKAAREO page to grant access allowing faculty members to update area information in PROGCAT Faculty and Advisor Self-Service users.

Key block

Use this section to specify the area, term, or user for which you want to grant faculty members update access. You can enter any combination of values, or leave all fields blank. If you leave all fields blank, the system displays all areas when you go to the base section.

Field Description
Area Code associated with the area to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members area update access.
ID Banner ID of the faculty member to whom you want to filter area access.

Base section

Use this section to enter the details to grant faculty members update access for the data entered in the Key block.

Field Description
Area Code associated with the area to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members area update access.
ID Banner ID of the faculty member to whom you want to grant faculty members area update access.
Active Indicator Check box used to indicate whether faculty members can update area details.
Activity Date Date on which the record was last updated. Display only.
User Banner ID of the user who last changed this record. Display only.

Programme Catalogue Course Access Control List (SKACRSO) page

Use the SKACRSO page to grant access allowing faculty members to update course information in PROGCAT Faculty and Advisor Self-Service users.

Key block

Use this section to specify the subject, course, term or user for which you want to grant faculty members update access.

You can enter any combination of values, or leave all fields blank. If you leave all fields blank, the system displays all courses when you go to the base section.

Field Description
Subject Code associated with the subject to which you want to grant faculty members update access.
Course Number associated with the course to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members area update access.
ID Banner ID of the faculty member to whom you want to filter course access.

Base section

Use this section to enter the details to grant faculty members update access for the data specified in the Key block.

Field Description
Subject Code Code associated with the subject to which you want to grant faculty members update access.
Course Number Number associated with the course to which you want to grant faculty members update access.
Term Term code of the term for which you want to grant faculty members area update access.
ID Banner ID of the faculty member to whom you want to grant faculty members area update access.
Active Indicator Check box used to indicate whether faculty members can update area details.
Activity Date Date on which the record was last updated. Display only.
User Banner ID of the user who last changed this record. Display only.
