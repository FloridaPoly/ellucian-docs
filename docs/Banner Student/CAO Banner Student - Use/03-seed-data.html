Seed Data

This topic provides information about the following seed data delivered for Banner CAO.

GZVCAOI CAO Interface Configuration

The system configurable variables on the CAO Interface Configuration page (GZVCAOI) are used to tailor the CAO module based on an institution's needs. These variables must be changed by institution staff.

The static codes normally do not need to be changed.

Address Order (CAOADDRORDER)

The address order is used to determine the address type that appears in the Original Applicant block on the SZAIREC page. Your institution must enter the necessary values.

Admission Type Code (CAOADMTCODE)

This system configurable variable is used to define the admission type code. Your institution must enter the necessary values.

Applicant Attribute Code (CAOAPPATTRIB)

The applicant attribute code is used by the SZPIIMG process to create an attribute (SARAATT) record when an application is loaded from the master file.

If a default applicant attribute code is not specified, then a SARAATT record will not be created by the SZPIIMG process. The value will be stored in the SARAATT_ATTS_CODE column.

Your institution must enter the necessary values.

Institution Flag Position (CAOAS02)

This seed data is used to define the institution flag position for the AS02 field in the Application Selection (AS) file. Your institution must enter the necessary values.

Address Type Code (CAOATYPCODE)

This system configurable variable is used to define the address type code. Your institution must enter the necessary values

Auto Match (CAOAUTOMATCH)

The CAOAUTOMATCH system variable is used to indicate whether the CAO Interface: Merge+Load File Process (SZPIIMG) should automatically load matched applicants into Banner. Your institution must enter the necessary values.

Gender matching rule

The CAOGENDERMATCHING group decides whether the CAO Interface: Merge+Load File Process (SZPIIMG) should match the records based on legal sex or none (no legal sex data is considered in the matching). Institutions must enter the necessary values.

Banner Origin (CAOBANNERORIGIN)

This system configurable variable is used to define the SPRIDEN origin for Banner generated records. Your institution must enter the necessary values.

Nationality Codes (CAOCNTRY)

This static code is used to map the Banner three-character nationality codes (ISO Standard 6133) to the CAO country code on the GZVCAOI page.

The Banner three-character nationality codes are delivered as seed data to the Nation Codes Table (STVNATN). This data does not need to be modified by your institution.

County/Nation Mapping Codes (CAOCNTYNAT)

The codes defined for CAOCNTYNAT map the appropriate Banner nation code for Ireland or Great Britain to each of the CAO county codes.

Cohort Codes (CAOCOHORT)

These system configuration variables match the first three or four characters of the CAO ID number in the cohort group. The CAO will supply the number prefixes and the corresponding cohort codes at the beginning of the cycle. This task must be done every year before the processing cycle begins.

Your institution must enter the necessary values.

Case Conversion (CAOCONVERSION)

This system configurable variable defines the case for applicant names and addresses. Your institution must enter the necessary values.

CAO Comment Type for SMS Indicator Codes (CAOSMSCODE)

This system configurable variable defines the comment type code (from STVCMTT) to store on comment (SPRCMNT) records containing the value for the SMSFlag, ID23. Your institution must enter the necessary values.

CAO County Codes (CAOCOUNTY)

This static code is used to map the Banner two-character county codes to the CAO county codes.

This data does not need to be modified by your institution.

Course Codes (CAOCOURSE)

This system configurable variable is used to map the CAO course codes for your institution to fields used by the Banner pages. Your institution must enter the necessary values.

Debug Log (CAODEBUGLOG)

This system configurable variable is used to define the full path of the SQL debug log.

This is an obsolete Group Code and is replaced by the combination of CAODEBUGDIR and CAODEBUGFILE.

Your institution must enter the necessary values. This is an obsolete Group Code and is replaced by the combination of CAODEBUGDIR and CAODEBUGFILE.

Debug Log Location (CAODEBUGDIR)

This system configurable variable is used to define the Oracle directory name for the location of the debug log. Your institution must enter the necessary values.

Debug Log Filename (CAODEBUGFILE)

This system configurable variable is used to define the file name of the debug log. Your institution must enter the necessary values.

Deferral Comment Type Code (CAODFRLCODE)

The SZPIIMG process stores the deferral flag from the ID21 field as a comment in the SPRCMNT table.

The default comment type code is used to define the comment type when the SPRCMNT record is created. If a default comment type code is not entered and the deferral flag (ID21 field) is not blank, an exception will be generated and processing of the application will cease. The value will be stored in the SPRCMNT_CMTT_CODE column.

Your institution must enter the necessary values.

Diploma Code (CAODPLMCODE)

This system configurable variable is used to define the diploma code. Your institution must enter the necessary values.

Conversion of Exam Results for Type 6 (CAOEF6)

This static code is used to define how to convert the exam results for type 6 (Other Exam and Information). This data does not need to be modified by your institution

Conversion of Exam Results for Type 7 (CAOEF7)

This static code was used to define how to convert the exam results for type 7 (Leaving Certificate post 1991) and 9 (Leaving Certificate post 1999). This is an obsolete code and replaced by CAOEF9.

Conversion of Exam Results for Type 9 (CAOEF9)

This static code is used to define how to convert the exam results for type 7 (Leaving Certificate post 1991) and 9 (Leaving Certificate post 1999 and post 2017).

This data does not need to be modified by your institution.

Conversion of Exam Results Level (CAOEF9LEVEL)

This static code is used to define how to convert the exam result levels from the Exam results (EF) file into an associated code in the Testing Validation table STVTEFR.

This will then be saved onto the Banner Test Score table (SORTEST). This data does not need to be modified by your institution.

E-Mail Type Code (CAOEMALCODE)

An e-mail code type is used when recording a CAO applicant's e-mail address.

If an e-mail address exists in the Text (TX) file, the SZPIIFT process will create a record in the GOREMAL table assigning the default e-mail type code to the new record. The value will be stored in the GOREMAL_EMAL_CODE column.

If the CAOEMALCODE group is blank or not valid, an e-mail record will not be created.

Your institution must enter the necessary values.

E-Mail Preferred Indicator (CAOEMALPREF)

When an e-mail address is loaded through a Text (TX) file and a GOREMAL record is created for an applicant, this setting indicates if CAO would mark the newly added e-mail record as preferred or not in the field GOREMAL_PREFERRED_IND.

If CAOEMALPREF is set to Y, the loaded e-mail addresses are marked as preferred.

If CAOEMALPREF is set to N, the loaded e-mail addresses are marked as not preferred.

Your institution must enter the necessary values.

Comment Type Code (CAOERCMTT)

This system configuration variable defines the Comment Type code that will be inserted into the Person Comment page (SPACMNT) when the SZPIIFT process loads an exam file record with no exam results for the current exam year (for the exam types defined for CAOLOADERTYP).

Your institution must enter the necessary values.

Expected Results Year (CAOEREXMYR)

This system configuration variable defines the current exam year for a specified exam type. Your institution must enter the necessary values.

Exam Types (CAOEXAMTYPES)

This system configuration variable defines the list of exam types that the SZPIEEF process will load. Your institution must enter the necessary values.

GCSE Base Year (CAOGCSEYEAR)

This system configurable variable denotes the base year for the GCSE exam results. Your institution must enter the necessary values.

Banner Generated Identification Numbers (CAOGENERATEID)

This system configurable variable is used to define when Banner IDs are generated. Your institution must enter the necessary values.

Country of Birth and Nationality (CAOID08)

This group is no longer used.

Address Country Codes (CAOID13)

This group is no longer used. The Address Country code is mapped through the STVNATN page.

Load Expected Results (CAOLOADERTYP)

System configurable variable defines the exam types for which the SZPIIFT process should create a record in the SPACMNT page when processing an exam file record with no exam results for the current exam year to indicate that results are expected for the applicant. Institutions should enter the necessary values.

Load Reply (CAOLOADREPLY)

The Load Reply indicator is used to indicate if a lapsed offer decision should be generated when processing Offer/Acceptance (OF) transactions using the CAO Interface: OF Data Load Process (SZPIIOF).

When processing an OF transaction for an existing CAO application where the acceptance date is blank, the SZPIIOF process will check whether the reply date is populated with a date before the current date. If the reply date is populated with a date before the current date, then a decision record (SARAPPD) can be generated with a type of OL (Offer Lapsed) depending on the value for the CAOLOADREPLY group on the GZVCAOI page.

Your institution must enter the necessary values.

Match Address (CAOMATCHADDRESS)

This is no longer in use. The code was left in the system in case your institution used it for local customizations.

Match PPS (CAOMATCHPPS)

This is no longer in use. The code was left in the system in case your institution used it for local customizations.

CAO Result Code (CAORESULT)

This system configurable variable is used to define the CAO result code. Seed data is provided for the result code.

Maximum Score (CAOMAXSCORE)

This group is used to define the maximum score for which a random rank will be determined (either from the CAO or generated by the software) when entering CAO ratings.

Your institution must enter the necessary values.

Minimum Score (CAOMINSCORE)

This group is used to define the minimum score for which a random rank will be determined (either from the CAO or generated by the software) when entering CAO ratings.

Your institution must enter the necessary values.

Mobile Telephone Number (CAOMOBILEADDR)

The Mobile Telephone Number parameter is used to determine if mobile telephone numbers should be associated with an address record when processing the CAO text file (TX).

If the CAOMOBILEADDR parameter has a value of N, the mobile phone number will be stored in the SPRTELE table with a null value for the ATYP_CODE and ADDR_SEQNO fields. If the parameter has a value of Y, the mobile phone number is stored with the default CAO address type in the ATYP_CODE field. The sequence number, if not already known, is fetched from an existing SPRTELE mobile phone record for the applicant, or if none is present, the sequence number is fetched from the applicant's most recent SPRADDR record for the default address type. Your institution must enter the necessary values.

Mobile Phone Code (CAOMOBLCODE)

A mobile telephone type code is used when recording a CAO applicant's mobile telephone number.

If a mobile telephone number exists in the Text (TX) file, the SZPIIFT process will create a record in the SPRTELE table assigning the default telephone type code to the new record. The value will be stored in the SPRTELE_TELE_CODE column.

If the CAOMOBLCODE group is blank or not valid, a telephone record will not be created.

Your institution must enter the necessary values.

Offer Month (CAOMONTH)

The Offer Month parameter is used to associate a month with the month value contained in the Offer file in fields OF08 and OF10.

The dates in an Offer file are in the format of MDD, where M is a value between 1 and 5, and DD is the day of the month. A value of 1 is considered to be the 8th month, a value of 2 is the 9th month, a value of 3 is the 10th month, a value of 4 is the 11th month, and a value of 5 is the 12th month.

The CAOMONTH parameter value is used along with the DD portion of the OF08/OF10 field and the current year to page an offer date for the decision record in the SARAPPD table.

The values in the External Code fields are the values included in the Offer file (current values are 1-5). The values in the Internal Code fields represent the months used to store decision records in the SARAPPD table. The Internal Code values can be changed to any valid month from 1-12.

If CAO introduces a new value such as 6, the only required change would be to introduce a new CAOMONTH record with an external code of 6 and the relevant month in the internal code.

Your institution must enter the necessary values.

Current CAO Name Type Code (CAONEWNTYP)

This system configurable variable is used to define the current CAO name type code. Your institution must enter the necessary values.

Previous CAO Name Type Code (CAOOLDNTYP)

This system configurable variable is used to define the previous CAO name type code. Your institution must enter the necessary values.

CAO ID Origin (CAOORIGIN)

This system configurable variable is used to define the origin of the CAO ID. Your institution must enter the necessary values.

Process E-mail (CAOPROCESSEMAIL)

The Process E-mail parameter is used to determine if e-mails should be processed in the GOREMAL table from the CAO text file (TX) using the SZPIIFT process. Your institution must enter the necessary values.

Rating Rank Length (CAORANKLENGTH)

This group is used to define the length of the rating rank value, which will be stored in the SORTEST_TEIN_CODE column. The SZPIIRS process retrieves the rank values according to the maximum length specified for the rank length. Your institution must enter the necessary values.

Overwrite Rating Rank Indicator (CAORANKOVR)

This group is used to indicate if a user can overwrite the random values for rating ranks and supplemental ranks in the SZARXPR, SZARMAS, and SZAIIOT pages. Your institution must enter the necessary values.

Residency Code (CAORESDCODE)

This group is used to map a CAO residency code to a Banner residency code. Your institution must enter the necessary values.

Rating Score Length (CAOSCORELENGTH)

This group is used to define the length of the rating score value, which will be stored in the SORTEST_TEST_SCORE column. The SZPIIRS process retrieves the score values according to the maximum length specified for the score length. Your institution must enter the necessary values.

Automatic School File Update (CAOSFAUTOUPD)

This system configurable variable is used indicate whether the CAO Interface: Load Schools Process (SZPIISF) should automatically update existing school entries with data from the schools file, or create a report that indicates that an entry exists but the schools file data is different. Your institution must enter the necessary values.

Signature Indicator (CAOSIGNATURE)

This system configurable variable is used to define the signature indicator, which determines the value stored in the GOBINTL_SIGNATURE_IND column. Your institution must enter the necessary values.

CAO Exam Subjects (CAOSLESC)

This static code is used to map the two-character CAO school exam subjects to the three-character Banner mnemonic equivalents. This data does not need to be modified by your institution.

Spouse Indicator (CAOSPOUSE)

This system configurable variable is used to define the spouse indicator, which determines the value stored in the GOBINTL_SPOUSE_IND column.

Note: This system configurable variable is only available in CAO 6.0.

Your institution must enter the necessary values.

Student Type (CAOSTYP)

This group is used to define student type. The student type value is stored in the SARADAP_STYP_CODE column when an application record is created. The same value is later stored in the SGBSTDN_STYP_CODE column when a General Student record is created.

Your institution must enter the necessary values.

Telephone Type Code (CAOTELECODE)

This system configurable variable is used to define the telephone type code. Your institution must enter the necessary values.

Telephone to Address Association (CAOTELEADDR)

This system configurable variable is used as an indicator if a telephone number loaded through the Identification (ID) file would be associated with an address loaded from the same file. Your institution must enter the necessary values.

Term Code (CAOTERMCODE)

This system configurable variable is used to define the current term code. Your institution must enter the necessary values

Category Flag (CAOUSECAT)

This group is used to indicate if the CAO category flag from the ID file should be used to populate the cohort field.

The system will raise a validation exception when the value for the Internal Code field is Y for the CAOUSECAT group, and the CAO category flag from the ID file is null.

Your institution must enter the necessary values.

Institution Merger indicator

The CAOINSTITUTIONMERGER group is used to indicate if the institution is merged.

STVAPDC Admission Application Decision Codes

The following codes are delivered for use with the CAO module.

  • OD - Offered
  • AD - Accepted
  • SU - Superceded
  • OL - Offer Lapsed

STVADMR Admissions Request Checklist Codes

The following codes are delivered for use with the CAO module.

  • EF - Exam File
  • LC - Leaving Certificate
  • SR - Inst or Splmntry Rate
  • AS - Application Selection File
  • OF - Offer/Acceptance File

STVASRC Address Source Code

The CAO - Central Applications Office code is delivered. It is stored against all addresses loaded from CAO files.

STVCNTY County Codes

  • 8 - Matric Exam of the NUI (1992)
