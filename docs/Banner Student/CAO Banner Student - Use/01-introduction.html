Introduction

The Central Applications Office (CAO) accepts applications for admission to undergraduate courses in Higher Education Institutions (HEIs) in Ireland.

The purpose of CAO is to process applications centrally and to deal with them in an efficient and fair manner. The HEIs that are participating with the CAO retain the ability to make decisions on admissions.

CAO is the agent for and acts on behalf of the HEIs participating in the Application System. The application regulations, procedures, and timetable are agreed annually by these HEIs. CAO has no discretion to set the regulations aside to either afford special treatment to any applicant over another, or to deprive any applicant of the applicant's entitlement in favor of another.

The Banner CAO interface provides the ability to load admissions data files provided by the CAO into the Banner Student application.

Functions

The CAO module provides the ability to do the following.

  • Configure the Banner CAO data values to match your institution's Banner Student system.

    This is achieved by indicating which values in the Banner Student system relate to the values on the CAO files. This process is referred to as 'mapping'. Many of the default mappings provided as seed data do not need to be changed. See Implement the CAO module for details on which parameters need to be mapped by the user.

  • Send and receive transaction files to and from CAO.
  • Review, maintain, and process applicants' data as per the CAO scheme.
  • Link the admissions data obtained through CAO and the Admissions module of the Banner Student system during the management of admissions activities.
  • Automatically create student records in Banner after offers have been accepted.
