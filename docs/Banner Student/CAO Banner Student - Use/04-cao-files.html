Application Selection File (AS)

This file contains the details of the applicants' preferences. The file indicates whether or not the applicant has made a course selection at your institution. The CAO has calculated these points (ratings) for each course for the applicant. The format of transactions on the file is as follows.

Field Location Description Comments
AS01 1-8 Application Number.  
AS02 9-88 Institution flags. Each character represents one of your institutions. The flag (1 or 0) indicates if there are course selections for that particular institution in the AS03 field.

For example, if an institution is represented by character 8, then that character is checked for a value of 1 or 0.
AS11 89-119 (Space)  
AS03 120-169 Ten five-character course codes. Ordered by preference left to right.
AS05 170-229 Ten six-digit Ratings.  
AS07 230-259 Ten three-character subject-option codes.  
AS09 260-267 (Spaces)  
AS10 268-279 Date and time when record written. The date and time when the record was written is checked to determine whether updates should occur to existing CAO ™ records.

Examination Type

The examination type is a one-digit code specifying the type of examination. A student might have supplied the exam results for a number of exam types, including multiple result sets for the same exam type. The examination types included in the CAO module are as follows.

Exam Code Exam Title
0 NUI Irish Exempt (post-1999)
1 Leaving Certificate (pre-1992)
2 Matriculation Exam of NUI (pre-1992)
3 Matriculation Exam of University of Dublin
4 General Certificate of (Secondary) Education Examination (Northern Ireland)
5 General Certificate of (Secondary) Education Examination (Britain)
6 Indicator to show which fields are ticked on page 3 of the application form.
7 Leaving Certificate (post-1991)
8 Matriculation Exam of the NUI (1992)
9 Leaving Certificate (post-1999)
R Rating
S Supplemental

Examination Subjects and Results

The examination subjects and results can contain up to twelve entries, each consisting of up to four characters in the format 'SSLR' where SS is your institution leaving examination subject code, LR is the level or the result of the examination or both.

Text File (TX)

The CAO will provide a text file that captures free format text. This data will include the country of birth of the applicant if not Ireland or the U.K., and the nationality of the applicant if not Ireland or the U.K.

The data will also include whether an applicant has applied for a vacant place and whether the applicant has previously applied to the CAO. The format of transactions on the file is as follows.

Field Location Description
TX01 1-8 Application Number.
TX02 9 Record Type Flag (‘6’).
TX03 10-11 Text Type Code.
TX04 12-80 Text.

The user is warned where an acceptance decision is associated with an existing CAO application but there is no longer an acceptance date in the OF transaction.

When processing an OF transaction for an existing CAO application where the acceptance date (OF10) is blank, the SZPIIOF process will check the reply date. The decision date will correspond to the value in the reply date field mapped through the CAOMONTH GZVCAOI mapping data.

Vocational Award File (VA)

This file contains the applicant qualifications data sent by the CAO. The format of transactions on the file is as follows.

VA Field Content Location Contents
VA01 8 1 - 8 Application Number.
VA02 1 9 Examination Type ( '2' ).
VA03 2 10 - 11 Examination Year ( yy ).
VA04 6 12 - 17 Examination Number (Blank from 2005).
VA05 8 18 - 25 Award Code.
VA06 1 26 - 26 (Blank from 2013).
VA07 144 27 - 170 Up to 16 Module Code & Result 9-character combinations (each mmmmmmmmr).
VA08 12 171– 182 QQI/FETAC candidate number (PPS Number, unverified).
VA09 4 183 - 186 FETAC sitting score for candidate.
VA10 4 187 - 190 FETAC combined sitting score for candidate.
VA11 4 191 – 194 FETAC best sitting score for candidate.
VA12 6 195 - 200 Date Record updated.
When the SZPIIFT process is run for VA file, the file data gets stored in the SORQQIA and SORQQIR tables and can be viewed in SOAQQIA page.
The VA file is processed as follows.
  • When VA file is loaded with award code which does not exist in the STVSAWD table, the award code is NULL in the SOAQQIA page.
  • The Module Code value is validated against STVQQIM validation table.
  • Result Code value is validated against the GZVCAOI CAORESULT parameter values.
  • When both the Module Code and Result Code values are provided in VA file, the corresponding data gets into the SORQQIR table and is viewed in SOAQQIA page.
  • If the data is loaded for the existing Student ID, the data is created in the SORQQIA table with a new sequence number and users can view the entire data related to the Student ID.

Net Acceptance file

CAO sends the Net Acceptance file that includes the Leaving Certificate Examination (LCE) points for each applicant for the student's specific courses.

To import the Net Acceptance file, see the Net Acceptance File Import (SORNAIM) process available in the CAO Reports content.

Files sent to the CAO

The following file can be sent to the module.

Ratings File (RF)

This file consists of the following types of records.

  • Ratings (R)
  • Supplemental Scores (S)

The S record is used to supply an additional score that is added to the CAO rating, as notified in the AS transactions. Typically this is done for students that need extra assessment for portfolios, special tests, or performance tests.

The R records are used to send an absolute score, which overwrites the CAO rating. Typically, this would be for students who are ineligible, deferred or mature.

Multiple R and S scores can be created and sent to the CAO for each applicant.

A transmission of R type records will include all applicants for all courses at a given institution that have an institution assigned rating. A transmission of S type scores will include all applicants for all courses at a given institution that have institution assigned supplemental scores.

The format of transactions on the file is as follows.

Field Location Description
RF14 1 Record Type ('R' or 'S').
RF15 2-9 Application Number.
RF16 10-23 Course/Subject-option/Rating.
RF17 24-37 Course/Subject-option/Rating.
RF18 38-51 Course/Subject-option/Rating.
RF19 52-65 Course/Subject-option/Rating.
RF20 66-79 Course/Subject-option/Rating.
RF21 80 (Spaces)

The rating consists of six digits. For the Irish Institutes of Technology, the first four digits represent the rate. Normally the rating score is in the range 0025 to 0600. Supplemental scores can range from 0 to 600, giving a high score of 1200. The last two digits are used to randomly rank students with the same score. Students with the same rating are selected using the ranking value in the order 01 through 99.

The following rating values are reserved and used for special purposes:
  • Blank: Not processed
  • 000000: Ineligible
  • 000001: Holding score
  • 999999: Automatic offer (typically deferred or mature)
  • 888888: Some institutions have reserved special values for coding additional information.

The SZPIIRS process is used to create the ratings file.
