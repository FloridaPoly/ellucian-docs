Release 8.10

The Banner CAO 8.10 release includes enhancements and a defect fix.

Technical Currency Updates

As part of ongoing technical currency initiatives, Banner General Java batch programs have been upgraded to support the latest versions of key Spring frameworks. This enhancement ensures improved compatibility, performance, and alignment with modern development standards. Banner General Java batch programs now support Spring Framework 7.x, Spring-boot 4.x and Spring-batch 6x libraries at runtime.

This enhancement addresses PE0008177 in the Ellucian Customer Center.

Modified fnDoSaradap function

The fnDoSaradap function of SZAUFPR_PKG is modified so that concentrations 1 and 2 are now correctly associated with their corresponding major using GZVCAOI‑configured major values.

This defect addresses PD0033498 in the Ellucian Customer Center.

Enhancements

Regulatory enhancements

Summary of the Banner CAO 9.3.29 and 8.4 release regulatory enhancements.

With this release, you can:
  • Import the Net Acceptance file to create and display the LCE points for applications This satisfies PE0001467.
  • Withdraw applications based on the user input value for the Year of Entry. This satisfies PD0003145.
  • Define if the gender matching is based on Legal Sex or None options, with a new parameter available with this release. This satisfies PE0001460.
  • Define CAO institution merger with a new parameter available with this release. This satisfies PE0001466.

To support the 9.3.29 and 8.4 enhancement, the release includes the following updates.

Change page

The LCE Points field is new to the CAO Application section of the SZAIIOT page.

Changed table

The SZRADAP_APPL_LCE_POINTS (Leaving certificate examination points for application) column with VARCHAR2(5) is new to the SZRADAP table to support the new LCE Points field in the SZAIIOT page.

New process

The Net Acceptance File Import (SORNAIM) process is new to import the Net Acceptance files that the CAO sends. The file includes the Leaving Certificate Examination (LCE) points and inserts into the SZRADAP table for each applicant for the student's specific courses. The information is available in .xlsx format.

To know more about the SORNAIM process refer to CAO Use and CAO Reports content.

Enhancements

Regulatory enhancements

Summary of the Banner CAO 8.3.3.4 release regulatory enhancements.

With this release, using the Banner CAO application you can create study path records. The Study Path feature allow institutions to associate specific course registration records to the learner curriculum records during registration.

Using the Study Path feature, you can do the following.
  • Track separate student status codes and academic standings (along with various other data) based on the student's curriculum
  • Permit tracking of enrollment eligibility that is separate from a student's overall enrollment status
  • Keep courses with an associated study path within the degree sequence created for that study path
  • Create study paths when an applicant is accepted with a decision code that creates the general student record
  • Create a study path from an existing curriculum record

To support this enhancement, this release includes the following updates.
