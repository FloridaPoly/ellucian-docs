Set up Banner PSIS

Learn about the tasks you must perform to set up Banner PSIS.

Become familiar with the PSIS documentation, available from the Statistics Canada website.

Enter required data elements

PSIS reporting requires specific information from all Canadian post-secondary institutions for each twelve-month period.

The captured information consists of the programs and courses offered, and enrollment data from each reporting institution. Captured data is stored in specific tables that accommodate PSIS reporting requirements. For both the Preliminary and Final reports, all terms, parts of term, programs, and courses are reported.

To enter the required data elements you must perform the following steps:

  1. Define Programs Associated with PSIS Reporting.
  2. Set Up GTVSDAX Entries.
  3. Define Values for the PSIS Reporting Cycle.
  4. Define Crosswalks between Banner Values and PSIS Codes.

Define programs associated with PSIS reporting

A code for a non-program must be defined. For example, you could create the program code NONPRGM to distinguish non-programs.

Procedure

  1. Access the Program Definition Rules (SMAPRLE) form.
  2. Select Insert Record.
  3. Enter the program code in the Program field (for example, BA).
  4. Enter a description of the program.
  5. Enter the relevant program information.
  6. Select Save.
  7. Repeat the steps above for all programs associated with PSIS reporting.

Set up GTVSDAX entries

Learn how to add PSIS crosswalk entries to GTVSDAX.

Procedure

  1. Access the Crosswalk Validation (GTVSDAX) form.
  2. Select Insert Record.
  3. Enter a code in the Internal Codefield.
  4. Enter the appropriate number in the Sequencefield.
  5. Enter PSISin the Groupfield.
  6. Enter a description in the Descriptionfield.
  7. Enter the appropriate code in the External Codefield.
  8. Select Save.
  9. Repeat the steps above for the remaining PSIS crosswalk values.

Define values for the PSIS reporting cycle

A preliminary and final report type must be defined for each reporting year. These cycles are designated as the reporting year concatenated with the report type (for example, 2002P and 2002F).

Procedure

  1. Access the Statistics Canada PSIS form.
  2. Enter the reporting year, institution code and report type, and select Next Block.
  3. Enter the first date after the end of the winter term.
  4. From the Institution Type field, select S for a single institution or M for multiple institutions.
  5. Select the last valid term code for the reporting cycle.
  6. Select the unit of measure used to define credits granted for a program.
  7. Select Save.

Define crosswalks between banner values and PSIS codes

Learn how to map Banner values to PSIS codes.

About this task

When Banner PSIS is installed, seed data for element labels is added to the Elements Validation Table (SVVELMT). You can also add new element labels to this table using the Statistics Canada Elements Validation (SVVELMT) form.

Using the Statistics Canada Crosswalk Code Validation (SVVXWLK) form, you specify which Banner table contains the values for each element label, then you use the Statistics Canada PSIS Crosswalk (SVAXWLK) form to specify which Banner code is to be associated with the PSIS code.

Procedure

  1. Access the Statistics Canada Crosswalk Code Validation (SVVXWLK) form.
  2. Perform a query to locate the desired element label, or insert a new record to create it.
  3. If you inserted a new record, enter the element label in the Element Label field.Valid values are those defined on the Statistics Canada Elements Validation (SVVELMT) form.
  4. Enter the name of the baseline Banner table to be cross-walked for this element in the Banner Table field.
  5. Enter the name of the Banner PSIS table to be cross-walked for this element in the PSIS Table field.
  6. Select the System Required check box.
  7. Save your changes.
  8. Access the Statistics Canada PSIS Crosswalk (SVAXWLK) form.
  9. Select the element from the LOV in the Element Label field in the Key block.

    You must use the LOV to populate the Element Label and Banner Table fields in the Key block; you cannot enter a valid value directly.When you enter a valid element label, the system displays the name of the Banner table that was cross-walked to the element label in step 4 of this procedure.

  10. Go to the next block.
  11. Perform a query to locate the desired PSIS code record, or insert a new record to create it.
    Valid values are those defined on the Statistics Canada Elements Rule (SVACODE) form.
  12. Enter the Banner value that is to be associated with the PSIS value in the Banner Value field.
    Valid values are those defined for the Banner table displayed in the Key block.
  13. Enter the first term for which this crosswalk is to be in effect in the Effective Term Code From field.
  14. Enter the last term for which this crosswalk is to be in effect in the Effective Term Code To field.
  15. Save your changes.

Capture institution-related data

Institution data consists of an institution’s description (ID), programs (IP) and courses (IC). The information can be entered by an optional process or manually.

All of the institution’s terms or part-of-terms, programs and courses offered during the reporting period must be defined.

The non-program code (for example, NONPGRM) must be defined in your institution’s program data.

To capture institution-related data, you must perform the following steps:

  1. Input Default Institution Related Data upon Installation.
  2. Input Default Institution Related Data on a Yearly Basis.
  3. Manually Input Institution Related Data.

Input default institution related data upon installation

This setup step describes how to use the optional processes to populate the PSIS application tables with the default values when the release has been installed.

About this task

This setup step is optional and should be performed only one time after the installation.

Procedure

  1. Access the Fill SVRIDTB with Defaults Process (SVPIDDV) form.
  2. Enter the desired values in the parameters, including entering F for the Process Type parameter.
  3. Run the process.
    The SVRIDTB table is populated with the default data as found on SOATERM.

    After running this optional process, SVAIDTB can be used to add or modify the associated data.

  4. Access the Fill SVRIPTB with Defaults Process (SVPIPDV) form.
  5. Enter the desired values in the parameters, including entering F for the Process Type parameter.
  6. Run the process.
    The SVRIPTB table is populated with the current programs defined on SMAPRLE and with the default values for all PSIS fields.

    After running the optional process, you can use SVAIPTB to add or modify the associated data.

    Note: If multiple institutions are supported, do not use SVPIPDV.
  7. Access the Fill SVRICTB with Defaults Process (SVPICDV) form.
  8. Enter the desired values in the parameters, including entering F for the Process Type parameter.
  9. Run the process.
    The SVRICTB table is populated with the current courses as defined on SCACRSE, and with the default values for all PSIS fields.

    After running the optional process, you can use SVAICTB to add or modify the associated data.

Manually input institution related data

Learn how to add data, or modify data that was added through the optional processes.

Procedure

  1. Access the Statistics Canada PSIS Institution Description Data Capture (SVAIDTB) form.
  2. Enter the reporting year, select the institution code, and select Next Block.
  3. Double-click in the Termfield, select a term and click OK.
  4. Double-click in the Part of Term field, select a part of term code, and click OK.
  5. In the Withdrawal Date field, enter the date after which a student cannot withdraw from a course without receiving a penalty.
  6. If applicable, enter any provincial information in the Provincial ID Elements field.
  7. Repeat steps 3 through 6 for all term and part of term combinations within the PSIS reporting year.
  8. Select Save.
  9. Open the Statistics Canada PSIS Institution Program Data Capture (SVAIPTB) form.
    When the program data is entered into SVAIPTB, the data is only updated if the program characteristics change or new programs are added.
  10. Enter the program ID and term, and select Next Block.
  11. Enter the necessary program data in the fields.
    Press Tab to move from field to field and to open the next block in the sequence.
  12. Select Save.
  13. Repeat steps 10 through 12 for each program offered during the PSIS reporting cycle.
  14. Access the Statistics Canada PSIS Institution Course Data Capture (SVAICTB) form.
    When the course data is entered into SVAICTB, the data is only updated if the course characteristics change or new courses are added.
  15. Enter a subject code, course number and term, and select Next Block.
  16. Enter the necessary course data in the fields.
    Press Tab to move from field to field and to open the next block in the sequence.
  17. Select Save.
  18. Repeat steps 15 through 17 for each course offered during the PSIS reporting cycle.

Capture student related data

Student data consists of a student’s programs (SP). The student data for description (SD) and course (SC) comes from existing Banner data. The SP data can be entered by an optional process or manually.

To capture student-related data, you must perform the following steps:

  1. Input Default Student Related Data upon Installation.
  2. Input Default Student Related Data on a Yearly Basis.
  3. Manually Input Student Related Data.

Input default student related data upon installation

Learn how to use the optional process to populate the PSIS application tables with the default values after the release has been installed.

Before you begin

This setup step is optional and should only be performed one time after the installation.

Procedure

  1. Access the Fill SVRSPTB with Defaults Process (SVPSPDV) form.
  2. Enter the desired values in the parameters, including entering F for the Process Type parameter.
  3. Run the process.
    The SVRSPTB table is populated with the current program information as defined on the course catalog (SGASTDN), and with the default values for all PSIS fields.

What to do next

After running this optional process, use SVASPTB to add or modify the associated data.

Manually input student related data

Learn how to select the student population and then add data, or modify data that was added through the optional process.

About this task

The SP file contains one record for each student and program combination. Students registered in more than one program have multiple SP records.

Procedure

  1. Run the psisseldef.sqland psispop.sqlscripts to select a population for the PSIS report.

    The default selection criteria checks for student registration activity in the reporting cycle (registered this term), or graduation activity (SHRDGMR status and term) for the reporting cycle and PIDM (select each PIDM only once).

    Include the following values:

    • Registered students during the specified PSIS year
    • Graduated students during the specified PSIS year

    The following values are required in the psisseldef.sqlscript:

    • eapplication- Application code for the PSIS population
    • eselection- Selection for the PSIS population
    • ecreator_id- According to creator
    • edescription- Description for the PSIS population.

    The following values are required in the psispop.sqlscript:

    • eapplication- Application code for the PSIS population
    • eselection- Selection for the PSIS population
    • ecreator_id- According to creator
    • euser_id- According to user
    • estart_date- Start date of current PSIS year
    • eend_date- End date of current PSIS year

    The Banner Baseline Population Selection module (GLRSLCT) is a suitable alternative to this step. Use the method that best suits your situation.

  2. Access the Statistics Canada PSIS Student Program Data Capture (SVASPTB) form.
  3. Enter a student ID and term, and select Next Block.
  4. Enter the student’s program data in the fields.
    Press Tab to move from field to field and to open the next block in the sequence.
  5. Select Save.
  6. Repeat steps 3 through 5 for each course offered during the PSIS reporting cycle.

Perform local modifications

Learn how to perfrom local modifications.

You must perform local modifications for the following institutions:

  • MPHEC institutions.
  • Ontario institutions.

Make local modifications for MPHEC institutions

Institutions under the Maritime Provinces Higher Education Commissions (MPHEC) need to perform the following local modifications.

Procedure

  1. Populate the following elements in SVACODE, SVVXWLK, and SVAXWLK using the values specified in Enhanced Student Information System (PSIS), Files and Data Element Descriptions for MPHEC (Version 2.2, February 2003).
    • Provincial Program Category element IP2030
    • Provincial Program Funding Code element IP2040
    • Provincial Course Funding Code element IC3160
    • Provincial Funding Classification element SD4260
    • Provincial Student Program element SP5025
    • Special Initiative element SP5060
  2. Add province specific values to the STVMAJR_CIPC_CODE field for elements SP5020 and SP5021.
  3. Use the generic procedures to make the local modifications to accommodate the following fields:
    • IP2401
    • IP2402
    • SD4402
    • SD4403
    • SP5085
