Generic procedures

If one or more of the fields in the PSIS flat files do not match the calculation method used at your institution, you can modify that calculation to reflect your requirements by using the generic procedures.

Insert data generic procedures

The following generic procedures are used to insert records into the PSIS tables.

This procedure... Inserts records into this table...
generic_data_ID() PSIS Reporting Institution Description File Table (SVRESID)
generic_data_IP() PSIS Reporting Institution Program File Table (SVRESIP)
generic_data_IC() PSIS Reporting Institution Course File Table (SVRESIC)
generic_data_SD() PSIS Reporting Student Description File Table (SVRESSD)
generic_data_SP() PSIS Reporting Student Program File Table (SVRESSP)
generic_data_SC() PSIS Reporting Student Course File Table (SVRESSC)
generic_data_ST() PSIS Reporting Student Transfer File Table (SVRESST)

Exclude data generic procedures

You can exclude data from the PSIS report by adding local code to these new generic procedures. These generic procedures will default to Y to include the data.

You will be able to insert an SQL that will check a condition. For example, if the CRN where SHRGRDE_COMPLETED_IND= Y, the procedure will return a TRUE, which will include the CRN data in the PSIS report. If the CRN where SHRGRDE_COMPLETED_IND= N, the procedure will return a FALSE, and will go to the next record without including the CRN data in the PSIS report. The following code sample shows the code that would produce this result:

{if(!compare (shrgrde_completed_ind, "Y", EQS)) 
return FALSE;
returnTRUE;}
Note: The user is responsible to maintain the coherence between the code added to the generic procedure and the rest of the PSIS elements.
