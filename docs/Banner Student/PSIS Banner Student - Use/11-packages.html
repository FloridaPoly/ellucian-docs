Packages

The SVKPSIS database package contains the following functions and procedures.

Function Description
f_psis_calc_degree_credits Calculates degree credits for a given program (SP5230).
f_psis_calc_olr_end_date Calculates the CRN end date for an Open Learning Registration (OLR) course.
f_psis_calc_transfer_credits Calculates transfer credits for a given program (SP5220).
f_psis_check_coop Checksthe coop program indicator code for the specified student and term (SP5070).
f_psis_check_for_disable Checks disability or medical record for disability indicator (SD4215).
f_psis_check_residence Determines residence status (SD4220).
f_psis_check_sensitivity Determines if the student has a confidential or deceased indicator (SD4200).
f_psis_get_email_address Obtains e-mail from GOREMAL based on the e-mail type (SD4090).
f_psis_get_fa_amount Totals all student charges within a specified date range (SP5210).
f_psis_get_fees Totals all charges (considered fees) within a specified date range (SD4276).
f_psis_get_prev_name Obtains previous last name (where available) for the specified person (SD4050).
f_psis_get_program_status Obtains the status at the end of the program (SP5100).
f_psis_get_start_date Obtains the earliest start date based on term entries in the SVRSPTB table. The SVRSPTB records originate in SGBSTDN.
f_psis_get_tuition Totals charges from TBRACCD (SD4273).
f_psis_get_xwlk_info ReconcilesPSIS and Banner values (p_label,p_value, p_table).
f_psis_check_elmt_code Checks the valid code for the element.
p_psis_file_str Builds the record based on the length set up in the SVVELMT table.
f_psis_get_prog_type Gets the program type: PROGRAM /NONPROGRAM.
f_psis_get_course_tuition Gets the tuition amount for the course.
f_psis_continue_edu Gets the continuous education indicator.
