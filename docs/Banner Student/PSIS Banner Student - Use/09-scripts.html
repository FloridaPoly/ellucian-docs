Scripts

The psisseldef.sql and psispop.sql scripts define and create a default population. Both scripts can be used as an alternative to the Banner baseline Population Selection module. Use the method that best suits your situation.

psisseldef.sql and psispop.sql

Use of this SQL method for population selection requires the following to be included:

  • Registered Students during the specified PSIS year
  • Graduated Students during the specified PSIS year

The following values are required in the PSISSELDEF.sqlscript:

  • eapplication

    Application code for PSIS population

  • eselection

    Selection for PSIS population

  • ecreator_id

    According to creator

  • edescription

    Description for PSIS population

The following values are required in the PSISPOP.sqlscript:

  • eapplication

    Application code for PSIS population

  • eselection

    Selection for PSIS population

  • ecreator_id

    According to creator

  • euser_id– According to user
  • estart_date

    Start date of current PSIS year

  • eend_date

    End date of current PSIS year
