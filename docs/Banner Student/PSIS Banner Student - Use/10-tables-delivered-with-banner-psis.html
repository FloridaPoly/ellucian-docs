Tables delivered with Banner PSIS

Learn about the tables delivered with Banner PSIS.

Release Tracking Solution Centre Table (GVRVERS)

This table tracks the release numbers of a Canadian Solution Centre (CSC) localization. This table will be used for all CSC localizations.

Statistics Canada PSIS Institution Control Table (SVBESIS)

This table stores the control parameters for each PSIS reporting year.

Elements Rule Table (SVRCODE)

This table defines the valid codes given by Statistics Canada for the elements.

PSIS Reporting Institution Course File Table (SVRESIC)

This table stores the institution course data generated from the SVPESIS process.

PSIS Reporting Institution Description File Table (SVRESID)

This table stores the institution description data generated from the SVPESIS process.

PSIS Reporting Institution Program File Table (SVRESIP)

This table stores the institution program data generated from the SVPESIS process.

PSIS Reporting Student Course File Table (SVRESSC)

This table stores the records for each student/course combination generated from the SVPESIS process.

PSIS Reporting Student Description File Table (SVRESSD)

This table stores the student’s demographic and descriptive data generated from the SVPESIS process.

PSIS Reporting Student Program File Table (SVRESSP)

This table stores one record for each student/program combination generated from the SVPESIS process.

PSIS Reporting Student Transfer File Table (SVRESST)

This table stores the student’s transfer courses data generated from the SVPESIS process.

PSIS Institution Course - Multiple Institutions Table (SVRICIN)

This table holds the course details for institutions that report with a Statistics Canada campus code, or share a common database.

Statistics Canada PSIS Institution Course Data Capture Table (SVRICTB)

This table stores PSIS characteristics for courses. Records are stored by effective term.

Statistics Canada PSIS Institution Description Data Capture Table (SVRIDTB)

This table stores valid terms and part of terms for a given PSIS reporting year.

PSIS Institution Program - Multiple Institutions Table (SVRIPIN)

This table holds program details for institutions that report with Statistics Canada campus codes, or share a common database.

Statistics Canada PSIS Institution Program Data Capture Table (SVRIPTB)

This table stores additional PSIS program related data by effective term.

Statistics Canada PSIS Student Description Data Capture Table (SVRSPTB)

This table stores student program data by effective term.

Statistics Canada PSIS Crosswalk Table (SVRXWLK)

This table stores crosswalk information for PSIS processing.

Elements Validation Table (SVVELMT)

This table defines all the elements of flat file which needs to be sent to Statistics Canada.

Statistics Canada Crosswalk Code Table (SVVXWLK)

This table is used to store all labels associated with PSIS reporting.
