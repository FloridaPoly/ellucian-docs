Extract data and generate files

Learn how to gather data from Banner tables and PSIS tables and generate PSIS flat files.

The tables are defined after the inputting the required data elements. Institutions can review the captured data to verify its accuracy. Changes or corrections to the captured data must be made at the source level.

Extract and verify PSIS data

Learn how to extract data from Banner source files and populate the PSIS extract tables.

Before you begin

Make sure you've set up Banner PSIS.

Procedure

  1. Run the PSIS Extraction Process (SVPESIS) to populate the PSIS extract tables.

    Information is pulled from the appropriate Banner source, and from the data element fields from SVAIDTB, SVAIPTB, and SVAICTB to populate the SVRESID, SVRESIP, and SVRESIC tables.

    SVPESIS also populates the SVRESSP, SVRESSC, and SVRESST tables for each PIDM generated during the population selection.

    The data is pulled from the appropriate Banner source and from the data element fields from SVASPTB.

  2. To verify the extracted data, access the Statistics Canada PSIS Inquiry (SVIESIS) form.
    1. Select the report year, institution code, report type, and PSIS file, then select Next Block.
    2. Verify the information for the selected PSIS file.
      Use the scroll bar to view all of the information.
    3. Select Rollback after the information is verified.
    4. Repeat steps 2a through 2c for the remaining PSIS files.
  3. Access the Statistics Canada PSIS Student Inquiry (SVIESTU) form to view the PSIS data for a given student ID.
    1. Select a student ID.
    2. Select the report year, institution code, and report type, then select Next Block.
    3. Verify the data.
    4. Select the following options to verify the remaining data for the student:
      • More...
      • Student Description
      • Student Program
      • Student Course
      • Student Transfer
  4. Access the Statistics Canada PSIS Student Summary (SVIESTQ) form to view all of a student’s combinations of Reporting Year, Report Type and Institution.
    SVIESTQ can also be opened by clicking the Sum icon in the upper-right corner of the Key block on SVIESTU.
    1. Select a student ID, then select Next Block.
    2. Verify the data.

Use generic procedures to extract PSIS data

If one or more of the fields in the PSIS flat files do not match the calculation method used at your institution, you can modify that calculation using the generic procedures to reflect your requirements.

Before you begin

Make sure you've set up Banner PSIS.

About this task

Follow these rules to use the generic procedures to insert local code.

Note: The user is responsible for keeping the coherence between the code added in the generic procedure and the rest of the PSIS elements.

Procedure

  1. Select the correct procedure to insert or exclude the local code, depending on the PSIS elements that need to be changed for one or more tables.
    For example, if the elements need to be inserted into the SVRESSD table, then use the generic_data_SD procedure. If records need to be excluded from the SVRESSD table, then use the generic_check_SD procedure.
  2. Assign the WW value to the corresponding PSIS field. This rule applies only to the generic_data procedures.
    For example, if the element modified is the “Immigration status of student,” then add a line resembling the following to the generic procedure:
    strcpy(svressd_immigration_status,
    psisuser_immigration_status)
  3. Any new procedure or variable that needs to be added because of local modifications should use the psisuser prefix for its definition (that is, psisuser_procedurename, psisuser_variablename).

Generate PSIS flat files

This procedure runs a Banner job submission batch program that produces a series of PSIS related flat files. Information collected and verified through the PSIS interface is used to produce a series of flat files.

About this task

The resulting flat files are then delivered to Statistics Canada. The necessary flat files are produced according to the following schedule:

Schedule Required PSIS Procedure
October Produce metadata flat files.
January Produce preliminary flat files.
July Produce final flat files.
Note: Statistics Canada’s Prescreen software is used to verify the contents of the PSIS flat files. Installation and use of this software is beyond the scope of this document. Refer to Statistics Canada Prescreen documentation for additional details.

This procedure is used to create the flat files that are sent to Statistics Canada.

Procedure

  1. Run the PSIS Flat Files Generation Process (SVPESFF) form.
  2. Verify the data contained in the flat file using a text editor or the external Statistics Canada pre-screening process.
  3. If errors exist on the flat file, repeat the previous setup steps to correct the data, then rerun all subsequent processes until the files are free from fatal errors.PSIS pre-screening software and operating instructions are provided by Statistics Canada.
  4. Copy resulting PSIS flat files to the appropriate media for transport to Statistics Canada.
  5. Send resulting PSIS flat files to Statistics Canada using the prescribed method.
