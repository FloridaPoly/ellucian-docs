Crosswalk element labels

From the Statistics Canada PSIS Crosswalk (SVAXWLK) form, the element label is used to match Banner values with PSIS codes that Statistics Canada will recognize. The crosswalk element labels are added to the SVVXWLK form during the installation process.

Gender Codes (SD4240) (SVVXWLK)

This element label determines the gender of a student. The Banner values are from SVVXWLK.

The following PSIS codes can be crosswalked to Banner values.

PSIS Code Description
1 M (Male)
2 F (Female)
X Gender other than M/F.

Visible Minority Codes (SD4210) (STVETHN)

This element label determines if a student is a visible minority. The Banner values are from STVETHN.

The following PSIS codes can be crosswalked to Banner values.

PSIS Code Description
1 Visible minority.
2 North American Aboriginal person.
3 Not a member of a visible minority or Aboriginal group.
9 Unknown if a student is a member of a visible minority or Aboriginal group.

Brokered Course (SC6080) (STVSCCD)

This element label determines if the course was brokered. The Banner values are from STVSCCD.

The following PSIS codes can be crosswalked to Banner values.

PSIS Code Description
1 Yes, and the reporting post-secondary institution is the sponsor.
2 Yes, and the reporting post-secondary institution is the host.
3 No
9 Unknown

Continuing Education Indicator Code (SP5005 and SC5005) (STVLEVL)

This element label determines the continuing education status of the program or course in which the student is enrolled. The Banner values are from STVLEVL.

The following PSIS codes can be crosswalked to Banner values.

PSIS Code Description
1 Yes
2 No
9 Unknown

Country of Citizenship (SD4280)

This element label determines an international student’s country of citizenship code. The Banner values are from STVCITZ. Crosswalk the Banner values to the country codes provided by Statistics Canada.

If a student is registered in a department, faculty or division of continuing education or adult training extension (SP5005 or SC5005), and the information on the country of citizenship is not available, the EDI equivalent country code of Canada CA is populated. If the country of citizenship of a student is unknown, then ZZ code is populated.

Elementary/Secondary Institute Code (SD4335) (STVSBGI)

This element label determines the institution code of the Canadian elementary/secondary school that the student last attended. The Banner values are from STVSBGI.

If the school was outside of Canada, leave the PSIS code blank. If the school was within Canada, use the elementary/secondary school codes available from Statistics Canada.

PSIS County Code (SD4120) (STVCNTY)

This element label determines the code for the student’s permanent county. The Banner values are from STVCNTY. For counties outside of Canada, assign 9898 as the PSIS code.

For counties within Canada, assign a four digit county code available from Statistics Canada.

PSIS Institution Code (ST7070)

This element label is used to crosswalk the PSIS institution codes from Banner values in STVSGBI. A list of PSIS institution codes is available from Statistics Canada.

Immigration Status Code (SD4290) (STVCITZ)

This element label determines the visa type code (immigration status) of the student. The Banner values are from STVCITZ.

The following PSIS codes can be crosswalked to Banner values.

PSIS Code Description

1 Permanent resident, formerly called landed immigrant
2 Student Visa: a permit obtained by a student to enter Canada for the sole purpose of attending an educational institution
3 Other visa, including students who are in Canada on diplomatic, trade, or other missions
4 Non-Canadian, status unknown (refugees and other foreign students in Canada whose status is unknown)
5 Non-Canadian, no visa status as student is studying outside Canada (for example, by Internet)

Institute Code (SC6190) (STVBLDG)

This element label crosswalks a Canadian institution code (STVINST) with the building where the student received course instruction (STVBLDG). Use the PSIS institution codes provided by Statistics Canada.

Note: You must crosswalk only building codes that will be used during PSIS reporting.
