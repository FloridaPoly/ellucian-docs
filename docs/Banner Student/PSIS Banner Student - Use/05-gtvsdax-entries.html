GTVSDAX entries

The Banner value entered in the External Code field on GTVSDAX determines the source of the data generated during the SVPESIS process.

The information in the GTVSDAX entries topics describe what information needs to be entered on GTVSDAX. You must enter the External Code that applies to your institution.

Cost Recovery Course (SC6050)

The External Code defined here determines from where to retrieve the data if a student took a course on cost recovery.

Internal Code Internal Seq Internal Group Description External Codes
COURCSTREC 1 PSIS Cost Recovery Course 01- Campus

Code 02 - College Code

Cost Recovery Program (SP5200)

The External Code defined here determines from where to retrieve the data if a student took a program on cost recovery.

Internal Code Internal Seq Internal Group Description External Codes
PROGCSTREC 1 PSIS Cost Recovery Program 01 - Campus

Code 02 - College Code

Default Mail Type (SD4090)

The External Code defined here determines from where to retrieve a student’s default email.

Internal Code Internal Seq Internal Group Description External Codes
DFLTEMAL 1 PSIS Default e- mail The GTVEMAL_CODE for the first e-mail address to be retrieved.

Delivery (SC6100 - 6180)

The External Code defined here determines from where to retrieve the data on how a course was delivered to the student.

Internal Code Internal Seq Internal Group Description External Codes
DELVRYMETH 1 PSIS Delivery Method 1 - Use STVSCHD

2 - Use STVATTN

3 - Use STVATTR

Immigration Status (SD4290)

The External Code defined here determines from where to retrieve the data on the visa type code (immigration status) of the student.

Internal Code Internal Seq Internal Group Description External Codes
IMMIGMETH 1 PSIS Immigration status 1- Citizenship

2 - Visa Type
Note: The External Code values 1 and 2 are used for internal purposes only. Do not use 1 or 2 as a PSIS code.

Non Program Code

The External Code defined here defines a value for the Program field in the cases where institutions do not handle programs.

Internal Code Internal Seq Internal Group Description External Codes
NONPROGRAM 1 PSIS Non-program The institution code from SMAPRLE that represents a PSIS non-program (for example, NONPRGM).

Previous Country (SD3000)

The External Code defined here determines from where to retrieve the data to identify a student’s previous country.

Internal Code Internal Seq Internal Group Description External Codes
PREVCNTRY 1 PSIS Previous Country The address type value (SPRADDR_ATYP_CODE) field that identifies the previous address.

The External Code defined here determines from where to retrieve the data for a program’s end date and end status.

Internal Code Internal Seq Internal Group Description External Codes

The External Code defined here determines from where to retrieve the data to identify a student’s current address.

Internal Code Internal Seq Internal Group Description External Codes
SDCUADDR 1 PSIS Current Address The address type value (SPRADDR_ATYP_CODE) field that identifies the student’s current address.

Student ID Type (SD4010)

2 - Provincial student identification number
