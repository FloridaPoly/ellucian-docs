Release 9.3.29 and 8.3

The Banner XIGN 9.3.29 and 8.3 release documentation contains all content that supports the most recent major release.

Changed Objects

List of page changes available for this release.

Changed Objects What is the change?
GKKXIMP spec Added new global variables for the UCAS XML LINK to work through Data Connect.
GKKXIMP body Updates to use the new parameter mduu-ucas-xml-Interface , introduced in UCAS 8.22 (code/dml) for the UCAS XML LINK to work through DATA CONNECT.

Changed Objects

List of page changes available for this release.

Changed Objects What is the change?
GKVXPRO
The page defaults to a read-only state, prohibiting insertions, updates, and deletions. However, it can be configured for read-write access through a parameter available in the gurocfg table introduced in the General 8.18 release.
  • To enable insertions, updates, and deletions on the page, users must manually execute the script gurocfgi_081800.sql in the database. After the successful execution, the page will permit these actions.
  • The gurocfg_value value can be made True or False from GUACONF for this setting, APP ID ='BAN_GEN' and name ='mduu-xign-read-write' after the script is run manually.
  • The default value script is True.
  • The value True means allow insert, update, delete in the MDUU and XIGN pages.
GKAXPRO
The page defaults to a read-only state, prohibiting insertions, updates, and deletions. However, it can be configured for read-write access through a parameter available in the gurocfg table introduced in the General 8.18 release.
  • To enable insertions, updates, and deletions on the page, users must manually execute the script script gurocfgi_081800.sql in the database. After the successful execution, the page will permit these actions.
  • The gurocfg_value value can be made True or False from GUACONF for this setting, APP ID =BAN_GEN and name ='mduu-xign-read-write after the script is run manually.
  • The default value script is True.
  • The value True means allow insert, update, delete in the MDUU and XIGN pages.

Global database consolidation

This release includes updates to consolidate Banner database objects for regional localizations into a single global database.

See the Banner General 9.3.26 and 8.16 Release Notes for more detailed information, including a list of tables and scripts.

See KB000502796 - Global Database Project Customer Communication and FAQ in the Ellucian Customer Center for additional details about the global database impact and benefits.

This enhancement addresses PR00036090 in the Ellucian Customer Center.
