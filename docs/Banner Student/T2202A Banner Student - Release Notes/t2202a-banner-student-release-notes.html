Release 8.26

The Banner T2202A 8.26 releases includes regulatory updates for 2025.

T2202A Canadian tax updates for tax year 2025

Ellucian resolved a schema validation issue in the Relevé 8 Process (SVRRELX) that prevented generated XML files from passing Revenu Québec schema validation. The process was incorrectly including language-related XML tags that are prohibited in the 2025.1 RL8 schema specification, causing validation failures when institutions attempted to submit tax reporting files to Revenu Québec.

Ellucian updated the SVRRELX process to align with Revenu Québec 2025.1 schema requirements. The corrected process:

  • Excludes all language-related tags (Langue and CourrielLangue) from generated RL8 XML output.
  • Generates XML files that pass validation against the official Revenu Québec RL-8 XSD schema.
  • Complies with Guide SW-308-V specifications for the 2025.1 schema version.
  • Eliminates the need for manual XML file editing before submission to Revenu Québec.
  • Maintains all required RL8 data elements while removing only the prohibited language designations.

This correction specifically affects the SVRRELX process for RL8 generation. The T2202 processing and other Canadian tax form generation processes are not affected by this change. Institutions using SVRRELX for RL8 reporting should verify that generated XML files now validate successfully before filing with Revenu Québec.

This defect addresses PD0031414 in the Ellucian Customer Center.

Release 8.25.1

The Banner T2202A 8.25.1 releases includes an enhancement.

Note: The Banner T2202A processing script is the T2202A Calculation Q.M.-TTC (SVPTAXC) process, and it generates the T2202A forms that includes the institution’s Authorization Number. The t2202a_admin_web.sql script is used for menu setup, but the SVPTAXC process handles the main calculation and form generation.

T2202A Canadian tax updates for tax year 2025

Ellucian is delivering annual Banner Student T2202A Canadian regulatory updates that keep the Banner Self-Service 9 PDF/XSL templates and user interface (UI) in compliance.

Ellucian is updating the XSL template that is used to render the T2202A PDF so that the correct tax year (for example, 2025) displays on the printed form.

These enhancements keep the Banner Self-Service 9 PDF/HTML generation and display of the T2202A form synchronized with Canada Revenue Agency (CRA) or MRQ (Quebec) tax authority rules and annual form changes.

These changes include year or layout updates and any required text, format, or defect corrections.

This XSL file is stored in the Report Format (SVRTFMT) table.

This enhancement addresses PE0007570 in the Ellucian Customer Center.

Releases 9.3.40 and 8.25

The Banner T2202A 9.3.40 and 8.25 releases include enhancements.

Note: The Banner T2202A processing script is the T2202A Calculation Q.M.-TTC (SVPTAXC) process, and it generates the T2202A forms that includes the institution’s Authorization Number. The t2202a_admin_web.sql script is used for menu setup, but the SVPTAXC process handles the main calculation and form generation.

T2202A regulatory updates

Ellucian is delivering seed data for year-end regulatory updates and defect corrections. These regulatory changes apply to 2025 year-end T2202A and Releve 8 (RL-8). You must administer these updates to support 2025 T2202A and RL-8 changes and certifications.

  1. The student first name field (GivenName) is now optional.
  2. The post-secondary educational institution postal code field (PostalZipCode) is now optional.
Additionally:
  • There are changes to the T2202A XML format.
  • The PDF is updated to reflect the 2025 tax year.
  • The RL-8 certification number is updated. For details, see PE0007348 below.

This 9.3.40 enhancement addresses PE0007231 in the Ellucian Customer Center.

T2202A page updates

The T2202A XML Transmission Information Control (SVAXLTM) page and T2202 XML File Generation (SVRTXML) process no longer require an institutional postal code (PostalZipCode) or student first name (StudentFirstName). These fields are now optional to accommodate regulatory updates for the 2025 tax reporting year. The SVAXLTM page now accepts a value or allows the value to be null.

This 9.3.40 enhancement addresses PE0007232 in the Ellucian Customer Center.

T2202A Relevé script updates

The Relevé 8 (RL-8) script is updated to the include 2025 certification number. This regulatory enhancement accommodates the Québec requirement that partners obtain a certification number each year to be printed on the Relevé 8 form. The certification number will be included on the form per Québec requirements.

Additionally, the SVRAUTH_REL8_XML_CERT_NUM database field is updated with the 2025 certification number provided by Revenue Québec.

This 8.25 enhancement addresses PE0007348 in the Ellucian Customer Center.

Release 8.23

These release notes describe new features, enhancements, and updates in Banner T2202A.

Banner 9 menu migration

With the end of life for Banner 8 in September 2025, Ellucian is transitioning from the Banner Web Tailor TW% tables to the new GU% tables. The Banner Extensibility application has delivered seed data to migrate all of the Baseline records from Banner Web Tailor TW% tables to the new GU% tables.

You must migrate the existing local records from the TW% tables manually. Ellucian recommends using the GUAWMNU and GUAWROL administrative pages.

The seed data for Ellucian-supported languages is also delivered for the Baseline menu items.

See the Banner General admin page content for more details about menu settings and customization using the Banner administrative pages, GUAWMNU and GUAWROL.

Insert statement for SVRAUTH updated

Ellucian updated the insert statement for adding the appropriate certification from Revenue Québec for the 2024 Rl-8 when using the Relevé 8 Authorization and Certification Number Control (SVRAUTH) table.

You cannot submit data to the Canada Revenue Agency (CRA) unless you manually make this change.

The correct statement for RL-8 for 2024 is:


update svrauth
set svrauth_rel8_xml_cert_num = 'RQ-24-08-025', svrauth_software_vers = '8.22.0.1', svrauth_xml_schema_vers = '<Transmission VersionSchema="2024.2" xmlns="http://www.mrq.gouv.qc.ca/T5">', svrauth_activity_date = sysdate
where svrauth_txyr = '2024';
commit;
