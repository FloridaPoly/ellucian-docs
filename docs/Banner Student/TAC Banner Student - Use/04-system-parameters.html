System Parameters

This table provides a list of system parameters available on the Report System Parameters (SKARSYS) page.

Parameter Name Default Value Description
VTAC_SELECT_BASIS_REF Selection Basis This parameter is used by TAC to correctly populate the Reference Qualifier in SARPRFN when the student in a VTAC file has a Basis of Selection value.
UAC_UMAT_ID UMAT This parameter is used by TAC to correctly populate the Reference Qualifier in SARPRFN when the student in a UAC file has a UMAT ID.
DEFAULT_ADMIT_​INTAKE D When program offering rules on SKAPOFR are copied from one academic year to another, then the default admit intake value is used to populate the Intake field when a valid term code cannot be determined.
DEFER-OFFER-DECISION UPDATEME Used to record the decision code that indicates that the student has deferred their offer. It is used in TAC reconciliation processing.
DMC D8 Date format setting for correctly writing dates of birth to the SARPERS table.
EMERG_CONTACT_RELATION_CODE E Used by the TAC load process to correctly populate electronic admissions with the relation qualifier code for an applicant's emergency contact. The code is then mapped in the EDI Cross-Reference Rules (SOAXREF) page for the Cross-reference Label (STVRELT). When the baseline Match, Load, and Verify Process (SARETMT) page is run, the EMERG_CONTACT_RELATION_CODE parameter is correctly mapped to a baseline relative code and loaded into the Guardian Information (SOAFOLK) page.
EMPLOYER_RELATION_CODE W Used by the TAC load process to correctly populate electronic admissions with the relation qualifier code for an applicant's employer contact. The code is then mapped in the SOAXREF for the STVRELT label. When the baseline SARETMT page is run, the EMPLOYER_RELATION_CODE parameter is correctly mapped to a baseline relative code and loaded into the Guardian Information (SOAFOLK) page.
FEE_HELP_LIMIT_MEDICAL 106328 Sets the fee help limit for medical courses, used in determining fee help usage reported by TACs.
FEE_HELP_LIMIT_STANDARD 85062.00 Sets the ordinary fee help limit, used in determining fee help usage reported by TACs.
NEXT_OF_KIN_RELATION_CODE K Used by the TAC load process to correctly populate electronic admissions with the relation qualifier code for an applicant's next of kin contact. The code is then mapped in the SOAXREF for STVRELT. When the baseline SARETMT page is run, the NEXT_OF_KIN_RELATION_CODE parameter is correctly mapped to a baseline relative code and loaded into SOAFOLK.
OFFER_DECISION   Used to indicate the offer decision code that should be inserted into the Application Decision (STVAPDC) table when running any of the TAC post load processes.
PROXY_RELATION_CODE Y This parameter is used by the TAC load process to correctly populate Electronic Admissions with the Relation Qualifier code for an applicant's Proxy Relationship. The code is then mapped in the EDI Cross-Reference Rules form (SOAXREF) for the Crossreference Label STVRELT. When the baseline Match, Load and Verify (SARETMT) process is run the PROXY_RELATION_CODE is correctly mapped to a baseline Relative code and loaded into the Guardian Information (SOAFOLK) page.
SATAC_ADMIT_BASIS_REF BASIS OF ADMISSION Used by the TAC load process to correctly populate electronic admissions with the Basis of Admission values for each person's application. The codes are then mapped in SOAXREF for the Cross-reference Label (RFNOQLFR) and the Electronic Admissions Person References table is populated with records for the basis of admission code, the basis of admission note and the Preference Course Rank Set (PCRS) basis of admission code for each separate course application.
SATAC_ALT_TELE MA Used by the TAC load process to correctly populate electronic admissions with the Phone Qualifier code for an applicant's Alternate phone number. The code is then mapped in SOAXREF for the STVTELE label. When the baseline SARETMT page is run, the SATAC_ALT_TELE parameter is correctly mapped to a baseline telephone type code and loaded into the baseline telephone details Table (SPRTELE).
SATAC_BRAIN_DISAB BRAIN Used by the TAC load process to correctly populate electronic admissions with the medical condition code when an applicant indicates a Brain disability. The code is then mapped in SOAXREF for STVMEDI label. When the baseline SARETMT page is run, the SATAC_BRAIN_DISAB parameter is correctly mapped to a baseline medical code and loaded into the baseline Medical Details (SPRMEDI) table.
SATAC_CAS_REF COURSE ALLOCATABILITY STATUS Used by the TAC load process to correctly populate electronic admissions with the course allocatability status and reason for each person's application. The codes are then mapped in SOAXREF for the RFNOQLFR label and the Electronic Admissions Person References table is populated with records for the Course Allocatability Status (CAS) and reason for each separate course application. The CAS reason will be truncated to 80 characters to fit into the field. The original CAS reason value will remain in the TAC load staging table.
