Release 9.3.41 and 8.3

The Banner PROGCAT 9.3.41 and 8.3 release delivers WCAG label changes and language translation defect fix.

WCAG Label changes

To enhance accessibility and ensure compliance with WCAG guidelines, Ellucian has added missing labels to the SKAAREO and SKACRSO pages. These updates improve screen‑reader compatibility and overall usability for assistive technologies. There is no change in functionality.

This defect satisfies PD0030042 in the Ellucian Customer Center.

Language translation fix

progcat_gubobjs.properties resources DML was modified to correct the GUBOBJS_DESC for *PROGCAT key text.

This defect satisfies PD0030161 in the Ellucian Customer Center.

Release 8.2

The Banner PROGCAT 8.2 release provides global database updates and defect corrections.

Global database changes

PROGCAT objects were modified to support the implementation of Ellucian's Global Database initiative.

This enhancement addresses PE0003323 in the Ellucian Customer Center.

Table 1. Changed packages
Package Change
skkdtre Corrected the PR_INSERT_SKBPROT procedure to fix the compilation errors.
skkpfee Updated Copyright and AUDIT TRAIL. No functional or code changes.
skkprot Updated the package to follow Banner code standards. No functional or code changes.
skkptre Updated Copyright and AUDIT TRAIL. No functional or code changes.
Note: All of the PROGCAT objects are redelivered with this version of PROGCAT. This allows a single install for all new PROGCAT installations. Existing clients are not impacted by this because the seed data will not be executed if it already exists in the database.

build.properties and translation files updated

  • Added missing properties from PROGCAT 8.0.1.2 in the build.properties file.
  • PROGCAT translation files were updated to follow Banner standards.

This enhancement addresses PE0002831 in the Ellucian Customer Center.

Enhancements

Registration enhancements

Enhancements to set up your registration.

The registration enhancements are as follows:
  • The SOATERM web settings and web controls are enhanced. The system now considers SOATERM web controls (Catalog Search Control/Display Long Course Title) to determine whether the SCACRSE course title or the SCASYLB long course title display in PROGCAT. (IDEA-20880, CR-000183142)
  • The long title from SMAPROG is enhanced. The Program Description in program details page/program description section shows the program text that is added with Print value REQS and LONG, respectively. (CR-000165401)
  • The Provided Area Edit Supplemental Data Access icon is enhanced. The Edit Supplemental Data icon is added next to the Areas in the Programme Details/Program Structure section. (IDEA-21184, CR-000183143)
