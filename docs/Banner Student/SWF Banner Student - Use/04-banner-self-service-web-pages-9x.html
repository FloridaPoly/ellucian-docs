Banner Self-Service Web Pages (9x)

This section explains the procedures and Self Service web pages used in the Banner Standard Workload Form (SWF).

Access SWFs as a faculty member

Provides a step-by-step procedure for a faculty member to view or print their own Standard Workload Forms (SWFs) of a selected SWF term.

Procedure

  1. Access Banner Self-Service.
  2. From the main menu, click Faculty Services.
  3. On the Standard Workload Forms page (bwvkswff.P_ChooseSwf), select the SWF term code that you want to view.
  4. Click View SWF.

View SWF

Provides a step-by-step procedure to view a selected SWF if you are a faculty member and also an administrator. Only users who have been designated as SWF administrators, deans, and associate deans, can perform this procedure.

Procedure

  1. Access Banner Self-Service.
  2. From the main menu, click Faculty Services.
  3. From the Faculty Services menu, click Standard Workload Forms.
  4. In the Standard Workload Forms page (bwvkxswf.P_SelectAdminOption), click No if you do not act as an administrator.
  5. Click Submit.
  6. In the Standard Workload Forms page (bwvkswff.P_ChooseReport), select the term code for which you want to view the SWF from the drop-down list.
  7. Click Continue.
  8. In the Standard Workload Forms (SWF) page (bwvkswff.P_ChooseSwf), select the SWF that you want to view from the drop-down list.
  9. Click View SWF.

Print multiple SWFs and timetables

Use the following procedure to print multiple SWFs.

Procedure

  1. Access Banner Self-Service.
  2. From the main menu, click Faculty Services.
  3. From the Faculty Services menu, click Standard Workload Forms.
  4. In the Standard Workload Forms page (bwvkxswf.P_SelectAdminOption), click Yes if you are an administrator.
  5. Click Submit.
  6. In the Standard Workload Forms page (bwvkxswf.P_FilterSWF), select the SWF term code report that you want to execute and print.
  7. In the # of Records on a Page field, enter the number of records that you want to view and print and click Execute Query.
  8. In the Standard Workload Forms page (bwvkxswf.P_MultipleSWF), select one or more SWF reports that you want to print.
  9. To select all the displayed SWF records for viewing or printing, click Select All.
  10. Click Print Multiple SWF to display all SWFs.
  11. Use the print function of the browser to print preview the SWFs.
  12. Adjust the page margins and use the landscape orientation to maximize the printing area.
  13. Close the Print preview window.
  14. Click Back in your browser.
  15. Click Print Multiple Timetable to display all selected SWF timetables.
  16. Use the Print option in your browser to print the timetables.

Standard Workload Forms (bwvkxswf.P_SelectAdminOption)

This page allows you to log into the SWF Self-Service Web pages either as an administrator, dean, an associate dean, or as an individual faculty member. Administrators, deans and associate deans have an administrator's role that has the privilege to access to their responsible faculty members’ SWFs.

Standard Workload Forms (bwvkxswf.P_FilterSWF)

With an administrator role, this page allows you to search SWF records with the following searching options.

Standard Workload Forms (bwvkxswf.P_MultipleSWF)

This page allows you to execute SWF records for a particular term. You can also print multiple SWF records.

Standard Workload Form (SWF) (bwvkswff.P_DispSwfSlip)

This page allows you to view the SWF record.

Standard Workload Forms (bwvkswff.P_ChooseReport)

This page allows you to choose a SWF report.

Standard Workload Form (SWF) page (bwvkswff.P_ChooseSwf)

This page allows you to view the selected SWF record.

SWF Course Timetable (bwvkswff.P_DispSwf)

This page allows you to view the selected SWF course timetable.

Note: Faculty members cannot view this page if the View Timetable option is turned off.
