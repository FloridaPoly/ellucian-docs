Seed Data

Seed data is used by administrators who will be using the Banner Mass Data Update Utility (MDUU) to change the status of SWFs of all faculty members and to generate the annual CAAT Full-Time Academic SWF Data Collection report files.

There is another set of seed data used for controlling SWF display on the Faculty and Advisor Self-Service. See the Banner Mass Data Update Utility Handbook for more information about MDUU.

Business Rule Process Code seed data

The following table lists the business rule process codes and the rules that are delivered as seed data.

Business Rule Process Code Rules Description
SWF_DATA_EXTRACT Extracts the reporting data for the annual CBIS reporting. All related seed data is delivered for installation.
SWF_DATA_LOAD Imports the third-party data of faculty member and course information that is not in the Banner Student system.
SWF_STATUS_CHANGE Changes all faculty members' SWF status from Signed or Finalized to Completed by the institutional SWF administrator.

SWF Report Data Mapping Rules (SVRDMAP) seed data

These seed records are sample rules for various settings.

For example: The Banner value 'Y' for the “W” report code of the “OT” report code group sets the default Active SWF overtime indicator to be the Total Workload Overtime Hours in the Signature Detail window of SVAFSWF page. With this rule, only the total workload overtime hours are considered in a SWF.
Note: Only the first record is taken as the option for relevant processes.
