SWF Pages in Faculty Self-Service (9x)

Banner Faculty Self-Service 9x includes pages that allow Canadian users to view faculty members' Standard Workload Forms (SWF).

Users can access the SWF 9x pages from the menu icon on the Faculty Services application landing page.

In addition to setting up access for a SWF administrator as described in Set up SWF security, a WebTailor administrator must assign them the new Standard Workload Form Administrator user role.
