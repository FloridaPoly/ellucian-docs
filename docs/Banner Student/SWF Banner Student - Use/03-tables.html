Tables

Describes the various tables in SWF.

Non-Banner Course Information table (SIRSWFC)

Stores third party course data for use in SWF processing.

Non-Banner Faculty Information table (SIRSWFF)

Stores third party faculty member data for use in SWF processing.

SWF Assigned Complementary Hours Table (SVRASHR)

Stores the complimentary hours of each SWF.

SWF Course Section Workload Type Distribution Rules Table (SVRCWTD)

Used to set up the distribution (percentages) rules of preparation and evaluation feedback types for a course section.

SWF Course Wise Meeting Time and Campus Table (SVRFMET)

Stores the meeting information course wise.

Generated SWF Base Table (SVRGWFB)

Stores the generated SWF base information such as SWF period dates, status and signing indicators, and dates.

Generated SWF Detail Table (SVRGWFD)

Stores the course wise information to generate SWF details.

SWF Security Access Control Table (SVRSACC)

Stores the SWF administrators' system access assignments.

The access assignments control administrative users access to SWF records through either Banner SWF admin pages or Faculty and Advisor Self-Service.

Faculty Member SWF Linked Course Assignment Table (SVRSASG)

Stores a faculty member's multiple course assignments that are linked to the Banner SWF course.

The linked course assignments are also used to recalculate class size or teaching contact hours on the SWF.

SWF Errors and Warnings Table (SVRSERR)

Stores some of store error and warning messages that are generated from processes initiated within the Faculty Standard Workload Form (SVAFSWF).

SWF Faculty Information Table (SVRSFAC)

TStores some of faculty member information that is used in SWF generation purpose. The records are effective by term code.

Faculty Standard Workload Form Base Table (SVRSWFB)

Used to set up faculty members in the Banner SWF base information and complimentary activities for the purpose of generating SWFs.

Faculty Standard Workload Form Detail Table (SVRSWFD)

Used to set up faculty members’ Banner SWF course information for the purpose of generating SWFs.

Generated SWF Complementary Hours Table (SVRWFCH)

Stores the complementary hours information on generated SWF.

SWF Workload Type Factor Rules Table (SVRWTYP)

Stores SWF workload type factor rules based on the collective agreement.

SWF Reporting Code Group Table (SVVRDAT)

Stores the codes defined by Collective Bargaining Information Services (CBIS) and some Banner SWF rules.

SWF Workload Category Validation Table (SVVWCAT)

Stores the SWF workload category validation data. This data supports the Workload Category Validation (SVVWCAT) page.

SWF Workload Type Validation Table (SVVWTYP)

Stores validation records for a number of SWF workload types.
