Ellucian Ethos Data Access release notes

These release notes describe enhancements, new features, and updates in Data Access releases.

Release June 10, 2026

This release of Data Access includes maintenance updates and defect resolutions.

Function impacts

The following functions are impacted:
  • The Data Access environment will be unavailable and loads cannot be run during the maintenance window.
  • Change notification processing will be delayed until after the maintenance window.

Ellucian has resolved an issue where GraphQL queries filtering on person credentials to return a person that satisfies the filter criteria did not return all credentials for that person. This issue is now resolved, consistent with the EEDM API behavior. For details, see PD0034276 in the Ellucian Customer Center.

For information about this release, see the release page for DA June 2026 4.45.0 release, PR00043683, in the Ellucian Customer Center.

Release August 13 2025

The August 13, 2025 release of Data Access includes technical currency maintenance updates.

Preview date: Aug 7, 2025

Production date: Aug 13, 2025

This addresses Product Defect PD0023138 in the Ellucian Customer Center where a 30-minute timeout occurred, even when users were actively working during that period.

The following functions are impacted:
  • The Data Access environment will be unavailable and loads cannot be run during the maintenance window.
  • Change notification processing will be delayed until after the maintenance window.
  • Experience users using the Housing Card, Person Manager, Apply, and any integrations using GraphQL queries may be impacted for two to three minutes during the upgrade window times.

Refer to PR00041642 DA Aug 2025 4.38.0 Release in the Ellucian Customer Center.

Release June 18 2025
