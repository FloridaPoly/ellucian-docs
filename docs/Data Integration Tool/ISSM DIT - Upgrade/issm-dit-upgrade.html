Upgrade ISSM Data Integration Tool

Before upgrading, confirm you have all required software installed on the ISSM Data Integration Tool server, which is also the ISSM server.

See ISSM Data Integration Tool server requirements in the Getting Started content. for more information. After verifying you may download the installer from the Ellucian Customer Center website and begin installation.

Note: Uninstall older versions of ODAC before installing the new version. Ensure to install ODAC 12.2c R1 on Windows Server 2016 before upgrading to DIT 2.0.6. The minimum version of DIT required for an upgrade is DIT 2.0.4.
Note: The process of upgrading from one version of the Data Integration Tool to another is essentially the same as the initial installation process.

The upgrade steps follow a base Data Integration Tool installation. You can modify them based on specific configuration modifications you make to the ISSM and the Data Integration Tool application. Review these steps before upgrading the Data Integration Tool application.

If you are installing the ISSM Data Integration Tool for the first time (not upgrading), see Install content.

Download ISSM DIT for upgrade

You need to have an account on the Ellucian Customer Center.

About this task

You can register for a Ellucian Customer Center account at: https://clientapps.ellucian.com/SignUp.

Steps to download DIT 2.0.6 from the Ellucian Customer Center:

Procedure

  1. Log in to the Ellucian Customer Center.
  2. Go to Resources > Downloads.
  3. Select Find a Download > Search Downloads.
  4. Install International Scholar Dossier, starting with the department portion of the application.
  5. In the Search For field, type ISSMDataIntegrationTool206.zip.
  6. In the Show Results for field, select Files.
  7. Click Search.
  8. In the File Name column, select ISSMDataIntegrationTool206.zip to download.
  9. Transfer the zip file to the DIT Web server, and extract the files to a temporary directory.
    You can download the ISSMDataIntegrationTool206.zip file through an alternate method from the Ellucian Download Center.

Verify the existing ISSM and ISSM DIT Installation

Confirm that the current ISSM and ISSM Data Integration Tool applications are running properly.

About this task

This step is especially important if you are installing this tool on a test system that has not been used recently.

Procedure

  1. Log onto the ISSM server.
  2. Verify that all prerequisite software is installed.
  3. Open a Web browser and confirm that ISSM is working by starting up the application.
  4. Because you are upgrading an existing version of the ISSM Data Integration Tool, run this tool to confirm that it is running.

Install the ISSM DIT application files for upgrade

Install the ISSM Data Integration Tool application files for upgrade.

About this task

Perform the following steps to install the files on the ISSM server.

Procedure

  1. Stop IIS. Open command prompt and enter iisreset/stop.
  2. Back up the \fsaATLAS\DataIntegrationTool directory and the fsaATLAS database.
  3. Open Windows Explorer and navigate to setup.exe that you extracted from the ISSMDataIntegrationTool206.zip file.
    Note: Before you begin the upgrade: Make a complete and current backup of the fsaATLAS\DataIntegrationTool folder and sub-directories on the ISSM server. Ensure that all users have logged out of ISSM and that they will not attempt to reconnect to the application during the entire upgrade process.
  4. Right click setup.exe and select Run as Administrator.
  5. Click Next.
    On the License Agreement review the license agreement in the text box, choose the I accept option.
  6. Click Next.
    On the Customer Information window enter your user name and organization. There is an Install this application for: option. By default this is set to Anyone who uses this computer (all users). Do not change this setting unless you are directed to do so by customer support.
  7. Click Next.

    The default and recommended destination folder for this tool is fsaATLAS\DataIntegrationTool. Click Change to select a different installation directory.

    Note: If you are changing the installation directory, make sure not to select another directory within the installation directory. For example: If your current installation directory is C:\fsaATLAS\DataIntegrationTool, then the new directory must not be within C:\fsaATLAS\DataIntegrationTool.
  8. Click Next.

    On the Database Server enter the following information for the database:

    Database server name
    Server Name that will host the fsaATLAS database. This name should include the entire server name.
    Database Login ID
    SQL Login ID that has the privilege to install a new database on the server above.
    Database Password
    SQL Password for the user above.
  9. Click Next to install the application to the indicated directory.
  10. On the Ready to Install the Program window check the settings you have made and if they are correct click Install.
    If a setting is incorrect, click Back to return to the appropriate window and change the information.
  11. Click Finish when the installation of the files is complete.
  12. Start IIS. Open command prompt and enter iisreset/start.

Restore the ISSM DIT configuration and log files

You must restore the Data Integration Tool configuration and log files on the ISSM Server where DIT 2.0.6 is installed.

Procedure

  1. Move the backup of the fsaATLAS\DataIntegrationTool directory to the ISSM Server where DIT 2.0.6 is installed.
  2. Copy the following files to the fsaATLAS\DataIntegrationTool\XML directory:
    • IntegrationConfig.xml
    • CommonSettings.config
  3. Copy the Error.log file to the fsaATLAS\DataIntegrationTool\LogFiles directory.
    Note: If your source data only comes from an XML file, proceed to Update SMTP settings in the Install content. You do not have to follow the steps in Edit tnsnames.ora (Banner connections only) in the Install content.

Edit tnsnames.ora (Banner connections only)

The SQL*Net tnsnames.ora configuration file, which is distributed with ODP.NET, must have the correct information to connect to the Banner database, and be in the correct location on the ISSM Data Integration Tool server.

Procedure

  1. Navigate to the \oracledirectory\network\ADMIN directory, where oracledirectory is the directory that contains the Oracle files (for example, OraHome_1) and confirm that the tnsnames.ora file is located here:
    If the file is in the one of the directories listed above, continue to step 4 in these steps (editing the file). If the file is not in this location, continue to the next item.
  2. Navigate to the default location of the tnsnames.ora file. By default, this location is \oracledirectory\network\ADMIN\SAMPLE.
  3. Copy the tnsnames.ora file and place it in \oracledirectory\network\ADMIN directory.
  4. Edit this file with an editor and enter the connection string and any other information necessary for connecting with the Banner Server instance.
  5. Save and close the file.

Update SMTP settings

A new feature in v1.1 Hotfix 1 sends an e-mail notification of data processing results to the registered e-mail address.

About this task

You must configure the feature to be fully functional.

Procedure

  1. Navigate to [CurrentInstallDrive]:\fsaATLAS\DataIntegrationTool folder, open both fsaATLASDataIntegrationTool.exe.config and ExtractRunner.exe.config files.
  2. Look for the following SMTP information section: 
    <smtp from="">
<network host="smtp.server.com" password="" port="25" userName="" />
</smtp>
  3. Update the SMTP information section above with your institution SMTP server information.
  4. If your institution SMTP server requires SSL connection, please update the following setting to true in both files mentioned above: 
    <appSettings file="xml\commonsettings.config">
<add key="IsSSLEnabledForEmail" value="false" />
</appSettings>

    For additional information about this feature, see Work with configurations based on a Banner Database in the Config content.

Start ISSM DIT

You can now use ISSM Data Integration Tool.

From the ISSM Data Integration Tool server (or from a remote connection), select Start > Programs > ISSM Data Integration Tool (Group) > ISSM Data Integration Tool. You can also navigate to the ISSM Data Integration Tool directory (for example,\fsaATLAS\DataIntegrationTool) and run fsaATLASDataIntegrationTool.exe.

You can now begin using the ISSM Data Integration Tool to access your source data.

If you do not upgrade Oracle Database Access Component to ODAC 12.2c R1 or ODAC 12c R4, an unhandled exception error displays, and DIT will not work.

Warning: Running the DIT setup.exe again after the successful installation will leave the DIT application in an unstable state.

To avoid the Character length of Foreign Address Line 1 is longer than 60 error message you must open the configuration and save it again after the successful upgrade.

Note: If you perform a migration of the system, you must login to DIT and reschedule all the configurations again on the ISSM Data Integration Tool - Task Scheduler window.
