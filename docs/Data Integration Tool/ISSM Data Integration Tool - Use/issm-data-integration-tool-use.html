Data Integration Tool

Information to use the ISSM Data Integration Tool (DIT).

ISSM Data Integration Tool implementation includes installing and configuring DIT to work with ISSM and Banner 8.x and Banner 9.x (for Banner integration). Successful, quick deployment of this tool requires IT personnel, a Banner/Oracle DBA expert, and the ISSM advising staff to work together on configuration, user setup, and data migration policies. After the set up, a scheduled task runs and creates an XML file that is compatible with the ISSM Campus DataLink System. This data is then available in the DataLink Manager to import into ISSM.

When the application is running in a production environment, day-to-day server administration is generally no longer required.

Use the Data Integration Tool

Any connection information you store in the ISSM Data Integration Tool, which includes the Banner instance name, username, and password, you must encrypt it to be hidden outside of the tool.

Security and Permissions

All information relative to connecting to a Banner Oracle database is encrypted at the ISSM Data Integration Tool server level.

Therefore, any connection information you store in the ISSM Data Integration Tool, which includes the Banner instance name, username, and password, you must encrypt it to be hidden outside of the tool.

Define User Permissions

Define user permissions through ISSM. Only users with the rights to modify Campus DataLink files can use the ISSM Data Integration Tool.

About this task

A user who does not have the appropriate permissions cannot log in to the tool. If you are getting an Invalid Username or Password message, check with the ISSM Administrator to confirm whether you have the Configure Campus Data Link permission.

Procedure

  1. Open ISSM.
  2. Go to Enterprise Manager > Configure User Permissions & Roles.
  3. Locate the user and click Edit Info in the Edit Permissions column.
  4. In the Permissions for username (where username is the name of the user), make sure to select the Configure Campus Data Link check box.
  5. Save the user information.

Start up the ISSM Data Integration Tool

Starting the ISSM Data Integration Tool.

Procedure

  1. Open the ISSM Data Integration Tool. There are two ways that you can open this tool:
    • Select Start > All Programs > ISSM Data Integration Tool.
    • Select the ISSM Data Integration Tool shortcut located on the desktop.
  2. Type the username and password. This is the same login name and password that you use in ISSM.
  3. Click Login to continue into the application.

Results

This username must have the rights to edit Campus DataLink files.

Configure the ISSM Data Integration Tool

You must configure information on the various configuration tabs.

Procedure

  1. Click Add New Configuration.
  2. Enter the configuration information.
    • If the source type is an XML type, enter the name of the configuration, element information, and the XML and XSD file locations.
    • If the source type is Banner type, enter the configuration name and the connection information and click Connect to connect with the Banner database.
  3. Fill in all of the necessary fields in each of the configuration's tabs.
  4. Save the configuration.
  5. From the Main Menu, click the configuration's schedule icon to schedule the task to run.
  6. Fill in the appropriate schedule information and run the scheduled task.
    Note: Review the information concerning how to save the information during the XML file creation.
    This creates a Campus DataLink-compatible XML file, invokes the DataLink process, and pushes the data in to ISSM.
  7. After you finish running and creating the Campus Datalink, start up ISSM.
  8. Go to Campus DataLink > View Students (to view student data), or Campus DataLink > View EVs (to view scholar data).
    If these pages do not show any information, you may want to view any messages that may appear in the DataLink Manager. Review the Campus DataLink information in the ISSM Install content on the Ellucian Documentation site.

Main tab

The Main tab displays information about existing configurations.

A configuration contains the appropriate settings for connecting to the source data, information about how you can map the fields between the source data and ISSM. From this tab, you can also schedule when the configurations are run.

Main tab fields

Field names and their descriptions on the Main tab.

Type Description
Configuration Name Displays the configuration name. Click this link to edit the configuration.
Source Displays the source type.
Date Last Edited Displays the date and time the configuration was last edited. This field cannot be edited.
Schedule Displays when the task was scheduled.
Calendar Click this icon to schedule the task.
Next Run Date Displays the next time and date that the task runs again. If you are displaying this screen when the task is running, the date and time will be updated the next time you open the tool.
Copy Click this icon to copy the configuration.
Delete Click this icon to delete the configuration.
