Release 2.0.7

ISSM Data Integration Tool 2.0.7 release provides enhancements and defect corrections.

Enhancements

Technology certification

From DIT 2.0.7 onwards, the latest versions of the following software are supported.

Field Description
Microsoft SQL OLEDB It is mandatory to use Microsoft SQL OLEDB v19.0 driver for the ADO connections to the database for DIT 2.0.7 version.
Note: After June 2023, Ellucian will no longer test DIT on Windows Server 2016.
