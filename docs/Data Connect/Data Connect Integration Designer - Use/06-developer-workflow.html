Developer workflow

A pipeline that has already been developed in the Designer can be published so it becomes available to Integration Packages.

After it is published, a Pipeline can be viewed on the Integration Packages user interface (UI) and jobs can be created for it.

There are two ways to develop a pipeline: You can create a pipeline from scratch using the + PIPELINE button on Integration Designer or you can open an already existing pipeline and click CREATE DRAFT. Both these options create a draft pipeline that can then be edited in the Designer. The second option creates a draft copy of an already published pipeline, which can be modified per your requirements before being published.

The Quick Start provides instructions and a first pipeline example you can use as reference when developing a pipeline.

When development of a pipeline in the designer is completed and the pipeline is tested to ensure that it runs successfully, click the Publish button on the Designer to publish the pipeline. The Publish button is only enabled on the Designer when all fitting configurations on the pipeline are complete. Proceed to the publishing process section to publish a pipeline.
