Before you start

Formalize the elements of the integration strategy before creating a pipeline.

Prerequisites

Requirement Type
Confirm stakeholders have a clear understanding of both the personas and data flow. Business or Strategy
Ensure the APIs that you will use provide you with the correct information. Business or Strategy
Review the available Transformations to help estimate the amount of work.
  • What type of transformations are required?
  • Do the current transformations fulfill the requirements or are additional manual transformations required?
 Design
Determine if crosswalks are needed. Crosswalks are dictionaries that can be referenced inside the pipelines, allowing you to detach data mappings from the pipeline, and allowing each client to setup their own mappings. Strategy or Design
Register your application in Ethos Integration when using Ethos APIs. You need the provided API key to call these endpoints. Technical
Verify endpoints access, including security permissions, etc. is setup. A pipeline requires access to the appropriate data sources, for example from the files stored in an S3 bucket, to SFTP and REST calls, to APIs being correctly set up. Technical

Useful info

Pipelines can use Ethos APIs as data sources or as destinations, requiring only a valid API key. Review the OpenAPI documentation for the APIs your pipelines will use to become familiar with the data types, versions, and RESTful actions available.

You can find the available APIs in the API Catalog. The OpenAPI documentation is available for each API through the catalog.
