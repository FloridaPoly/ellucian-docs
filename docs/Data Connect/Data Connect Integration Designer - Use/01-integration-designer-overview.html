Integration Designer overview

The Integration Designer provides the ability to define data workflows in a low code way.

These workflows can:
  • Connect to disparate data sources and data formats through Ellucian Ethos.
  • Create data transformations and mappings to third-party sources and formats.
  • Build and maintain integrations through Ethos to third parties.
  • Surface third-party data in Ethos.
Benefits of developing pipelines include:
  • Low-code user interface (UI) for creating integrations.
  • Preview and validation of integrations before sharing with business users.
  • Comprehensive Integration Packages UI that operational users can manage.
  • SaaS safe integrations without an integration server.
  • Ethos native with out-of-the-box support to GET data, POST data, consume change notifications, and run GraphQL queries.
  • Out-of-the-box fittings to parse JSON, XML, and CSV or TSV sources.
  • Support for REST and SOAP calls.
  • Out-of-the-box no-code transformations like Field Mapping, Delimited Formatter or Parser, JSON Formatter or Parser, XML Formatter or Parser, Fixed Width Formatter or Parser, and SFTP Fitting.
  • Configuration-friendly integrations that operational users can customize.
  • Integration packages and pipelines that can be shared across tenants.

Low Code

A low code platform lets you create integrations through visual tools.

For example, you can drag and drop segments, and configure them through context-appropriate dialogs.

As such a platform, the Designer provides a powerful UI to create well-defined integration solutions called pipelines.

Advantages of this approach include:
  • Easy to learn: Available pipeline fittings are simple but highly configurable.
  • Configuration instead of coding: Each pipeline segment provides context-sensitive dialogs, with appropriate help tooltips.
  • Ease of development: Preview and validate integrations, then publish to your business users.
  • Thought for developer personas: Powerful JavaScript fittings for low-level transformations.
  • Portable integration packages: Share packages with clients with the push of a button.
