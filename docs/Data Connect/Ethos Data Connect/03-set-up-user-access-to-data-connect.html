Set up user access to Data Connect

Set up user access to the Data Connect Integration Designer

Users access the Data Connect Integration Designer through Ellucian Experience, from either the Application menu or the Data Connect Designer card.

Starting point User experience
Application menu The user clicks Integration Designer on the Application menu to go to a page listing all of the integration packages for which they have Designer access. The user then selects a package on that page.
Data Connect Designer card In the card, the user sees a list of all of the integration packages for which they have Designer access. The user can click any integration package to go directly to that package, or click View all results to go to a page listing all of their packages.

To enable a user to access the Integration Designer through both the Application menu and the card, you must grant that user access to both the Integration Designer (in Experience Setup permissions) and the Data Connect Designer card (in Experience Configuration).

If you want to enable access only through the Application menu, rather than supporting both access options, you only need to configure the permissions in Experience Setup. You can skip the card setup.

Set up roles and users for the Integration Designer

To enable users to develop integrations using the Data Connect Integration Designer, you must first set up the users and roles that need access.

About this task

For a user to access the Data Connect Integration Designer, that user must have the following:
  • Access to the Integration Designer. You grant that access by assigning permissions to roles or individual users in the Permissions area of Experience Setup.
  • Access to the Data Connect Designer card (required only if you want users to be able to access the Integration Designer from the card in addition to the Application menu). You grant card access by assigning roles to the Experience card in the Card Management area of Ellucian Experience.

For a description of the user access options (Application menu or card), see Set up user access to the Data Connect Integration Designer.

Procedure

  1. Identify all of the people at your institution who need access to the Data Connect Integration Designer.
  2. Decide whether you want to grant Integration Designer permissions to individual users, or grant permissions to roles and then assign those roles to individual users.
  3. Set up the roles that you need for both card access and Integration Designer permissions, and add those roles in Experience Setup.
    See Set up roles for Ellucian Experience.
  4. In Experience Setup, add the individual users to whom you want to grant Integration Designer permissions.
    See Add administrative users.

Set up the Data Connect Designer card in Experience

If you set up the Data Connect Designer card in Ellucian Experience, users can access the Data Connect Integration Designer through the card.

Before you begin

Before setting up the card, you need to set up the roles that you want to have access to the card. See Set up roles and users for the Integration Designer.

About this task

As described in Set up user access to the Data Connect Integration Designer, Data Connect supports two options for accessing the Integration Designer through Ellucian Experience: from the Application menu or from the Data Connect Designer card. If you choose to support access only through the Application menu, you can skip this procedure.

Procedure

Set up the Data Connect Designer card in the card setup wizard using the general card setup procedure in Set up an Experience card, with the considerations described below.
  1. When selecting the card in the Card Management table, edit the card with Data Connect Designer in the Card Type column.
  2. Complete the Details section of the card setup page as described in Set up an Experience card.
  3. In the Roles step of the card setup wizard, select the roles that you set up for access to the Data Connect Designer card.

Grant permissions for the Integration Designer

In Experience Setup, grant the permissions that allow users to access the Data Connect Integration Designer.

Before you begin

Before granting permissions, you need to set up the roles and users that you want to have access to the Integration Designer. See Set up roles and users for the Integration Designer.

About this task

The Integration Designer uses a single Experience permission to support targeted user access. For example, this permission will allow the roles or individuals to:
  • Create and maintain all of the Integration Designer integrations that your institution has licensed.
  • Create, view and maintain Integration Designer crosswalks in the Integration Designer Experience card.
  • View all the Integration Designer integrations in the Integration Designer Experience card.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments menu, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. In the Experience Setup header, click Permissions.
  3. On the Permissions page, click Data Connect Designer.
  4. On the Data Connect Designer Permissions page, in the left pane, click Designer.
  5. In the right pane, select the Develop check box for each role or user who you want to be able to access the Integration Designer.
  6. Click Save.
  7. In the Confirm Changes to Permissions dialog, review the permissions changes and then click SAVE to complete the process or click CANCEL to go back and modify your selections.
  8. Instruct any user whose permissions have changed to log out of Experience and log back in.
    Experience permissions are cached. Logging out and back in refreshes the cache and ensures that the user has the granted permissions within Experience.

Set up user access to Data Connect integrations

Users manage Data Connect integrations through Ellucian Experience, from either the Application menu or the Data Connect Packages card.

Starting point User experience
Application menu The user clicks Integration Packages on the Application menu to go to a page listing all of the integrations for which they have access. The user then selects an integration on that page.
Data Connect Packages card In the card, the user sees a list of all of the integrations for which they have access. The user can click any integration to go directly to that integration.

To enable a user to manage a Data Connect integration through both the Application menu and the card, you must grant that user access to both the Data Connect integration (in Experience Setup permissions) and the Data Connect Packages card (in Experience Configuration).

If you want to enable access only through the Application menu, rather than supporting both access options, you only need to configure the permissions in Experience Setup. You can skip the card setup.

Set up roles and users for Data Connect integrations

To enable users to manage Data Connect integrations, you must first set up the users and roles that need access.

About this task

For a user to manage a Data Connect integration, that user must have the following:
  • Access to the appropriate integration. You grant that access by assigning permissions to roles or individual users in the Permissions area of Experience Setup.
  • Access to the Data Connect Packages card (required only if you want users to be able to access Data Connect integrations from the card in addition to the Application menu). You grant card access by assigning roles to the Experience card in the Card Management area of Ellucian Experience.

For a description of the user access options (Application menu or card), see Set up user access to Data Connect integrations.

For example, there might be a few people at your institution who should be able to manage all Data Connect settings and integrations, others who should be able to manage just one integration, and others who should be able to view, but not modify, an integration. You could grant all of those users access to the Experience card and then assign appropriate permissions to limit their access within Data Connect.

Procedure

  1. Identify all of the people at your institution who need access to Data Connect integrations.
  2. Review the list of permissions in Data Connect permissions, and identify the people who should have each type of access within Data Connect.
  3. Decide whether you want to grant Data Connect permissions to individual users, or grant permissions to roles and then assign those roles to individual users.
  4. Set up the roles that you need for both card access and Data Connect permissions, and add those roles in Experience Setup. See Set up roles for Ellucian Experience.
  5. In Experience Setup, add the individual users to whom you want to grant Data Connect permissions. See Add administrative users.

Grant permissions for Data Connect integrations

Grant the permissions that allow users to view and manage Data Connect integrations.

Before you begin

Before granting permissions, you need to set up the roles and users that you want to have different permissions. See Set up roles and users for Data Connect integrations.

About this task

Data Connect leverages Experience permissions to support targeted user access. For example, you can specify different users and roles who can:
  • Specify pipeline-level parameters for one or all of the Data Connect integrations that your institution has licensed.
  • Create, maintain, and run pipeline jobs for one or all of the Data Connect integrations that your institution has licensed.
  • View, but not modify, those pipeline jobs; and view job run results.
  • Create and maintain Data Connect crosswalks.
  • View, but not modify, those crosswalks.
  • Manage global Data Connect settings that apply to all integrations.

For general information about Experience permissions, and the detailed procedure for granting permissions, see Grant Experience application permissions.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments menu, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. In the Experience Setup header, click Permissions.
  3. On the Permissions page, click Data Connect.
  4. On the Data Connect Permissions page, assign permissions by selecting a feature in the left pane and then assigning the desired permissions to roles and individual users in the right pane.
    See Data Connect permissions for details about Data Connect features and the access granted by each permission.
  5. Click Save.
  6. In the Confirm Changes to Permissions dialog, review the permissions changes and then click SAVE to complete the process or click CANCEL to go back and modify your selections.
  7. Instruct any user whose permissions have changed to log out of Experience and log back in.
    Experience permissions are cached. Logging out and back in refreshes the cache and ensures that the user has the granted permissions within Experience.
Data Connect permissions

To access a Data Connect integration through Ellucian Experience, a user must be granted permissions to manage or view Data Connect features.

Feature Permission Available functions
Global Configuration View View global Data Connect settings.
Edit Modify global Data Connect settings.
Crosswalks View View Data Connect crosswalks.
Edit Create and modify Data Connect crosswalks.
Integration Packages
  • <integration package 1>
  • <integration package 2>

Select Integration Packages to grant permissions to all of your integration packages, or select a specific integration package to grant permissions to only that integration package.

Note: A user who has been granted the Develop permission for the Data Connect Integration Designer will be able to view the list of all of your institution's integration packages in the Data Connect integration packages card. However, to view or manage an integration package, that user will also need to have the View or Manage permission on the integration package.
 View See this integration package listed in the Experience card, and click the link to access the Experience page with detailed information.
View pipeline job information:
  • View job parameters.
  • View job run information, including job run history and errors.
Manage Same functions listed above for the View permission, plus the ability to manage pipeline jobs:
  • Create a new job.
  • Schedule recurring job runs.
  • Run an existing job.
  • Enter and modify job-level parameters.
  • Upload a supplemental file.
  • Download a job run file.
  • Disable or enable a job.
  • Terminate a job run.
  • Delete a job.
Setup Enter and modify pipeline-level parameters and sub-pipeline settings.

The Setup column is displayed only if at least one integration package includes pipeline-level parameters or sub-pipeline settings.

Not all integration packages include pipeline-level parameters or sub-pipeline settings. For integration packages that do not include either of those, you do not need to assign the Setup permission to any users.

Set up user access for Data Connect rulesets

Define permissions to determine who can create and view Data Connect rulesets.

  • To enable a user to manage rulesets through both the Application menu and the card, you must grant that user access to both Data Connect rulesets (in Experience Setup permissions) and the Data Connect Packages card (in Experience Configuration).
  • If you want to enable access only through the Application menu, rather than supporting both access options, you only need to configure the permissions in Experience Setup. You can skip the card setup.

Grant permissions for Data Connect rulesets

Grant the permissions that allow users to view and manage Data Connect rulesets.

Before you begin

Before granting permissions, you need to set up the roles and users that you want to have different permissions. See Set up roles and users for Data Connect rulesets.

About this task

Data Connect leverages Experience permissions to support targeted user access. For example, you can specify different users and roles who can:
  • Create, test, and publish rulesets.
  • View, but not modify, those rulesets.

For general information about Experience permissions, and the detailed procedure for granting permissions, see Grant Experience application permissions.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments menu, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. In the Experience Setup header, click Permissions.
  3. On the Permissions page, click Rules Engine.
  4. On the Rules Engine Permissions page, expand Data Connect.
  5. Assign permissions by selecting a feature in the left pane and then assigning the desired permissions to roles and individual users in the right pane.
    • To grant a role or user the same permission (Edit or View) on both Rulesets and Facts, select Data Connect.
    • To grant a role or user permission to manage facts, select Facts.
    • To grant a role or user permission to manage rulesets, select Rulesets.

    The table below shows the permissions required for either managing or viewing rulesets.

    User functions Minimum required permissions
    Manage (create, edit, test, publish, copy, and archive) rulesets on the Rulesets tab in Integration Packages. Rulesets = Edit

    Facts = View
    View, but not manage, rulesets on the Rulesets tab. Rulesets = View

    Facts = View
    Configure the Run Ruleset fitting in the Integration Designer. Rulesets = View
    Note the following:
    • The View permission for Facts enables users to see and use the Elements list in ruleset configuration.
    • The Edit permission for Facts is currently not used to support Data Connect ruleset configuration. Data Connect rulesets use Ellucian-delivered facts (elements) for which only the View permission is required.
  6. Click Save.
  7. In the Confirm Changes to Permissions dialog, review the permissions changes and then click SAVE to complete the process or click CANCEL to go back and modify your selections.
  8. Instruct any user whose permissions have changed to log out of Experience and log back in.
    Experience permissions are cached. Logging out and back in refreshes the cache and ensures that the user has the granted permissions within Experience.
