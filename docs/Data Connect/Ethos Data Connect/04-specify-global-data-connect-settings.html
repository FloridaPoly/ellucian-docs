Specify global Data Connect settings

Specify the file retention period

Specify the time after which files created by pipeline jobs are deleted.

Before you begin

The user performing this procedure must have the following access:
  • (Optional) A role that has been assigned to the Experience card. (Required only if your institution supports access through the card in addition to the Application menu.)
  • Edit permissions on Data Connect global configuration.
  • View or Manage permissions on at least one integration package, to access the Integration Packages page where the Settings link is located.

That access is granted by an administrator as described in Set up user access to Data Connect integrations.

About this task

Some pipeline jobs generate files, such as .csv or .json files, that might be used by another pipeline or available for you to download. The generated files are stored with Data Connect, and are automatically deleted after a specified file retention period. The default is 180 days. If you want to specify a shorter period, use the procedure below.

Procedure

  1. From the Experience dashboard, click the Applications icon in the Experience Bar and then click Integration Packages.
  2. Click the Settings tab.
  3. On the Settings page, in the Retention days field, select the desired retention period.
    Files generated by pipeline jobs will be automatically deleted after the specified time has elapsed.
  4. Click Save.

Specify the time zone

The time zone is used by Data Connect scheduled pipeline jobs and by Insights scheduled jobs.

Before you begin

The user performing this procedure must have the following access:
  • (Optional) A role that has been assigned to the Experience card. (Required only if your institution supports access through the card in addition to the Application menu.)
  • Edit permissions on Data Connect global configuration.
  • View or Manage permissions on at least one integration package, to access the Integration Packages page where the Settings link is located.

That access is granted by an administrator as described in Set up user access to Data Connect integrations.

About this task

After you select a time zone, any Data Connect job run schedules that you set up previously will automatically be adjusted to be based on local time in that time zone rather than UTC time. You can see the adjusted schedule by editing the existing job.

Procedure

  1. From the Experience dashboard, click the Applications icon in the Experience Bar and then click Integration Packages.
  2. Click the Settings tab.
  3. On the Settings page, in the Tenant time zone field, select the time zone that should be used for scheduled jobs.
    Tip: Hover over the help icon to see the time zone based on your computer settings. If this is the time zone that you want to use for scheduled jobs, select that time zone in the Tenant time zone field.
  4. Click Save.
