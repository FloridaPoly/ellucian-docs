Data Connect overview

Ethos Data Connect is a data transformation framework that provides the ability to connect to different data sources and data formats using Ellucian Ethos. Data Connect provides the ability to define data workflows that include data transformations and mappings to third-party sources and formats.

Delivered Data Connect integrations

Ellucian delivers some integrations that are built on Data Connect. These include, for example:
  • An integration with the National Student Clearinghouse Postsecondary Data Partnership (NSC-PDP) initiative in the U.S. This integration extracts data from Banner or Colleague, creates PDP data files in the data file format specified by the NSC, and transmits those files to the NSC.
  • An integration that supports the processing of teacher training applications submitted to institutions through the Apply for teacher training service of the Department for Education (DfE) Apply service in England. This integration retrieves applications using the DfE's API, sends them to Banner, Quercus, or CRM Recruit for processing, and posts the decisions back to the DfE.

Data Connect Integration Designer

You can build your own integrations using the Data Connect Integration Designer, which is available with Experience Premium.

The Data Connect Integration Designer enables users to create custom integrations with Data Connect's low-code solution. Users can use the designer to bi-directionally integrate with data from Ellucian solutions and third parties through APIs and flat files, transform and map data, and send to target destinations.

Access to Data Connect through Ellucian Experience

Users access Data Connect through Ellucian Experience. Before setting up Data Connect, you will need to set up Ellucian Experience.

Where to find the documentation

This Data Connect documentation provides general procedures for setting up user access to Data Connect, using the Data Connect Integration Designer to create your integrations, and creating and managing pipeline jobs.

Documentation specific to each Data Connect integration delivered by Ellucian is with the related product documentation.

Terminology for Ellucian-delivered integrations

The table below defines terms used in configuring and using Data Connect integrations delivered by Ellucian. To help clarify the terms, the table includes examples for the NSC-PDP integration.

Term Definition Created by Example for NSC-PDP integration
Integration package The complete set of pipelines and other components that support an integration. Ellucian1 Ellucian delivers an integration package for NSC-PDP.
Pipeline A component that performs a specific piece of an integration. Ellucian1 The NSC-PDP integration is comprised of multiple pipelines including, for example, a PDPCoursesReport pipeline that creates a course report data file from data extracted from Banner or Colleague.
Pipeline job An instance of a pipeline with settings unique to your implementation. You You would create a pipeline job for the PDPCoursesReport pipeline, specifying settings such as academic year.
Pipeline job run An instance of a pipeline job. You You would periodically run your PDPCoursesReport pipeline job to pick up changes for course sections that you had created or updated in Banner or Colleague.
Crosswalk A mapping of values in one application to another application. You To support the NSC-PDP integration, you would create crosswalks that map your institution-specific Banner or Colleague codes to NSC-defined PDP codes.
1 For integrations that you create using the Data Connect Integration Designer, you would create these artifacts.

FAQs

Common questions associated with Data Connect.

Question Answer
What can I use Data Connect for?
You can use Data Connect for:
  • Flat file integrations
  • Data transformations
  • Replacing AWS Lambda functions and integrating with custom cards
  • Integrating custom data with Ellucian Insights
Where do I create and edit Data Connect pipelines? You can create and edit Data Connect pipelines using the Integration Designer card in Experience.
Where do I run and schedule Data Connect jobs? You can run and schedule job runs for Data Connect in the Integration Packages card in Experience.
Can I share my pipeline from my test to prod environment? Yes, you can use the Sharing integration pipelines and transform functions documentation. This is the recommended approach for promoting pipelines to higher environments. However, if you want to move a pipeline to another environment and edit it, pipelines can also be exported and imported as .json files. See the pipeline actions section in Share individual pipelines.
Can a multi-institution customer share between their parent and children tenants? Child to child? Yes, Multi-institution customers can use the Sharing integration pipelines and transform functions . This is the recommended approach for sharing pipelines. However, pipelines can also be exported and imported as .json files. See the pipeline actions section in Share individual pipelines.
What is the retention period for files that are generated by Data Connect? By default, files generated by Data Connect are retained for six months.
Can I change the retention period for files generated by Data Connect? Yes, users with permission can change the retention period for files generated by Data Connect by following the steps in Specify the file retention period.
Can I modify a pipeline that is delivered by Ellucian? At this time, no. We hope to provide this capability in the future.
Do I need to have an Experience license to run delivered packages from Ellucian? No. All Experience Foundation customers have access to the Integration Packages card in Experience. Customers who are licensed for products that use Data Connect can see the packages that are available to them.
Where does the documentation live for Ellucian delivered Integration Packages? Documentation for delivered packages can be found under the product the integration package is a part of. For example, integration packages for Apply can be found under the Apply product.
Can I use Data Connect to send data from my Ellucian systems to a third party? Yes, as long as the third party provides APIs, Data Connect can be used to create SaaS-safe integrations to send Data to and from third parties, using the Ellucian-delivered APIs and the HTTP fittings to call the APIs provided by the third party.
Why can't I see the Integration Designer card?
In order to see the Integration Designer card, you need to have an Experience license. If you have an Experience license, please work with your Experience administrator to ensure that:
  • The card is enabled
  • The card is assigned to your role

You can then search for the card in Discover and bookmark it on your home page.
Why can't I see the Integration Packages card?
Please work with your Experience administrator to ensure that:
  • The card is enabled
  • The card is assigned to your role
How can I call BPAPIs in Data Connect pipelines? You can call BPAPIs using any of the Ethos fittings under the Source category.
Is there a way to have a pipeline kick off another pipeline? That functionality is currently not available.
How can I test my pipeline? You can test your pipeline using the Test button in the Integration Designer.
What programming languages does Data Connect use? Data Connect uses Javascript. The Insights Fittings available through the Insights Enterprise Pro license use SQL.
Can I query my ERP using SQL from Data Connect? No. Data Connect is meant to create SaaS safe integrations and relies upon using APIs to interact with source systems.
How many recipients can I add on the Send Notification fitting? 50 recipients total across to/cc/bcc.
What are some resources I can use to get more comfortable with general programming concepts and APIs so that I can be more confident when building Data Connect pipelines?
Some basic knowledge on HTTP, JavaScript, and general programming concepts will help in creating pipelines in Data Connect. Some suggested resources include but are not limited to:
  1. https://www.linkedin.com/learning/learning-the-javascript-language-22309208
  2. https://www.linkedin.com/learning/http-essential-training
  3. Loops (how to iterate various arrays or data sets)
  4. Control structures (if/then else) with various data types (if values are undefined, comparing strings, numbers, and other data structures)
  5. Data types in JavaScript (strings, array, objects) and how to deal with them
What file formats are supported by Data Connect?

Data Connect can parse and export delimited files with the delimited formatter (csv being the most commonly known format), but other types of format are also be supported.

Data Connect can parse and generate JSON files.

Data Connect can parse and format XML files.

Data Connect can generate txt files. Using custom code with JavaScript transform, many more complex formats can be parsed or exported.
Is there a recommended limit on how much data can be extracted from Insights through the Extract Data fitting? Ellucian recommends not extracting more than 6GB of data from Insights.
How often does Data Connect release updates? Ellucian typically releases a Data Connect update every three weeks.
