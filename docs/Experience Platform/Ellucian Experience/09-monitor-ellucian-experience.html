Monitor Ellucian Experience

Send Experience data to Google Analytics

You can view Ellucian Experience site usage information from within your Google Analytics account.

About this task

If you configure Experience and Google Analytics using the procedure below, Experience will send information about Experience user events to Google Analytics. These events include, for example:
  • Page views, based on an Experience user accessing an Experience page (such as the dashboard; the All Cards, Profile, and Configuration pages; and any Experience page associated with an Experience card such as the Classes card).
  • Card views, based on an Experience user accessing an Experience page with that card loaded on the page.
  • Clicks of links in Experience cards and pages.

Each event identifies the browser, such as Chrome or Safari. If the user accesses Experience through the Experience App rather than a web browser, the browser is identified as "Experience."

Information is sent to Google Analytics only if a user has enabled sharing of usage data, either during Experience onboarding or later from the Profile page. If the user is using the Experience App on iOS, the user must also have consented to activity tracking through iOS privacy settings.

Note: Experience requires Google Analytics 4.

Procedure

  1. Set up Google Analytics to work with Experience data. The following are the high-level steps; see Google documentation for details.
    1. Create an Analytics account, or use an existing account.
    2. Within that account, create a Google Analytics 4 property for Experience.
      Example property name: Ellucian Experience
    3. Within that property, create a data stream of the Web type for Experience.
      For the Website URL, enter the URL displayed in the Ellucian Experience Dashboard URL field on the Dashboard Setup tab in Ellucian Experience Setup. Enter only the portion after https://

      Example: experience.elluciancloud.com/mycollege

    Note: The Google documentation includes steps for setting up data collection on the website. You can skip those steps. Experience will automatically collect and send data after you enter the Analytics Measurement ID in Ellucian Experience Setup as described later in this procedure.
  2. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments drop-down, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  3. Enter the Google Analytics Measurement ID in Ellucian Experience Setup:
    1. In Google Analytics, from the data stream details, copy the Measurement ID.
      The ID will have the form G﻿-﻿XXXXXXXXXX.
    2. In Experience Setup, click the User Activity tab.
    3. In the Connect Google Analytics section of the page, in the Google Analytics Measurement ID field, paste the Measurement ID that you copied from Google Analytics.
    4. Click Save.
  4. In Google Analytics, create custom dimensions that allow you to view Experience data filtered by attributes such as Experience user role and Experience environment (Test or Production).
    For the procedure, see the Google documentation for creating custom dimensions. For examples, see Google Analytics custom dimensions for Experience.
    Notes about custom dimensions:
    • When you create a new custom dimension, your Google Analytics reports will reflect that custom dimension only for Experience events that occur after that time. For example, if you create a custom dimension for the student role, and then view a Google Analytics report of card views and filter it by student role, the report will display only card views that occurred after you created the custom dimension. If there are no events matching those criteria (for example, if you attempt to report on a custom dimension immediately after creating it), Google Analytics might display a message or results indicating no data was returned.
    • The setup of custom dimensions includes entering a user property. You can either type in the user property or select from a drop-down list. The drop-down list is populated based on data sent from Experience to Google Analytics. For example, the first time that any user with the student role accesses Experience, and that data is sent to Google Analytics, the role_student property will appear in the drop-down list. This might take 24 hours or more after the event in Experience.

View a site user count

You can view the number of unique users who accessed Ellucian Experience in a particular month or year.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments drop-down, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. Click the User Activity tab.
  3. In the Login Usage section of the page, click Monthly to view the number of users by month, or Annual to view the number of users by year.
    The table displays the number of unique users who accessed your Ellucian Experience site. If a user accessed the site multiple times, that user is counted just one time.

View a user's available cards

Determine the cards that are visible to a particular user.

About this task

You will first determine the user's assigned roles and then determine the available cards based on those roles.

Procedure

  1. Determine the user's assigned roles:
    1. Sign in to Ellucian Experience as that user.
    2. Access the Profile page.
    3. In the Roles section of the Profile page, determine the user's roles.
  2. Determine the cards visible to that user:
    1. Access Ellucian Experience as a user with the Card Management administrative permission.
    2. Click the Main Menu icon and then click Configuration to access the Configuration page.
    3. Click the Card Management tab.
    4. In the Filter cards by roles drop-down list, select the user's assigned roles that you determined above.
      The Card Management table displays only the cards visible to that user, which includes cards assigned specifically to that user's roles and cards assigned to Select all users.

Generate a user information report

Generate a report of personal data stored and maintained in Ellucian Experience for a user. You can use this report to fulfill a user's request for personal data as required by the General Data Protection Regulation (GDPR).

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments drop-down, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. Click the User Activity tab.
  3. In the User Information section, in the User ID field, enter either of the following:
    • This person's ID of the type specified in the Person identifier type field on the Claims tab in Ellucian Experience Setup (for example, the Banner ID, Colleague Person ID, or PowerCampus ID).
    • Any email address for this user stored in the ERP.
  4. Click Export.
    Experience generates and downloads to your computer a .json file that contains all user data and log activity stored and maintained in Experience for this user.

User data tracking options

Users can choose whether to permit Experience to track their data with cookies and analytics tools.

On first login, Ellucian Experience users are presented with an Enhance Your Experience dialog where they can choose whether to allow the use of non-essential cookies and third-party analytics to improve Ellucian Experience. The dialog includes a link to the What is tracked in Experience page in this documentation. That documentation page is publicly-accessible, not requiring a login to the Ellucian Documentation site.

Users can change their decision later from the Settings area of the Experience user profile.

What is tracked in Experience

Ellucian Experience uses non-essential cookies and third-party analytics tools to help Ellucian understand how users interact with our product. This information helps us improve your experience by refining features and optimizing the functionality of the platform for your daily use.

Cookies

Cookies make your experience smoother and help us understand what you enjoy most. Here’s how they work:
  1. When you visit a site, the site places a cookie on your device. This cookie is like a digital note that can store information, such as what pages you visit or how long you stay.
  2. As you interact with the site, the cookie collects data (such as clicks, time spent, and your device type).
  3. The cookie sends this data back to the site’s analytics software. This software gathers and organizes data from many users to show patterns, such as which pages are popular or where people tend to leave.
  4. The site uses these patterns to improve features, fix issues, or make pages more useful based on what people are actually doing on the site.

What We Measure

We track general interactions with our platform, such as:
  • Which pages you visit most often (for example, dashboard or profile page).
  • How you engage with key features, such as buttons or menus.
  • Your overall usage patterns, such as time spent on certain sections.
  • Navigational paths through the platform to identify common workflows.
  • Engagement with in-app guides, messages, and prompts.
  • Which device you are using to access the portal, along with the browser type, browser version and operating system.

Why We Collect This Data

We collect this information to:
  • Understand which features are most valuable to users.
  • Identify areas for improvement and make the platform more user-friendly.
  • Track general trends in how users move through the platform, which helps us make data-driven decisions for new updates.

How We Use This Data

To answer questions like “How are students using this feature?”, the analytics tools use data from cookies you allowed. This data shows general behavior by role (like student or faculty) within a feature, all under a secure ID—no names or personal details are attached.

The goal is to understand how groups, such as students across different universities, interact with the platform. By working with large data sets, patterns emerge, making it easier to improve the experience for everyone without focusing on any individual’s data.

Your Control

You have full control over whether non-essential cookies are used or not. Essential cookies are required for the platform to work properly, but you can opt in or out of additional analytics cookies at any time using the Share Usage Data setting in the user profile. If you opt out, only essential cookies will be used.

For more detailed information, please review the full Ellucian Privacy Notice.
