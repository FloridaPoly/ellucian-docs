Manage Experience SDK extensions

Enable an extension in Experience environments

Enable an extension in an environment, such as Test or Production, to make the content (such as cards) within that extension available in that environment.

About this task

As an alternative to this procedure, you can enable the extension and deploy it to Experience environments when you build and upload the extension, as described in Build and upload an extension. If you use that option, you can skip this procedure.

Procedure

  1. In Experience Setup, click the Extensions tab to access Extension Management.
  2. If there is an Accounts drop-down at the top of the page, select the appropriate account. (Most institutions will have just one account, in which case the account name is displayed and there is no drop-down.)
  3. Locate the extension that you are working with, and click the Edit Extension icon in that row.
  4. In the Edit Extension Version dialog box, enable the extension:
    1. In the Environments field, select the environments where you want the extension to be enabled.
      If you select an environment in which another version of this extension is enabled, that other version will be automatically disabled because it is being replaced by this version. Any content (such as cards) within that extension will also be replaced by the version of that content in this extension version.
    2. Click the Enable toggle switch to enable the extension.
    3. Click Save.

Set up an extension card in an environment

In each environment where you enabled an extension, set up the cards within the extension.

Before you begin

The user performing this procedure must have been granted the Card Management administrative permission in Ellucian Experience Setup, as described in Grant Experience dashboard permissions.

Procedure

  1. Access Ellucian Experience as a user with the Card Management administrative permission.
  2. Click the Main Menu icon and then click Configuration to access the Configuration page.
  3. Click the Card Management tab.
  4. In the Card type column, locate the extension card that you want to configure.
    The card type displayed here comes from the displayCardType property that you specified when you set up the card within the extension.
  5. In the Actions column, click the More icon and then click Edit to access the Edit Card page.
  6. In the Details section of the page, enter basic card settings:
    1. In the Card Information area, enter descriptive information:
      Setting Description
      Card title This title is displayed at the top of the card. Ellucian recommends a title length of 55 characters or less to ensure readability on all devices.
      Card description This description is not displayed on the card, but is used in search.
      Card tags Tags are used in search and to filter the cards displayed on the All Cards page and on category pages when accessed from the Experience main menu. You can enter multiple tags, separated by commas.
      The title, description, and tags help Ellucian Experience users to find cards of interest to them on the All Cards page and on category pages when accessed from the Experience main menu:
      • The tags are displayed at the top of the page. Users can click a tag to filter the display to only cards with that tag.
      • When a user searches for cards, the search includes the text that you enter for title, description, and tags.

      For Ellucian-delivered cards, the default card title and description are translated if one of your users selects another language in their Experience profile. If you change the title or description, it will not be translated.

      Setting Description
      Mini card icon Select the icon that best represents this card's content, to be used on small viewports where cards are displayed as mini cards that can be expanded to view content. To see all of the icons at a glance, click  Attachment on this page to download the table of Experience icons.
    2. In the Card Placement area, enter information about where users see this card:
      Setting Description
      Category (Optional) Select a content category in which this card will appear on the Experience main menu for Experience users, and on the Card Management tab for content administrators. For more information, see Set up content categories.
      Specify card's placement Select an option to specify where this card appears on the home page and whether end users can remove or move the card.
      • Default display - The card is initially not on the user's home page, but it is on the All Cards and category pages where users can save the card to their home page. On the home page, users can move or remove the card.
      • Display on home page - The card will appear on the home pages of all users who have a role selected for this card when they next access Experience:
        • For users who do not currently have this card on their home page, the card will be placed above other cards they have saved, but below any locked cards. The user will receive a notification about the new card.
        • For users who already have this card on their home page, the card will remain in its current position and they will not receive a notification.

        The user can move or remove the card.

      • Lock on home page - The card will appear on the home pages of all users who have a role selected for this card when they next access Experience, and those users will receive a notification about the locked card. Locked cards appear above any cards that the user has saved, and in the order that you specify as described in Specify the order of locked cards. The user cannot move or remove locked cards.
    3. Optional: In the External Link area, enter the settings in the table below if you want the card to contain an external link.
      • In full-size cards, the external link is accessed from the card action menu
      • On small viewports, where clicking a mini card opens an expanded view of the card, the external link is displayed on the card itself.

      In the Experience web application (in the browser), links to targets outside of Experience will open in a new tab, while links to Experience pages will open in the same tab. In the Experience mobile app, the link will open in an overlay window.

      Setting Description
      External link label Enter the text for the link as it will appear in the card.
      External link URL Enter the link target URL.
    4. Click Next.
  7. In the Configuration section of the page, enter the settings (if any) that you defined within the extension for this card.
    These can include both extension-level settings and card-level settings. Both are maintained in card configuration. If you created multiple cards within a single extension, you only need to enter extension-level settings one time, in any of those cards. The entered values will then automatically appear in card setup for the other cards.
  8. Click Next.
  9. In the Roles section of the page, do either of the following to specify which users will see this card:
    • Click Select all users to assign this card to all Ellucian Experience users.
    • Select roles to assign this card only to users with those roles. Your institution defines the available roles on the Roles tab in Experience Setup. Note that content can be assigned to roles, but not to individual users, added on the Roles tab.
  10. In the preview area of the page, check the card preview and mini card preview, and adjust the Details and Configuration settings if needed to achieve the desired display.
  11. At the bottom of the page, use the Enable Card toggle switch to specify whether the card will be available now to Ellucian Experience users.
    You might disable a card, for example, if you want to create the card now but do not yet want to make it available to users.
  12. Click Finish.
    If you enabled the card, it is now available on the All Cards page and category pages to users with a role that you assigned to the card.

Delete a token

Users with access to Ellucian Experience Setup can delete tokens created by other users. For example, as a security measure, you might want to delete a token created by someone who is no longer with your organization.

About this task

Use this procedure to delete a token for another user. If you want to revoke your own token, replace it by generating a new token as described in Build and upload an extension.

Procedure

  1. In Experience Setup, click the Extensions tab to access Extension Management.
  2. If there is an Accounts drop-down at the top of the page, select the appropriate account. (Most institutions will have just one account, in which case the account name is displayed and there is no drop-down.)
  3. Click the Tokens subtab.
  4. In the All Tokens section of the page, locate the row for the token that you want to delete, and then click the Delete Token icon in that row.
  5. In the Delete Token confirmation dialog box, click Delete.
