Add content using the Experience APIs

Developers at your institution can create API requests to add content from a contributing solution to Ellucian Experience, using the Experience APIs.

The following APIs are available for managing content in Experience:

API Description
Tasks API for managing tasks that appear in the Experience Task List.

To support API requests, developers will do the following to set up access from the contributing solution to Experience and then configure the API requests:

Procedure Description
Set up the contributing solution in Ethos Integration In Ethos Integration, set up the solution that will make the API request to Experience.
Enable an Experience API In Experience Setup, enable an Experience API to make it available for access to Experience.
Grant permissions to access an Experience API In Experience Setup, grant permissions to allow the contributing solution to make requests to Experience through an Experience API.
Make requests to the Experience APIs In the contributing solution, insert the code that gets an Ethos token from the Ethos Integration authorization service and sends an API request that includes the Ethos token to Experience.

Set up access to Experience through an Experience API

Set up the contributing solution in Ethos Integration

In Ethos Integration, set up the solution that will make the API request to Ellucian Experience.

About this task

You will create an Ethos application for the contributing solution and then allow that solution to access Experience through the Experience platform component.

Procedure

  1. On the Ethos Integration header bar, click the gear icon and then select the Ethos environment where you want to perform this procedure.
  2. On the Ethos Integration header bar, click Applications.
  3. In the Create New App area of the page, click Manually.
  4. In the Add Application dialog box, leave the check boxes cleared (the default) and click Continue.
  5. On the Application Details page of the wizard, enter the information described below and then click Next.
    Field Entry
    Application name Enter a unique name for this application.

    Make sure the name uniquely identifies this application. When you need to select an application elsewhere in the Ethos Integration user interface, you will use the name to select the correct application.
    Description (Optional) Enter a description of this application.
  6. On the Add Subscriptions page of the wizard, click Skip.
  7. On the Ethos Integration header bar, click Platform Components.
  8. On the Ethos Platform Components page, locate the Ellucian Experience tile and click View.
  9. On the Ethos Platform Component Overview page, click the Application Access tab.
  10. Click Add Application Access.
  11. In the Add Application Access dialog box, do the following:
    1. In the Resource Owner drop-down list, select the Ethos application you created for the contributing solution.
    2. Click Add.

Enable an Experience API

In Experience Setup, enable an Experience API to make it available for access to Ellucian Experience.

About this task

Enabling the API results in the API being added as an owned resource to the Experience platform component in Ethos Integration.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments drop-down, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. Click the Dashboard Setup tab.
  3. In the Experience APIs section of the page, click Enable next to the API you want to use.
    Note: APIs are displayed only after you enter and successfully validate the Ethos Integration API key on this same page.

Grant permissions to access an Experience API

In Experience Setup, grant permissions to allow the contributing solution to make requests to Ellucian Experience through an Experience API.

Procedure

  1. Access Ellucian Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the desired Experience Setup instance under the Experience category:
      • Click Experience Setup to access the Production instance of Experience Setup.
      • Click Experience Setup Test to access the Test instance of Experience Setup.
    2. (If applicable) In Experience Setup, in the Environments drop-down, select the desired Ethos environment.
      The option to select an environment is available only if multiple Ethos environments are associated with this Experience Setup instance.
  2. In the Experience Setup header, click Permissions.
  3. On the Permissions page, click Experience Platform.
  4. On the Experience Platform Permissions page, expand API.
  5. Select the Experience API for which you want to grant permissions.
    • To grant permissions to manage all APIs, select API. Granting permissions at this level grants permission to manage all APIs listed under the API heading, including any APIs added in the future.
    • To grant permission to manage a particular API, select that API.
  6. In the row for your contributing solution, select the check boxes for the request types (POST, GET, PUT, or DELETE) needed to support the API requests.
    The Application column lists all of the Ethos applications that have been granted access to the Experience platform component in Ethos Integration. If you don't see the Ethos application for your contributing solution, make sure it is set up properly as described in Set up the contributing solution in Ethos Integration.
  7. Click Save.
  8. In the Confirm Changes to Permissions dialog, review the permissions changes and then click SAVE to complete the process or click CANCEL to go back and modify your selections.

Make requests to the Experience APIs

In the contributing solution, insert the code that sends the API request to Ellucian Experience.

Each request is a two-step process:
  • Get an Ethos token from the Ethos Integration authorization service.
  • Send an API request that includes the Ethos token to Ellucian Experience.

Code to get the Ethos token

This cURL example shows the code that would get the Ethos token from the Ethos Integration authorization service.

curl -X POST 
-H "Authorization: Bearer {API_KEY}" 
-H "Cache-Control: no-cache" 'https://integrate.elluciancloud.com/auth'
For API_KEY, substitute the API key for the Ethos application you created for the contributing solution. To get that API key:
  1. In Ethos Integration, click the Applications tab and then click the application you created in Set up the contributing solution in Ethos Integration.
  2. On the Application Overview page, on the API Keys tab, click the Copy Key to Clipboard icon.

Code to make the API request

The form of the API request depends on the particular API and request method you are using. Detailed specifications for each Experience API are in the API Catalog. Access the API Catalog and then search for the desired API. You can use the search filter to limit the search results by selecting Experience in the API Owner filter.

The following cURL example uses the Tasks API to send a task to be displayed in the Experience Task List.

curl -X POST \
-H 'Authorization: Bearer {Ethos_Token}' \
-d '{
 "poc": "admin@eloyce.edu",
 "link": "https://myparking.eloyce.edu/tickets?id=1234",
 "title": "Parking Ticket",
 "sourceName": "MyParking",
 "assigneeId": "947419bb-26f4-43c5-9a75-e2f345e32af5",
 "tenantId": "4fe349d5-0d68-4df6-bd29-a3a112054e7f",
 "notifications": true
}' \
https://integrate.elluciancloud.com/api/tasks

For Ethos_Token, substitute the Ethos token that came back from the Ethos Integration authorization service.
