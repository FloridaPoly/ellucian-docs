Getting Started

Current feature set and scope

EUP supports integration with Banner or Colleague and a range of identity management services. This complements the functionality provided by other Ellucian solutions.

EUP supports integration with different Banner solutions, specifically Banner On-Premises, Banner SaaS, and Banner Managed Cloud. Ongoing development efforts for EUP are focused on the integration with other Banner solutions and other Ellucian applications and products. For more information, contact your account executive or customer success manager.

You can provision identity data from Banner or Colleague to the following identity management services with EUP:
  • Microsoft Entra ID
  • Okta LDAP
  • On-premises agents—AD and LDAP
  • System for Cross-domain Identity Management (SCIM) endpoints
Note: The current release of EUP does not support Services Provisioning Markup Language (SPML) endpoints but Ellucian can work with your institution to address this issue. Contact your Ellucian technical representative for more information.

Scope

Ellucian has designed EUP as a targeted solution for enabling Single Sign-On (SSO) by provisioning identity data from Banner or Colleague to an identity management service. EUP is focused on this specific requirement, and Ellucian has carefully defined its scope so as to avoid duplicating or replicating functionality provided by other products and solutions in its product suite. Instead, EUP augments or complements existing functionality provided by the other products and solutions in the suite. So:
  • EUP does not provision, migrate, or store biographical data about a person and does not provide a mechanism for managing this information in a central location. However, the suite includes the Ellucian Person Manager SaaS platform component that does provide this functionality. See Ellucian Person Manager for details.
  • EUP does not manage authorization. For authorization requirements, consider Ellucian Ethos Identity. See About Ellucian Ethos Identity for more information. So, for example you can configure a WS-Federation service provider with Ellucian Ethos Identity and use this provider to federate through EUP and authenticate with say, Microsoft Entra ID.

Role mapping

EUP enables institutions to map the user roles and assignments to an identity management service.

User roles are a fundamental feature of any Identity and Access Management system as they determine the level of access a user has to specific digital resources and data. Administrators can define and maintain user roles in several Ellucian products and applications.

EUP enables institutions to map the user roles and assignments from Banner or Colleague to the identity management service, that is, EUP acts as a conduit to move these roles from Banner or Colleague to the service. The default group type is Security, and the mapping uses an existing group, if this group exists. You can configure role mapping using the dedicated Administrative UI that Ellucian provides for EUP.

Bulk provisioning and deprovisioning

EUP supports bulk provisioning of users and groups using a dedicated Ethos Data Connect integration package.

Typical use cases for this feature include new institutions, who want to implement EUP and bulk provision existing users from Ellucian. Institutions that already have deployed EUP may also want to use this functionality if they have temporarily suspended real-time provisioning for some reason, for example during busy periods such as admission and registration windows. They can then bulk provision users before they enable real-time provisioning again.

To bulk provision users, you must create a pipeline job for the EUP integration package using a card on your Experience dashboard. You can specify different configuration settings when you create the job, including the population selection criteria, which determine the users that the job will provision to the identity management service. You can then run the pipeline job to provision these users. The bulk provision process will only create new users in the service, and will not update existing users.

Note: Institutions need an Experience Foundation license to use the bulk provisioning feature for EUP.

EUP also supports the deprovisioning of users, for example, when a faculty member takes a sabbatical, or a student leaves a course. You configure the deprovisioning settings as part of the role mapping configuration.

Monitoring and troubleshooting

EUP includes Provisioning Metrics—an Experience-supported application that enables administrators to monitor and troubleshoot provisioning activity in their institutions.

The provisioning of identity data is a mission-critical activity for any organization, but perhaps especially for higher education institutions. As such, an essential requirement for these institutions is that they can monitor all provisioning activity, with the ability to quickly investigate, troubleshoot, and resolve any errors.

To address this requirement, EUP includes Provisioning Metrics—an Experience-supported application that enables institutions to monitor the flow of identity data from Ellucian to the identity management service. It leverages all of the functionality provided by the Ellucian Experience platform to deliver a powerful, intuitive monitoring and troubleshooting tool that administrators can access from their Experience dashboard. Administrators can view summary metrics for all provisioning requests generated by EUP, and also view details about the requests for individual users. Provisioning Metrics also includes functionality managing these requests. So, for example, administrators use this application to retry requests that have failed because of an availability issue with the identity management service.
