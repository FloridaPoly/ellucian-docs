Download and view the API Catalog

The API Catalog is available for download as a zip file. Once unzipped, open the extracted YAML files using an tool (such as Visual Studio Code) or an OpenAPI-compatible viewer. In Visual Studio Code, you can open the folder, search across files, and optionally use a Swagger extension to render interactive API documentation.

Warning: The API Catalog download, including the Download and View the API Catalog instructions, are being provided for customer and Ellucian Partner use only and should not be distributed to anyone, except by Ellucian.
Note: Be aware that some Ellucian-specific properties are not supported in Swagger views and must be viewed directly in the YAML files.

Download and unzip the full API Catalog

The entire API Catalog is attached to this publication for download.

  1. Click attachments on this page.
  2. Click the production_API_catalog.zip file icon to download the zip file.
  3. Right-click on the file, and select Extract All (Windows) or double-click to unzip (Mac).
  4. When prompted, extract the contents to a root level folder. Nesting the unzipped contents deeper in your file tree may result in errors with filename lengths.

Choose a tool to view the API files

The API definitions are provided in .yaml format and can be viewed using a variety of tools.

Visual Studio Code is one recommended option; however, customers may also use:

  • Other tools such as IntelliJ IDEA, Eclipse, or Notepad++
  • Online OpenAPI tools such as Swagger Editor (https://editor.swagger.io)
  • Any OpenAPI-compatible viewer or editor

These tools can render the YAML files into a Swagger-style, interactive API view.

Open the Folder in Visual Studio Code

The following instructions are for Visual Studio Code, as an example of how the API Catalog files can be used.

  1. Launch Visual Studio Code.
  2. Select File > Open Folder.
  3. Navigate to, and select, the APICatalog folder that is inside the extracted contents folder.

Search across YAML files

  1. Press Ctrl > Shift > F (Windows) or Cmd > Shift > F (Mac).
  2. Enter a keyword to search across all API definitions. Results appears across all .yaml files in the directory.

Install Swagger editor extension (optional)

  1. In Visual Studio Code, go to the Extensions panel.
  2. Search for OpenAPI (Swagger) Editor.
  3. Install the extension authored by 42Crunch.

View APIs in Swagger format (optional)

  1. Open any .yaml file.
  2. Right-click and select Preview OpenAPI Document or use the extension panel. This displays the API in an interactive Swagger-style view.
Note: Extensions and online OpenAPI viewers are not likely to display Ellucian custom properties, such as those for lineage or security objects. To view those properties, you need to view the .yaml file contents directly.

API Catalog and API documentation information

This documentation page describes the API Catalog and provides guidance in getting information about an API.

Ethos Data Model Entity Reference

If you were seeking the Ethos Data Model Entity Reference index, it has been replaced with the API Catalog.

API Catalog Tiles

The Home Page > API Catalog link returns an API Catalog page with additional API tiles that are sorted by API owner. When clicked, these tiles return a Search Results page listing the available APIs.

API Filters

On the Search Results page, the Filters pane displays filters that allow you to further refine the current search results. As you select filters, the list of additional filters available updates to allow more granular refinement of your search criteria. When no additional filters display, that means there is no further available metadata to further refine the current list of APIs.

API Documentation

From the Search Results page, you can access documentation specific to each API by selecting the API title. The APIs in the catalog that are documented using the industry standard OpenAPI 3.0 specifications, are displayed using Swagger. You can also download the .yaml or .json file, depending on the API, from the API Documentation page and open it using any OpenAPI specification tool.

Data lineage for APIs published in the API Catalog is accessed from the API Catalog pages as the lineage is embedded in the schemas located at the bottom of the API Catalog pages.

API Types

The API Catalog includes Ethos Data Model-based APIs, product-specific Business Process APIs, and product-specific Specification-based APIs. On the Search Results page, you can filter the results by API Type.

API Versions

The Search Results page displays all available versions of an API. When an API has multiple versions available, a label appears for “Also available in:”; if there is only one version of an API, the "Also available in:" label does not display. There are times when the "Also available in:" does not display, if you refresh the page, the option does show up.

The API Catalog requires versions to be displayed using an X.X.X format (semantic versioning). To meet this requirement, early Ethos Data Models that did not conform to semantic versioning have had to have their versions adjusted for display only. For example, academic-levels v6.0 appears as v6.0.0 in the catalog. Please refer to the API-specific documentation for acceptable Accept header syntax.

API Release Types

An API is considered General Availability unless specifically designated as Beta or Select Release.
  • General Availability: Available to all customers
  • Beta: released for testing - API subject to change before general availability release
  • Select Release: Released to a vetted list of customers before general availability

API deprecation

Deprecation refers to functions or elements that are in the process of being replaced by newer ones. Ellucian has a standard two year window between when deprecation is announced and when the API is sunset. When deprecation for an API has been announced, the API will continue to work and is supported for prioritized defect fixes until the API is sunset after the two year period. For more information, see the deprecation policy.
