Banner eTranscript API

This page lists all of the Banner eTranscript API content that has not been converted to the OpenAPI standard.

The objective of Banner eTranscript APIs is to expose the services to Ellucian Cloud for transcript order processing. These RESTful APIs are delivered in an eTranscript.war file as part of the upgrade process. They support real-time and automated processing of orders between the NSC, the Ellucian Cloud, and Banner.

Ellucian Advise Banner APIs

This page lists the Ellucian Advise Banner API content that has not been converted to the OpenAPI standard.

Unless stated otherwise, paging parameters are supported for all APIs, with the exception of APIs that require an array of identifiers in the body of the request. Paging parameters are max and offset, where max is the maximum number of records to be returned, and offset is the starting record number relative to 0. The total number of records in the database is returned as a header parameter named X-Hedtech-TotalCount.
