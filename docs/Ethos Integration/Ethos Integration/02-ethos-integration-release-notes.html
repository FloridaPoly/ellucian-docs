Ellucian Messaging Adapter 6.0.2

Ellucian Messaging Adapter (EMA) 6.0.2 includes defect fixes and fix for security vulnerabilities.

Upgrade considerations

Ellucian currently maintains two major versions of the Ellucian Messaging Adapter (EMA):
  • EMA 6.x requires Grails 7 and Tomcat 10.
  • EMA 5.x runs on Grails 6 and Tomcat 9.

If you are using the Banner Event Publisher (BEP) and EMA on the same Tomcat server, you should remain on EMA 5.x rather than upgrading to EMA 6.x at this time. BEP is currently running on Grails 6/Tomcat 9. A future BEP update will run on Grails 7/Tomcat 10, at which time you should upgrade to EMA 6.x.

EMA 5.x will be fully supported until Banner applications are released with Grails 7 support.

EMA 6.0.2 highlights

For details about the release, see the release page PR00043431 in the Ellucian Customer Center.

For information about the defects and common vulnerabilities and exposures (CVEs) addressed in this release, see the Related Defects tab on that release page. The defect fixes include
  • PD0033297: Update documentation supporting message squashing logic.
  • PD0033655: Individual log files missing - all logs only go to stdout.

Release April 23, 2026

The April 23, 2026 release of Ethos Integration introduces a new consolidated application view within Experience. It also contains a maintenance release with infrastructure updates and defect resolutions.

This release introduces a new consolidated Ethos Integration application view within Experience, which allows precise control of the users who can view Ethos configurations using role-based permissions. In addition, the new application view means that users can now access Published Messages from within the Ethos Integration application directly in Experience, provided they have the required permissions. See User access to Ethos Integration through Experience and related topics for more information.

This release also includes infrastructure updates and defect resolutions. In particular, it fixes an issue related to naming conflicts and the Publishing Serverless API. See PD0024086 in the Ellucian Customer Center for details.

There is no downtime and no post-maintenance activities are needed.

Refer to PR00043324 Ethos Integration Maintenance Release P.20260423 in the Ellucian Customer Center. For details on all issues addressed in this release, see the Related Defects tab on the release page.

Ellucian Messaging Adapter 6.0.0

Ellucian Messaging Adapter (EMA) 6.0.0 is a major version release of EMA.

Warning: This major version update of EMA has a breaking change. Due to the adoption of Grails 7, it will NOT work on Tomcat 9 anymore. You will have to use Tomcat 10 to deploy EMA 6.

EMA 6.0.0 highlights

Release December 17 2025

The December 17, 2025 release of Ethos Integration delivers the ability to add unrestricted IP addresses and contains a maintenance release containing infrastructure updates and defect resolution.

There is no downtime and no post-maintenance activities are needed.

This release improves security by automatically restricting all IP traffic for an API key upon new creation of an Ethos application. When you create an application, by default, the API key is disabled for all IP addresses. You can add multiple IP addresses that an API key is open to, or make an API key unrestricted. See Create an application and modify API key restrictions and Add an API key and manage IP restrictions.

This change will not impact any existing API keys.

This release includes a fix an error when users attempted to edit a resource for the Integration API application. See PD0029001 in the Ellucian Customer Center.

Release March 22 2024

The March 22, 2024 release of Ethos Integration provides reorganized documentation for improved navigation.

Reorganized documentation for improved navigation

The Ethos Integration documentation in this Ellucian Documentation site has been reorganized to improve the ability to find content. Previously, the documentation was in standard categories such as Configure and Use, with no intuitive way to navigate between those categories.

The reorganized documentation presents the table of contents for all of the Ethos Integration documentation in one view, as shown in the contents pane to the left of this page. The top-level sections have more descriptive names, such as “Connect applications to Ethos Integration” rather than “Configure.”

This reorganization has the side effect of breaking bookmarked links because the previous website URLs included the category name. Example of the last part of the URL for the "Create an application using a catalog" page, which was previously in the "Configure" category:
  • Old URL: https://resources.elluciancloud.com/bundle/ethos_integration_acn_configure/page/t_create_an_application_using_a_catalog.html
  • New URL: https://resources.elluciancloud.com/bundle/ethos_integration/page/t_create_an_application_using_a_catalog.html

You can fix your bookmarks by editing the ethos_integration segment of the bookmark URL as illustrated by the example above. For all Ethos Integration documentation pages, that segment is now just ethos_integration.
