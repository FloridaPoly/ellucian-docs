Set up access to Ethos Integration

Get access to Ethos Integration

Individuals with access to the administrative interface of Ellucian Ethos Integration can configure and monitor the flow of messages between integrated applications.

To gain access to the Ellucian Ethos Integration environments for your institution, you must:
  1. Obtain an Ellucian Customer Center account.
  2. Request access to Ellucian Ethos Integration.

Obtain an Ellucian Customer Center account

An Ellucian Customer Center account ensures that you are associated with one or more institution in the Ellucian CRM system, and that you have an account with Okta, the identity provider for Ellucian.

Before you begin

To confirm that you have a Customer Center account, go to https://clientapps.ellucian.com/signup. If you have already registered with that email address, you will receive a message that the record was found. Or you can submit a case by sending an email to csenablement@ellucian.com and Ellucian can verify the account.

Procedure

  1. Go to https://elluciansupport.service-now.com/
  2. Click Customer Login.
  3. Click Sign up for an account.
  4. Enter the email address provided to you by your institution and complete the CAPTCHA requirements.
  5. Click Submit.
    A registration email generates from no-reply@okta.com. Ensure you are not blocking this email address or domain, or that the email is not in your spam folder.
  6. When you receive the registration email, confirm your registration, and set your password.

Request access to Ellucian Ethos Integration

After you confirm that you have access to the Ellucian Customer Center, you request access to Ellucian Ethos Integration.

Before you begin

Consult with your IT staff to verify if your institution has an Ethos Integration tenant.

Procedure

  1. Go to your Customer Center portal.
  2. Click the Support tab.
  3. Click Request & View Access.
  4. Select Ethos Integration.
    This action sends a notification to the customer administrator to approve your request. When it is approved, you will see the Ethos Integration application under the Tools tab.

Log in to Ethos Integration

When you receive access to the Ellucian Customer Center, log in to Ellucian Ethos Integration.

Procedure

  1. Select Tools > Ethos > Integration.
  2. Select a tenant environment.
    The Enhance Your Experience page displays, prompting you to indicate whether you will allow Ellucian to enable cookies to track your usage in Ethos Integration using Google Analytics.
  3. On the Enhance Your Experience page, click No, Thanks, or Accept.

Set up access to Ethos Integration through Ellucian Experience

User access to Ethos Integration through Experience

Experience users can view their Ethos Integration integrations through Ellucian Experience, from either the Application Menu or the Ethos Integration cards.

Starting Point User Experience
Application Menu The user clicks Ethos Integration on the Application Menu to open a page listing the Ethos Integration features they have access to. The user then selects a feature on that page.
Ethos Integration cards The user can search and select any of the following Ethos Integration cards to view the feature details:
  • Ethos Integration—Applications
  • Ethos Integration—Errors
  • Ethos Integration—Audit Logs

To enable a user to view the Ethos Integration through both the Application Menu and the Ethos Integration cards, you must grant that user access to both in Experience Setup permissions. See Set up permissions to access Ethos Integration in Ellucian Experience and Set up the Ethos Integration cards in Experience for details.

If you want a user to view their integrations using both the menu and the cards, you must complete the setup procedures for each method.

Set up permissions to access Ethos Integration in Ellucian Experience

Administrators set up permissions for the cards that display in Ellucian Experience. After the permissions and roles are set up, the administrator then sets up the Ethos Integration card in Ellucian Experience.

Before you begin

In Ellucian Experience, you must configure roles and permissions. See Set up roles for Ellucian Experience and Grant administrative permissions.

Procedure

  1. Access Experience Setup:
    1. In the Ellucian Customer Center, click Tools and then select the Experience Setup instance under the Experience category:
      • Click Experience Setup (Test) to access the Test instance of Experience Setup.
      • Click Experience Setup to access the Production instance of Experience Setup.
    2. (Experience Test only) In Experience Setup, in the Environments drop-down, select the desired Ethos non-Production environment (For example, Test, or any additional Ethos environment that you have licensed, such as Development).
      This option is available only if you have licensed Ethos non-Production environments in addition to Test.
      The Ellucian Experience Setup page displays.
  2. In the Experience Setup header, click Permissions.
  3. On the Permissions page, select Ethos Integration.
    The Ethos Integration Permissions page displays.
  4. Grant the required view permissions for Ethos Integration capabilities.
    To access Ethos Integration through Ellucian Experience, you must grant a user view permissions for the capabilities associated with its features.
    Feature Capability Permission Available Functions
    Applications Configuration View View the Ethos Integration Applications configuration page. Also view and copy API keys from the Experience card and application.
    Resources View View Resources information relevant to the authoritative applications, such as:
    • Resource owner or owners
    • Defaults
    • Value transformations
    • API behavior
    • API Details
    • Health
    • Event Configuration
    Reports Error Messages View View the Ethos Integration Errors page from the Experience card and application.
    Audit Logs View View the Ethos Integration Audit Logs page from the Experience card and application.
    Published Messages View View the Ethos Integration Published Messages page from the Experience application.
  5. Select the check boxes in the View column for the roles or individuals you want to allow view access.
  6. Click Save.

Set up the Ethos Integration cards in Experience

Users access Ethos Integration integrations through the Ethos Integration cards in Ellucian Experience.

Before you begin

Before you set up the cards, you must configure the roles that you want to have access to the cards. See Set up permissions to access Ethos Integration in Ellucian Experience.

Procedure

Set up the Ethos Integration cards in the card setup wizard using the general card setup procedure in Set up an Experience card, with the considerations described below.
  1. Use the search field to find the following Ethos Integration cards.
  2. When selecting the card in the Card Management table, edit the card with one of the Ethos Integration card names in the Card Type column.
    • EI Applications Card
    • EI Audit Logs Card
    • EI Errors Card
  3. In the Roles step of the card setup wizard, select the roles that you set up for access to the card you are setting up.
