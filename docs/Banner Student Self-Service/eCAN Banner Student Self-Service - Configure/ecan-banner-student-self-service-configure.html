eCAN overview

Banner Student Self-Service includes functionality for students to view and print a Commonwealth Assistance Notice (CAN). The Electronic Commonwealth Assistance Notice (eCAN) enables students to view their Commonwealth Assistance Notice (CAN) online which has the same information in a hard copy CAN.

All students who are Commonwealth supported, and who request Commonwealth assistance, can view their respective CAN.

Prerequisites

The required releases for Banner eCAN 9.16.1 are as follows:
  • Banner Common DB Upgrade 9.23.0.1
  • Banner Student 8.21.1
  • Banner General 8.13
  • Banner Accounts Receivable 8.7
  • Banner Web General 8.8.0.1 (proxy feature)
  • Banner Financial Aid 8.39.2 (For Financial Aid Self-Service only)
  • Banner Student Aid 8.12.2.3 (For Student Aid Self-Service only)
  • Banner ASCGEN 8.15.1 (For USI and Commonwealth Assistance Notice only)
  • Banner GRDS 8.2.2 (For Graduation Management only)

View your current CAN details

View your current Commonwealth Notice details.

Procedure

  1. Access Student Self-Service.
  2. When the Student Records menu is displayed, click Commonwealth Assistance Notice.
  3. In the New Commonwealth Assistance Notice page, select a program from the Program drop-down list.
  4. Select a help type from the HELP Type drop-down list.
  5. Select a term from the Term drop-down list.
  6. Click Continue.
    In the Commonwealth Assistance Notice page, depending upon the program, HELP type, and term code selected from the New Commonwealth Assistance Notice page, you will view the CAN information for a student.

eCAN Self-Service pages

Banner includes Self-Service pages to allow students to view their electronic Commonwealth Assistance Notice (CAN) details online.

eCAN Web menu

The Student Records Menu contains the Commonwealth Assistance Notice link that you can use to view the Commonwealth Assistance Notice page.

eCAN Web pages

List of Banner eCAN Self Service Web pages that you can use to view CAN details.

Generate New Commonwealth Assistance Notice

The Generate New Commonwealth Assistance Notice page allows you to select the Program, HELP Type and Term of the CAN that you want to view.

If the student has SA-HELP, the SA-HELP HELP type will be available regardless of the Program that you select.

Commonwealth Assistance Notice

The Commonwealth Assistance Notice page displays the details of the CAN for the program, term code, and the HELP type that you select from the Generate New Commonwealth Assistance Notice page.

Setup requirements

Setup is required for the Commonwealth Assistance Notice page to work as expected.

Item Description
Name Display Rules (GUANDSP) page Use the Hierarchy window in the GUANDSP page and configure the Commonwealth Assistance Notice page to use a specific Name Display Rule with the following hierarchy rules:
  • Product: Student
  • Application: Student Self Service
  • Page: Commonwealth Assistance Notice
  • Usage: The name display rule that you want to use
  • Maximum Length: The maximum length to display for a name.
