CAEI overview

Banner Commonwealth Assistance Expression of Interest (CAEI) provides a solution for institutions to record details of student expressions of interest in Commonwealth Assistance. The processing functionality includes Self-Service Web pages and data storage to support expressions of interest in Commonwealth Assistance.

You can perform the following tasks:
  • Provide Self-Service Web pages for eligible students to submit an expression of interest in the following help types:
    • Commonwealth support and HECS-HELP
    • FEE-HELP
    • OS-HELP
    • SA-HELP
    • VET Student Loan
  • Store expression of interest in Commonwealth assistance data.

Prerequisites

There are minimum required releases for the Banner CAEI are as follows:

  • Banner ASCGEN 8.16.1
  • Banner Student 8.24
  • Banner Student Self-Service 9.20 (Banner Commonwealth Assistance Expression of Interest 9.20 is available as a part of Banner Student Self-Service 9.20)
  • Banner Document Management (BDM) 8.6.0.1 or later with ApplicationXtender 20.4 or later, including ApplicationXtender Web Access and ApplicationXtender Web Services.

CAEI Self-Service

Changes to the Australian government processing for Commonwealth Assistance includes updates where the institutions can no longer use their own eCAF (Commonwealth Assistance Form) solutions but must instead use APIs to post enrolment information about eligible, interested students to a government website.

Emails are sent to the students from that website, inviting them to submit their eCAFs directly on the Australian government site, using a passkey provided in the email.

The institution has a responsibility for recording the details of the Commonwealth assistance in which the student is interested, including evidence of their citizenship/resident status as part of eligibility checking.

Banner includes Self-Service pages to allow students to submit expressions of interest in Commonwealth Assistance. This chapter describes the Web pages as delivered. These descriptions are used to help you extend the delivered pages to meet your institution's needs.

Instructions to perform Self-Service CAEI tasks.

Set up CAEI document upload

Configure and set up CAEI document upload using the Banner Applications Configurations (GUACONF) page.

Procedure

  1. Log in to the BannerAdmin application.
  2. Open the BannerApplications Configurations (GUACONF) page.
  3. Select Application ID > SSS to modify the Student Self Service application related configurations for Banner Document Management.
  4. Select the Configuration window.
  5. To filter and search for the BDM configuration names, enter, for example bdm%
    Configuration Name ConfigurationType Configuration Value
    bdm.enabled boolean True
    bdmserver.file.location string ForWindows Server user: C:/BDM/temp

    For Linux server user: /home/ oracle/ BDM_DOCUMENTS_FOLDER

    Note: These are the examples of shared paths on Linux and Windows server. Ensure that you read and writer access to these shared paths in the environment so that BDM API upload can place the files temporally in this location.
    bdmserver.AXWebServicesUrl string For example, http://ax_test_server/ AppXtenderservices/ axservicesinterface.asmx
    bdmserver.AXWebAccessURL string For example, http://ax_test_server/ AppXtender/
    bdmserver.Username string For example, AXSUPERUSER
    bdmserver.Password encrypted text The password for the user
    bdmserver.AppName string B-S-ADMN
    bdmserver.BdmDataSource string For example, TESTDB
    bdmserver.restrictedFile_ext list [.exe,.zip,.xlsx]
    bdmserver.defaultFileSize integer 10
  6. Click the Configuration Value field that you want to change and update.
  7. Click Save.

Submit expressions of interest in Commonwealth Assistance

You can submit an expression of interest in Commonwealth Assistance for the various help types.

Procedure

  1. Access Banner Student Self-Service.
  2. Go to Banner () > Student > Student Records > Expression of Interest Commonwealth Assistance.
  3. In the New Expression of Interest in Commonwealth Assistance page, click New Expression of Interest.
  4. When the New Expression of Interest page displays, read the information, and select the program for which you want to submit this expression of interest in Commonwealth assistance.
  5. In the Select Commonwealth Assistance Type section, choose your desired help type that you want to request for from the following help type options available:
    • Commonwealth Support and HECS-HELP
    • FEE-HELP
    • OS-HELP
    • SA-HELP
    • VET Student Loan
  6. Click Continue.
  7. In the Commonwealth Assistance Interest page, provide information about your citizenship and residence status, including the type of evidence you have for that citizenship and residence status.
  8. Click the Attach Document link to identify, select, and upload your supporting PDF document from your local folder.
    After you attach your supporting document from your local folder, the page lists the identified document name as the selected file.
  9. Click Continue.
    The New Expression of Interest in Commonwealth Assistance page displays the summary of your current Expression of Interest in Commonwealth Assistance, and you can submit any new expressions of interest in Commonwealth assistance for which you may be eligible.

View current expression of interest in Commonwealth assistance

View your current expression of interest in Commonwealth assistance details.

Procedure

  1. Access Banner Student Self-Service.
  2. When the Student Records menu displays, click Expression of Interest in Commonwealth Assistance.
  3. In the New Expression of Interest in Commonwealth Assistance page, if desired, print a copy of the page for your records.

Select Commonwealth Assistance Type section

Use the Select Commonwealth Assistance Type section to select the type of Commonwealth assistance for the expression of interest.

Note: The Select Commonwealth Assistance Type section is a part of the New Expression of Interest page that appears if the student is eligible for Commonwealth assistance.

An eligibility function is used to determine which types of Commonwealth assistance are available for the student for their selected program. The eligibility function considers the student’s program, citizenship status, and residence status. For students applying for Commonwealth support and HECS-HELP, the eligibility function also considers the rate code attached to their curriculum. For students applying for OS-HELP, the eligibility function also verifies that the student has an appropriate cohort code.
