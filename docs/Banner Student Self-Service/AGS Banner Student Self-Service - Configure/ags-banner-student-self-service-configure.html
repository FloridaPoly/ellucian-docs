AGS overview

Banner Australian Government Statistics (AGS) delivers a solution for students to provide responses to Australian government statistical questions used in regulatory reporting. The processing functionality includes a Self-Service Web page that saves data in several Banner tables to support Australian regulatory reporting.

With AGS, you can provide a Self-Service Web page for students to submit responses to the Australian government statistical questions.

Prerequisites

The required releases for Banner AGS 9.21.0.2 are as follows:
  • Banner Student 8.25.2
  • Banner ASCGEN 8.16.3
  • Banner Student Self-Service 9.21.0.2 (Banner Australian Government Statistics 9.21.0.2 is available as a part of Banner Student Self-Service 9.21.0.2)

AGS Self-Service pages

Australian regulatory reporting requires institutions to gather data from students such as their demographic background, educational background, whether they have disabilities and reasons for studying their course.

Banner includes a Self-Service page to allow students to submit responses to these statistical questions. This chapter describes the Web page as delivered. These descriptions help you to extend the delivered page to meet your institution's needs.

AGS tasks

This chapter explains the tasks and procedures that you can perform using the Banner AGS Self-Service Web pages.

Set up AGS configuration

Configure and set up AGS using the Banner Applications Configurations (GUACONF) page.

Procedure

  1. Log in to the BannerAdmin application.
  2. Open the BannerApplications Configurations (GUACONF) page.
  3. Select Application ID > SSS to modify the Student Self Service application related configurations for Banner Australian Government Statistics.
  4. Select the Configuration window.
  5. To filter and search for the BDM configuration names, enter, for example government.statistics.apac%
    Configuration Name ConfigurationType Configuration Value
    government.statistics.​apac.course.information.​enabled boolean true

    By default, this configuration is set to true to display the Course Information section in the Australian Government Statistics page.

    You can set the configuration to false to hide the Course Information section.

    government.statistics.apac.​default.disability.service string The RQ value is available and you can change this to your preferred valid value from the Disability Service Validation page (STVSPSR). The value recorded here saves for each disability record when a student indicates that they have one or more disabilities and selects the I would like to receive advice and information on support services, equipment and facilities. check box.
  6. Click the ConfigurationValue field that you want to change and update.
  7. Click Save.

Set up AGS Information text

Configure and set up AGS information text using the Information Text Editor (GUAINFO) page.

Procedure

  1. Log in to the BannerAdmin application.
  2. Open the Information Text Editor (GUAINFO) page.
  3. To filter and search for the AGS information text, enter, for example GOVERNMENT_STATISTICS for the Page Name.
    Page Name Message Label Message
    GOVERNMENT_STATISTICS government.statistics.​info Check your Government Statistics and Disability Details and amend if necessary.
    GOVERNMENT_STATISTICS government.statistics.​citizenship.info <p>Once your citizenship status, Aboriginal and Torres Strait Islander status and country of birth have been saved, you will not be able to change them on this page. If the information in these fields is not correct, you will need to get a student services representative to change them for you.</p>
    GOVERNMENT_STATISTICS government.statistics.​institution.info <p>If your high school is not listed, please select "Unknown High School". If your tertiary institution is not listed, please select "Unknown Prior College".</p>
  4. Copy the record to Local and change the message.
  5. Click Save.

Submit responses to AGS

Submit responses for Australian Government statistical questions.

Procedure

  1. Access Banner Student Self-Service.
  2. Go to Banner () > Student > Student Records > Government Statistics.
  3. The data in the General Information section is display only and you cannot change on this page.
    Some of the questions will already have responses, depending on how much information was gathered from the student during admissions processing. You cannot change the responses to the first three questions in the Citizenship Resident Status Information section after you save the responses.
  4. Select or enter responses in each section.
  5. Click Save.
    The Government Statistics page refreshes your responses, and you can change some of the data if you want to make corrections and update.

AGS Web menu

The Student Records Menu contains the Government Statistics link option that you can use to answer Australian Government statistical questions.

The menu for the Government Statistics page is available in the BannerSelf-Service Menu Maintenance (GUASMNU) page. Navigate through the bmenu.P_StuMainMnu > bmenu.P_AdminMnu > governmentStatistics path to access this menu.

To know more about the common features available in Banner General Self-Service and about using the GUASMNU page, refer to the Banner General Self-Service Use content.

Web page fields

List of Web page fields and descriptions available in the Government Statistics page.

General Information section

List of fields available in the General Information section.

Item Description/source information

Updates to Banner

The General Information section of Government Statistics page is for display only purpose and does not update Banner.

Citizenship Resident Status Information section

List of fields available in the Citizenship Resident Status Information section. The fields are for display only purpose and you cannot edit or update in Self-Service.

Item Description/source information
What is your citizenship status this year? Descriptions from the STVCITZ page display for the student to select. After saving, the system stores this field value in the SPBPERS table.
Are you of Australian Aboriginal or Torres Strait Islander descent? Descriptions from the STVETHN page display for the student to select. After saving, the system stores this field value in the SPBPERS table.
What is your birth country? Descriptions from the STVNATN page display for the student to select. After saving, the system stores this field value in the GOBINTL table.
What year did you arrive in Australia? You can view this field only if the student selects a country other than Australia in the What is your birth country? field. After saving, the system stores this field value in the SKBENRL table
What language do you speak at home? Descriptions from the STVLANG page display for the student to select. After saving, the system stores this field value in the GOBINTL table.

Updates to Banner

System updates to Banner are as follows.
  • Saves the What is your citizenship resident status this year? and Are you of Australian Aboriginal or Torres Strait Islander descent? field replies in the SPBPERS table.
  • Saves the What is your birth country? and What language do you speak at home? field replies in the GOBINTL table.
  • Saves the What year did you arrive in Australia? field reply in the SKBENRL table.

Academic Information section

List of fields available in the Academic Information section.

Item Description/source information
Have you completed your final year of Secondary Education? If the student selects Yes, you can view the additional fields to record the high school and the last year of enrolment.

If the data already exists in the High School (SORHSCH) table with the graduation date populated, system selects the Yes option button, and displays the existing data.
What is your high school? Descriptions from the STVSBGI table for records where the Institution Type = H display for the student to select.

Ellucian recommends that you have a My school is not listed option in the STVSBGI table for a student to select when their school is not listed.

If the student selects Yes option button for the Have you completed your final year of Secondary Education? field question, the What is your high school? is a required input field.
Please specify year of your last enrolment If the student selects the Yes option button for the Have you completed your final year of Secondary Education? field question, the Please specify year of your last enrolment is a required input field.
What is the highest level of education you completed prior to this course? Descriptions from the STVDLEV page display for the student to select.

Each value corresponds to a DEFAULT-DEGC system parameter in the SKARSYS page. The system saves the value that is recorded for the corresponding system parameter in the Degree field of the SOAPCOL page.
What is your tertiary institution? Descriptions from the STVSBGI page for records where the Institution Type = C display for the student to select.

Ellucian recommends that you have a My institution is not listed option in STVSBGI for a student to select when their institution is not listed.

If the student selects a value for the What is the highest level of education you completed prior to this course? field question, the What is your tertiary institution? field question is a required input field.
Please specify year of your last enrolment. If the student selects a value for the What is the highest level of education you completed prior to this course? field question, the Please specify year of your last enrolment field question is a required input field.
What is the highest education level of your Parent/Guardian? Parent/Guardian 1 Descriptions from the Social Economic Identity Rules page for the PARENT1 Social Economic code display for the student to select.
Parent Guardian 2 Descriptions from the Social Economic Identity Rules page for the PARENT2 Social Economic code display for the student to select.

Updates to Banner

System updates to Banner are as follows.
  • Saves the What is your high school? and Please specify year of your last enrolment field replies in the SORHSCH table. The system saves the graduation date in the Graduation Date field, using the value that you enter in the Please specify year of your last enrolment field with 31 December to complete the date.
  • Saves the What is the highest level of education you completed prior to this course?, What is your tertiary institution?, and Please specify year of your last enrolment field replies for the high school in the SORPCOL and SORDEGR tables. The system saves the year in the Year field and the Degree field which is the value for system parameter that corresponds to the highest level of education that the student selects. For example, if the student selects Bachelor, this corresponds to level 07 in regulatory reporting, and the system saves the degree code value that the system records for the DEFAULT-DEGC-07 system parameter from the SKARSYS table in the Degree field.
  • Saves the What is the highest education level of your Parent/Guardian? field reply for each Parent/Guardian in the GORPSID table.

Disability Information section

List of fields available in the Disability Information section.

Item Description/source information
Do you have a disability? If the student selects Yes, the system displays the additional fields to record disability information.

If the data already exists in the Disability (SGRDISA) table where the effective to date is either blank or is later than the current system date, the system selects the Yes option button and displays the existing data.
Please check all disabilities that apply to you. Descriptions from the STVDISA table display a list of check boxes for the student to select.

If the student clears the check box for an existing disability, the system updates that record with an Effective To date while saving the page.
I would like to receive advice and information on support services, equipment and facilities. System saves the value from the GUACONF page in the Service Code field for each disability record when a student indicates that they have one or more disabilities and selects the I would like to receive advice and information on support services, equipment and facilities check box.

Updates to Banner

System updates to Banner are as follows.
  • Saves the data in the SGADISA table with the Effective From date of the current system date.
  • If the student clears the check box for an existing disability, the system updates that record with an Effective To date and saves the page.
  • Saves the value from the GUACONF page in the Service Code for each disability record when a student indicates that they have one or more disabilities and selects the I would like to receive advice and information on support services, equipment and facilities. check box.

Course Information section

Note: You can view this section only if you enable this section the GUACONF page.

List of fields available in the Course Information section.

Item Description/source information
Which describes your current employment status? Descriptions from the STVGAIN page display for the student to select a value.
The following questions display for each current, active study path.
Which best describes your main reason for undertaking this course/apprenticeship/traineeship? Descriptions from the STVCAPL page display for the student to select a value.

Updates to Banner

System updates to Banner are as follows.
  • Saves the Which describes your current employment status? field reply in the SGBSTDN table record for the effective term.
  • Saves the 'Which best describes your main reason for undertaking this course/apprenticeship/traineeship? and 'Will you be studying full-time or part-time? field replies in the SGRSTSP table for the study path and effective term, respectively.
