Configuration entries maintained on GUACONF

The majority of the Student Self-Service configurations can be maintained on the Banner Applications Configurations (GUACONF) page in Banner Admin.

For Student Self-Service, the configurations are associated with the SSS application ID.

Note: For MEP institutions, create the configuration entry in GUACONF page by replacing the all text with 'institution code' (in lowercase). You can create other configuration entries by prefixing the configuration with the 'institution code' (in uppercase), otherwise it will pick the same configuration for both the MEP codes. For example, if the configuration is banner.theme.cacheTimeOut, then you should prefix it with the institution MEP code like this: NORTH.banner.theme.cacheTimeOut (if the institution code is NORTH).
